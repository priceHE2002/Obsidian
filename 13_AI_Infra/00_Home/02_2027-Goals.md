# 2027 AI Infra Goals

## 北极星目标

到 2027 年春季，能用自己的代码和 benchmark 回答：

> **一个 LLM inference runtime 为什么慢？我如何从 scheduling、memory、kernel 三个层面定位并优化它？**

## 技术目标

- [ ] 能独立解释 LLM 的 Prefill / Decode execution path
- [ ] 能独立实现 autoregressive decoding loop
- [ ] 能实现 KV Cache
- [ ] 能实现 Request State Machine + Continuous Batching
- [ ] 能实现 block-based KV allocator + per-request block table
- [ ] 能实现 Prefix Cache
- [ ] 能写至少 2 个真实相关的 Triton kernel
- [ ] 能使用 Nsight Systems / Nsight Compute 找瓶颈
- [ ] 能产出 TTFT、TPOT、throughput、P50/P95、VRAM 的可复现实验
- [ ] 能与 HuggingFace / vLLM 做公平对比

## 求职目标

- [ ] 3 月底开始投 AI Infra 实习
- [ ] 至少完成 1 个主流 MLSys 开源项目的小型 PR
- [ ] 能完成 10 分钟 MiniServe 深度介绍
- [ ] 能完成 30–60 分钟项目深挖问答
