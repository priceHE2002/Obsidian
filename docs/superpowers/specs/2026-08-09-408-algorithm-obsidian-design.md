# 408 算法题单 Obsidian 化设计

## 目标

在保险库根目录创建 `数据结构/`，将现有 Excel 中的 47 道 LeetCode 训练题与 2017—2026 共 10 道 408 真题转换为 Obsidian 原生可查看、筛选和维护的刷题系统。

题目顺序必须保持：

> 母题模块 → 对应 LeetCode 训练题 → 对应 408 真题

不修改现有 Excel 文件，不依赖 Dataview 等第三方插件，只使用当前已经启用的 Obsidian Bases、Markdown、属性和内部链接。

## 文件结构

```text
数据结构/
├── 408算法刷题总览.md
├── 408算法刷题记录.base
├── 408算法母题索引.md
└── 题目/
    ├── 001_LC27_移除元素.md
    ├── 002_LC41_缺失的第一个正数.md
    ├── 003_LC121_买卖股票的最佳时机.md
    ├── 005_2018真题_最小未出现正整数.md
    ├── 056_LC75_颜色分类.md
    └── 057_LC164_最大间距.md
```

上图只展示代表性文件；其余题目使用同一规则生成。题目文件名使用三位顺序号，保证文件列表与训练顺序一致。真题文件使用“年份真题”作为编号部分，例如 `005_2018真题_最小未出现正整数.md`。

## 数据模型

每道题单独保存为 Markdown 笔记，以 YAML 属性作为 Bases 的数据源。字段如下：

| 属性 | 含义 |
|---|---|
| `order` | 全局训练顺序，1—57 |
| `mother_id` | 母题编号 M01—M12 |
| `mother` | 母题名称 |
| `chapter` | 408 大纲章节 |
| `source_type` | LeetCode 或 408真题 |
| `problem_id` | LC 题号或真题年份 |
| `priority` | S+、S、A、B |
| `time_limit` | 建议限时，单位为分钟 |
| `handwriting` | 必须、建议、否 |
| `goal` | 核心训练目标 |
| `status` | 未开始、学习中、已AC、已二刷、可纸笔 |
| `first_date`、`first_minutes`、`first_result` | 首刷记录 |
| `second_date`、`second_result` | 二刷记录 |
| `paper_date`、`paper_score` | 纸笔训练记录 |
| `error_type` | 主要错误类型 |
| `next_review`、`review_count` | 复习安排 |
| `mastery` | 掌握评分 1—5 |
| `weakness` | 错题和薄弱点 |
| `note` | 补充备注 |

每个题目正文提供“训练要求、思路记录、代码/伪代码、复杂度、错因复盘、再次手写”六个区域。真题正文额外提示：题目名称是训练摘要，正式作答以真题原卷的数据结构和函数接口为准。

## Bases 视图

`408算法刷题记录.base` 全局只读取 `数据结构/题目/` 中带有 `408/数据结构/刷题` 标签的 Markdown 笔记，并定义以下公式：

- `completion`：未开始 0%、学习中 25%、已AC 50%、已二刷 75%、可纸笔 100%。
- `status_icon`：以图标区分当前状态。
- `days_to_review`：计算距离下次复习的天数。
- `overdue`：下次复习日期已到且尚未达到“可纸笔”时显示提醒。

提供以下视图：

1. **全部题目**：按 `mother_id` 分组，显示顺序、来源、题号、优先级、状态和复习字段。
2. **母题路线**：按母题分组，突出“训练题 → 真题”的排列关系。
3. **408 真题**：仅显示 2017—2026 十道真题及纸笔得分。
4. **待复习**：显示已经设置复习日期且仍未达到“可纸笔”的题目。
5. **可纸笔**：显示已经达到最终掌握标准的题目。

完成率列使用 Average 汇总，纸笔得分使用 Average 汇总，复习次数使用 Sum 汇总。

## 总览与母题索引

`408算法刷题总览.md` 是入口笔记，包含：

- 使用方法和状态判定说明；
- 四轮复习节奏；
- 嵌入“全部题目”“408 真题”“待复习”三个 Bases 视图；
- 到母题索引和原始 Excel 的说明性链接位置。

`408算法母题索引.md` 列出 M01—M12 的核心思想、LeetCode 题号、对应真题年份、过关要求，并链接到总览。

## 兼容性与限制

- 使用 Obsidian 1.13.4 已启用的原生 Bases 功能。
- Markdown 文件在没有 Bases 的普通 Markdown 阅读器中仍能正常阅读，但自动筛选、分组和公式仅在 Obsidian 中生效。
- Obsidian 原生 Bases 不复刻 Excel 的图表外观；其功能等价物是分组表格、公式列和汇总行。
- 初始日期和得分保持为空，状态统一为“未开始”，复习次数为 0。

## 验证标准

完成后必须验证：

1. `数据结构/题目/` 恰好包含 57 个题目笔记；
2. 其中 LeetCode 47 道、408 真题 10 道；
3. 真题年份完整覆盖 2017—2026；
4. 全部笔记都具备必需属性，`order` 连续且无重复；
5. `.base` 文件是合法 YAML，所有视图引用的属性和公式均已定义；
6. Obsidian 能打开总览、Bases 和代表性题目笔记，无 YAML 或控制台错误；
7. 总览中的嵌入视图能够显示题目，并保持“母题 → 训练题 → 真题”的顺序。
