## 📋 真题题面

> [!info] 2025 年第 41 题 · 数组后缀最大乘积
> 综合题 · 13 分 · 考点：顺序表

设有两个长度均为 n 的一维整型数组 A 和 res，对数组 A 中的每个元素 A[i]，计算 A[i] 与 A[j]（0 ≤ i ≤ j ≤ n-1）乘积的最大值，并将其保存到 res[i] 中。

**示例**：若 A = {1, 4, -9, 6}，则得到 res = {6, 24, 81, 36}。

函数原型：
```c
void calMulMax(int A[], int res[], int n);
```

**要求**：
(1) 给出算法的基本设计思想。（4 分）
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（7 分）
(3) 说明你所设计算法的时间复杂度和空间复杂度。（2 分）

> [!tip]- 💡 思路提示（先自己思考再展开）
> 注意 A[i] 的正负性决定应乘以最大还是最小的后缀值；可维护后缀最大值与后缀最小值（负负得正），一趟从右往左扫描即可。
