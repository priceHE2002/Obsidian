## 📋 真题题面

> [!info] 2017 年第 41 题 · 表达式树转中缀表达式
> 综合题 · 15 分 · 考点：树与森林、中序遍历

请设计一个算法，将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。

**示例**：下列两棵表达式树作为算法输入时，输出的中缀表达式分别为 `(a+b)*(c*(-d))` 和 `(a*b)+(-(c-d))`。
- 表达式树 1：根为 `*`，左子树根 `+`（左叶 `a`、右叶 `b`），右子树根 `*`（左叶 `c`、右子树根 `-`，其右叶 `d`）
- 表达式树 2：根为 `+`，左子树根 `*`（左叶 `a`、右叶 `b`），右子树根 `-`（右子树根 `-`，其左叶 `c`、右叶 `d`）

> 注：单目运算符 -（取负）在树里以左子树为空、右子树为操作数表示。

二叉树结点的定义如下：
```c
typedef struct node {
    char data[10];   // 存储操作数或操作符
    struct node *left, *right;
} BTree;
```

**要求**：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。

> [!tip]- 💡 思路提示（先自己思考再展开）
> 中序遍历输出，但需根据结点类型与操作符优先级决定是否加括号：叶子结点直接输出；非叶子结点左右子树需加括号，单目负号单独处理（左子树为空）。
