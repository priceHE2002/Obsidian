## 📋 真题题面

> [!info] 2023 年第 41 题 · 邻接矩阵中寻找 K 顶点
> 综合题 · 10 分 · 考点：邻接矩阵、图基本概念

已知有向图 G 采用邻接矩阵存储，类型定义如下：

```c
typedef struct {                    // 图的类型定义
    int  numVertices, numEdges;     // 图中顶点数和有向边数
    char VerticesList[MAXV];        // 顶点表，MAXV 为已定义常量
    int  Edge[MAXV][MAXV];          // 邻接矩阵
} MGraph;
```

将图中**出度大于入度**的顶点称为 K 顶点。设计算法 `int printVertices(MGraph G)`：对给定任意非空有向图 G，输出 G 中所有 K 顶点，并返回 K 顶点的个数。

**要求**：
(1) 给出算法的设计思想。
(2) 根据算法思想，写出 C/C++ 描述，并注释。

> [!tip]- 💡 思路提示（先自己思考再展开）
> 扫描邻接矩阵：第 i 行和为出度，第 i 列和为入度；出度 > 入度即为 K 顶点。复杂度 O(n²)。注意有向图按行/列分别统计。
