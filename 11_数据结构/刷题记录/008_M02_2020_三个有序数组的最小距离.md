## 📋 真题题面

> [!info] 2020 年第 41 题 · 三个有序数组的最小距离
> 综合题 · 8 分 · 考点：顺序表

定义三元组 (a, b, c)（a, b, c 均为正数）的距离 D = |a - b| + |b - c| + |c - a|。给定 3 个非空整数集合 S₁, S₂, S₃，按升序分别存储在 3 个数组中。请设计一个尽可能高效的算法，计算并输出所有可能的三元组 (a, b, c)（a ∈ S₁, b ∈ S₂, c ∈ S₃）中的最小距离。

**示例**：S₁ = {-1, 0, 9}，S₂ = {-25, -10, 10, 11}，S₃ = {2, 9, 17, 30, 41}，则最小距离为 2，相应的三元组为 (9, 10, 9)。

**要求**：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
(3) 说明你所设计算法的时间复杂度和空间复杂度。

> [!tip]- 💡 思路提示（先自己思考再展开）
> 利用三个数组均升序的性质：每次移动当前三个指针中指向最小元素的那个指针，更新最小距离；证明移动不会遗漏更优解。复杂度 O(n₁+n₂+n₃)。
