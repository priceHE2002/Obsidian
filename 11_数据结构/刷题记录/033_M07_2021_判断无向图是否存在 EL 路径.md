## 📋 真题题面

> [!info] 2021 年第 41 题 · 判断无向图是否存在 EL 路径
> 综合题 · 5 分 · 考点：邻接矩阵、图基本概念

已知无向连通图 G 由顶点集 V 和边集 E 组成，|E| > 0，当 G 中度为奇数的顶点个数为不大于 2 的偶数时，G 存在包含所有边且长度为 |E| 的路径（称为 EL 路径）。设图 G 采用邻接矩阵存储，类型定义如下：

```c
typedef struct {                    // 图的定义
    int numVertices, numEdges;      // 图中实际的顶点数和边数
    char VerticesList[MAXV];        // 顶点表，MAXV 为已定义常量
    int Edge[MAXV][MAXV];           // 邻接矩阵
} MGraph;
```

请设计算法 `int IsExistEL(MGraph G)`，判断 G 是否存在 EL 路径，若存在则返回 1，否则返回 0。

**要求**：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
(3) 说明你所设计算法的时间复杂度和空间复杂度。

> [!tip]- 💡 思路提示（先自己思考再展开）
> EL 路径即欧拉路径（一笔画）。无向连通图存在欧拉路径 ⟺ 度为奇数的顶点数为 0 或 2。遍历邻接矩阵统计各顶点度数即可，注意遍历时避免重复计数。
