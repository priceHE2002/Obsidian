# 408 真题冲刺

> [!tip] 闭卷与纸笔
> 真题训练以闭卷作答和纸笔验证为准；优先补齐待校准证据与尚未达到可纸笔阶段的题目。

```dataview
TABLE 引用 AS 年份, 标题, 母题, 状态, 证据状态, 纸笔得分, 下次复习
FROM "11_数据结构/刷题记录"
WHERE 来源 = "408真题"
SORT choice(证据状态 = "待校准", 0, choice(状态 = "可纸笔", 2, 1)) ASC, 题号 ASC, 引用 ASC
```
