# 408 算法训练总览

> [!tip] 说明
> 所有统计均由 Dataview 自动读取「刷题记录」文件夹中的笔记属性；只需在每道题笔记顶部填写属性即可。左侧为总览，右侧列表为母题索引。

## 📈 核心指标

```dataviewjs
// 核心指标统计
const recs = dv.pages('"11_数据结构/刷题记录"')
  .where(p => p.题号)
  .sort(p => p.题号, 'asc');

const total = recs.length;
const statusCount = s => recs.where(p => p.状态 === s).length;
const 已AC = statusCount('已AC');
const 已二刷 = statusCount('已二刷');
const 可纸笔 = statusCount('可纸笔');
const 学习中 = statusCount('学习中');
const 未开始 = statusCount('未开始');
const done = 已AC + 已二刷 + 可纸笔; // 已 AC 及以上

const exams = recs.where(p => p.来源 === '408真题');
const examTotal = exams.length;
const examPen = exams.where(p => p.状态 === '可纸笔').length;

// 复习次数总和
const reviewSum = recs.reduce((a, p) => a + (parseInt(p.复习次数) || 0), 0);

// 到期未复习：下次复习日期 <= 今天 且 状态 != 可纸笔
const today = dv.date('today');
let due = 0;
recs.forEach(p => {
  const rd = p.下次复习;
  if (rd && dv.date(rd) <= today && p.状态 !== '可纸笔') due++;
});

// 总体完成率：平均每题的完成率（0/0.25/0.5/0.75/1）
const rateMap = {'未开始':0, '学习中':0.25, '已AC':0.5, '已二刷':0.75, '可纸笔':1};
let totalRate = recs.reduce((a, p) => a + (rateMap[p.状态] ?? 0), 0) / (total || 1);

dv.paragraph(
`### 核心指标

| 指标 | 数值 |
|---|---|
| **总任务** | **${total}** |
| 已 AC 及以上 | ${done} |
| 纸笔达标 | ${可纸笔} |
| **总体完成率** | **${(totalRate * 100).toFixed(1)}%** |
| 真题数量 | ${examTotal} |
| 真题纸笔达标 | ${examPen} |
| 到期未复习 | ${due} |
| 累计复习次数 | ${reviewSum} |`
);

// 状态分布
dv.paragraph(
`### 状态分布

| 状态 | 题数 | 占比 |
|---|---|---|
| 未开始 | ${未开始} | ${((未开始/total)*100).toFixed(1)}% |
| 学习中 | ${学习中} | ${((学习中/total)*100).toFixed(1)}% |
| 已 AC | ${已AC} | ${((已AC/total)*100).toFixed(1)}% |
| 已二刷 | ${已二刷} | ${((已二刷/total)*100).toFixed(1)}% |
| 可纸笔 | ${可纸笔} | ${((可纸笔/total)*100).toFixed(1)}% |`
);
```

## 📋 母题完成情况

```dataviewjs
const recs = dv.pages('"11_数据结构/刷题记录"').where(p => p.题号);
const rateMap = {'未开始':0, '学习中':0.25, '已AC':0.5, '已二刷':0.75, '可纸笔':1};

// 母题顺序（M01~M12）
const mods = [
  ['M01','数组原地操作与一次扫描'],['M02','有序数组双指针与多指针'],['M03','单链表原地操作'],
  ['M04','栈与队列按定义模拟'],['M05','二叉树遍历、递归与构造'],['M06','并查集与堆'],
  ['M07','图的存储、度与遍历'],['M08','最小生成树与最短路径'],['M09','拓扑排序与关键路径'],
  ['M10','折半、散列与字符串查找'],['M11','BST 与中序有序'],['M12','经典排序、归并与划分']
];

let rows = ['| 母题 | 模块 | 完成率 | 任务数 | 纸笔达标数 |'];
rows.push('|---|---|---|---|---|');
for (const [mid, name] of mods) {
  const items = recs.where(p => p.母题 === mid);
  const n = items.length;
  const pen = items.where(p => p.状态 === '可纸笔').length;
  const rate = n ? items.reduce((a, p) => a + (rateMap[p.状态] ?? 0), 0) / n : 0;
  const pct = (rate * 100).toFixed(0) + '%';
  rows.push(`| ${mid} | ${name} | **${pct}** | ${n} | ${pen} |`);
}
dv.paragraph(rows.join('\n'));
```
