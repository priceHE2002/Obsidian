## 状态口径

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 未完成 | 灰 `#9aa4b2` | 还没看（初始状态） |
| 已完成 | 绿 `#34d399` | 看完打卡 |

打卡时自动写入「完成日期」（当天）；取消打卡会清空日期。

## 三种打卡方式（任选）

1. **在总览里点状态点**：打开 `总览.md`，在底部课程清单里点每行两个圆点之一（灰=未完成，绿=已完成），进度环、KPI、专题进度条**实时联动**。
2. **打开单篇笔记点按钮**：进入某节课的笔记，顶部「⚡ 打卡」有未完成/已完成按钮，点一下即改。
3. **直接改 frontmatter**：在笔记开头把 `状态: "未完成"` 改成 `状态: "已完成"`（并可选填 `完成日期`）。修改后回到总览，Dataview 会自动刷新（约 1 秒）。

## 笔记 frontmatter 字段

```yaml
课程: "零壹每日一题"   # 所属专题（分组字段）
课程序: 1             # 专题排序序号
序号: 1               # 专题内排序序号
标题: "零壹408每日一题day1-氧气讲解版"
时长: "7:13"          # 视频时长
状态: "未完成"         # 未完成 | 已完成
完成日期: "2026-08-21" # 打卡后自动写入
```

## 在总览里能做什么

- **筛选**：顶部「专题筛选」「状态筛选」chips，可只看某个专题 / 只看未完成。
- **排序**：点表格表头（序 / 课程 / 标题 / 时长 / 状态 / 日期）切换升降序。
- **跳转**：点标题打开该节课笔记（新标签页；按 Ctrl/Cmd 点击则在当前页打开）。
