# 计算模型

在经典理论计算机科学中，真正激动人心的事情在 70 年代后就不再发生了；那之后的一切，都只是试图把渐近复杂度里的对数替换成比对数略小一点的东西。如果 50 年前这类算法还寄望于终有一天会有足够的算力来处理那些它们胜过渐近性更差但更实用的对手的大型数据集，那么如今我们已经知道，那一天永远不会到来。

这正是本书的主题：接受现实，并超越单纯的渐近复杂度，为你手头的硬件做优化。在这里你大概学不到任何一个渐近更快的算法，但你会学到如何从你所有那些非指数增长的晶体管中榨取性能，这是一项影响深远得多的技能。

计算机仍在变快，但方向与计算模型正交，我们需要创造新的模型。

为什么超越 Big O 去优化算法很重要。

本章的目标，是解释为何会如此，

它已变得重要得多。

这一模型在当时运作良好。如今计算机和程序执行环境要复杂得多。

在本章中，我们将探究这一现象发生的原因。

### 超越 Big O

情况就是如此。更多的计算机不是"高"，而是"宽"。

模型通常只"计费"（charge）一种类型的操作。

RAM 模型（random-access machines，随机存取机）

字 RAM 模型（Word RAM model）

外部存储模型（External memory model）

不同类型的并行 RAM 模型

通信复杂度（Communication complexity）

还有许多其他框架。有些从密码学或一般通信的角度出发。有些面向硬件设计者。有计数晶体管数量的"晶体管模型"（Transistor model），或基于物理熵定律的"能量模型"（energy model）。还有量子算法，甚至可能是人类执行的算法，在这种情形下你还需要关心错误。
