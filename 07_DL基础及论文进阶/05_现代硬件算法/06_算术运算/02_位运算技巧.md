# 位运算技巧

本文很大程度上基于 Sean Eron Anderson 所著的 [Bit Twiddling Hacks](https://graphics.stanford.edu/~seander/bithacks.html)。部分方法因已被硬件解决而被移除，另有一些方法被补充进来。其中大多数都已被编译器优化。

在提供 `cmov` 指令的体系结构上，其中大量内容已经过时。

这同时也作为一道练习题。

## 基本操作

`>>`

注意，算术右移对负数会移入 `1`，对正数则移入 `0`。（尽管这在某些实现中可能未定义？）

在 C/C++ 中，对负数进行左移或右移会触发未定义行为（undefined behavior）。

`<<`

`rol` 指令执行"循环左移"（rotate left）。

`__builtin_popcount` `popcnt` 返回 x 中 1 的个数（即置位位数）。

`__builtin_parity` 返回 x 的*奇偶性*（即 x 中 1 的位数对 2 取模的结果）。

这大概是用于 [错误检测](https://en.wikipedia.org/wiki/Parity_bit)。

`__builtin_clrsb` 返回 x 中前导冗余符号位的个数，即从最高有效位开始、与其相同的连续位数。对于 0 或其他取值没有特殊处理。

`__builtin_ffs` 返回 x 中最低有效 1 位的位置加一；若 x 为零，则返回零。

`__builtin_clz` 从最高有效位位置开始，返回 x 中前导 0 位的个数。若 x 为 0，则结果未定义。

`__builtin_ctz` 从最低有效位位置开始，返回 x 中末尾 0 位的个数。若 x 为 0，则结果未定义。

`ctz`、`clz` -> `__lg`

## 配方

### 整数的符号

`(x < 0)` 或 `x >> 31`

### 判断两个整数是否同号

`x ^ z < 0`

### 整数的绝对值

提取符号位：`int mask = x >> 31`。对于负数，该值为 `1`；对于正数，该值为 `0`。

将其与原始数字异或：`x ^ mask`（其效果等价于根据符号加上或减去 1）。

用第 2 步的结果减去 mask：`(x ^ mask) - mask`

或者，也可以使用 `(v + mask) ^ mask`，其效果相同但方向相反。

### 取最后一个 1 位

`x & -x`

### 移除整数的最后一个 1 位

`x & (x - 1)`

### 判断是否为 2 的幂

`(x & (x - 1)) == 0`

注意，0 也会被判定为 2 的幂。

### 反转比特位

Clang 提供了 `__builtin_bitreverse{8,16,32,64}`。

```c++
int reverseBits(int x)
{
	unsigned int s = sizeof(x) * 8;
	T mask = ~T(0);
	while ((s >>= 1) > 0)
	{
		mask ^= mask << s;
		x = ((x >> s) & mask) | ((x << s) & ~mask);
	}
	return x;
}
```

### 用异或交换两个数

你可能听说过这个技巧。

```c++
a ^= b;
b ^= a;
a ^= b;
```

但这并非底层真正的实现方式。底层有一条单独的 `xchg` 交换指令。

### 对 2 的幂取模

若 `m = (1 << k)`，则 `x % m` 等同于 `x & (m - 1)`。

## 掩码

掩码操作。

### 暴力枚举

你可以采用递归（显然很慢）。你也可以采用无分支（branchless）的方式。

背包问题有一个 $O(2^n)$ 的暴力解法。

```c++
int ans = 0;
for (int mask = 0; mask < (1 << n); mask++) {
    int s = 0;
    for (int i = 0; i < n; i++)
        if (mask >> i & 1)
            s += a[i];
    if (s <= C)
        ans = max(ans, s);
}
```

### 所有子集的子集

```c++
for (int submask = mask; submask != 0; submask = (submask - 1) & mask) {
    // ...
}
```

事实上，总数将为 $3^n$。每次迭代中，每一个比特位可能处于三种状态之一：不在 $m$ 中、尚不在 $s$ 中、同时处于 $s$ 和 $m$ 中。由于总共有 $n$ 个比特位，因此最多有 $3^n$ 种不同的组合。
