# 牛顿法

追求最高可能的精度，对于一个实用的算法而言很少是必需的。在真实世界的数据中，建模和测量误差通常比浮点数舍入带来的误差大好几个数量级，因此我们常常非常乐意选择一种以精度换取速度的大致方法。

在本节中，我们介绍此类近似数值算法中最重要的基石之一：*牛顿法*（Newton's method）。

## 牛顿法

牛顿法是一个简单却非常强大的算法，用于寻找实值函数的近似根，也就是如下通用方程的解：

$$
f(x) = 0
$$

关于函数 $f$ 唯一假设的是：至少存在一个根，且 $f(x)$ 在搜索区间上连续且可导。也有一些[无聊的边界情况](https://en.wikipedia.org/wiki/Newton%27s_method#Failure_analysis)，但它们在实践中几乎不会发生，因此我们将非正式地说该函数是"良好"的。

算法的核心思想是：从某个初始近似 $x_0$ 出发，然后迭代地改进它——在 $x = x_i$ 处作函数图像的切线，并将下一个近似 $x_{i+1}$ 设为该切线与 $x$ 轴交点的 $x$ 坐标。其直觉在于：如果函数 $f$ 是"[良好](https://en.wikipedia.org/wiki/Smoothness)"的，且 $x_i$ 已经足够接近根，那么 $x_{i+1}$ 会更接近。

![](img/newton.png)

为了得到 $x_n$ 的交点，我们需要令其切线函数等于零：

$$
0 = f(x_i) + (x_{i+1} - x_i) f'(x_i)
$$

由此我们导出

$$
x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}
$$

牛顿法非常重要：它是科学与工程领域广泛一类优化求解器的基础。

### 平方根

作为一个简单的例子，让我们推导求平方根问题的算法：

$$
x = \sqrt n \iff x^2 = n \iff f(x) = x^2 - n = 0
$$

如果我们将 $f(x) = x^2 - n$ 代入上面的通用公式，我们可以得到如下更新规则：

$$
x_{i+1} = x_i - \frac{x_i^2 - n}{2 x_i} = \frac{x_i + n / x_i}{2}
$$

在实践中，我们还希望在它足够接近正确答案时立即停止，这只需在每次迭代后简单检查即可：

```cpp
const double EPS = 1e-9;

double sqrt(double n) {
    double x = 1;
    while (abs(x * x - n) > eps)
        x = (x + n / x) / 2;
    return x;
}
```

该算法对许多函数都会收敛，尽管它可靠且有保证地收敛只针对其中某个子集（例如凸函数）。另一个问题是，如果发生收敛，收敛速度有多快。

### 收敛速率

让我们对求 $2$ 的平方根运行几次牛顿法迭代，从 $x_0 = 1$ 开始，并检查每次迭代后它得到了多少位正确的数字：

仔细观察，我们可以看到准确的数字位数在每次迭代中大约翻倍。这一惊人的收敛速率并非巧合。

为了定量地分析收敛速率，我们需要考虑第 $i$ 次迭代上的一个小相对误差 $\delta_i$，并确定在下一次迭代中误差 $\delta_{i+1}$ 缩小了多少：

$$
|\delta_i| = \frac{|x_n - x|}{x}
$$

我们可以将 $x_i$ 表达为 $x \cdot (1 + \delta_i)$。将其代入牛顿迭代公式，并在两边同除以 $x$，我们得到

$$
1 + \delta_{i+1} = \frac{1}{2} (1 + \delta_i + \frac{1}{1 + \delta_i}) = \frac{1}{2} (1 + \delta_i + 1 - \delta_i + \delta_i^2 + o(\delta_i^2)) = 1 + \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这里我们对 $(1 + \delta_i)^{-1}$ 在 $0$ 处进行了泰勒展开，用到了误差 $d_i$ 很小的假设（由于序列收敛，对于足够大的 $n$ 有 $d_i \ll 1$）。

整理出 $\delta_{i+1}$，我们得到

$$
\delta_{i+1} = \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这意味着一旦我们接近解，误差在每次迭代中大约平方（并减半）。由于对数 $(- \log_{10} \delta_i)$ 大致就是答案 $x_i$ 中正确有效数字的位数，相对误差的平方恰好对应于我们所观察到的有效数字位数的翻倍。

这被称为 *二次收敛*（quadratic convergence），事实上，它并不限于求平方根。详细证明留作练习，但可以证明，一般情况下有

$$
|\delta_{i+1}| = \frac{|f''(x_i)|}{2 \cdot |f'(x_n)|} \cdot \delta_i^2
$$

这在某些附加假设下（即 $f'(x)$ 不等于 $0$ 且 $f''(x)$ 连续）至少产生二次收敛。
