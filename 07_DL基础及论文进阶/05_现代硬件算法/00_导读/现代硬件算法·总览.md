# 现代硬件算法

这是一本即将问世的高性能计算著作，书名为《Algorithms for Modern Hardware》（现代硬件算法），作者为 [Sergey Slotin](http://sereja.me/)。

本书的目标读者涵盖从性能工程师、实用算法研究者，到刚修完高级算法课程、希望学到比"从 $O(n \log n)$ 优化到 $O(n \log \log n)$"更实用的方法来为程序提速的计算机科学本科生。

全书素材均 [托管于 GitHub](https://github.com/algorithmica-org/algorithmica)，相关代码则位于一个 [独立的代码仓库](https://github.com/sslotin/scmm-code)。这并非一个协作项目，但我们非常欢迎任何形式的贡献与反馈。

**在高校讲授性能工程。** 我写作本书的目标之一，是改变计算机科学——更准确地说，算法设计——在高校中的教学方式。容我细说。

支撑大多数计算机科学课程的有两本极具影响力的教材。两者无疑都十分杰出，但 [其中一本](https://en.wikipedia.org/wiki/The_Art_of_Computer_Programming) 已有 50 年历史，[另一本](https://en.wikipedia.org/wiki/Introduction_to_Algorithms) 也有 30 年历史，而自那时起 [[现代硬件.md|计算机已发生了巨大变化]]。渐近复杂度已不再是唯一的决定因素。在现代实用算法设计中，你会选择那种能更好利用硬件中各类并行性的方案，而非那种在星系级规模输入上理论运算次数更少的方案。

然而，大多数高校的计算机科学课程完全忽视了这一转变。尽管已有一些旨在纠正这一点的优秀课程——例如 MIT 的"[Performance Engineering of Software Systems](https://ocw.mit.edu/courses/electrical-engineering-and-computer-science/6-172-performance-engineering-of-software-systems-fall-2018/)"、Aalto 大学的"[Programming Parallel Computers](https://ppc.cs.aalto.fi/)"，以及一些非学术课程如 Denis Bakhvalov 的"[Performance Ninja](https://github.com/dendibakh/perf-ninja)"——但大多数计算机科学毕业生仍把现代硬件当成 1990 年代的东西来对待。

我真正想要实现的，是让性能工程在算法导论之后就开课讲授。撰写该主题的第一本综合性教材是其中的重要一环，这也正是我赶在夏天前完成它的原因——好让各高校能在下一个学年采用它。但创建一门新课所需远不止于此：你需要均衡的课程大纲、课程基础设施、讲义幻灯片、实验作业……因此，在完成主书之后的一段时间里，我将致力于为*讲授*性能工程而准备课程材料与工具——我也期待与同样希望将其变为现实的其他人合作。

### Part I: Performance Engineering

第一部分涵盖计算机体系结构基础与单线程算法的优化。

它循序渐进地讲解主要的 CPU 优化主题，如缓存、SIMD 与流水线，并给出简短的 C++ 示例，随后是大型案例研究，在这些研究中我们通常能相对于某些 STL 算法或数据结构取得显著的加速。

### Disclaimer: Technology Choices

本书示例使用 C++、GCC、x86-64、CUDA 与 Spark，但所传达的底层原理并不局限于这些技术。

为求心安，我并不满意其中任何一项选择：这些技术只是当下最为普及且稳定，因而对读者更有帮助。我本分别会选择 C / Rust / [Carbon?](https://github.com/carbon-language/carbon-lang)、LLVM、arm、OpenCL 与 Dask；或许会有第二版，在其中替换部分技术栈。
