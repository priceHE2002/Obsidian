# 扩展欧几里得算法

[[模运算.md#剩余|费马定理]] 使我们能够通过 [[快速幂.md|快速幂]] 在 $O(\log n)$ 次运算内计算模乘逆元，但它仅适用于素数模。它有一个推广，即 [欧拉定理](https://en.wikipedia.org/wiki/Euler%27s_theorem)（Euler's theorem）：若 $m$ 与 $a$ 互素，则

$$
a^{\phi(m)} \equiv 1 \pmod m
$$

其中 $\phi(m)$ 为 [欧拉函数](https://en.wikipedia.org/wiki/Euler%27s_totient_function)（Euler's totient function），定义为小于 $m$ 且与 $m$ 互素的正整数 $x$ 的个数。在 $m$ 为素数的特殊情况下，全部 $m - 1$ 个剩余都与其互素，从而 $\phi(m) = m - 1$，即为费马定理。

若已知 $\phi(m)$，我们可以用 $a^{\phi(m) - 1}$ 来计算 $a$ 的逆元，但反过来，计算它的速度并不快：通常你需要先求得 $m$ 的 [[整数分解.md]]。还有一种更通用的方法，它通过改造 [[二进制 GCD.md|欧几里得算法]] 来实现。

### 算法

*扩展欧几里得算法* 除了求 $g = \gcd(a, b)$ 外，还能找到满足下式的整数 $x$ 和 $y$：

$$
a \cdot x + b \cdot y = g
$$

若将 $b$ 替换为 $m$、$g$ 替换为 $1$，便可解决求模逆元的问题：

$$
a^{-1} \cdot a + k \cdot m = 1
$$

注意，若 $a$ 与 $m$ 不互素，则无解，因为 $a$ 与 $m$ 的任意整数线性组合都不可能得到它们最大公约数以外的数。

该算法也是递归的：它计算 $\gcd(b, a \bmod b)$ 的系数 $x'$ 和 $y'$，并由此还原出原始数对的解。若已有数对 $(b, a \bmod b)$ 的解 $(x', y')$

$$
b \cdot x' + (a \bmod b) \cdot y' = g
$$

那么，为得到初始输入的解，可将表达式 $(a \bmod b)$ 改写为 $(a - \lfloor \frac{a}{b} \rfloor \cdot b)$，代入前述方程：

$$
b \cdot x' + (a - \Big \lfloor \frac{a}{b} \Big \rfloor \cdot b) \cdot y' = g
$$

现在按 $a$ 和 $b$ 重新分组整理，得到

$$
a \cdot \underbrace{y'}_x + b \cdot \underbrace{(x' - \Big \lfloor \frac{a}{b} \Big \rfloor \cdot y')}_y = g
$$

将其与初始表达式比较，可知我们只需将 $a$ 与 $b$ 的系数直接作为初始的 $x$ 和 $y$ 即可。

### 实现

我们将算法实现为一个递归函数。由于其输出不是单个整数，而是三个整数，我们通过引用将系数传给它：

```c++
int gcd(int a, int b, int &x, int &y) {
    if (a == 0) {
        x = 0;
        y = 1;
        return b;
    }
    int x1, y1;
    int d = gcd(b % a, a, x1, y1);
    x = y1 - (b / a) * x1;
    y = x1;
    return d;
}
```

要计算逆元，我们只需传入 $a$ 和 $m$，并返回算法求得的 $x$ 系数。由于传入的是两个正数，其中一个系数为正、另一个为负（取决于迭代次数是奇数还是偶数），因此我们有时需要检查 $x$ 是否为负，若为负则加上 $m$ 以得到正确的剩余：

```c++
int inverse(int a) {
    int x, y;
    gcd(a, M, x, y);
    if (x < 0)
        x += M;
    return x;
}
```

它的运行时间约为 160ns——比用 [[快速幂.md|快速幂]] 求逆元快 10ns。要进一步优化，我们可以类似地将其改为迭代版本，耗时 135ns：

```c++
int inverse(int a) {
    int b = M, x = 1, y = 0;
    while (a != 1) {
        y -= b / a * x;
        b %= a;
        swap(a, b);
        swap(x, y);
    }
    return x < 0 ? x + M : x;
}
```

注意，与快速幂不同，其运行时间取决于 $a$ 的值。例如，对于特定的 $m$ 值（$10^9 + 7$），最坏输入恰好是 564400443，此时算法执行 37 次迭代，耗时 250ns。
