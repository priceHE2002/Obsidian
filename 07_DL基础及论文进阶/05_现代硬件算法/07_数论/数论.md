# 数论

1940 年，英国数学家 G. H. Hardy 发表了一篇著名的随笔《一个数学家的辩白》（A Mathematician's Apology），探讨这样一种观念：数学应当为其自身而追求，而非为了应用。

与数学类似，计算机科学的各个分支也构成了一个谱系，一端是数理逻辑与可计算性理论，另一端是 Web 编程与应用程序开发。我推测，作为读者的你更偏向应用一端：本书旨在说明，从事实用算法设计而非理论计算机科学的人实在太少了——而既然你已经读到了第 7 章，你大概也认同这一论断。

不过，无论个人观点如何，人们都能理解 Hardy 的立场。动笔之时他已 62 岁，亲历了第一次世界大战以及正在进行、且因科学的武器化而愈发惨烈的第二次世界大战所带来的破坏。作为一位数论学者，Hardy 在这样一个"无用"的领域中工作、无需面对任何道德困境，感到一丝宁静，他写道：

> 迄今为止，还没有人发现数论或相对论能服务于任何战争目的，而且在许多年内似乎也不太可能有人能做到这一点。

颇具讽刺意味的是，仅 5 年之后，这一论断就被证明大错特错：原子弹的研制离不开对相对论的理解，而计算机时代密码学的诞生则广泛建立在数论基础之上——数论的计算层面正是本章的主题。
