# 缓存无关算法

在[[外部存储模型.md|外部存储模型]]的语境下，高效算法有两类：

- *缓存感知*（cache-aware）算法：针对*已知*的 $B$ 与 $M$ 高效。
- *缓存无关*（cache-oblivious）算法：针对*任意*的 $B$ 与 $M$ 高效。

例如，[[外部排序.md|外部归并排序]]是一种缓存感知、但非缓存无关的算法：我们需要知道系统的内存特征，即可用内存与块大小的比值，才能找到进行 $k$ 路归并排序的正确 $k$。

缓存无关算法之所以有趣，是因为它们会自动对缓存层次中的所有内存层级都达到最优，而不仅仅是对它们专门调优的那一层。本文中，我们将考察它们在矩阵计算上的一些应用。

## 矩阵转置

假设我们有一个大小为 $N \times N$ 的方阵 $A$，需要对其进行转置。按定义的朴素做法大致如下：

```cpp
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
        swap(a[j * N + i], a[i * N + j]);
```

这里我们用一个指向内存区域起始位置的单一指针，而非二维数组，以便更清楚地展现其内存操作。

这段代码的 I/O 复杂度为 $O(N^2)$，因为写操作不是顺序的。如果你尝试交换迭代变量，情况会反过来，但结果是一样的。

### 算法

*缓存无关*算法依赖于如下的分块矩阵恒等式：

$$
\begin{pmatrix}
A & B \\
C & D
\end{pmatrix}^T=
\begin{pmatrix}
A^T & C^T \\
B^T & D^T
\end{pmatrix}
$$

它让我们能够用分治的方法递归求解：

1. 把输入矩阵分成 4 个较小的矩阵。
2. 对每个矩阵递归地转置。
3. 通过交换角落的结果矩阵来合并结果。

在矩阵上实现分治比在数组上略复杂一些，但核心思想是相同的。我们不想显式地复制子矩阵，而是想使用对它们的"视图"（views），并且在数据开始能放进 L1 缓存时切换到朴素方法（如果你事先不知道缓存大小，也可以选一个像 $32 \times 32$ 这样的小值）。我们还需要仔细处理 $n$ 为奇数、从而无法把矩阵均分为 4 个相等子矩阵的情况。

```cpp
void transpose(int *a, int n, int N) {
    if (n <= 32) {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < i; j++)
                swap(a[i * N + j], a[j * N + i]);
    } else {
        int k = n / 2;

        transpose(a, k, N);
        transpose(a + k, k, N);
        transpose(a + k * N, k, N);
        transpose(a + k * N + k, k, N);
        
        for (int i = 0; i < k; i++)
            for (int j = 0; j < k; j++)
                swap(a[i * N + (j + k)], a[(i + k) * N + j]);
        
        if (n & 1)
            for (int i = 0; i < n - 1; i++)
                swap(a[i * N + n - 1], a[(n - 1) * N + i]);
    }
}
```

该算法的 I/O 复杂度为 $O(\frac{N^2}{B})$，因为在每一归并阶段我们只需要触及大约一半的内存块，这意味着每个阶段我们的问题都在缩小。

把这段代码推广到非方阵的一般情形，留作读者的练习。

## 矩阵乘法

接下来，考虑稍微复杂一些的东西：矩阵乘法。

$$
C_{ij} = \sum_k A_{ik} B_{kj}
$$

朴素算法只是把定义直接翻译成代码：

```cpp
// don't forget to initialize c[][] with zeroes
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        for (int k = 0; k < n; k++)
            c[i * n + j] += a[i * n + k] * b[k * n + j];
```

由于每次标量乘法都需要单独读取一个块，它总共需要访问 $O(N^3)$ 个块。

一个众所周知的优化是先对 $B$ 做转置：

```cpp
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
        swap(b[j][i], b[i][j])
// ^ or use our faster transpose from before

for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        for (int k = 0; k < n; k++)
            c[i * n + j] += a[i * n + k] * b[j * n + k]; // <- note the indices
```

无论转置是用朴素方法还是用我们此前开发的缓存无关方法完成，其中一个矩阵被转置后的矩阵乘法都会以 $O(N^3/B + N^2)$ 工作，因为此时所有内存访问都是顺序的。

看起来我们似乎无法做得更好，但事实表明我们可以。

### 算法

缓存无关矩阵乘法依赖于与转置本质上相同的技巧。我们需要把数据切分到能放进最低层缓存（即 $N^2 \leq M$）为止。对于矩阵乘法，这等价于使用如下公式：

$$
\begin{pmatrix}
A_{11} & A_{12} \\
A_{21} & A_{22} \\
\end{pmatrix} \begin{pmatrix}
B_{11} & B_{12} \\
B_{21} & B_{22} \\
\end{pmatrix} = \begin{pmatrix}
A_{11} B_{11} + A_{12} B_{21} & A_{11} B_{12} + A_{12} B_{22}\\
A_{21} B_{11} + A_{22} B_{21} & A_{21} B_{12} + A_{22} B_{22}\\
\end{pmatrix}
$$

不过它实现起来稍难一些，因为现在我们总共有 8 次递归矩阵乘法：

```cpp
void matmul(const float *a, const float *b, float *c, int n, int N) {
    if (n <= 32) {
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                for (int k = 0; k < n; k++)
                    c[i * N + j] += a[i * N + k] * b[k * N + j];
    } else {
        int k = n / 2;

        // c11 = a11 b11 + a12 b21
        matmul(a,     b,         c, k, N);
        matmul(a + k, b + k * N, c, k, N);
        
        // c12 = a11 b12 + a12 b22
        matmul(a,     b + k,         c + k, k, N);
        matmul(a + k, b + k * N + k, c + k, k, N);
        
        // c21 = a21 b11 + a22 b21
        matmul(a + k * N,     b,         c + k * N, k, N);
        matmul(a + k * N + k, b + k * N, c + k * N, k, N);
        
        // c22 = a21 b12 + a22 b22
        mul(a + k * N,     b + k,         c + k * N + k, k, N);
        mul(a + k * N + k, b + k * N + k, c + k * N + k, k, N);

        if (n & 1) {
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    for (int k = (i < n - 1 && j < n - 1) ? n - 1 : 0; k < n; k++)
                        c[i * N + j] += a[i * N + k] * b[k * N + j];
        }
    }
}
```

由于这里还有很多其他因素在起作用，我们不打算对这套实现做基准测试，而是直接在外部存储模型下做理论性能分析。

### 分析

该算法的算术复杂度保持不变，因为递推式

$$
T(N) = 8 \cdot T(N/2) + \Theta(N^2)
$$

的解为 $T(N) = \Theta(N^3)$。

我们似乎还没有"征服"任何东西，但让我们思考一下它的 I/O 复杂度：

$$
T(N) = \begin{cases}
O(\frac{N^2}{B}) & N \leq \sqrt M & \text{(we only need to read it)} \\
8 \cdot T(N/2) + O(\frac{N^2}{B}) & \text{otherwise}
\end{cases}
$$

该递推由 $O((\frac{N}{\sqrt M})^3)$ 个基例主导，意味着总复杂度为

$$
T(N) = O\left(\frac{(\sqrt{M})^2}{B} \cdot \left(\frac{N}{\sqrt M}\right)^3\right) = O\left(\frac{N^3}{B\sqrt{M}}\right)
$$

这比单纯的 $O(\frac{N^3}{B})$ 要好，而且好不少。

### Strassen 算法

与 Karatsuba 算法精神相似，矩阵乘法可以被分解为涉及 7 次大小为 $\frac{n}{2}$ 的矩阵乘法的形式，而主定理告诉我们，这样的分治算法将以 $O(n^{\log_2 7}) \approx O(n^{2.81})$ 时间工作，在外部存储模型中也有类似的渐近界。

这项被称为 Strassen 算法的技术，同样把每个矩阵分成 4 份：

$$
\begin{pmatrix}
C_{11} & C_{12} \\
C_{21} & C_{22} \\
\end{pmatrix}
=\begin{pmatrix}
A_{11} & A_{12} \\
A_{21} & A_{22} \\
\end{pmatrix}
\begin{pmatrix}
B_{11} & B_{12} \\
B_{21} & B_{22} \\
\end{pmatrix}
$$

但随后它计算 $\frac{N}{2} \times \frac{N}{2}$ 矩阵的中间乘积，并将它们组合得到矩阵 $C$：

$$
\begin{aligned}
   M_1 &= (A_{11} + A_{22})(B_{11} + B_{22})   & C_{11} &= M_1 + M_4 - M_5 + M_7
\\ M_2 &= (A_{21} + A_{22}) B_{11}             & C_{12} &= M_3 + M_5
\\ M_3 &= A_{11} (B_{21} - B_{22})             & C_{21} &= M_2 + M_4
\\ M_4 &= A_{22} (B_{21} - B_{11})             & C_{22} &= M_1 - M_2 + M_3 + M_6
\\ M_5 &= (A_{11} + A_{12}) B_{22}
\\ M_6 &= (A_{21} - A_{11}) (B_{11} + B_{12})
\\ M_7 &= (A_{12} - A_{22}) (B_{21} + B_{22})
\end{aligned}
$$

如果你愿意，可以用简单的代入来验证这些公式。

据我所知，主流的优化线性代数库都没有使用 Strassen 算法，尽管存在一些[原型实现](https://arxiv.org/pdf/1605.01078.pdf)，它们在矩阵大于约 2000 时效率较高。

这项技术实际上已经被多次扩展，通过考虑更多子矩阵乘积来进一步降低渐近界。截至 2020 年，当前世界纪录是 $O(n^{2.3728596})$。能否以 $O(n^2)$ 或至少 $O(n^2 \log^k n)$ 的时间做矩阵乘法，仍是一个开放问题。
