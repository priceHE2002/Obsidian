# 循环与条件分支

考虑一个稍微复杂点的例子：

```nasm
loop:
    add  edx, DWORD PTR [rax]
    add  rax, 4
    cmp  rax, rcx
    jne  loop
```

它计算一个 32 位整数数组的和，正如一个简单的 `for` 循环那样。

循环的「主体」是 `add edx, DWORD PTR [rax]`：这条指令从迭代器 `rax` 处加载数据，并把它加到累加器 `edx`。接着，我们用 `add rax, 4` 把迭代器向前移动 4 个字节。然后发生了一件稍微复杂些的事。

### 跳转

汇编没有 if、for、函数或其他高级语言拥有的控制流结构。它所拥有的是 `goto`，或者在底层编程世界里被称为「跳转」（jump）。

**跳转**（Jump）把指令指针移动到由其操作数指定的位置。这个位置可以是一个内存中的绝对地址、相对于当前地址的偏移，甚至可以是 [[间接跳转.md|运行时计算]] 的。为了避免直接管理这些地址的麻烦，你可以用一个字符串后跟 `:` 来标记任意指令，然后把这个字符串当作标号（label）使用，在转换成机器码时它会被替换为该指令的相对地址。

标号可以是任意字符串，但编译器并不富于创意，[通常](https://godbolt.org/z/T45x8GKa5) 在给标号取名时只是用源代码中的行号以及带函数签名的函数名。

**无条件**跳转 `jmp` 只能用来实现 `while (true)` 这类循环，或把程序的各部分缝合在一起。一系列 **条件** 跳转用于实现真正的控制流。

你大概会认为这些条件是作为 `bool` 在某个地方计算出来、并作为操作数传给条件跳转的：毕竟在编程语言中就是这么做的。但在硬件上并非如此实现。条件操作使用一个特殊的 `FLAGS` 寄存器，它首先需要由执行某种检查指令来填充。

在我们的例子中，`cmp rax, rcx` 把迭代器 `rax` 与数组末尾指针 `rcx` 作比较。这会更新 `FLAGS` 寄存器，现在它就能被 `jne loop` 使用：`jne` 查寻其中的某一位，判断两个值是否相等，然后要么跳回开头，要么继续到下一条指令，从而退出循环。

### 循环展开

你或许已经注意到上面这个循环的一点是：处理单个元素的开销很大。在每个周期里，只有一条有用的指令被执行，其余 3 条都在递增迭代器并尝试弄清楚我们是否已完成。

我们能做的是通过把多次迭代归并在一起来*展开*（unroll）循环——等价于在 C 中写成这样：

```c++
for (int i = 0; i < n; i += 4) {
    s += a[i];
    s += a[i + 1];
    s += a[i + 2];
    s += a[i + 3];
}
```

在汇编中，它会大致长这样：

```nasm
loop:
    add  edx, [rax]
    add  edx, [rax+4]
    add  edx, [rax+8]
    add  edx, [rax+12]
    add  rax, 16
    cmp  rax, rsi
    jne  loop
```

现在我们只需要 3 条循环控制指令对应 4 条有用指令（就效率而言，从 $\frac{1}{4}$ 提升到 $\frac{4}{7}$），而且还可以继续下去，把开销降到几乎为零。

在实践中，展开循环并不总是性能所必需，因为现代处理器实际上并不是逐条执行指令，而是维护一个 [[指令级并行.md|待执行指令队列]]，使得两个独立操作可以并发执行而不必互相等待。

我们的情况也是如此：展开带来的真正加速不会达到四倍，因为递增计数器和检查是否完成的操作与循环主体相互独立，可以被调度为与它并发运行。但仍然可能值得 [[情境化优化.md|请编译器]] 在一定程度上展开它。

### 另一种思路

你不必显式地使用 `cmp` 或类似指令来制造条件跳转。许多其他指令会读取或修改 `FLAGS` 寄存器，有时是作为附带产生可选异常检查的副作用。

例如，`add` 总是会设置若干标志，表示结果是否为零、是否为负、是否发生上溢或下溢，等等。利用这一机制，编译器经常生成这样的循环：

```nasm
    mov  rax, -100  ; replace 100 with the array size
loop:
    add  edx, DWORD PTR [rax + 100 + rcx]
    add  rax, 4
    jnz  loop       ; checks if the result is zero
```

这段代码对人类来说稍难阅读，但它在重复部分少了一条指令，而这可能对性能产生实质影响。
