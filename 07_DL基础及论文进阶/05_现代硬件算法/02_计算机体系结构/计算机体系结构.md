# 计算机体系结构

当我开始自学如何优化程序时，我犯下的一个大错就是主要依赖经验主义的方法。由于不理解计算机真正的工作原理，我会半随机地交换嵌套循环、重排算术运算、合并分支条件、手工内联函数，并照搬从别人那里听来的各种性能技巧，盲目地寄希望于性能提升。

不幸的是，这就是大多数程序员进行优化的方式。大多数关于性能的论述并不教你从定性角度去推理软件性能，而是给出关于某些实现方式的一般性建议——而笼统的性能直觉显然是不够的。

如果我在进行算法编程*之前*先学习了计算机体系结构，大概能省下几十乃至上百个小时。因此，即便大多数人对它并不*热衷*，我们仍将在最开头几章研究 CPU 的工作原理，并从学习汇编语言开始。
