# 事件驱动并发

你或许在 JavaScript 中见过它。这类语言都有一个不断运转的事件循环（event loop）。它们也使用单线程，因为几乎每个阻塞操作本质上都是 I/O。

```js
var callback = function() {
    console.log("Button clicked")
}

document.getElementById('someButton').addEventListener("click", callback)
```

事件驱动的环境通常是单线程的，并通过对请求进行"分片（sharding）"来实现多线程效果。

## Actor 模型（Actor Model）

一种更为通用的做法被称为 *actor 模型*。

它在 JVM 世界中非常流行。

```scala
import akka.actor.Actor
import akka.actor.ActorSystem
import akka.actor.Props

class HelloActor extends Actor {
  def receive = {
    case "hello" => println("hello back at you")
    case _       => println("huh?")
  }
}

object Main extends App {
  val system = ActorSystem("HelloSystem")
  // default Actor constructor
  val helloActor = system.actorOf(Props[HelloActor], name = "helloactor")
  helloActor ! "hello"
  helloActor ! "buenos dias"
}
```

使用消息代理（message broker）的一个非常重要的好处是，你可以将通信解耦，并且还能把 actor 迁移到另一台网络节点上，从而支持分布式计算。
