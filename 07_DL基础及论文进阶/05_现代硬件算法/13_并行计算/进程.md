# 进程

当你需要的时候，它表现良好。

`fork` 系统调用用于创建一个新进程，称为子进程（child process），它与发起 `fork()` 调用的进程（父进程，parent process）并发运行。新子进程创建之后，两个进程都会执行 `fork()` 系统调用之后的那条指令。子进程使用与父进程相同的程序计数器（pc，program counter）、相同的 CPU 寄存器，以及相同的已打开文件。

它不接收任何参数，并返回一个整数值。下面是 `fork()` 返回的不同取值。

```cpp
#include <stdio.h> 
#include <sys/types.h> 
#include <unistd.h> 
int main() { 
    // make two process which run same 
    // program after this instruction 
    fork(); 
  
    printf("Hello world!\n"); 
    return 0; 
} 
```

主要缺点是额外的开销。它受操作系统管理。当你需要这种粒度时，会使用相互独立的进程。

分叉出来的进程既看不到、也无法修改彼此的内存空间。
