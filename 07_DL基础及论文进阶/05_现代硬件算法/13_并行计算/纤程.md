# 纤程

*纤程（fibers）*是由语言自身实现的轻量级线程。它们的工作方式是：当一个纤程暂停时，语言运行时会接管并从上次离开的地方拾起另一个纤程。因此，语言必须维护属于自己的运行时（runtime）。

```go
package main

import (
	"fmt"
	"time"
)

func say(s string) {
	for i := 0; i < 5; i++ {
		time.Sleep(100 * time.Millisecond)
		fmt.Println(s)
	}
}

func main() {
	go say("world")
	say("hello")
}
```

它们的工作方式是：语言维护一组线程，随时可以从它们上次离开的位置接管执行。这被称为 N:M 调度。

其他语言也存在类似的运行时，例如用于 C++ 和 Rust 的运行时。
