# 同步原语

考虑下面这个循环：

```cpp
int s = 0;

for (int i = 0; i < n; i++) {
    s += a[i];
}
```

我们可以这样把它并行化：

```cpp
int s = 0;

#pragma omp parallel for
for (int i = 0; i < n; i++) {
    s += a[i];
}
```

这段代码使用了 OpenMP，下一章将予以介绍。你现在只需知道：它会生成若干线程，并把工作均匀地分配在它们之间。你也可以用 C++ 的线程写出一个等价的函数。
