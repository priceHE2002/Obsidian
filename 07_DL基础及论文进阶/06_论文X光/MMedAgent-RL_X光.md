# MMedAgent-RL_X光

**MMedAgent-RL: Optimizing Multi-Agent Collaboration for Multimodal Medical Reasoning**
*Peng Xia, Jinglu Wang et al.（UNC / Microsoft Research / CMU） | ICLR 2026 | arXiv 2506.00555*

## 论文说了什么

**问题**：让一堆 AI 模型模拟"看病"这件事——先分诊、再请专科医生会诊、最后由主治医师拍板——早有人做了。但会诊意见不可靠：专科医生有时全对，有时互相打架，有时**整齐地一起错**。之前的工作都卡在这一步：流程是写死的，主治医师没有学过怎么听意见，只能盲目采纳或者盲目多数投票。

**视角**：作者不去改流程，只训练"拍板的那个人"。整个流水线是：Qwen2.5-VL 当分诊医生（用 GRPO 训），然后把病例交给一批冻结的商用模型当专科医生（o3 / GPT-4o / HuatuoGPT-Vision / Qwen2.5-VL 轮着扮），最后 Qwen2.5-VL 当主治医师（也用 GRPO 训）。

关键在那根**熵旋钮**上。想象你在陌生城市找一家店，朋友给了三个地址，全指向同一个地方。你有两个选择：直接走过去，或者先在地图上扫一眼周边。如果朋友全对，直接走最省事；可万一那家店搬过、三个人一起记错了呢——**地址越是一致，你越危险**。而"允许自己多看几条路"这件事，在模型里就是一个旋钮：生成下一个词时，是几乎确定地选一个，还是给几个候选都留点机会——这就是策略熵。

本文做的事就是：**按"专科医生答得对不对"给病例分三档，每档配不同的旋钮松紧**。医生全对的病例，旋钮拧死（不许探索，老实采纳）；医生答一半的，旋钮松一点（两边都留）；医生**全错的**那档，旋钮拧到最大——逼它别跟着大伙儿走，自己重查。形式上就是标准的 GRPO 损失加一项按档位取值的熵奖励 $\gamma_s \cdot H_t$，其中 $\gamma_{\text{easy}} \approx 0$，$\gamma_{\text{medium}} > 0$，$\gamma_{\text{hard}} \gg \gamma_{\text{medium}}$。三档依次训，是个课程。

论文自己强调了这一点的**新意**："与以往按问题表述或数据领域定义难度的课程学习不同，我们按专科医生诊断的准确率来分类任务。"——换了一根排序轴。

**结果**：

- 实验证明：五个医学 VQA 数据集（3 个同分布 VQA-RAD / SLAKE / PathVQA，2 个分布外 OmniMedVQA / MMMU-Med），**同分布平均 73.3%，分布外平均 72.6%**。作为对照，单智能体里最强的 GPT-4o 平均 68.6%。论文报的相对提升是：超过底座 Qwen2.5-VL-7B **21%**、超过 SFT **23.6%**，超过 MedAgents / MDAgents / AFlow 分别 23% / 19% / 17%。
- 实验证明：再叠一个多数投票的测试时扩展，同分布平均从 73.3 涨到 **76.1**，分布外从 72.6 涨到 **76.6**（论文记为 +4.5%）。
- 实验证明：消融的分量排序很清楚——分诊模块 **+3%**，会诊机制 **+4.5%**，C-MARL **+18.6%**。去掉 C-MARL 后 MMMU-Med 从 71.9 掉到 50.2，**掉 21.7 个点**，是全部消融里最大的一处。
- 实验证明：按测试集难度分层后，**"专家集体错"（Hard）这一档增益最大**，整体 +20%。作者认为这正是在"误导性共识"上有效。
- 作者推测：这种结构化推理"展现了更像人类科学 AI 系统的潜力"。作者也主动承认，模型并**没有**出现人类那种"aha moment"。

理论部分给了一个（非正式的）定理 4.1：课程学习的收敛优于标准 SGD，理由是每一档之间的最优参数距离小，前一档的解可以当后一档的 warm start；反过来，标准 SGD 在这些条件下**无法收敛到最优策略**。

**一句话**：这篇论文是说——当一帮会整齐出错的人给你出主意时，别只是听或者投票，而是把他们的意见按"错得有多离谱"分三档，从全对的那些开始教你怎么听，最后专门练他们全错的那一档。

```
  专科医生们(冻结,只提供意见)          主治医师(只训这一个)
        |                                    |
        |   会诊意见 y_d                     |
        +----------------------------------> |
                                             |
                     按 y_d 答对程度 s 分三档
                                             |
        +------------------------------------+------------------------------------+
        |                                    |                                    |
      s = 1                              0 < s < 1                              s = 0
     全体答对                             意见打架                             全体答错
        |                                    |                                    |
     γ ≈ 0                                γ 中等                               γ 很大
  "别乱想,听他的"                      "两边都看看"                       "别听,自己查"
        |                                    |                                    |
        +------------------------------------+------------------------------------+
                                             |
                                       三档依次训练
                                             |
                                             v
                              学会 什么时候信 / 什么时候抗
```

## 对我意味着什么

**可能改变我的**：我给 shadow bundle 分层用的是"预测效用"这根轴，本文让我看到该叠加另一根——**"便宜先验错得有多离谱"**。先验自信地错的地方，才是反事实验证最该砸算力的地方。

### 换一根排序轴

本文最实在的贡献不是那个熵奖励，而是它把课程学习排序的依据从"题目属性"换成了"信号可靠性"。这两根轴排的是同一批数据点，但含义完全不同：难度是题目自己的属性，和你请谁帮忙无关；可靠度是"给建议的那个人"和"这道题"之间的关系。

```
  同一批样本,两种排课轴

  轴一: 按"题有多难"  (前人一直在用的)
     易 ----------> 中 ----------> 难

  轴二: 按"老师错得多离谱"  (本文换的轴)
     全对 ---------> 半对 ---------> 全错
       |              |              |
     不许探索       稍微探索       往死里探索
     (听他的)       (两头看)       (它越一致越可疑)

  同样一批数据点,只换排序依据
  |
  +-- 难度 = 题目自己的属性,和谁在帮你无关
  +-- 可靠度 = "给建议的人"和"题"的关系
```

我在 CounterStruct v2.1 里已经有一根便宜的解析先验（§12），也给 shadow bundle 做了分层（§14.1 "Bundle stratification"）。但分层依据是**预测效用**——先验觉得哪个动作好，就在哪个动作周围多撒反事实分支。本文那根轴建议的是相反方向的分配：**先验越自信地"错"，越值得花钱去验**。前者是"哪里可能有大收益"，后者是"哪里最可能被骗"。这两种预算分配在有限算力下是竞争关系，而我此前只考虑了前一种。

> 别按题排课，按"给建议的人有多不可靠"排课。

### 一致不是证据

"误导性共识"这个说法值得单独记住。它的要点不是"专家会错"——那太显然了——而是**整体一致恰恰是最危险的那种错**。本文的 Hard 档定义得很准："专科医生一致地给出错误建议，制造出一个误导性共识"。

```
  我原来的映射:
    专家分歧度 -----------------> 我的信心
        高      中      低(一致)
        低 ------> 中 ------> 高        单调上升

  实际情况:
    专家分歧度 -----------------> 我的信心
        高      中      低(一致)
        低 ------> 中 ------> 高
                              \
                               \___ 断崖
                                     ^
                          危险区不是"分歧"
                          是"一致,且来源不独立"

  决策改变:
    分歧时 -> 花预算去验证
    一致时 -> 先问一句"你们是各自得出,还是互相抄的"
```

这对我是个直接可用的检查项。我方案里的 global prior 和 task-local residual，本质上就是两个不同来源的"意见"，而 merge-after-write 时序封死的是**泄漏**，封不住**相关性**——如果两者共享同一批 shadow 数据得出，它们的一致并不构成独立确认。同理，多 seed 一致也不等于独立，除非 seed 之间的数据顺序真的独立。

> 一致只在来源独立时才算证据——否则它只是相关性的伪装。

### 开放问题

论文把两件事捆在一个叫 C-MARL 的名字下一起卖：**(a) 按可靠度分档的顺序**，和 **(b) 按分档调整的熵奖励**。消融表只给了累加式的答案（w/o C-MARL -> +Easy -> +Medium -> +Hard），"同数据、换顺序、固定熵"和"同顺序、固定熵"这两个对照都没有。

```
  论文把两个东西绑在一起:
     (a) 按可靠度分档的 顺序
     (b) 按分档调的 熵奖励
              |
              +----------+----------+
              |                     |
       它们是同一件事?        还是可拆的两件事?
              |                     |
        +-----+-----+         +-----+-----+
        | 只换顺序  |         | 只换熵    |
        | 熵固定    |         | 顺序打乱  |
        +-----------+         +-----------+
              |                     |
          没做过的对照        没做过的对照

   如果"只换顺序"就够 -> 核心是排课
   如果"只换熵"也够   -> 核心是允许探索
   两个都不够         -> 18.6 点里有多少只是"多训了 RL"?
```

还有一个细节值得记下来：SLAKE 在"加到 Medium 档"时是 76.9，加完 Hard 档反而掉到 76.2。完整模型并非每一列都是最优——这说明课程的后半段也有代价，只是被平均分盖住了。

**所以真正该问的是：如果"打乱顺序 + 固定熵"能复现那 18.6 点里的大部分，那这篇论文卖的是排课，还是探索？你会怎么设计这两个对照，让它一次实验就分开？**
