# OnlyAct_X光

**OnlyAct: Extracting Action Representations from Foundation Models for World Models**
*Runjia Li, Minghao Chen, Junyu Xie, Philip Torr, Andrea Vedaldi, Tomas Jakab | arXiv 2611.14420*

## 论文说了什么

**问题**：视频世界模型的训练被动作监督卡住。动作标签稀缺、分散在互不兼容的规格里，而且永远不会随无标注视频语料一起长大。业界的绕法是联合训练一个编码器（把连续两帧压成 latent action）和一个解码器（用「前一帧 + latent」重建下一帧），逼 latent 只带新信息。这条路有两个结构性问题：从零学动作空间会限制对未见域的泛化；瓶颈的松紧是在「表达力」和「场景泄漏」之间做零和交易，域偏移时尤其危险。

**视角**：换个起点。不从零学动作，而是从一个已经在大规模、多样视频上预训练过的基础模型（V-JEPA 2）出发——它对一对帧的嵌入里已经带了大量动作信息。真正剩下的问题只有一个：**怎么把动作抽出来、把场景丢掉**。

**结果**：提出无标签的对比适配框架，重塑预训练空间的几何而不加重建瓶颈；并给出统一评测协议（动作表达力 / 场景不变性 / 动作条件视频生成质量三轴，覆盖机器人操作、相机导航、游戏、驾驶，多数基准在适配阶段没见过）。与无标注 latent-action 方法相比，表示表达力明显更强、场景不变性持平，训出的世界模型把演示动作迁移到新场景更忠实。具体数值 `[摘要未给]`。

## 方法拆解

1. **底座**：V-JEPA 2 的帧对嵌入作为初始动作载体，全程不引入像素重建目标。
2. **对比适配（无标签）**：不同场景、同一运动的帧对拉近；同场景、不同运动的帧对推开。正负样本都从视频自身挖掘，不需要任何动作标签。
3. **不加瓶颈**：与「encoder + 下一帧重建 decoder」相反，这里不要求 latent 能重建画面，因此不存在「紧则丢细节、松则漏场景」的两难。
4. **评测**：三轴协议跨四个域，其中多数基准在适配时未见，用来检测泛化而不是拟合。

## 锐评

- **对照一：latent action 从零学 + 下一帧重建的路线**。那类方法（LAPA 式）把动作空间和像素重建绑死，瓶颈参数直接决定能表达多少动作；OnlyAct 用对比目标替代重建目标，把「分离场景」和「保留动作」拆成两个方向的约束而不是一个瓶颈宽度。代价是完全继承 V-JEPA 2 的视觉先验与偏差，摘要未给参数量、推理成本与适配所需数据量。
- **对照二：用 VLM 给视频打动作标签的路线**。那条路受标注规格限制、且要人写 ontology；OnlyAct 只需要帧对，监督形态更接近无标注视频的自然形式。但摘要未说明「同运动跨场景」这类正样本对具体怎么构造——如果依赖检索或人工挖掘管线，无标签的优势会被削弱。
- **对照三：端到端 VLA（π0 / RT-2 一类）**。OnlyAct 不直接输出低层动作，而是提供可迁移的动作表示给世界模型/策略，定位是「中间层」而非策略本体。
- **真实局限**：三轴评测里「动作表达力」用什么代理指标、场景不变性怎么量化，摘要都没展开；方法正确性高度依赖 V-JEPA 2 的嵌入质量，换一个更弱的底座是否仍成立 `[摘要未给]`。

## 借鉴意义

- **数据管线**：动作监督可以从「遥操作 + 动作标签」换成「视频里挖同运动跨场景对」，对做操作数据规模化的项目是直接可用的替代品。
- **训练接口**：可以把 OnlyAct 表示当 VLA 的辅助目标（冻结主干、只训头部），用少量带动作数据做对齐，避免从零学 latent action。
- **评测习惯**：三轴拆解（表达力 / 不变性 / 生成质量）比单一「下游成功率」更能定位失败环节，值得照搬到自己的世界模型评测里。
