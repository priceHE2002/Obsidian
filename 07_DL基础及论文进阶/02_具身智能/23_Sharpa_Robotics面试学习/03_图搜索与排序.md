# 图搜索与排序

> 【本次重建答案】题目来自 S3；华容道缺少具体条件，以下为条件化解法。

## Q03【截图题目 S3】华容道最少多少步可以复原？

### 思路分析

先问清棋盘、初始/目标布局、一“步”的含义、滑块尺寸、是否允许旋转。若指等代价滑动数字拼图，可把布局当顶点、合法移动当边，最短移动次数就是图的最短路径长度。

### 严格推导

等代价边使用 BFS，按距离 0、1、2…层次扩展；首次发现目标时，若存在更短路径，目标应在更早层被发现，与首次发现矛盾。因此首次距离为最短。

~~~python
from collections import deque

def sliding_puzzle_min_moves(start, goal, rows, cols):
    start, goal = tuple(start), tuple(goal)
    if len(start) != rows * cols or len(goal) != rows * cols:
        raise ValueError('shape mismatch')
    if len(set(start)) != len(start) or set(start) != set(goal) or 0 not in start:
        raise ValueError('require unique tiles and one blank 0')
    queue = deque([(start, start.index(0), 0)])
    seen = {start}
    while queue:
        state, z, distance = queue.popleft()
        if state == goal:
            return distance
        r, c = divmod(z, cols)
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            rr, cc = r + dr, c + dc
            if 0 <= rr < rows and 0 <= cc < cols:
                nz = rr * cols + cc
                nxt = list(state)
                nxt[z], nxt[nz] = nxt[nz], nxt[z]
                nxt = tuple(nxt)
                if nxt not in seen:
                    seen.add(nxt)
                    queue.append((nxt, nz, distance + 1))
    return -1
~~~

该代码只解“每块占一格、0 为单个空格”的数字拼图；不适用于多尺寸滑块的经典华容道。一般图 BFS 为 O(V+E) 时间、O(V) 空间；这里每个状态的复制/哈希还要 O(RC)，不能遗漏状态表示成本。可达状态数随格子数阶乘增长，不适合对 15-puzzle 盲目全量 BFS。

【学习扩展】数字拼图可做奇偶可解性检查；A* 用 g+h。以标准目标为例，非空格到目标格子的曼哈顿距离总和是可采纳启发，因为每步只能让一个数字沿网格移动一格。大空间可考虑 IDA*。若规则变化，启发函数和奇偶判据都要重新核对。

### 结论

$$\boxed{\text{题目条件不足，不能给数值；等代价状态图用 BFS 求最短步数。}}$$

## Q04【截图题目 S3】二维 0/1 网格中岛屿数量是多少？

### 思路分析

先说明默认上下左右四连通；若题目采用八连通，以题目为准。岛屿就是陆地诱导子图的连通分量。每找到一个未访问的陆地，计数加 1，并遍历它所在分量。

### 严格推导

~~~python

def num_islands(grid):
    if not grid or not grid[0]:
        return 0
    rows, cols = len(grid), len(grid[0])
    if any(len(row) != cols for row in grid):
        raise ValueError('ragged grid')
    visited = set()
    answer = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] != 1 or (r, c) in visited:
                continue
            answer += 1
            visited.add((r, c))
            stack = [(r, c)]
            while stack:
                x, y = stack.pop()
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    xx, yy = x + dx, y + dy
                    if (0 <= xx < rows and 0 <= yy < cols
                            and grid[xx][yy] == 1 and (xx, yy) not in visited):
                        visited.add((xx, yy))
                        stack.append((xx, yy))
    return answer
~~~

入栈时就标记，可避免多个邻居重复压入同一节点。一次搜索恰好覆盖一个连通分量；不同搜索之间不重叠，因此累加得到分量数。每格最多入栈一次、检查四条边，时间 O(RC)，辅助空间最坏 O(RC)。即便原地把 1 改成 0 省去 visited，栈的最坏空间仍为 O(RC)。

### 结论

$$\boxed{\text{岛屿数等于连通分量数；DFS/BFS 时间 }O(RC)\text{，辅助空间最坏 }O(RC).}$$

【学习扩展】并查集适合逐步增加陆地的在线问题。若输入是字符 '1'，必须调整判断，不能与整数 1 混用。

## Q05【截图题目 S3】手写快速排序并分析复杂度

### 思路分析

选择枢轴，将区间分成小于、等于、大于三段，再递归处理两侧。三路划分能避免大量重复元素时反复处理等值区。

### 严格推导

~~~python
import random

def quicksort_inplace(a):
    def sort(lo, hi):
        while lo < hi:
            pivot = a[random.randrange(lo, hi + 1)]
            lt, i, gt = lo, lo, hi
            while i <= gt:
                if a[i] < pivot:
                    a[lt], a[i] = a[i], a[lt]
                    lt += 1
                    i += 1
                elif a[i] > pivot:
                    a[i], a[gt] = a[gt], a[i]
                    gt -= 1
                else:
                    i += 1
            # 递归较短侧，较长侧用循环，限制调用栈深度。
            if lt - lo < hi - gt:
                sort(lo, lt - 1)
                lo = gt + 1
            else:
                sort(gt + 1, hi)
                hi = lt - 1
    sort(0, len(a) - 1)
    return a
~~~

划分不变式：a[lo:lt]<pivot，a[lt:i]=pivot，a[i:gt+1] 未处理，a[gt+1:hi+1]>pivot。每次缩小未知区间；当 i>gt 时完成划分。递归区间严格缩小，结合归纳得到整个序列升序。

平衡时 T(N)=2T(N/2)+Θ(N)=Θ(N log N)。随机枢轴下期望 O(N log N)，最坏每次只排除一个元素，T(N)=T(N−1)+Θ(N)=Θ(N²)。此版本仅递归较短侧，调用栈 O(log N)，即使时间退化也不会线性深递归；普通双侧递归快排最坏栈深为 O(N)。快排通常不稳定。

### 结论

$$\boxed{\text{随机三路快排：期望 }O(N\log N)\text{，最坏 }O(N^2)\text{；本实现栈空间 }O(\log N).}$$

## Q06【截图题目 S3】unsigned int 怎样排序？

### 思路分析

unsigned 只说明非负、固定位宽，不等于实际数值范围足够小。先问位宽 W、样本量 N、是否要求稳定、能否使用 O(N) 额外内存。

### 严格推导

- 若键落在 [0,U)，计数排序时间 O(N+U)、计数空间 O(U)。完整 uint32 范围的计数数组有 2³² 项，若每项 4 字节，需要 16 GiB，仅计数器就可能不可接受。
- 固定位宽整数可用 LSD 基数排序。每次处理 b 位，桶数 2ᵇ，轮数 ⌈W/b⌉；每轮必须稳定，才能保留已排好的低位顺序。
- 时间 O(⌈W/b⌉(N+2ᵇ))，辅助空间 O(N+2ᵇ)。uint32、b=8 时共 4 轮。
- 桶排序把数值分到区间桶，再在桶内排序；其性能依赖分布和桶内算法，不等同于计数或基数排序。

~~~python

def radix_sort_uint32(values):
    a = list(values)
    if any(not isinstance(x, int) or x < 0 or x >= (1 << 32) for x in a):
        raise ValueError('require uint32 values')
    for shift in range(0, 32, 8):
        count = [0] * 256
        for x in a:
            count[(x >> shift) & 255] += 1
        offset = [0] * 256
        for j in range(1, 256):
            offset[j] = offset[j - 1] + count[j - 1]
        out = [0] * len(a)
        for x in a:  # 保持输入次序，保证本轮稳定。
            digit = (x >> shift) & 255
            out[offset[digit]] = x
            offset[digit] += 1
        a = out
    return a
~~~

每轮稳定排序后，数组按已处理的低位整体有序；归纳到处理完 W 位，得到整数全序。C/C++ 的 unsigned int 位宽需由平台或题意确定，不能无条件认定为 32。

### 结论

$$\boxed{\text{范围小可计数；固定位宽可基数；条件不明时比较排序仍是有效方案。}}$$
