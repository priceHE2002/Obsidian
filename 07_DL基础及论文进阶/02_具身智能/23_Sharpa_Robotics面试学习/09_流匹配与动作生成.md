# 流匹配与动作生成

> 【通用清单 S4】【本次重建答案】以下用简单线性路径推导条件流匹配。它是教学特例，不代表所有 Flow Matching 路径或某个公司的内部实现。

## Q30【通用清单 S4】Flow Matching 的训练与采样怎样写？

### 思路分析

训练网络预测把噪声搬运到数据的速度场；推理时从噪声出发积分 ODE。先确定时间方向，再写速度目标，避免把噪声端和数据端反过来。方法背景见 [Flow Matching 原论文](https://arxiv.org/abs/2210.02747)。

### 严格推导

本例约定 $x_0\sim\mathcal N(0,I)$ 为噪声，$x_1\sim p_{data}$ 为数据，独立配对；$t\sim U(0,1)$：

$$x_t=(1-t)x_0+tx_1,\qquad\frac{dx_t}{dt}=x_1-x_0.$$

条件 c 可以包含图像、语言和机器人状态。训练目标：

$$\mathcal L(\theta)=\mathbb E\left[\left\|v_\theta(x_t,t,c)-(x_1-x_0)\right\|^2\right].$$

为何学到可用速度场？对固定 $(x_t,t,c)$，令 Y=$x_1-x_0$，则平方误差的条件期望可分解为：

$$\mathbb E[\|v-Y\|^2\mid x_t,t,c]
=\|v-\mathbb E[Y\mid x_t,t,c]\|^2
+\mathbb E[\|Y-\mathbb E[Y\mid x_t,t,c]\|^2\mid x_t,t,c].$$

第二项与 v 无关，所以理想回归解是条件平均速度。在适当正则条件和正确求解下，这对应所构造边缘概率路径的速度场；有限模型、有限数据和有限步求解存在近似误差，不构成精确采样保证。

~~~python

def flow_matching_loss(model, x1, condition):
    x0 = torch.randn_like(x1)
    t = torch.rand(x1.shape[0], device=x1.device)
    broadcast_t = t.reshape((-1,) + (1,) * (x1.ndim - 1))
    xt = (1 - broadcast_t) * x0 + broadcast_t * x1
    target = x1 - x0
    prediction = model(xt, t, condition)
    return (prediction - target).square().mean()


@torch.no_grad()
def sample_euler(model, x0, condition, steps=20):
    # 调用前 model.eval()；steps=20 仅是接口默认示例，不是性能承诺。
    if steps <= 0:
        raise ValueError('steps must be positive')
    x = x0.clone()
    dt = 1.0 / steps
    for j in range(steps):
        t = torch.full((x.shape[0],), j * dt, device=x.device)
        x = x + dt * model(x, t, condition)
    return x
~~~

训练不需要每次通过求解整条 ODE 得到损失；采样需要数值积分。Euler 在常规光滑条件下全局误差为 O(Δt)，增加求解精度会增加速度场调用数，实际要比较成功率、延迟和 NFE。学习路径的线性插值不表示每条推理轨迹都等于训练样本对之间的直线。

### 结论

$$\boxed{\text{训练回归路径速度，采样从噪声端沿同一时间方向积分到数据端。}}$$

## Q31【学习扩展】怎样把流匹配用于动作 chunk？

### 思路分析

把连续动作序列作为待生成数据，条件为当前观测和任务；一次生成多步动作，再根据反馈滚动执行。

### 严格推导

设 $A=[a_t,\ldots,a_{t+H-1}]\in\mathbb R^{H\times d_a}$，训练时用归一化后的真实动作 chunk 作为 x1，噪声 x0 同形状；速度场输出也为 [B,H,d_a]。动作维度随机器人变化时需要有效维 mask，损失按有效元素归一化。

推理从噪声生成动作 chunk，反归一化后执行前 h 步（h≤H），读取新观测再规划。H 是预测长度，h 是执行长度，不应混淆。还须约定绝对/增量动作、关节/末端空间、旋转表达、夹爪单位和控制频率。

评估包括：任务成功率、动作平滑性、约束违反率、端到端延迟、求解次数、分布外失败；不能只用动作 MSE 给多模态任务下结论。

### 结论

$$\boxed{\text{动作 chunk 可作为条件生成目标；落地仍取决于动作语义、求解延迟与闭环反馈。}}$$

## Q32【学习扩展】流匹配、扩散和世界模型怎样区分？

### 思路分析

前两者是可用于生成分布的训练/建模路线，“世界模型”是对环境动力学建模的任务角色，分类维度不同。

### 严格推导

扩散常以噪声扰动与去噪/score 等目标训练；流匹配以构造路径上的速度回归训练。两者的路径和参数化可以发生联系，不宜说“一个绝对随机、一个绝对确定”。流匹配的 ODE 给定初始噪声后可确定，但从随机初值开始，生成分布依然有随机性。

世界模型可用扩散或流匹配生成未来观测，也可用潜在状态转移模型；动作策略同样可用扩散或流匹配直接生成动作。必须看条件与输出：预测下一状态是动力学问题，生成当前应执行的动作是策略问题，两者可以协作但不能等同。

### 结论

$$\boxed{\text{流匹配/扩散是建模方法，世界模型/策略是任务角色；按输入输出区分。}}$$
