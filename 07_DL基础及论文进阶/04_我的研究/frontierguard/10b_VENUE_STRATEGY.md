## 时间线（CoRL 主投口径）
- W1–W10：6 个手内技能（含 2 个新接触任务）+ 2 个臂式技能 + 技能库/评测 harness；W8 Go/No-Go：本地 N 上限、4 技能可训。
- W10–W16：FG 分配 + 校准头 + 统一策略条件化；W16 主曲线预跑。
- W16–W24：主实验（fixed-K、N 扫描、≥5 seeds）、校准评测、agent 2×2、长程任务；W20 中检（6 技能+FG 主曲线），W26 实验冻结。
- W26–W30：写作 + 视频 + 开源 + 内审；**CoRL 2027 截稿前提交**。
- W31–W44：若 CoRL 被拒/大修 → 按审稿意见补实验，改投 ICLR 2028；若中 → 准备 camera-ready/workshop。

## 对 v1 的要求（与 ICRA 版不同）
1. **贡献表述**：不写"机器人系统"，写"**技能库级数据分配 → 技能校准 → agent 组合成功率** 的受控实证研究 + 方法 + 开源基准"；系统是测量装置。
2. **实验严谨性权重更高**：主假设预注册、≥5 seeds、fixed-K 为主、CI/效应量、消融 ≥8、负结果分支、LLM 版本/温度/成本固定并披露。
3. **理论可弱化但不能为零**：给"LP 导数 × epistemic 不确定性"的直觉与一个可检验命题（不需要收敛证明），CoRL/ICLR 都接受。
4. **机器人细节保留**：CoRL 审稿人要看真实 dexterous 任务与失败分析；技能表、资产来源、接触参数、视频必须齐全。
5. **成本/算力透明**：本地 4070 Ti Super + 租卡预算 ≤¥5,000；给出每实验 GPU-h 与复现脚本。
6. **中稿概率**：由 judge 按 CoRL/ICLR 分开估，并给"CoRL→ICLR 级联"总概率；>50% 只可能在级联口径下成立，需在最终交付中如实说明。

## 理论目标（2026-11-02 judge 定标，Lead 采纳）
- **只加"传播界"不够**：`|Πp − Πp̂| ≤ Σ|p_b − p̂_b| ≤ Hε`（独立时 √H·σ）两行可证，审稿人会称 *elementary*；其价值在可检验经验律（成功率随技能链长 H 的退化斜率与 ECE 同向），不在数学本身。S≈3.48（Novelty 3.2 / TQ 3.7 / Insight 3.2）→ CoRL 质量 44%、级联质量 65%、期望 47%。
- **真正抬分的是 Neyman 刻画**：把 FG 写成"组合成功估计方差下的最优分配 n_b* ∝ w_b σ_b 的在线自适应近似"，给最优性一阶条件 + FG 是其非平稳近似；这与传播界合起来 S≈3.58（Novelty 3.4 / TQ 3.9）→ CoRL 46%、ICLR 41%、级联质量 68%、**期望 47–48%**。
- **不追 S≥3.65**：每 +0.1 分约 2 周，exec 0.72→0.60，期望反而下降；现实上限 S≈3.55–3.58。
- **成本**：正文 0.75–1 页 + 附录 2–3 页；1 人 3–4 周（含 Neyman 共 5–6 周），插入 W2–W5 与技能工程并行。writer 已启动 `17_theory_bound_dexterous.md`。
- **可选加分**：多 LLM 泛化（3 个 planner，+Insight ~0.5，2 周、¥800）——仅在 W18 前主实验按计划时做；多形态迁移进主线、PPO 收敛证明、conformal 包装均不做。
