# Lens 02 — 探索 / 遗憾 / 非平稳（bandit · PAC-MDP · 并行 scaling）

## 候选 A：漂移受限分配（DLA）——1/(1+α) 家族、3/5 律、符号定理与 ρ 相变

- **论文一句话论点（thesis）**：分配不是 bandit 而是"漂移参数的估计设计"：`n_b*∝(w_b A_b)^{1/(1+α)}`，α 由无量纲 `ρ_b=D_bK^{3/2}√(n_b/v_b)` 定；fixed-K 下 `ρ∝√N`、fixed-B 下 `ρ∝N^0`。α=1→Neyman(½)、α=½→ECE(⅔)、α=⅔（漂移）→`n*∝w^{3/5}(vD)^{2/5}`；**ECE 目标指数是 (¾,¼)，比 Neyman 更平——H2 实测 ≈1.000 是定理而非意外**。
- **第一性原理缺口**：SGS 把非平稳压成 3 档 band、LGA 压成 LP×σ̂，没人把非平稳写成**可测的 α**，也没人问"何时分配没用"。judge 的 frontier Neyman 比 1.000 只对 v 求异质；真正决定增益的是 **v·D**，D 从未被测过。另：现稿 σ̂ 有三套语义——算法 `+λσ̂`（乐观）、引理 4a `LP/σ̂`（比值）、正文"降温"（悲观）、A1 预期按降温写死。**理论分析的不是实际跑的算法**，这是审稿人 20 分钟能抓的。
- **形式化对象/定理/算法**：① 命题（漂移地板）`MSE_b ≥ c(v_bσ_w²/n_b)^{2/3}`（Kalman 稳态/Le Cam 两点；窗口估计器达 1.19×）；② 故 `n*∝w^{3/5}(vD)^{2/5}` 在 EMA/窗口类内 minimax；③ **符号定理**：`∂²/∂n∂v>0`（估计目标：越方差越该采）vs `<0`（优化目标：噪声拖梯度）——同一 σ̂ 不可能两用；④ **相变**：ρ≪1 时 uniform/Neyman/SGS 的 Δ 等价（TOST），ρ≫1 时 3/5 优于 ½。
- **可证伪预测**：P1 用日志 D̂_b 分布预测三结局（ρ≫1⇒3/5 现在就该赢；ρ≈1⇒相变在可达 N 内；ρ≪1⇒当前规模分配无效、N* 可外推），先写死再看 8192。P2 合成床（M=64、已知 p_b(t)）拟合指数 (3/5,2/5,2/5)±.04，平稳床 (½,½,0)。P3 `LGA−σ̂` 在 decision-ECE 上**优于** LGA（与现预注册相反）、min-skill 更差。P4 `SER+LGA` 次可加（SER 降 D 即降 ρ）。
- **最小实验包**：合成床 CPU 1 天；**离线 D̂/ρ/增益比 0 GPU、3 天（生死步）**；本地 LR∈{1e-4,3e-4,1e-3}×{uniform,LGA}×2seed×N=1024=12 runs、26 本地 GPU-h、¥0（外生移 ρ）；租卡 DLA(3/5)×2seed×8192=2 runs 19h ¥133 + 2048 2 runs ¥44 → 净 ¥149（削 G2 两变体），余 ¥42。8 周 W13–W21、约 24 人日；依赖现有 83 runs 日志、CRN 快照、head 代码。
- **与近邻区别**：P2P/ADEPT 只报单工作点、无分配理论；OmniReset 改 MDP 的 ρ₀（优化方差），不在估计轴上，**主表并列是类目错误**；SGS=α→0 的 bang-bang 三档平滑；SER 不改 α 只降 D，**与 LGA 拮抗**；Neyman=α=1 特例；LGA=v 符号错、α 随 σ̂ 漂移的启发式。
- **为什么不是 incremental**：审稿人原话——"3/5 只是拉格朗日一页纸"。答：贡献不在指数，在 (i) α 由 ρ 识别、ρ 由 N 决定；(ii) 下界证明没有更好的分配；(iii) 相变预测"何时分配没用"，把会被归因为调参失败的负结果变成定理。
- **S 增量归因**：N+.75→4.00、Ins+.60→4.05、TQ+.20→4.05、Exp+.15→3.80、C+.08、Rep+.05；等权 +.31，按 N/Ins 合计 .44 则 +.36 → **S≈3.96（3.91–3.99）**。
- **目标 venue + 理由**：ICLR 2028 主（形式化+下界+相图）；CoRL 版 N 被 sim-only/4 技能压住，上限 ≈3.90。
- **风险与 rebuttal**：①"下界只对 EMA 类"→ 正是 P3：换 trend-aware 应使指数回 ½、收益变小（分配与估计可互换），实测。②"预测与分配同源"→ D̂ 取 W16 冻结的独立 checkpoint+CRN 快照，预测先写死；LR 扫描为外生干预。③"3 个 N 点太瘦"→ 合成床给 ground truth，4 技能只作外部效度。④ρ≪1 全程→ 诚实结论：给 N* 闭式、说明当前规模为何测不到，**两边都是论文**。

## 候选 B：分配审计——收益拆成估计/漂移/干涉，给"何时不值得分配"的判据

- **thesis**：`L≤R_est+R_drift+R_inter+R_churn`，四项各有独立外生干预（分配替换/LR/trunk 开关/冻结分配）；在已有 83 runs 上 0-GPU 审计，输出"支配项-规模"图与判据 `R_est 占比<30% ⇒ 重分配最多省 30%`。
- **缺口**：SGS/SER/OmniReset/LGA 只报一个总数，无人回答"赢在哪一项"；被问"相对 SGS 只是换判据"时无法回答。
- **形式化**：`R_est=Σw_b v_b/n_b`、`R_drift=Σw_b(D_bτ_b)²`、`R_inter=Σ_{g≠h}|cos(g_g,g_h)|s_h`、`R_churn=Σ_t TV(w_t,w_{t+1})`；引理：四项以 1+o(1) 控制 L。
- **可证伪预测**：P1 解释 ≥70% 的 LGA−uniform 差异；P2 支配项在 N* 切换且 N* 事先预测；P3 SER 收益随 N 消失（<1pp@8192）；P4 SGS 收益是 margin 的阶梯、与 N 无关。
- **最小实验包**：0 新训练；离线 3 天 + 8h CRN 子集重评（¥56）；6 周；**¥60**；与 A 共用日志。
- **区别**：不是再加 baseline，而是给整个家族一把解剖刀；与 SGS/SER/OmniReset 的差异从"判据不同"升级为"优化的遗憾项不同"。
- **非 incremental**："把四个数加起来"→ 每项配外生干预，是可识别分解不是事后归因；判据直接改实践（N>N* 就别做分配，去控漂移）。
- **S 归因**：Ins+.45、TQ+.12、N+.18、Exp+.10、C+.05 → +.18~.22 → **S≈3.78–3.82**。单独不到 3.95，是 A 的保险与"测量半边"。
- **venue**：CoRL 2027 / NeurIPS D&B（测量+负结果+协议最匹配）。
- **风险**：四项不可加（残差>30%）→ 退为"收益不可分解"的负结果，S−.10。

## 必答三问

| 方法 | 遗憾语义 | 盲点 |
|---|---|---|
| uniform | α=∞（份额与 wA 无关） | 漂移项不受控 |
| Neyman | α=1，平稳 L2 minimax | 漂移时非最优（应 3/5） |
| SGS | α→0 bang-bang（3 档平滑） | drift-blind：band 不变就看不见进步 |
| SER | 不改 α，只降 D/ρ | 与 LGA 拮抗，收益随 N 消失 |
| OmniReset | 改 ρ₀，降优化方差 | 与分配正交（类目错误） |
| LGA | 代理累积遗憾 O(√(TM log M)) | 代理≠终局；σ̂ 三义；v 符号错 |

- **下界**：有，`MSE_b≥c(v_bσ_w²/n_b)^{2/3}`；匹配上界 1.19×；L1/ECE 指数 (¾,¼)。仅对 EMA/窗口类成立——**这一限制本身是 P3 的可证伪点**，不是掩饰。书类（Cochran/Sayed/Whittle/Auer）非 arXiv。
- **N 与分配统一**：`ρ_b=D_bK^{3/2}√(n_b/v_b)` 一个无量纲数把"并行度"换掉；fixed-K `ρ∝√N`、fixed-B `ρ∝N^0`（**预测 fixed-B 下 Δ 与 N 无关的零假设**，更难造假）；收益是 ρ 的单调函数。

## 本视角结论

- **能到 3.95 吗**：有条件。A 点估计 3.96 → 质量 ≈58–60%、exec .85 → **49–51%（ICLR 口径）**；**CoRL 单会仍不可达 >50%**（N 上限 ≈3.90 → 45–47%）。故：坚持 CoRL 单会 >50%——本视角答"没有"；允许 ICLR 主投——"有，但依赖理论被实验支持（P≈.55）"。
- **最推荐**：A 作 §3、B 作 §5；**W12–W16 先做 0-GPU 判生死（1 周）**：算 `(v)` 与 `(vD)` 的预测增益比，前者≈1、后者≥1.3 才抬 A 为主贡献，否则按 B 收 CoRL。
