# Lens 01 — 信息论 / 实验设计

## 候选 A：技能库的决策可识别性（DIL）
- **thesis**：技能库校准不是"估多准"，是"设计上能否被识别"；计划集 Π 是设计变量，判据是决策信噪比 ρ=Δ/σ_Δ。现有基准皆落在 ρ≫1 饱和区，故"校准无用"的零结果是设计伪影，且可用闭式证书提前判定。
- **缺口**：现有分配族（Neyman/ECE-最优/LGA）把技能当独立参数；但计划分是**共享因子的乘积**，一阶敏感度在共享技能上精确抵消。不是"没人做"，是目标函数把 per-skill 误差当独立项，对共享结构的零空间无感知，也就无法回答"这个基准能否测出校准"。
- **形式化**：S(π)=∏q_g，q_g=1−(1−p_g)^{R+1}，ρ_g=(R+1)(1−p_g)^R/q_g，c_g=S(π)ρ_g·1[g∈π]−S(π′)ρ_g·1[g∈π′]。
  ①**抵消定理**：g 同属两计划时 |c_g|/|c_disc|≈Δ/S≈0.07（已数值验证）。
  ②**决策 Fisher 信息** I_dec=c_g²v_g；c-最优 n*∝√I_dec，共享格权重为 0，方差降 M/P 倍。
  ③**κ 律**：κ=ρ√v 单调降 ⇒ 弱技能该多采；p=0.15 vs 0.5，DFI 给弱格 4.7×，Neyman 反给强格 1.4×——**在 p<0.5 上两族方向相反**。
  ④**顺序必然性**：静态执行该 c-最优会饿死识别对手所需的格——60 计划下准确率 0.24（uniform 0.69）。须 SDFI（重识别+10% 地板）：+10~15pp、样本效率 2~2.5×。
  ⑤**可识别性证书**：ρ≥3 时任何分配规则以 ≥99% 概率不改变选择 ⇒ 该基准原理上测不出校准。
  ⑥**成本弹性分裂**：信息通道 n*∝√(wv/c)（古典 c-最优，Elfving 1952 的带成本形式），进度通道按边际收益/成本配平（≈1/c）；LGA 两通道同用 1/c，信息通道被多罚一个平方。
- **可证伪**：①真实库 |c_shared|/|c_disc|≤0.15（>0.3 ⇒ 跨计划误差相关、抵消失效，改写为"相关误差下边际统计连界都给不出"）；②SDFI 用 ≤55% rollout 达同等计划准确率（|Π|≥12 中位数）；③现有 512k rollout 下 ρ≥5（预计 ≈20）且 99% 重采样不改选择；④信息通道改 c^{-1/2} 后份额变 ≥20%、准确率 +≥2pp。
- **实验包**：E1 合成 10^4 库×6 规则×4 预算，纯 CPU 2–3 天，0 GPU/¥0；E2 复用现有 512k CRN rollout 子采样；E3 扩 Π 至 24 个合法序；E4 8run×N2048=25 GPU-h≈¥176，**替换**现有 8 个 LGA run ⇒ 净 ¥0；E5 240 episode 替换现有 240 个 ⇒ 净 ¥0。**合计 ≤¥176、≤25 GPU-h、18 周**，本地+租卡，依赖现有 rollout 与 LGA 日志。
- **区分**：P2P＝并行规模换样本效率，无决策对象；ADEPT＝技能适配，目标仍是 per-skill 成功率；OmniReset＝重置分布，无计划选择；SGS＝均衡配比破探索瓶颈，目标是覆盖/学习速度；SER＝错峰重置，纯系统层；LGA＝LP+σ̂ 加权，目标学习进度、且信息通道成本弹性错配。六者都优化"每技能估得更准/学得更快"，无人把 Π 当设计变量、无人给可识别性判据。
- **非 incremental（模拟审稿人）**："OCBA 早做决策加权，Neyman 早处理异方差；共享因子零权重是两行推导，'顺序做'是教科书。" 反驳：零权重预言的是**方向性反转**（喂弱格而非前沿），与整个以 ECE/方差为目标的分配族相反；静态执行把准确率打到 0.24，是共享参数设计的新失效模式，非教科书结论；证书把担忧变成可算的数。
- **S 归因**：N +0.65（3.25→3.90）、Insight +0.55（3.45→4.00）、TQ +0.13、Exp +0.13、C/Rep +0.10 ⇒ **+0.33，S≈3.93**。
- **venue**：NeurIPS 2027（W27）——形式化对象+可证伪+测量科学正合口径，且核心主张 0 新训练可早投；同一 S 在更陡的 NeurIPS 映射下（阈值约低 0.1）可读作质量 0.60–0.62。备选 CoRL 2027、ICLR 2028。
- **风险**：被判"古典设计套壳"、增益仅 2× 且只在小 B、纯仿真 4 技能。rebuttal：主张是可识别性而非加速，2× 是副产品；合成覆盖 S∈[3,8]；证书与库规模无关。**替换**：砍掉 H2 的 −20% 阈值叙事与"2 计划"设定，改为可识别性协议。

## 候选 B：决策硬基准 + SDFI（稳健版）
- **thesis**：不赌理论野心，直接造"决策硬"基准：按 ρ∈[0.5,2] 设计 Π，首次让校准-组合效应可测，交付回放基准 + SDFI 的 2~2.5× 证据。
- **缺口**：现有技能库基准的 Π 都小、margin 大（ρ≫1），校准效应**原理上不可测**；不是没人试，是没人设计过可测的装置。
- **形式化**：ρ 证书 + Π 构造规则（序×重试×桶）+ SDFI。
- **可证伪**：①改造后 ρ∈[0.5,2]；②uniform@B=200 准确率 ≤0.75、SDFI ≥0.85；③证书的"可测/不可测"预测与实际重采样一致率 ≥90%。
- **实验包**：全复用+合成，≤¥176，14 周，0 新训练。
- **区分**：现有基准是排行榜，B 是"可识别性受控的测量装置"——同一条流水线能产出 ρ，评审可自行验证装置是否有效。
- **非 incremental**："又一个 benchmark"。反驳：交付的是可识别性证书，能证明某基准能否回答某问题，基准文献里没有这个物件。
- **S 归因**：N +0.40、Insight +0.35、Exp +0.30、TQ +0.10、C/Rep +0.20 ⇒ **+0.32，S≈3.92**；exec 更高（0.88）。
- **venue**：CoRL 2027。**风险**：被判 benchmark 论文；rebuttal：核心是证书而非排行榜。

## 本视角结论
**能摸到阈值但不稳**：A ≈3.93（3.90–3.96），质量 57%，exec 0.85 ⇒ 期望 ≈49%；B ≈3.92、exec 0.88 ⇒ ≈50%。瓶颈已从"想法"迁移到"执行完整度"；本视角独特优势是**核心主张 0 新算力**，可把 exec 推到 0.88–0.90，这才是过 50% 的真实杠杆。推荐 A，B 作降级。**与 lens 03 的 CD-SNR 同机器**：合并建议 03 出相变/接口偏差、01 出抵消·零权重·顺序必然·证书，否则两篇互杀。
