# Lens 03 — 组合泛化 / options / 技能链 / 分布偏移

**判断：能。** 现有 Prop 3 的病根不是常数松，而是**建模对象错**：planner 只在有限计划集上取 argmax，误差的作用是**阈值式**的，不是线性累积。换成"决策信噪比"后，同时得到两侧紧界、相变点、分配错配定理，以及一条**不随 n 消失**的偏差通道——后者源自"训练分布≠组合入口分布"。

## 候选 A：组合决策信噪比（CD-SNR）——相变点 + 分配错配 + 接口偏差

- **thesis**：技能库何时"可组合"由 ρ=Δ/D 决定（Δ=计划间 margin，D=计划分估计噪声），不由 per-skill ECE 决定；ρ 同时划出唯一值得花数据的窄带。
- **缺口**：①Prop 3 把 argmax 当连续扰动，只能给 2Hε 的方向界；②所有技能库工作把**隔离评测的 p** 写进 API，而组合改变技能入口分布——这是 n→∞ 也不消失的偏差，per-skill 校准原理上无法认证组合；③options/技能链理论（1609.05140、2106.13105、2401.03360）假设 model 已知，无人研究**估计误差**在 option 链上的传播。
- **形式化**：S(π)=∏q_i，q_i=1−(1−p_i)^{R+1}；灵敏度 c_{π,s}=S·a_s，a_s=(R+1)(1−p_s)^R/q_s。
  - **弹性律**：∂logS/∂logp_s=p_s·a_s∈(0,1]，p→0 时→1、p→1 时→0 ⇒ 组合被最弱技能支配；ECE 各技能等权，是错的泛函。
  - **Thm 1（两侧）**：Δ:=S(π*)−S(π₂)，D²=2S²Σ_s a_s²v_s/n_s。若 Δ≥D√(2log(2N_π/δ)) 则 P(误选)≤δ、**损失=0**（而非 2Hε）；若 Δ≤cD 则 Le Cam 两点下界给 E[loss]≥c′Δ。相变点 **B_c=4S²log(2N_π/δ)(Σ_s a_s√v_s)²/Δ²**。
  - **Thm 2（错配）**：组合最优 n_s∝a_s√v_s；ECE 最优 n_s∝(w_s√v_s)^{2/3}。前沿带内 v≈常数 ⇒ p∈[0.3,0.7] 上 ECE 权重仅变 **1.06×（≈均匀）**，组合权重变 **5.5×**；低 p 区两者对 p **反序**（∝p^{-1/2}↓ vs ∝p^{1/3}↑，p=0.1 vs 0.5 差 3.8×）。⇒ "平均校准最优 ≠ 组合风险最优"。**这正解释 judge 复算的 ECE 比值 1.000：不是实验没做好，而是 v 平坦使校准口径的分配收益理论上≈0；收益只在组合口径。** 附论：H2 的 −20% 在前沿带近不可达；应先从日志估查询权重 w 预测 ΔECE。
  - **Thm 3（双通道）**：|S−Ŝ|≤Σc_sε_s（方差，∝n^{−1/2}）+Σc_s|β_s|（接口偏差 β_s=p_s^{comp}−p_s^{iso}，n 不衰减）⇒ 正确对象是**接口条件可靠性** p(s|前驱诱导的入口分布)。
  - 推论：共同模误差把指数从 √H 推到 H，交叉 H*=(σ_δ/ᾱ)²。（PAC-Bayes 非主工具：计划集有限，union bound 已紧；它只收紧 ε_s，不改标度与偏差项。）
- **可证伪预测**：①重放扫描 n∈{25…4000}，loss 在 B_c 塌陷；H=3,R=2,p=(0.6,0.3,0.5) ⇒ Δ=8pp→B_c≈3.6e3/技能，3pp→2.6e4。**B_c 是 p̂ 的评测样本量**（corollary 用 500M 训练步判"不 binding"，但 API 的无偏 p̂ 只能来自 held-out=4e3/技能，恰在相变点）。②等预算下 ECE-最优 vs 组合-最优，组合成功率差 ≥5pp 且随 p 异质性增大；≈0 则错配量级可忽略。③β_{S7}<0 且 |Σc_sβ_s|≥ 方差通道；β≈0 则隔离评测惯例被验证。④LLM 的 argmax 一致率<100% ⇒ 决策规则失配（SNR 可靠性图可拟合 planner 温度）。
- **最小包**：E1 重放扫描 0 GPU/1.5 周/¥0（复用 512k CRN 二元结果 + scripted P2 + 合成计划族）；E2 接口偏差 4 GPU-h/1 周/¥30（L1/L2 日志取 500 入口态重放 S7/S8）；E3 分配替换 12 runs×N=2048≈38 GPU-h/¥270（**砍 G1b fixed-B 次要协议换此项，预算中性**）；E4 H 扫描 0 GPU。合计 ≈42 GPU-h、¥300、5 周。
- **区别**：P2P（2606.26428）单策略规模；ADEPT（2608.19182）单技能后训练；OmniReset（2603.15789）改 reset 分布；SGS（2610.12465）是 band 采样权重、无 plan 概念；SER（2511.21011）改 reset 时序；LGA 现版用 LP×σ̂、无组合项 → **LGA-C** 把技能分数换成 Λ_s=Σ_π ω_π c²_{π,s}v_s（组合口径的 Neyman 权重，可证 minimax），并加接口覆盖配额。
- **不是 incremental**（审稿人原话）："不过是 margin condition + Neyman 换权重。" → 贡献不是界，而是三个反直觉可检验推论（弹性律；ECE 与组合最优**反序**；分配收益**只在窄 SNR 带**存在）+ 一条不随 n 消失的偏差通道；且它**判定你们自己的 H2 阈值不可达**——可被现有数据立刻否证。
- **S 增量**：N+0.25、TQ+0.20、Insight+0.45、Exp+0.10、C+0.05、Rep 0 ⇒ 加权 ≈+0.33~0.40，S 3.93~4.00（能否 ≥3.95 取决于 Insight 是否被读成定理）。
- **venue**：ICLR 2028 主投（理论+相图）；CoRL 版保留机器人、基准与 agent。
- **风险/rebuttal**：相变不可见 → 双通道诊断树（全在同侧／偏差主导）都有故事；4 技能太 toy → 给 (H,B) 相图让读者自定位；scripted≠LLM → 报 argmax 一致率与温度。

## 候选 B：组合感知校准（CCE）——只换度量 + 一条定理

- **thesis**：不动训练与分配，只把"校准"从概率层搬到**决策层**：CCE = SNR 可靠性图偏差（计划对按预测 ρ 分箱，实测选中优计划的频率应≈Φ(ρ/√2)）。
- **缺口**：ECE 是边际泛函（1904.01685 证各变体互相矛盾），planner 用的却是**差值/排序**；conformal 给覆盖率而非决策 regret（2306.10193）。
- **形式化**：CCE=sup_t|obs_t−Φ(t)|，t=Δ̂/D̂，零自由参数 ⇒ 预测可直接否证；Thm 2 用作"为何 CCE 与 ECE 排序不同"。
- **预测**：①scripted 曲线落 Φ(·) 上；②LLM 曲线左移，σ_LLM/σ_stat≈2–4；③CCE 与组合成功率的相关 > ECE 的相关（Steiger）。
- **包**：E1+E2，4 GPU-h，¥30，3 周。
- **区别**：不改分配，与 SGS/LGA 正交；与 conformal 之别在对象为决策而非覆盖。
- **不是 incremental**："自定义指标易自证" → 指标有零自由参数的解析预测值，还能反估 planner 噪声。
- **S**：N+0.10、TQ+0.15、Insight+0.20、Exp+0.05 ⇒ +0.15~0.20，S 3.75~3.80。
- **venue**：CoRL（稳）。**风险**：P1≡P3（LLM 不用 p̂）则 CCE 退化；rebuttal：这正是 RQ3 负结果判据，scripted 臂仍立。

## 结论

A 是唯一有机会到 3.95 的：把论文从"测量"变成"技能库可组合性理论 + 反直觉分配结论"，核心实验几乎免费（复用旧数据）、预算中性（砍 fixed-B）。B 稳但只到 3.78 左右。诚实口径：A 全成时 CoRL 单会期望约 45–50%（质量 58–62% × exec 0.80–0.85）；ICLR 理论匹配更好，**可能**首次把单会推到 50% 附近，但不承诺。前提是 W6 前重写 §4、主假设改为"相变+错配"、H1/H2 降为支撑证据——这是定位级改动，不是加实验。
