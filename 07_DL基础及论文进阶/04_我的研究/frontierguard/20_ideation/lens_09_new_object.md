# Lens 09 — 发明新形式化对象

## 候选 A：Recovery Value —— 越可靠的技能库越不可识别

- **thesis**：库的真实价值是"失败后能否选对替代"；该泛函只由失败率供数，故 p_top→1 时必然不可识别，per-skill 校准/分配对它零收益。
- **第一性缺口**：工具学习（SayCan 2204.01691、Voyager 2305.16291、Gorilla 2305.15334、ToolLLM 2307.16789）把失败处理写成固定 fallback——本项目 `recovery_hint:"retry_if(p<0.5)"` 正是此类固定函数；决策校准线（Zhao 2107.05719、Kiyani 2510.23471、Tang 2504.15615）与 conformal 均假设决策分布、支持集固定、不随策略变。真实机制是 **planner 的策略决定采样支持集**，失败态的支持只由 (1−p) 供数。不是"没做"，是目标函数里没有"恢复"项。
- **形式化**：失败态 x∈X_fail，替代集 A(x)；
  **RV(L,Q)=E_{x∼X_fail}[max_{g∈A(x)}p_g(x) − p_{Q̂(x)}(x)]**；识别模 ι(Q)=sup{|ρ_k(L)−ρ_k(L′)| : TV(P_Q(·|L),P_Q(·|L′))≤ε}。
  - **Thm A1**：fallback 为固定函数 ⇒ 任意 n 下 ι=Θ(1)（两库在 supp(Q) 上同分布、失败态上不同）。故现有 `recovery_hint` 下"库知道失败后怎么办"是未识别命题。
  - **Thm A2（单调律）**：以置信 1−δ 分辨间隔 Δ 的 k 个替代，每替代需 n≥2z²σ²/Δ²；每次失败以 ε/k 概率喂给某替代 ⇒ 失败样本 F≥2z²kσ²/(εΔ²)，而 F=N(1−p_top) ⇒ **N ≥ 2z²kσ²/(ε(1−p_top)Δ²) ≈ 8kσ²/(ε(1−p_top)Δ²)**（z=1.96），对 p_top 严格递增：**技能越可靠，库越不可恢复**，与分配、校准无关。
  - **Cor A3（相变）**：N<N_c 时 RV 误差恒 Ω(Δ)，N>N_c 后按 N^{−1/2}；k=3,σ=.5,Δ=.1,ε=.25,p=.9 ⇒ N_c≈2.4×10⁴（LLM 口径超预算 28×，仿真口径仅 0.6 GPU-h）。
  - **RV-LGA**：在 LGA 预算中划恢复配额 ε*=min{1,√(8kσ²/(N(1−p)Δ²))}，fallback 加随机化地板。
- **可证伪预测**：①固定 `recovery_hint` 时替代排序与 CRN 真值一致率<60%（近随机），地板 ε=.25 后≥85%；②RV 随 p_top 单调：S7(p≈.55) 的 RV≥8pp 且与 S1(p≈.85) 差≥2×，无关则单调律被否；③识别误差–N 曲线在 N_c 处拐折，位置与公式差≤2×；④ε:0→.25 使 L1 成功率净变化≥0 且方差下降。
- **最小包**：E1 合成 10⁵ eps（0 GPU/2 周/¥0）；E2 失败态反事实重放 1,500 rollouts（0.2 GPU-h/1 周/¥0，复用 512k CRN + agent 日志）；E3 识别曲线 5×3×100（2 GPU-h/1 周/¥15）；E4 agent 2 种 fallback×2 任务×80 eps（¥245/1 周）。**合计 ≈3 GPU-h、5 周、¥260，全部本地 4070**；依赖：4 技能、L1/L2、CRN、`recovery_hint` 字段。
- **逐条区别**：P2P/ADEPT＝单技能规模与真机；OmniReset/SGS＝训练期 reset 分布、无失败态；SER＝reset 时序；LGA＝支持集**外生**下的 Neyman；CAPS(lens_04)＝上下文维度不可分辨+回放证书；**我们＝失败态根本没有数据，且供数率 ∝(1−p)**，故重加权/多采样无解。与 performative prediction(2002.06673)、退化反馈(1902.10730) 之别：他们证效用塌陷，我们给识别模+闭式预算相变。
- **不是 incremental**（审稿人原话）："active learning + fallback 而已。" → ①单调律方向在 AL 中不存在；②给闭式 N_c 而非启发式；③判定"更好校准"对本目标零收益，且可被现有 CRN 立刻否证。
- **S 增量**：N+.65、TQ+.25、Exp+.10、Ins+.60、C+.10、Rep 0 ⇒ **ΔS≈+.375，S≈3.98（3.94–4.02）**。
- **venue**：ICLR 2028 主投（形式化+反直觉律）；CoRL 版只留 §2+E4。
- **风险/rebuttal**：①RV<3pp → 改写"库的鲁棒性来自 fallback 近优"（正结果，S 回落 3.85）；②LLM 不用 p̂ → scripted 为主臂；③"不可识别是定义废话" → 承认方向平凡，贡献在量（N_c 闭式）与单调律，并用 CRN 真值直接测识别误差曲线。

## 候选 B：Plan Entropy —— 库的复杂度是 H(Π)，不是 S

- **thesis**：可达决策精度由**有效计划数** H(Π)=log|Π| 与噪声 D 决定（选择误差≈D√(2H(Π))），不由技能数 S 决定；类型化剪枝在固定预算下换到 √(log|Π_t|/log|Π_f|) 的精度，故"4 技能太小"问错了轴。
- **第一性缺口**：工具学习把库大小当能力（Gorilla、ToolLLM：API 越多越好）；技能库 scaling（lens_06 线）只看 per-skill 曲线；无人把**计划集大小**写进噪声项并给剪枝判据。union bound 人人会写，但"库结构→选择噪声→成功率"的定量链与最优点没人给。
- **形式化**：U(Π)=V(Π)−D√(2log|Π|)。**Thm B1**：flat 组合 log|Π_f|=Θ(H log S)；类型化后 log|Π_t|=log|Π_f|+log ρ（ρ=可行率），噪声比 √(1+logρ/(H log S))。**Thm B2**：U 在 |Π| 上有唯一内点，S*(B) 由 V′(|Π|)=D/√(2|Π|log|Π|) 给出，S>S* 加技能严格有害。**Cor B3（剪枝悖论）**：ρ→0 会删掉高价值计划使 V 下降，故 ρ 亦有内点 ρ*；"加类型"与"加技能"共用同一预算。
- **可证伪预测**：①合成 S=4..16 固定 B，错误率对 √(log|Π|) 线性（R²≥.9，斜率即 D√2），U 在 S∈[4,16] 有内点；②真实 4 技能类型化后错误率降至预测比 ±25%（对应 +3–6pp）；③S=6 vs 4 固定 B 下 U 不升（若成功率升≥3pp 且 U 升，则 S*>6，内点判据错）；④实测 D 与 CRN 方差预测差≤30%。
- **最小包**：E1 合成扫描（0 GPU/1.5 周/¥0）；E2 重放估 D 与 |Π|（0 GPU/.5 周/¥0）；E3 agent 类型化 2×2×80 eps（¥245/1 周）；E4 4 vs 6 复用 W17–22（边际 0）。**合计 0 GPU、4 周、¥245，本地**。
- **逐条区别**：与 P2P/ADEPT/OmniReset/SGS/SER 正交（不问计划集）；与 lens_06（per-skill 幂律）不同——我们给**计划集**复杂度项；与 LGA 互补（LGA 分预算，我们决定**该有多少计划**）。
- **不是 incremental**（原话）："union bound 谁不会。" → ①把 H(Π) 立为库的复杂度度量并实测斜率；②内点 S*(B) 与剪枝判据；③"技能数不是轴"直接反驳本领域最大审稿意见。
- **S 增量**：N+.45、TQ+.25、Exp+.15、Ins+.45、C+.10 ⇒ **ΔS≈+.30，S≈3.90**（单独不到 3.95，是补丁）。
- **venue**：CoRL 2027（稳）；NeurIPS D&B 备。
- **风险/rebuttal**：①"类型化=prompt 效应" → 同 LLM 同信息、只改可行集，加 scripted 臂；②S* 不显著 → 退为"H(Π) 是正确复杂度轴"的测量结论。

## 本视角结论

**有路，但只有 A 单独够到 3.95**：ΔS≈+.375 → 质量 57–60%、exec .85 ⇒ 单会 48–52%（点估计 50%，边缘，不承诺）。B 单独 3.90 但几乎免费，应并入 A 的"计划集复杂度"一节或作独立补丁。两者共享同一批 CRN 与 agent 日志，合计 ≈3 GPU-h、¥260、6 周；可砍 G2 消融 4 变体（8 runs ≈¥200）腾预算。诚实：A 成败押在"RV≥8pp 且随 p_top 单调"，不成立即回落 3.85（期望≈45%）。
