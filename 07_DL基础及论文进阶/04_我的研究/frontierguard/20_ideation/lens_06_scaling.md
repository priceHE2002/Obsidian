# Lens 06 — Scaling laws / 计算最优分配 / 数据配比

## 候选 A：库级标定律 —— 分配指数 κ、可加性失效、"分配何时没用"的闭式界

- **thesis**：每技能成功率 `p_g(C)=p_g^∞−a_g C^{−α_g}`；库级最优分配只由一个指数定：`C_g*∝(w_g a_g)^κ`，`κ=1/(1+α)`；共享 trunk 使"技能可加"失效，用 6×6 干涉矩阵 Λ 修正；以 held-out 技能/预算检验，并给 uniform 后悔的闭式界。
- **缺口**：分配只依赖曲线曲率；P2P（24,576 envs×7 天）/ADEPT 只报单个工作点，p(C) 曲率从未在 <2pp 误差棒下测过。配比律（2403.16952 / 2407.01492 / 2405.14908）假设域可加、目标是单一 loss，无"库 + min-skill 下限"结构，也从未检验共享参数下可加性。缺口是**形状**，不是规模。
- **形式化**：`log(p∞−p)=log a_g−α_g log C_g+α_gΣ_{h≠g}λ_{gh}s_h`，Λ=0 即 Chinchilla 型（可 LR 检验）；带下限 KKT→water-filling。**命题 R**：`U*−U_uni≈½·r̄·(1−κ)²·Var(log(w_g a_g))`——指数同质时分配收益是二阶小量（实测 <1pp）；收益只能来自 α 异质、下限 binding、Λ≠0、c_g 异质，四者皆可测。
- **可证伪预测**：P1 6 技能×6 预算（15.6–500M）分层拟合 R²≥.95、残差≤2.5pp、κ 的 CI 宽≤.20。P2 Λ≠0（LR p<.01，≥6/30 显著），修正后集中度比 ρ≥1.15。P3 仅用 ≤125M 五点，外推 500M 的 p 误差≤4pp、分配达 oracle 网格 90%、比 uniform 高≥5pp。P4 **份额预算不变性**：纯幂律下 argmax 份额与总预算无关（125M vs 500M 漂移≤5pp）；下限 binding 时弱技能份额随预算升——方向即判别律型。P5 held-out S3/S4 用 2 个早期点+3 描述子，500M 误差≤6pp。P6 |α(N2048)−α(N8192)|≤.10。
- **最小实验包**：**386 GPU-h**（租 340 / 本地 46）、14 周（W9–W22）、**¥3,965**：12 长 run（6 技能×2 seed 至 500M，6 checkpoint×1,000 CRN）+18 独立 run 校 LR/checkpoint 偏差+6 shift run×2 seed 测 Λ+4 held-out+8 N 臂+6 容差；拟合/层次模型/干涉共 14 人日。比现方案少 4 方法主格与 9 变体消融（省 ~15 人日）。
- **区别**：P2P/ADEPT 报点不报线；OmniReset 扩 reset 分布非技能预算；SGS 是 2^20 在线三档启发式，无律无外推（本文可证其为 α 同质特例）；SER 正交；LGA 降为无模型 baseline，regret 由命题 R 预测。
- **规模差为何是卖点**：①形状 vs 水平——分配只吃曲率，而大厂 7 天只产一个工作点；②干预 vs 观测——2^20 envs 一周只能试一种分配，500M 可做 6 预算×6 技能×2 N 的受控网格；③指数可移植——若 α 对 N 不变（P6），500M 测出的指数就是**大尺度一次 run 即可证伪的命题**，比"我们也跑得大"更可引用。
- **非 incremental**："只是对 36 个点做 y=a+b·log x" → 贡献在**对象**（带下限与干涉的库级律）、**检验**（held-out 技能+2 doubling 外推，非 R²）、**否证**（可加性不成立，而配比/课程方法都默认它成立）。
- **S 归因**：N+.60、Ins+.70、TQ+.15、Exp+.10、C−.08、Rep+.05 → **S≈3.93**（Λ≠0 且外推达标 3.97）。
- **venue**：NeurIPS 主、CoRL 备。
- **风险**：①checkpoint 被 LR schedule 污染→常数 LR+18 独立 run，把偏差当测量量报；②成功率有界→拟合可约间隙+logit 幂律 fallback；③曲线少→层次 pooling+held-out 技能，证据单位是预测；④Λ 欠功效→只报存活项，聚合 ρ 为主终点。

## 候选 B：成功率的标度是"度量依赖"的（容差 × 指标）

- **thesis**：成功率是阈值化有界指标，指数随容差（1/3/5mm）与指标（二元 vs 连续进度）系统变化；测此偏差并换算成"度量→分配"后悔 `R=[U(α₁)−U(α₂)]/U*`。
- **缺口**：2304.15004 只证指标会改"涌现"结论、止于 LLM；机器人 scaling 一律报单容差，没人问指数是否指标的产物，更没算它对分配的影响。
- **预测**：B1 |Δα(1mm,5mm)|≥.15 且符号预先写死；B2 二元 vs 连续 |Δα|≥.15；B3 N 不变性同 P6；B4 共享 α 的 pooled 模型 ΔWAIC<4。
- **实验包**：复用 A 全部 run，边际≈0（只改日志与评测口径）+S7 三容差 6 run；仍 386 GPU-h、10 周、¥ 不变。
- **区别**：把"成功率"当对象，不是再报 benchmark；SGS/OmniReset 不拟合指数。
- **非 incremental**："Schaeffer 机器人版" → 他们问"是否涌现"，我们问"算力放哪"，并给后悔量级与容差-指数斜率。
- **S 归因**：N+.35、Ins+.50、TQ+.10、Exp+.05、C+.05、Rep+.05 → **S≈3.83**。venue：NeurIPS D&B。
- **风险**：若 R<2%，结论改为"标度律对度量稳健"，仍可引用。

## 本视角结论

- **能到多少**：A 点估计 **S=3.93**（3.88–3.97）→ 质量 ≈58%、exec .80–.85 → 单会 **46–49%**；B 3.83 → ≈46%。**都不到 50%**；>50% 需 Λ≠0 与外推同时成立（P≈.35）再叠 exec .85。这是"38%→47%、且把方差换成可解释方差"的视角，不是银弹。
- **4–6 技能 / B≤500M 够不够**：够**库级**律（6 曲线×6 预算×2 seed、5 个 doubling、层次 pooling、2 个 doubling 外推），不够**普适**律；把"可预测视界"当测量量报告，规模短板即变科学量。6 技能从"加分"变"承重"。需 ≥36 个拟合点+12 个 held-out 点。
- **最推荐**：**不替换、换头**——A 作 §3（律 + "分配何时没用"的界）、校准作 §4（曲线即 p̂ 的参数化，白得校准）、agent 作 §5。守住"技能库+agent"原目标，贡献类型从"分配方法"换成"标定律+否证"。命题 R 还解释现方案 H1a 的 6pp 为何难达（平滑幂律下 <1pp），可作 W24 决策依据。
- **只做一件事**：先做 P4+P6，用现有 125M/500M 与 N=2048 的 run，2 周内判定律是否成立，是全部叙事的开关。
