# R2-agent · 执行证书：给"要执行的那个计划"下界，而不是给 p̂ 更准

**一句话 thesis**：组合让技能 API 的边际失效（孤立评测分布 ≠ 计划诱导入口分布），所以 planner 要的不是更准的 p̂，而是**对即将执行的那个计划给下界**；证书只在"W(m)<Δ/2<β̃"这条窄带里严格优于点估计，带外它更贵或更差——这条带可算、可测、可预注册。

**核心形式化对象（E-cert）**：三元组 (L_π, δ, C_π)。L_π = 计划 π 在**计划诱导入口分布**下成功率的单侧下界（P(S(π)≥L_π)≥1−δ，对 π∈Π̂ 同时成立）；C_π = 达到它的技能调用数（成本注记，使证书成为可设计变量）。planner 动作集 {执行 argmax L, 追加采样, 弃权}。β_g(π)=p_g^comp(π)−p_g^iso；β̂_g 是池化一阶修正，残差 β̃_g(π) 是**计划索引**且不随 n 消失的偏差——这是与所有"边际校准"工作的分界线。

**T1 适用带**：两实例上 π1,π2 的孤立边际观测完全相同、联合序相反，|ΔS|=Δ。则 (i) 任何只吃孤立边际的点 planner 的 sup 期望 regret ≥ Δ/2，**与 n 无关**（Le Cam 两点）；(ii) E-cert 取 m≥8log(2k/δ)/Δ² 即 regret 0（Hoeffding+乘积界，常数复用 17 的 2H(R+1)）；(iii) 故证书严格优于点估计 ⟺ **W(m)<Δ/2<β̃**。带外两侧：β̃<Δ/2 点估计已够；W≥Δ/2 谁都不行 → 弃权区。这是 (β̃,Δ,m) 的二维相图，合成 oracle 可精确画（0 GPU）。
**T2 弃权/追加**：追加 ⟺ σ/(2m^{3/2})>c/λ ⟺ m<m\*=(σλ/2c)^{2/3}；分辨率 m=z²S(1−S)/Δ²（Δ=5pp→346；m=200/350/500→±6.6/5.0/4.2pp）。弃权三条任一：L_max<τ；m\*(Δ̂)>余预算；两轮追加 L 增益<1pp。歧义集内仍执行 argmax L，得 **P(S(π_exec)≥L\*)≥1−α**——**执行下界**而非识别正确（BAI 与 conformal 都不给这条，弃权才因此可行）。
**T3 成本**：等预算下复用带 W_amort=S·H√(vH/B)/q_min，直采带 W_joint=√(kHS(1−S)/B)；W_joint<W_amort ⟺ k<k\*=H²(1−q)S/[q(1−S)]（H=3,q=.7→2.0）。故 k≥3 复用更省（k=10 省 5×）但宽 H 倍 → 两阶段成本 D·m₁+k′(m₁)Hm₂，最优点 m₁\*=(2σ²/Δ²)ln[(k−1)Δ²Hm₂/(2σ²D)]：**筛选深度只随裁决深度对数增长**；k=10,D=9,m₂=400→m₁\*≈400（6.3k vs 两端 8.7k rollouts）。

**与 21 的差异**：①21 的 q_i 未定义边际、β 只是补丁；本方案 q_i(π) 计划诱导、β 由入口态重放**可测**。②21 的 propose-certify 无成本定理；本方案给带、k\*、m₁\*。③21 的 agent 实验（2×2+剂量）把"证书"与"校准"混为一谈；本方案改 4 级阶梯：point → point+β̂ → 边际区间 → E-cert，每级只加一件事，主端点改 regret。

**实验最小包**：2 任务（L1 S1→S7→S8、L2 S2→S7→S8，H=3,R=2）×2 β regime（B0 规范入口 β≈0；B1 组合入口 β≥15pp）×4 条件×2 proposer×40 eps = 640 eps；另 interface ladder（I1 文本/I2 结构化/I3 工具强制）2×20×2=160 eps。**主端点 regret**（配对 n=80、SD .12→MDE 3.8pp）；success 只作描述（MDE 22pp）。设计规则：取 Δ≈SD_β≈8–10pp，则 E[regret]=Δ·2(1−Φ(Δ/√2SD_β))≈3.9–4.8pp，正好可测。β 操控检验=入口态重放测 SD_β。scripted 臂 40 eps 只是下限（≈3 GPU-h），pilot SD>.15 则预注册扩到 120 eps。LLM：Qwen2.5-7B-Instruct 本地 vLLM 4-bit、T=0、seed=0 + 2 API 快照（gpt-4o-mini-2024-07-18、deepseek-chat）；prompt v1.0 sha256 冻结、内容寻址缓存、报 vLLM/CUDA/量化版本串、5% prompt 重跑测 T=0 抖动。
**成本**：GPU ≤15 h（本地免费+租 20 h≈¥150）、LLM ¥450（800 eps×8 calls×2.2k tok≈15M tok+30% 冗余）、14–16 人日 → **≈¥600、8 周（W13–W20）**；替换 21 的 E4/E5（原 ¥641），净增≈0。

**S 与两口径**：ΔN+.20 / ΔTQ+.25 / ΔExp+.35 / ΔIns+.10 / ΔC+.15 / ΔRep+.10 → **ΔS=+0.21，S=3.72（3.66–3.78）**；CoRL 46%、ICLR 44%、级联 56%。**单独不过线，必须说明**。作 D 叙事脊柱：3.75+Exp.35/TQ.10/Ins.05 → S=3.85，CoRL σ(1.15×0.19)=58.6%×exec .87=**51%**、ICLR 48%、级联≈59%。正文 **0.75 页值得**（全文唯一回答"实践者该怎么做"，即 R3 的 weak-reject 理由）；LLM 接口律 0.5 页进 §5。

**最强攻击与预驳**：①"OCBA/R&S+conformal 换皮"→ 承认分配部分是 OCBA 特例、明确不作贡献；R&S 假设无偏可采样，本文核心是**内生、计划索引、不随 n 消失的 β**，并给 R&S 没有的执行下界与 k\*、m₁\*。②"β 是自造缺陷"→ 双 regime 操控+sign-flip 交互，无交互就如实报 β≈0。③"prompt 工程"→ scripted 主臂+CI 单变量+三级 interface。④"4 技能非库"→ 合成 20–100 技能验 k\*、m₁\*（0 GPU）。

**最大风险/fallback**：W6 测 SD_β；若 SD_β<0.5Δ（regret 上限<2pp）→ 转"证书成本–覆盖前沿"版（T2+T3+覆盖/弃权曲线+LLM 接口律），S≈3.68、CoRL 44%，并入 D 的测量章。LLM 全 null 不触发 fallback：它已预注册为**测量**（κ_CI<5%、κ_p>35%、recall 饱和）而非检验；若 LLM 真的忽略两阶信息，结论改为"证书必须由工具强制（I3），不能靠 prompt"——比"LLM 会用区间"更有用，且两种结果都成立。

**独立新颖性**：SayCan 把 affordance 当已知标量（无区间、无弃权）；ReAct 无统计量；Being-0 / CLASP 是系统（VLA+技能 / 语义关键点），不报 plan 级不确定性；decision calibration 在同一分布上校准单预测器，无 H 步依赖、无弃权成本；KnowNo / LBAP / Introspective 校准的是**任务意图歧义**（要不要问人），本文校准**可执行性**（组合入口偏移），二者正交，β 只在前者缺席处出现。
