# Lens 04 — agent 不确定性：工具 API、规划、可验证性

## 候选 A：CAPS —— 校准只值一个 log：从 per-skill 校准到 plan 级证书

**thesis**：技能 API 报的是边际 p̂，planner 要的是计划级保证；两者之间隔着 planner 自己诱导的查询偏移。我们证明：边际标量接口在 ECE=0 时仍可产生 Θ(1) 计划误差；而任何**带证书**的规划，回放成本下界 Ω(σ²/Δ²) 与 p̂ 无关，校准只在 ECE≪Δ 时省一个常数因子、并最多把 log|Π| 换成 log k——**校准的价值是相变的、有天花板的**。

**缺口**：SayCan/CaP/ReAct/Voyager/LLM-Modulo 把工具成功率当已知标量消费（2204.01691 / 2209.07753 / 2210.03629 / 2305.16291 / 2402.01817）；校准文献全在边际上做（2305.14975、2302.09664、2107.07511）；技能库报训练分布下的 p̂。三方交集的问题从未被命名：**p_g(x) 依赖 planner 选的 x，而 x 由 p̂ 决定**。不是"他们没做"，是目标函数里没有这一项。

**形式化**：计划 π=(g_i,x_i)，S(π)=∏[1−(1−p_{g_i}(x_i))^{R+1}]；偏移 w=dP_query/dP_cal。
- **T1（不可能性）**：p_A(x)=1−p_B(x) 在 X1/X2 取 0.9/0.1。边际 p̂_A=p̂_B=0.5、ECE=0；两计划真值 0.81 vs 0.01，planner 只能抛硬币 → 期望损失 0.40，**且不随校准变好而下降**。
- **T2（认证）**：LLM 出候选集 Π̂（|Π̂|=k），回放做 LCB 逐次淘汰：P(Δ-最优)≥1−α−δ，n=O(σ²(log k+log(1/δ))/Δ²)，**不依赖 p̂ 偏差**——偏差不随 n 消失，故证书不能吃 p̂。
- **T3（天花板）**：ECE≳Δ 时校准对证书零价值；ECE≪Δ 时至多省常数因子（方差比）+ log 因子。
- **T4（U 形）**：C(k)=c_LLM·k+n(k)，Δ_k 随 k 递减 → 存在内点 k*。

**可证伪预测**：①p̂ 注 ±10pp 噪声，CAPS 成功率变 <3pp，去认证层则降 ≥15pp；②成功率≈提案召回（斜率 1±0.15），而非 ≈1−ECE；③成本对 ECE/Δ 呈**相变**：<0.5 平坦、之后陡升，拐点先验预测误差 ≤2×；④20 个配置上 |ρ(ECE, top-k 召回)|<0.3。

**最小实验包**：合成库（CPU、10⁵ episodes，可精确算 w 与 π*）2 周 ¥0；LLM 本地 vLLM Qwen2.5-7B/14B（4070TiS 4-bit）主扫 + 2,000 eps API 复现，¥300–500、4 周；灵巧实例 S1/S2/S7/S8 仅验证书覆盖率 60 GPU-h（本地 N=1024 + 租 A100 20h）≈¥300。**合计 ≈¥900、10–12 周、≤120 GPU-h**。

**逐条区别**：P2P/ADEPT＝规模与真机（正交）；OmniReset/SGS＝task 级 reset 分配，我们＝plan 级证书与接口语义；SER＝reset 时序（无关）；LGA＝最小化**估计**误差（Neyman），CAPS＝最小化**决策**错误（margin 加权），LGA 降为采样器与 log 因子的来源；SayCan 等假设 affordance 可信，我们证明该假设在组合下失效。

**不是 incremental（模拟原话）**："conformal + bandit 拼装。" → 单独都不成立：conformal 给边际覆盖，而 planner 的选择是自适应的；bandit 需候选集，而召回不能由 p̂ 推出。T1/T3 是关于**接口该报什么**的陈述，不是关于估计器的陈述。

**反"prompt 工程"五件套**：①合成环境有 oracle 真值，π* 可精确算；②脚本 planner 对照（同算法、无 LLM），效应仍在即非提示词；③CRN 配对，只改 API 载荷；④CI 宽度单变量干预（分离二阶信息使用）；⑤预注册斜率/拐点，不是方向。

**S 归因**（权重由 S=3.60 反解：N.25/TQ.15/Exp.15/Ins.25/C.10/Rep.10）：N 3.25→3.95(+0.70)、Ins 3.45→4.00(+0.55)、TQ 3.85→4.05(+0.20)、Exp 3.65→3.80(+0.15)、C 3.80→3.90(+0.10)、Rep 4.40→4.40 → **ΔS=+0.375，S≈3.98（3.88–4.05）**；质量 57–60%，exec 0.85–0.90 → 期望 **50–54%（点估计 52%）**。

**venue**：ICLR 2028 主投（形式贡献 + LLM 行为）；CoRL 2027 先投机器人厚版（质量≈52%）。

**风险/rebuttal**：①"BAI 现成"→ 承认，贡献在 T1/T3 的接口分离与天花板；②"召回太高、问题不存在"→ 预注册：k=10 召回>0.95 则退化为"证书的成本收益"论文，U 形仍在；③"合成太干净"→ 灵巧实例 + 真实工具 API 复现。

## 候选 B：RECALL —— LLM planner 的 CI 盲视与召回律（受控测量）

**thesis**：LLM planner 是"点估计阈值机"：对 p̂ 敏感、对区间宽度不敏感；故"把 p̂ 校准得更好"有用，"报更宽的区间"无用。用已知真值的受控环境给出行为律 + 召回–成本律 + API 准则。

**缺口**：calibration-for-agents 假设 agent 会用二阶信息，却从未在 oracle 真值下因果测过；也没有 benchmark 能**只调 ECE**而不动其他量。

**形式化**：CI-sensitivity=P(仅改区间宽度时计划翻转)，point-sensitivity=P(仅改 p̂ 时翻转)；行为模型 π̂=argmax∏q̂(p̂) 可拟合；召回–成本律 C≈c·k+n(k)。

**预测**：①CI-sens<5%、point-sens>40%（同 10pp 扰动）；②12 个 API 条件下 |ρ(ECE, plan success)|<0.3；③LCB-only API 同 ECE 下 +8pp；④剂量斜率≈−H(R+1)（±2×）。

**实验包**：合成 6 域（|Π|=10²/10³/10⁴）+ MuJoCo 4 技能；6 planner×5 API 格式×3 seeds×100 eps≈9,000 eps（本地 7B 免费 + ¥400 API）；40 GPU-h；8 周；**¥600**。

**区别**：与 P2P/ADEPT/OmniReset/SGS/SER 全正交（它们不问 API 语义）；与 LGA 互补（LGA 产 p̂，我们测 p̂ 怎么被用）。

**不是 incremental**："benchmark 论文。" → 有预注册的**否定性行为结论**（CI 盲视）+ 可拟合行为模型 + 可操作 API 准则；oracle 真值排除测量伪影。

**S 归因**：N+0.35、Ins+0.40、Exp+0.20、TQ+0.05、C+0.10、Rep+0.05 → ΔS≈+0.24，**S≈3.84**；质量≈55%，exec 0.90–0.93 → 期望 **50–51%**。

**venue**：CoRL 2027 / NeurIPS D&B。**风险**：天花板低；若 LLM 真会用区间，故事反转为"LLM 会用二阶信息"，仍是正结果但 novelty 降。

## 本视角结论

1. **有路，且第一次真正触及 50% 边界**：A 期望 50–54%（S≈3.98），B 期望 50–51%（S≈3.84）但方差小。按 judge 自己的 σ 模型，A 恰好落在"质量 59%×exec 0.85–0.90"这条线上——是触及，不是保证。
2. **不要二选一**：B 就是 A 的 §4（行为测量）。合并后 exec 升到 0.88–0.90、质量不掉 → 期望 **52–55%**；且"oracle 真值 + 脚本 planner + CI 单变量干预"正是"不是 prompt 工程"的最强证据。
3. **代价**：A 把 LGA 降为组件、砍掉 493 GPU-h 主格（省 ¥3,900 / 30 周），与用户"大规模 RL 训技能"目标（1）有张力——需 Lead 拍板；4 技能资产与"技能即函数"目标保留。
4. **诚实**：+0.375 中 N+0.70、Ins+0.55 是最大假设，各有 ~30% 不成立概率；不成立则回落 S≈3.80、期望 45%。这是本视角唯一能过线的结构，但仍是边缘。
