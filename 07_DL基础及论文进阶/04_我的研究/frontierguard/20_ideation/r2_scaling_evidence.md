## 0. 模型（与 21 的 CSC 对齐）

- K 个技能，边际成功概率 q_g，缺陷 d_g = 1−q_g，假设尾部 d_g ~ G(d) = (d/d0)^κ（κ 为形状指数，κ=1 均匀，κ→0 重尾）。
- 计划 π = H 个不同技能；每个技能允许 R 次重试：q_i = 1 − (1−p_i)^{R+1}。
- 计划成功率 S(π) = E[∏ q_i]，依赖结构用 1 因子 copula：
  U_i = Φ(a_i Z + √(1−a_i²) ε_i)，corr(i,j) = a_i a_j；a_i = √ρ 即等相关。
  S 由 1 维积分精确算出（`plan_success`），ρ→1 退化为 comonotone（S = min q），ρ=0 退化为 ∏q。
- 认证 = 在 N 个候选计划上判"哪个最好"（排序证书），每个计划 m 次联合 rollout：
  L_i = Ŝ_i − ε − β，U_i = Ŝ_i + ε + β，成功 ⟺ L_(1) > U_(2)；
  ε = √(2s(1−s)ln(2N/α)/m) + (2/3)ln(2N/α)/m（Bernstein，s 为设计方差上界；Hoeffding 版为 √(ln(2N/α)/2m)）。
  预算 B = N·H·m（长度为 H 的联合 rollout 记 H 次技能执行）。
- **可认证占比** φ(K) := P(随机抽一个 K 技能库，其最优计划可被排序认证)。

## 1. 主定律（L1）

设相邻两个计划的成功率间隙为 Δ。对"最优 H 子集 ↔ 换掉最差一个技能"这一对：

  Δ = q^{H−1} · (R+1)(1−p)^R · Δp ,  Δp = 相邻技能的 p 间隙,

在尾部 d ~ (d/d0)^κ 的次序统计下 Δp ≈ (d0/κ)·H^{1/κ−1}·K^{−1/κ}，于是

  **Δ(K,H,p,R) = q^{H−1} · (d0/κ) · H^{1/κ−1} · (R+1)(1−p)^R · K^{−1/κ}**   (d0 = 1−p 的尺度)

由 Δ 的随机性（次序统计间隙近似指数/Gamma）得库级生存函数

  **φ(K) = exp[ −(K/K_c)^{1/κ} ]**，
  **K_c = [ c · q^{H−1}(d0/κ)H^{1/κ−1}(R+1)(1−p)^R / (2ε) ]^κ**，
  **B\*(K) = Θ( N H ln(2N/α) · K^{2/κ} / [ q^{H−1}(R+1)(1−p)^R Δp ]² )**

c 是把"单计划 ε"换成"对比 ε"的常数（两个计划共享 H−1 个技能，公共噪声相消 ⇒ 有效 ε 更小）：
仿真 H=3 时 **c ≈ 0.42**（≈ 1/(√H·1.4)，1.4 为 Bernstein 的保守余量）。c 是**唯一**自由常数。

**下界（匹配性）**：任何 α-正确算法至少需要 Ω(N/Δ²) 次 rollout（每个次优计划必须被压到 Δ 以下才能被排除，
标准 best-arm-identification 下界，Kaufmann–Cappé–Garivier, JMLR 2016）。故 L1 的 log 因子之外是紧的；
k-臂场景下 BAI 的经典复杂度即 Σ1/Δ_i²。

### 验证（精确 copula，reps=400–500/点）

| 检验 | 预测 | 实测 |
|---|---|---|
| Δ 对 K 的指数（κ=1） | −1 | **−0.973**（K=50…400） |
| Δ 对 K 的指数（κ=2） | −0.5 | **−0.454** |
| Δ 对 K 的指数（κ=1，全段） | −1 | −1.029（回归 logK 系数） |
| K_c 对 B 的指数（κ=0.5/1/2） | 0.25 / 0.5 / 1.0 | **0.278 / 0.568 / 1.018** |
| Weibull 塌缩指数 1/κ（R²，κ=1，B=1e7/1e8） | 1 | **0.993 / 0.996** |
| Weibull 塌缩指数 1/κ（R²，κ=2，B=1e6/1e7/1e8） | 1/2 | 0.995 / 0.990 / 0.970 |
| K_c 闭式 vs 拟合（κ=1，B=1e7 / 1e8） | 1.0 | **0.95 / 1.00** |
| K_c 闭式 vs 拟合（κ=2，B=1e6，K≥20 重拟合） | 1.0 | 0.66（尺度差 1.5×，形状对） |

κ=1、H=3、d0=0.4、ρ=0.3、N=10 的 φ(K) 原表（K=4,6,10,20,50,100,200,400）：

```
B=1e6 : 0.89 0.79 0.69 0.53 0.20 0.05 0.00 0.00
B=1e7 : 0.97 0.94 0.91 0.83 0.63 0.41 0.12 0.03
B=1e8 : 0.99 0.98 0.97 0.93 0.85 0.76 0.54 0.33
```
→ 固定 B 时 K 增大使 φ 单调崩塌；固定 K=100 时 B 每涨 10× 才把 φ 从 0.05 抬到 0.41 再到 0.76
（即"库大 10×，预算要 100×"：K_c ∝ B^{1/2} ⇒ B ∝ K²）。

## 2. 重试反演（L2）

Δ ∝ (1−p)^{R+1}（相对间隙模型；若技能间隙是**绝对**的，则指数为 R）。实测斜率（log Δ vs log(1−p)，K=20,H=3,κ=1）：

| R | 预测 R+1 | 实测 |
|---|---|---|
| 0 | 1 | **0.97** |
| 1 | 2 | **1.98** |
| 2 | 3 | **3.03** |

⇒ m\* ∝ (1−p)^{−2(R+1)}。**重试（提高单技能可靠性的标准手段）以指数 R+1 破坏可认证性。**
数值：R=2、p=0.95、K=100、Δp=5% ⇒ B\* ≈ 2.6e13 eps，是 R=0（1.8e9）的 **1.4×10⁴ 倍**。

另一个可配对数字（H 的指数）：Δ ∝ q^{H−1} ⇒ m\* ∝ q^{−2(H−1)}。
p=0.6 时 H: 3→6 使 m\* **×21**；p=0.9 时仅 **×1.9**。故"长计划惩罚"只在低可靠度区爆炸。

## 3. β 墙（L3a）

认证需要 Δ > 2β（β 为不可消除的建模/分布偏移余量，例如仿真-真机 gap）。由 Δ ≤ Δ_0 K^{−1/κ}：

  **K_β = [ Δ_0 / (2κβ) ]^κ，与 B 无关。** 超过 K_β，再多预算也无法认证。

实测（B=1e7，H=3，κ=1；Δ_0 = q²d0 = 0.36×0.4）：β=0.02 ⇒ K_β=3.6，
φ(K=4,10,20,50,100) = **0.55, 0.22, 0.07, 0.00, 0.00**（无 β 时为 0.96,0.91,0.82,0.63,0.41）。
β=0.01 ⇒ K_β=7.2，φ=0.72,0.49,0.25,0.04,0.00。断崖位置与预测一致。

## 4. 双轴相位图（L3b）

lens_06 的学习曲线 p(C) = p∞ − a C^{−α}（C=训练预算）。代入 L1/L2：

  K_c(C,B) ∝ B^{κ/2} · C^{−ακ(R+1)} ,  **B\*(K,C) ∝ C^{2α(R+1)}**。

在 (log C, log B) 平面上，**等保证线是斜率 2α(R+1) 的直线**：

| R | 斜率（α=0.15） | C: 125M→500M 时 B\* 倍数 |
|---|---|---|
| 0 | 0.30 | ×1.5 |
| 1 | 0.60 | ×2.3 |
| 2 | 0.90 | ×3.5 |

含义：(i) 训练预算增大使 S 变好但**使可认证库变小**（K_c ∝ C^{−0.15κ(R+1)}，4× 训练 ⇒ K_c ×0.81/×0.64/×0.51 对应 R=0/1/2）；
(ii) 两轴通过 R 耦合：R=0 时训练与认证近乎解耦（斜率 0.3，仍非零因为 Δ 含 (1−p) 的尺度项），R=2 时强耦合。
这就是"训练预算 vs 认证预算"的相位图：线下=不可认证，线上 K_c 随 B^{κ/2} 增长。
（注：α、a、p∞ 由 lens_06 的 386 GPU-h 实验给出，本轴只需代入，不需要新实验。）

## 5. 全库 vs 查询集（L4，爆炸项）

若要求认证**整个库**（N = K^H）而不是 planner 查出的 N 个候选：

  B\*_full = Θ(K^H · H · ln(2K^H/α) / Δ²)，即 **K^H·K^{2/κ}** —— 双重指数。

数值（H=3，κ=1，p=0.6，Δp=5%，α=0.05）：

| K | Δ | m\* | B\*(N=10) | B\*(N=K^H) |
|---|---|---|---|---|
| 4 | 3.6e−2 | 9.3e3 | 2.8e5 | 1.8e6 |
| 20 | 7.2e−3 | 2.3e5 | 6.9e6 | 5.6e9 |
| 100 | 1.4e−3 | 5.8e6 | **1.7e8** | **1.7e13** |
| 400 | 3.6e−4 | 9.3e7 | 2.8e9 | 1.8e16 |

⇒ "技能库必须可查询（planner 只评 N≪K^H）"从工程约定升级为**定理**：全库认证在 K=100 时需要 10¹³ 级 episode。
同时这也给出"库越大越不可认证"的定量版本：K 每 ×10，B\* ×100（κ=1）。

## 6. 对 21 的符号修正（重要）

21 的可证伪预测②称"正依赖下 marginal-only 证书覆盖率 < 1−α"。**符号反了。**

H=3，q=(0.70,0.65,0.75)，∏q = 0.3412，Fréchet 区间 [0.10, 0.65]：

| 联合律 | S_true | ∏q − S |
|---|---|---|
| 独立 | 0.3412 | 0 |
| 1 因子 ρ=+0.3 | **0.4152** | −0.074（∏q 偏保守，下界仍有效） |
| 1 因子 ρ=+0.6 | 0.4929 | −0.152 |
| 显式构造"恰好一个成功"（边际精确 = q） | **0.10 / 0.25 / 0.30** | +0.241/+0.091/+0.041（∏q **高于**真值 ⇒ 下界失效） |

"恰好一个成功"族：P(仅 i 成功)=q_i−s_0，P(全成功)=s_0，s_0 ∈ [0.10, 0.65]；边际精确等于 q，**完全合法**。
⇒ 乘积型下界在**正依赖时保守（覆盖 100%）**，在**负依赖时失效**。21 的预测②必须改方向，
否则审稿人用 3 行 Fréchet 反例即可击穿。修改后的正确陈述：
"marginal-only 乘积证书在 supermodular 依赖下有效但保守，在负依赖下失效；因此证书必须显式声明依赖假设或改用 comonotone 上界/反 monotone 下界。"

## 7. 与 21 的关系（为什么不是拼盘）

21 = 部分识别（Fréchet 界）+ 证书宽度 + 证书分配。它的统计对象是**单个计划**，K 只以 |Π| 出现在 log 里。
本提案的统计对象是**整个库**：K 以 K^{1/κ} 进入间隙、以 K^{2/κ} 进入预算、以 K^H 进入全库爆炸。
两者正交：21 的分配理论回答"给定 N 个计划怎么分样本"，本定律回答"K 多大时任何分配都不够"。
合装后 21 的 T2 上界变成 L1 的一个特例（N=|Π|），而 L1 提供 21 缺的**下界 + 相变 + 塌缩**。
