# 06 · 终稿 v3 的中稿概率复核（acceptance-judge）

| 项 | 值 |

## 3. H4/H8 的条件值（概率树）

- P(H4a 成立：≥1 个 任务×bucket 的 σ_a≥Δ_min/2 且 CI 下界>0) = **0.45**（DR 位姿 + 接触随机确有戏，但"CI 下界>0"是硬门槛）。
- P(FG 在噪声组显著优于 SGS-band | H4a 成立) = **0.55**（8 seeds，效应量可能小）。
- ⇒ P(噪声叙事可发表) ≈ **0.25**。
- P(H8 单侧显著且 ≥8pp) = **0.50**（pilot 门控会淘汰一批，但淘汰即走 D2，等于没有 H8）。
- **P(两者都成立) ≈ 0.25×0.50 ≈ 0.13**（v3 自估 ~35%，偏乐观）。
- 树：全好 0.15×56% + 主结果成立但机制弱 0.45×48% + 机制叙事失败/负结果 0.30×27% + 执行失败 0.10×14% = **39.5% ≈ 40%**。

**「条件上限」叙事审稿人是否接受？** **接受其诚实，但不为其付费。** 写作上把 H4a/H8 当 limitation 是加分（防 overclaim）；把它当卖点会被反问"那到底 general 不 general"。**别把这个分支写进中稿率论证——它是 13% 的彩票，不是设计目标。**

## 4. 内部一致性审计（重点）

**已核对通过**：1,178 runs = T1 492 + T2 686 ✓；本地 1,035.6 + 租卡 801.0 ≈ 1,837 GPU-h ✓；预算 ¥2,545/¥4,685/¥6,323 逐行复算 ✓（附录 D 实跑 ¥2,018→¥2,260→¥2,545，M9 修好了）；真机 540+90+270 ✓；TOST 2.5pp ✓；各格 runs = 任务×N×方法×seeds ✓。

**未闭合/矛盾（按严重度）**：

**① 致命：fixed-K 主终点未计价。** §5.3/§5.6/§12.2 标 T2-R1/R2/R3/R4/R5 为 K=1,172（fixed-K），但 §6.2 的小时按 B=15M（fixed-B）计：N=1024 应为 5.61 h/run（60M 步），预算只给 1.44 h；N=2048 应为 8.8 h，预算给 1.15 h。**若真按 fixed-K 跑，租卡 ¥2,018 → 约 ¥6,450（总价 ≈¥7,380），直接破 5,000；若按预算跑 fixed-B，则主终点不能是 fixed-K，M1/M2 名义化。** 二者必居其一，当前文本同时声称了两者。
**② 峰值占空比 52% 不实。** W10–W12 还压着 T1-B/T1-C（16.4 h/周），叠加后 ≈**104 h/周 = 62%**（§6.3 表漏了这一行），仍无重跑余量。
**③ 功效主张偏乐观。** n=90 的"15pp→power 0.8"需 baseline≈0.7 或 discordant≤0.3；n=180 的"10pp→0.45–0.5"需配对正相关。应写明假设的 discordant 比例（建议 π_d=0.35）。
**④ 小**：附录 D 与正文 GPU-h 漂 0.4–0.5 h；§12.2 个别行与本表差 0.1–0.2 h（无影响）。

## 5. 剩余 gap 与最小补救（≤3 项，按 pp/成本）

1. **修 fixed-K 预算（唯一能同时保住科学主张与钱的动作）**：主格改 3 方法（uniform/SGS-band/FG）×8 seeds×N{256,1024}=96+96 runs；N=2048 降为 3 seeds 或砍。租卡 +¥656 → 基准 ≈¥3,200（单因素 ≈¥4,600 仍闭合）。**+3~4pp，0 额外 GPU，2 天改文档。**
2. **T1-B/T1-C 移到 W13–W16**（与 T2-L2 错峰）：峰值回落 ≤52%。**+0.5pp（exec），1 天。**
3. **第 3 真机任务**（仅在 W24 pilot ≥8pp 时）：+2 人日、+270 trials，**+1~2pp**。
**不要再加**：seeds 8→12、MT50、HIL-SERL、第二个真机 embodiment、RGB 档 N=4096。
