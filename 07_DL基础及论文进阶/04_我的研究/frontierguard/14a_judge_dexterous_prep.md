## 3. 录用画像与 sim-only 评审标准

**ICRA 数据（仅作背景，不再是目标）**：`co:"ICRA 2026" AND abs:dexterous` 22 篇，真机/硬件 12 篇，纯仿真 RL 仅 1–2 篇 → 在 ICRA，sim-only 的**系统论文**确实无先例。

**CoRL 口径（主投）**：sim-only 是常态，**不构成主要扣分**（折价 0.95–1.0）。评审真正在意的三件事：① 任务是否真实、是否有代表性（灵巧手精细操作 ✓）；② 实验是否支撑 claim（✓ 若统计做足）；③ 与 P2P/ADEPT/SGS 的**机制差异**是否清楚（✗ 当前最弱）。CoRL 2026 已录 ADEPT（大规模 RL 灵巧预训练）与 SGS（success-band 采样）——**审稿人手上就有这两篇**。
**ICLR 口径（二投）**：embodiment 完全不重要，sim-only 无折价。但 ICLR 会问「ML 贡献是什么」——本方案若只是「搭系统 + 跑实验」，contribution 一栏会被打 1–2 分。ICLR 的最近邻不是 P2P，而是 **LLM agent + 工具/技能库** 与 **校准/不确定性用于决策** 两条 ML 文献线。

## 4. 六维 rubric（ML 会议口径）

| 维度 | 权重 | 1 分锚 | 3 分锚 | 5 分锚 |
|---|---|---|---|---|
| 新颖性/贡献 | **0.30** | 已有工作直接组合 | 各块有先例、问题定义有新意 | 新问题/新机制/新理论 |
| 技术正确性 | 0.20 | 形式化错误 | 自洽、有消融 | 有分析/定理支撑 |
| 实验严谨 | **0.30** | 单任务单 seed | 多任务多种子多基线 | 大 N scaling + 因果链 + 预注册 |
| 洞察与泛化 | 0.10 | 工程流水账 | 有可迁移观察 | 改变领域认知 |
| 清晰度 | 0.05 | 难读 | 结构清楚 | 图/视频有说服力 |
| 可复现性 | 0.05 | 无代码 | 部分开源 | 全开源 + artifact |

映射：**p = σ(1.15(S − c_v)) × sim-only 折价**。c 由「池均值 S=3.0 处等于该会录取率」定标：
- c_CoRL = **3.66**（CoRL 录取率取 32%，估计）；折价 0.97
- c_ICLR = **3.74**（取 30%，估计）；折价 0.95 ×「ML 洞察薄」适配罚 0.95
- c_D&B = **3.80**（取 25%，估计）

## 5. 先验计算

按「执行到位（8 技能、3 长程任务、无跨形态主线）」打分：
N 2.5、TQ 3.2、Exp 3.5、Insight 2.75、Clarity 3.5、Repro 4.5

S = 0.750 + 0.640 + 1.050 + 0.275 + 0.175 + 0.225 = **3.115**

- CoRL：σ(1.15×(3.115−3.66)) = σ(−0.627) = 34.8% → ×0.97 = **34%**
- ICLR：σ(1.15×(3.115−3.74)) = σ(−0.719) = 32.8% → ×0.95×0.95 = **30%**
- 级联（独立近似）：1 − 0.66×0.70 = **54%**；按相关性修正（同一弱点、改稿红利 +3pp）→ 二轮条件成功率 0.28 → **52%**
- 执行成功概率 **0.72**（scope 风险；砍到 8 技能并留 15% 缓冲后可达）
- 期望口径：CoRL 0.72×0.34 = **25%**；ICLR 0.72×0.30 = **22%**；级联 0.72×0.52 = **37%**

**与上轮 ICRA 口径对比**：期望 24% → **37%**。提升来自两处：去掉 sim-only 机器人相关性惩罚（+6pp 质量）、多一次独立机会（+13pp）。**但级联期望仍不到 50%。**

## 6. 单会 >50% 需要什么（诚实结论）

单会 p>50% ⇒ 需 σ(1.15(S−c)) ≥ 0.515/折价 ⇒
- CoRL：**S ≥ 3.65**（现 3.115，差 0.54）
- ICLR：**S ≥ 3.75**（差 0.64）

0.54 分是什么概念：Novelty 2.5→4.0（+0.45）+ Insight 2.75→3.5（+0.075）+ TQ 3.2→3.4（+0.04）。**这不是「写好一点」能拿到的，需要一次真正的机制或理论创新。** 三条可能的路径：

1. **加理论（最高 ROI）**：给出「per-skill 校准误差 → 长程组合成功率」的传播界（例如组合成功率的对数下界随 ECE 与技能数变化），并用它推导「校准驱动的技能选择」算法。TQ +0.6、Novelty +0.5、Insight +0.75 分档 → S≈**3.45**，CoRL 质量口径 **43%**，级联期望 **48%**。**这是唯一能在现有 scope 内把期望推到 48% 的动作。**
2. **换轨到 NeurIPS D&B**：评审标准不同（重 artifact 质量而非新颖性），但接受率更低（~25%）、且要按 benchmark 论文重写（数据集卡、许可证、覆盖度、基线 harness），是另一篇论文。
3. **加真机**：对 ML 会议**不加分**（ICLR 完全不看，CoRL 只是锦上添花），且用户明确不做 → 不列为路径。

**结论：单会达不到 >50%；级联在质量口径勉强 52%，期望口径 37%；把期望推到 48% 的唯一现实杠杆是「加理论界」。**

## 8. 加分 / 减分清单（ML 口径）

**加分**：① arXiv 摘要中 `skill library + dexterous` 仅 Being-0 一篇——「灵巧手技能库 + 校准 API + agent」组合真实空缺；② 校准 → 组合成功率的**因果链**是 ML 会议喜欢的「机制 + 实证」结构；③ 全开源、MuJoCo 系可复现（P2P 锁 Isaac Sim，我们门槛更低）；④ 预注册 + 多种子 + 功效分析（ML 会议比 ICRA 更吃这套）；⑤ 8 技能 × 大规模并行的 scaling 曲线有独立价值。
**减分**：① 三块拼盘、每块不深（系统论文的典型死法）；② FG 是上一轮方法复用，与本课题绑定弱；③ 无理论，ICLR 会直接打 contribution 1–2；④ agent 评测易被质疑为 prompt 工程；⑤ 8 技能成功率可能整体偏低，曲线难看；⑥ 与 P2P 规模差 1–2 个数量级，「不公平」的指控难完全消除。

## 9. 补偿策略（多会议口径）

1. **对 CoRL**：把 P2P 当「参照系」而非「基线」；用「同范式、开源手、1/10 规模」的对照讲**迁移中丢失了什么**（insight），不比数字。
2. **对 ICLR**：把论文重心从「系统」移到「**校准如何改变长程组合**」——给出传播界（§6-1）、在 3 个长程任务上验证、并说明该结论不依赖具体机器人。标题也要换（ML 化，弱化「灵巧手」）。
3. **开源 + artifact**：技能库、API schema、校准脚本、raw logs 全开源；投稿同日匿名 repo。
4. **视频**：90s，前 20s 展示 agent 连续组合 3 个精细技能的成功/失败对照——对 CoRL 是硬通货，对 ICLR 影响小。
5. **负结果与边界**：明确写 sim-only 局限；失败归因（执行失败 vs 规划失败）要能分开。
6. **统计换分**：预注册 + 功效分析 + TOST + ECE/Brier 置信区间。

## 11. NeurIPS 2027 D&B 机会项判断

**不建议分兵。** 三条理由：
1. **时间不成立**：D&B 截稿 W27，而技能库 + 校准要到 W24–W26 才成型，harness 冻结需 W22 前 → 实际要在 W20 前后分兵 3–4 周，正好撞在主 scaling（W13–W20）与 agent 评测（W27–W32）之间。
2. **评审口径完全不同**：D&B 要数据集卡、许可证、覆盖度、基线 harness、长期维护承诺；接受率 ~25%（估计），且**同一 artifact 随 CoRL 论文开源就能拿到大部分收益**。
3. **机会成本**：分兵 3–4 周 ≈ 牺牲 CoRL 质量口径 3–5pp 与执行概率 0.05，D&B 期望回报 <5pp → 负期望。

**替代方案**：CoRL 被拒后投 NeurIPS 2027 workshop（截稿 ~2027-08/09，工作量小），保留可见度，不占用主实验时间。
