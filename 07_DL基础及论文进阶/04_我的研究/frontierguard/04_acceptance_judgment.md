## 4. 与 SGS 的差距：审稿人会不会买账？

### 4.1 三条防线逐条评估

| v2 的防线 | 是否有效 | 判断 |
|---|---|---|
| **① 同层 head-to-head**（SGS-band 忠实重实现作一等公民 baseline） | **有效，但不解决问题** | 它把「你没比过 SGS」这个硬伤消掉了，但**比过之后若只赢 2–3pp，反而坐实「incremental」**。head-to-head 是必要不充分条件。 |
| **② SGS=FG 特例** | **无效，且是负资产** | 这是**参数极限的断言**，不是算法归约。「把 κ 设 0、σ 设 0、量化三档、关 guard」得到的是**你的权重映射的一个退化点**，不是 SGS 的算法（SGS 有自己的 band 阈值策略、重采样比、调度）。审稿人只要动手检查就会发现，然后**连带怀疑全文的严谨性**——比不说更糟。 |
| **③ 负结果分支（题目 B）** | **有效，但只加 2–3pp 的「可信度分」** | 作者主动预设失败分支，显著提升 AC 好感（「这群人不会硬吹」），但它改变不了「方法增量」的第一印象。 |

**结论：v2 的防线把「必拒」变成了「可辩」，但没有把「可辩」变成「该收」。**

### 4.2 为什么仍然会被说 incremental（机制层，不客气地说）

1. **motivation 重合 100%**：SGS 的「uniform 把经验浪费在已掌握/学不会的配置上」= v2 的 §0 第一句。审稿人读第一段就会想「这是 SGS 的引言」。
2. **层级重合 100%**：都在「并行 env 的 reset/重采样分配」这一层，都作用于 rollout 采样、都不改 PPO。
3. **信号重合 ~70%**：SGS = success-rate 分档；FG = LP 导数 × 不确定性门控。而 **PLR/RED/UPER 早已把「LP / regret 类信号」用于优先级采样**——所以「用 LP 导数」本身不新，「用在并行 env 分配 + 加不确定性门控」才是新的。
4. **真正的 delta 只剩两处**：(a) **导数**（区分「平台期」与「仍在进步」）；(b) **不确定性门控**（在结果噪声大时不被带偏）。这两处**都只在特定区制（regime）里才产生差异**——而 v2 的实验恰好只在**合成注入**的区制里证明了 (b)。
5. **规模反向**：SGS 2^20 env + 四足/机械臂装配 + 零样本真机；FG 2^11–2^14 + 一台廉价臂 + 2 任务。**审稿人会问「凭什么说你是更 general 的那个」**。

### 4.3 唯一能翻盘的东西（这是本文最重要的判断）

**novelty 不能靠论证获得，只能靠效应量获得。** 具体地：

- 若 **H4 在真实任务上成立**（域内自然 σ_a 就超过 Δ_min/2，SGS-band 的 regret 随 σ_a 增长而 FG 平坦，且 SGS 在真实任务上确实出现「追着噪声组跑」的机制性失误）→ 论文变成 **"success-rate 启发式在随机结果下会失效，这是它的边界"**，这是一个**有名字、可引用、可被后续工作复用**的结论 → Novelty 可到 **3.0–3.5**，p_cond 升到 **52%–58%**。
- 若 H4 只在**注入**噪声下成立 → 审稿人会说「你造了一个自己赢的场景」→ Novelty 停在 2.5，p_cond 47% 封顶。
- 若 **H8 真机 ≥20pp 干净显著** → Robotics 3.0→3.5、Novelty +0.25，p_cond → ~52%。
- 两者都成立 → S≈3.6 → **57%**，这就是 04a 里说的 45–55% 区间。

**因此：v2 目前把所有筹码押在两个「可能不出效应」的实验上，而这两个实验恰好是执行风险最高的两个（H4 依赖分组构造，H8 依赖零样本迁移）。这是全案最大的结构性风险，比 SGS 本身更致命。**

```
                                       + 至少 1–3 篇 follow-up 进入 ICRA 2028 池子，
                                       会持续抬高 novelty 门槛；这一项只减不加）
────────────────────────────────────
点估计                     = 35.6% → 报 36%
```

**80% 区间 26%–46%**：下界对应「E3 概率升到 0.35、E1 降到 0.22」；上界对应「E1 升到 0.45、novelty 被判 3.0」。**P(中稿 >50%) ≈ 15%**（需要 H4 与 H8 同时成立且写作/视频到位）。

### 5.4 达到 >50% 需要什么（反过来解方程）

要 p_overall > 50%，需 **p_cond ≥ 57%**（S ≥ 3.57）**且** 执行成功概率（E1+E2）≥ 0.80。按 §2 敏感性表，S 从 3.235 到 3.57 需 +0.335：
- Novelty +0.5（2.5→3.0，靠 H4 域内成立）→ +0.125
- Experimental +0.3（3.7→4.0，靠真机第 3 任务 + Tier-2 fixed-K）→ +0.075
- Technical +0.3（3.3→3.6，靠术语修正 + TOST + 特例表述修正）→ +0.060
- Robotics +0.3（3.0→3.3，靠「可及性」叙事 + 跨 embodiment 表）→ +0.045
- Clarity +0.3（3.5→3.8，靠 6 页重排 + 视频）→ +0.030
- 合计 +0.335 → S=3.57 → **56%**
同时执行成功概率要从 0.70 提到 0.80（靠 K-sweep + 真机 pilot + SGS 保真度验证）。
→ **总体 ≈ 0.80 × 0.56 ≈ 45%，再乘决策规则折扣 ≈ 48%–50%。** **这就是「>50% 是够得着的，但只是够得着」的准确含义。**

### 7.3 对 Lead 特别问的 6 个点的直接回答

1. **真机（2 任务 540 trials，只主张 ≥20pp）够不够？** **不够，且主张方式有风险。** 20pp 是很大的效应，只有 ~40% 概率真的出现；若真实效应是 10–12pp，n=90 配对测不出（power≈0.2），H8 直接失败。**必须加前置 pilot 门控（#4①）**；第 3 任务（+270 trials）比再加 trials 更值（回应「2 任务」的直接质疑更快）；HIL-SERL 微调**不加**；3 相机/多 embodiment **在本预算下不做**，用 sim 的 4 embodiment 表替代。
2. **理论够不够 technical quality？** **够「不被扣分」，不够「加分」。** ICRA 不要求定理；stylized model + 6 条可证伪预测 + 边界条件是**加分设计**。但「SGS=特例」这个断言会反噬，必须改（#5②）。**不要**为了「更像理论」去加收敛证明——那是 3 周换 0.2pp 的坏交易。
3. **方法差异够不够？** **LP 导数 × 不确定性 vs success-band 是真实的机制差异，但只在特定区制显现。** 加「任务级 MT10 附录」低 ROI（已在附录，保留即可）；「多 embodiment」在 sim 里已有（Panda/Go1/Cheetah/Humanoid），**只需在正文把它写成证据，不必新增实验**。
4. **统计够不够？** 8 seeds / fixed-K / oracle / 预注册 **方向对，但有三处必须修**：① H2 的「无交互」必须 TOST；② Tier-2 无 fixed-K（#1）；③ 主终点「协议 A」与「fixed-K 是决定性控制」自相矛盾（#1③）。负结果分支的可信度**取决于 W8 冻结是否真的冻在数据之前**——建议把 W8 的预注册文件 hash 写进论文附录。
5. **ICRA framing / 6 页 / 视频？** 当前 §10 的页分配**偏理论**，ICRA 版本必须**手术式重排**（#7）。视频不是装饰：ICRA 的 AC 常在 borderline 时看视频，**前 15 秒必须是「uniform 走平 / FG 继续涨」+ 真机对照**。
6. **改投 CoRL 2027 或 RA-L？** 见 §8：**ICRA 主投不变；RA-L 是更匹配的备胎；CoRL 2027 只做条件期权；IROS 2027 排除。**

### 10.2 两种结果分别怎么讲

**（I）如预期（FG>SGS 3–6pp，真机 ≥20pp，H4 成立）**
- 主张：`success-rate 启发式在随机结果下会系统性失效；LP 导数 + 不确定性门控是它的边界内替代方案`。
- 结构：边界判据作 §1 的 motivation → Table 1 差异表 → Fig.3 scaling → Fig.4a fixed-K → Fig.4b **域内自然噪声** → Fig.5 真机。
- 一句话卖点：**"We identify when success-based allocation fails, and fix exactly that regime."**

**（II）不如预期（FG−SGS <3pp 或真机不显著）**
- **不要硬吹**。切题目 B：`When Does Success Rate Suffice? A Calibration and Boundary Analysis of Progress Signals for Parallel RL`。
- 贡献改为：① 边界条件 (i)(ii) 的形式化 + 经验验证；② **测量研究**：在 4 族 6 信号上测「信号可分辨性 vs 收益」，给出「换信号最多值几 pp」的实证上界；③ fixed-K 方法学（很多 scaling 论文没做）。
- 场地：**RA-L / CoRL workshop**（ICRA 对负结果/分析型论文不友好，估计 ≤20%）。
- 心态：这不是失败——**沉没成本已经买到了一篇方法学论文 + 一个可复用的 artifact**。
