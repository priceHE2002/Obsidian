# 2026-11-08 论文推荐

> **今日锐评**：今天两条主线很清楚。世界模型开始补「物理因果」这块老短板：ReactWorld 把交互响应显式建模，Time-to-Goal 给 JEPA 补时间度量，都是在治「预测得像、但不按动作走」的毛病。VLA 侧则从模型转向监督信号：$A^3$-VLA 用交互引起的视觉变化反推注意力该放哪，TactileLab 干脆用刚体光流替代软体仿真来生成剪切触觉——后者如果成立，触觉 RL 的数据成本会掉一个量级。3DGS 的两篇（CrossPressor、BudgetSplat）出自同一组作者，一个治长序列融合、一个治原语冗余，方向是「可扩展」而不是「更清晰」。

## 必读

### 1. [TactileLab: Sim-to-Real Dexterous Robot Manipulation with Efficient Shear-Sensitive Tactile Simulation](https://arxiv.org/abs/2611.07881)

- **作者**：Yijiong Lin, Wenhao He, Toby Jack, Max Yang, Haoran Li, Nathan F. Lepora（机构未在 API 返回）
- **链接**：[arXiv](https://arxiv.org/abs/2611.07881)
- **解决了什么**：接触密集操作需要仿真器能表示触觉里的「剪切」，但高保真做法依赖软体/形变仿真，算力成本高到撑不起大规模 RL。
- **核心机制**：基于 IsaacLab 的多模态触觉仿真框架。关键是用**刚体仿真**估计接触面的稠密切向运动，得到 *simulated tactile flow*（光流场）来编码剪切相关动力学，替代软体形变；再与接触深度场（contact depth field）的几何特征互补，并在此之上提了一个策略结构（摘要在此截断，细节见正文）。
- **为什么今天必读**：触觉 sim-to-real 是 VLA 往精细操作走的卡点之一。把剪切用光流近似、把成本压回刚体仿真，意味着触觉数据可以和现有 IsaacLab 管线同规模扩张——这是「数据侧」的突破，不是又一个 policy trick。
- **精读卡**：[[03_TactileLab_X光|TactileLab]]

### 2. [ReactWorld: Structuring Interaction Responses for Embodied Video Generation](https://arxiv.org/abs/2611.06120)

- **作者**：Hanwei Liu, Huijia Zhang, Hanzhang Wang, Guangyu Liu, Hanbei Zhan, Linjie Hu 等
- **链接**：[arXiv](https://arxiv.org/abs/2611.06120)
- **解决了什么**：具身视频世界模型能预测「动作导致场景怎么变」，但生成的物体响应常和任务意图、接触动力学对不上——画面合理，物理不合理。
- **核心机制**：借 chain-of-thought 的思路，在生成骨干的特征空间里加一个 **interaction response field predictor**，显式预测三件事：参与者角色、未来运动响应强度、局部运动变化；再用 **response feedback adapter** 把「有预测 / 清零局部动力学」两种输出的差异变成物体特征的增量，并把预测位移转成时序注意力的位置偏置。响应只集中在局部区域和特定时间段，正好对上它的建模粒度。
- **为什么今天必读**：世界模型的核心评测就是「动作条件下响应是否一致」，这篇把「交互响应」从隐式学变成显式结构，是方法论层面的改动，不只涨点。
- **精读卡**：[[04_ReactWorld_X光|ReactWorld]]

## 值得看

### 1. [Time-to-Goal: Learned Temporal Metrics for Long-Horizon Planning with JEPA World Models](https://arxiv.org/abs/2611.05847)

- 作者：Ruilong Yu, Fei Ye
- 一句话：JEPA 用「预测潜状态与目标潜状态的距离」做规划，但这个欧氏代价并不保证「离目标越近代价越低」；作者在 flat LeWorldModel 上验证了不同时间偏移的状态会拿到相近代价，于是提出 T2G——用离线轨迹三元组 + margin ranking loss 学一个轻量时间度量，不需要 reward 或策略标签。
- 局限：只解决「排序」不解决「可达性」，且依赖离线轨迹覆盖；摘要没给长程任务的规模与基线数字。

### 2. [CrossPressor: Scalable Cross-View Fusion for Feed-Forward 3D Gaussian Splatting](https://arxiv.org/abs/2611.06258)

- 作者：Yuxi Hu, Wenhao Dong, Jun Zhang, Friedrich Fraundorfer
- 一句话：anchor 式压缩（如 ZPressor）把高斯解码限制在少量 anchor 特征图上，但 anchor 数量固定时，每个 anchor 要聚合的支持视图越来越多，形成 representation–fusion 失配；CrossPressor 用 coverage-cycled evidence routing 把证据分散到各支持视图与融合层，并用 K/V 投影前的路由 + joint context packing 降融合成本，training-free。
- 局限：只改融合不改 anchor 预算，超长序列下 anchor 本身仍会饱和；摘要没给与 ZPressor 的具体指标差。

### 3. [$A^3$-VLA: Automatic Perception-Guided Attention Alignment for Robot Manipulation](https://arxiv.org/abs/2611.06447)

- 作者：Shengzhe Zhang, Qi Zhang, Dazhong Shen, Chao Wang, Shaopeng Zhai, Hui Xiong
- 一句话：VLA 的动作预测目标本身没有细粒度感知监督，容易走「任务无关视觉捷径」；$A^3$-VLA 从交互引起的视觉变化里自动生成目标物体与机械臂的候选区域，再用分割模型离线精修，拿这些区域做注意力对齐。
- 局限：两阶段（候选生成 + 离线精修）带来额外工程链路，分割错误会直接变成监督噪声；摘要未给跨本体泛化结果。

### 4. [BudgetSplat: Budget-Controllable Generalizable Gaussian Splatting](https://arxiv.org/abs/2611.06593)

- 作者：Yuxi Hu, Jun Zhang, Wei Mao, Yuchen Rao, Friedrich Fraundorfer
- 一句话：像素对齐的 feed-forward 3DGS 会产生大量冗余原语，表示大小和渲染成本随分辨率、视图数快速上涨；BudgetSplat 把压缩写成「重要性估计 + 空间覆盖 + 跨视角冗余」的联合问题，单模型支持用户指定保留比例，不用按预算重训。
- 局限：预算比例是测试时超参，极端压缩下的质量下界没给；与 CrossPressor 同组，但两者是否叠加实验未知。

## 今日关联

- **ReactWorld ↔ 世界动作模型线**：[[01_具身智能论文精讲|具身智能精讲]] 里 WAM 一类工作做的是「动作条件视频预测」，ReactWorld 补的是「响应是否按接触动力学发生」，可以直接当 WAM 的一致性约束用。
- **TactileLab ↔ VLA 数据侧**：[[01_具身智能论文精讲|具身智能精讲]] 覆盖的 RT-2 / OpenVLA / π0 都是视觉+语言，没有触觉；触觉仿真规模化后，是多模态 VLA 的下一个数据入口。
- **$A^3$-VLA ↔ 注意力监督**：[[01_深度学习基础论文精讲|深度学习基础]] 里 Attention/ViT 讲的是「注意力学到什么」，这篇把它变成「用任务相关区域去监督注意力」，属于可解释性反哺训练。
- **CrossPressor / BudgetSplat**：同一组作者的两条压缩路线，一个管跨视图融合、一个管原语数量，理论上可组合成「长序列 + 低预算」的前馈 3DGS。
