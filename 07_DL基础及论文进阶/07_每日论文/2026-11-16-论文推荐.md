# 2026-11-16 论文推荐

> **今日锐评**：同批 635 篇里昨天那三篇已是旧面孔，今天补的是被它们挡住的新货。上海交大 / 中国电信 TeleAI / Cardiff 的 CoCode-World 把双人世界模型的跨视角一致性拆成「程序化 3D 代理管结构、RGB 参考管外观」，跨视角身份分 3.847 压过 Seedance 2.5 的 3.552；IIT Madras 的 ThermalSplat 用 soft census + 边界损失把无位姿两视图热成像做到 25.55 dB、单次前向 80 ms；AgiBot 的 STVLA 把几何基础模型塞进时序记忆，LIBERO 97.8%、实机超 π0.5 达 58.3 点。三条线的动作一致：补上被默认忽略的那一维输入——另一个视角、另一个模态、另一段时间。

## 必读

### 1. [CoCode-World: Shared 3D Proxy Representation for Multi-Player World Models](https://arxiv.org/abs/2611.15602)

- **作者与机构**：Qirui Li（上海交大 / TeleAI）, Xin Zhang, Yabo Chen（TeleAI）, Jinkun Hao（上海交大）, Paul L Rosin, Yu-Kun Lai（Cardiff University）, Haibin Huang, Yin Chen（TeleAI）, Ran Yi（上海交大，通讯）, Chi Zhang（TeleAI，通讯）
- **链接**：[arXiv](https://arxiv.org/abs/2611.15602) · [项目页](https://iapple233.github.io/CCW/)
- **解决了什么**：多人生成式世界模型要在两个相机不同运动、互相遮挡的条件下，对同一批实体给出一致观测。显式世界表示能控制空间，但为每张游戏地图精确建模会限制场景多样性；只共享几何又保不住外观——同一个角色在两个视角里不是同一个人。
- **核心机制**：把「结构控制」与「视觉合成」拆开。共享地图 $M$、实体观测 $E_t^{(p)}$、相机位姿 $C_t^{(p)}$ 先渲染出无纹理代理视频 $P_t^{(p)}=R(M,E_t^{(p)},C_t^{(p)})$，只交代轮廓、尺度、遮挡；外观由一对 RGB 参考图指定。两路代理、参考图、目标视角按「玩家 1 占左半、玩家 2 占右半」拼成一张画布，交给冻结的 MiniMax-H3 DiT 一次联合去噪 $p_{\theta,\phi}(V\mid P,I,c)$——跨视角通信直接复用模型原生 attention，只训 LoRA，不额外搭跨视角对齐模块。
- **关键数字**：Table 1 六项指标：DOVER 0.524 / LAION 5.655 / DINO Adj. 0.970 / Edge F1 0.124 / First-frame 0.684 / Cross-view 3.847；对比 Seedance 2.5（0.469 / 5.568 / 0.973 / 0.120 / 0.700 / 3.552）、SolarRenderer（0.454 / 5.477 / 0.968 / 0.073 / 0.655 / 3.696）、MiniMax-H3 底座（跨视角身份 2.868）、Gamma-World（0.697）。自建数据：FiveM 私服双人 GTA V，7,846 条约 5 s 片段，探索 66.4% / 骑行 18.7% / 交互 9.8% / 战斗 5.1%。
- **为什么今天必读**：多人/多智能体世界模型的「一致性」一直停在定性展示，这篇给了一个可测量的跨视角身份分，并把代价算清楚——不做双分支特征交换，只靠拼接画布 + 原生注意力。对多人具身仿真、协同 VR 是可复用的接口设计；注意它的第一帧保真度反而略低于 Seedance 2.5（0.684 vs 0.700），结构贴合与参考保真是可以互相挤占的。
- **精读卡**：[[15_CoCode-World_X光|CoCode-World]]

### 2. [STVLA: Spatial-aware and Temporal-memory for Vision-Language-Action Models](https://arxiv.org/abs/2611.16589)

- **作者与机构**：Zhuo Han, Yeqiang Wang, Xinran Wang, Hongwei Han, Yi Xiong, Zunian Wan, Jianbo Mao, Huan Peng, Yongcheng Liu, Wei Shan, Maoqing Yao（AgiBot 智元机器人）
- **链接**：[arXiv](https://arxiv.org/abs/2611.16589) · [项目页](https://stvla.github.io/)
- **解决了什么**：VLA 大多只看当前观测。外观记忆（视觉 token 历史）怕遮挡与视角变化；只有当前场景的空间表示又记不住「场景是怎么变的」。结果是多步任务里重复动作、丢失进度、抓空。
- **核心机制**：冻结 1B 的 VGGT-Ω 提取几何特征，用一个带变分瓶颈的压缩器（学习 query 的池化交叉注意力 + 重建/KL 辅助目标）压成 $N_s$ 个空间 token；当前视觉 token 与空间 token 拼接后进容量有界记忆库，用「相关性 × 非冗余」打分检索 $s_j=r_j u_j$，$r_j=\frac12(1+\cos(h_j,\bar x_t))$、$u_j=\frac{\|h_j-\bar x_t\|}{\|h_j\|+\|\bar x_t\|}$，再以标准化分数 $\tilde s_j$ 作加性偏置进入 token 级注意力 $\alpha_{j,n}=\mathrm{softmax}_{j,n}\!\left(\frac{q^\top k_{j,n}}{\sqrt d}+\beta\tilde s_j\right)$。检索结果门控融合，与指令、机器人状态一起 condition 动作 chunk 的 flow-matching 损失。
- **关键数字**：LIBERO 五套均值 97.8%（π0.5 96.6、MemoryVLA 96.5）；LIBERO-Mem 41.0%（π0.5 38.0）；MIKASA-Robo 45.2%（MemoryVLA 41.2、π0.5 32.4）；SimplerEnv Bridge 74.0%（MemoryVLA 71.9），Stack Cube 54.2% vs 37.5%。实机三任务均值 76.7%，对比 π0.5 35.6 / Spatial Forcing 36.1 / MemoryVLA 46.1：叠方块 100.0%（+58.3）、物体整理 85.0%（+30.0）、手机装盒 45.0%（+35.0）。消融（实机叠方块）：去掉记忆 100→95.0，去掉空间分支 →96.7；检索偏置 $\beta=0.5$ 时 100%，$\beta=0$（无偏置）80.0%；输入帧 $K=4$ 最优（100%），$K=5$ 反而掉到 86.7。
- **为什么今天必读**：它把「空间」与「记忆」并到同一条检索通道，而且检索规则是解析式的、零新增参数——比再训一个 memory encoder 便宜。消融还给出一个反直觉结论：几何帧不是越多越好，$K=4$ 之后掉点，因为多帧只增 token 与延迟、不增信息。对长程操作（要知道「刚才做到哪」）是当下最省算力的 VLA 改法。

### 3. [ThermalSplat: Generalizable Pose-Free Gaussian Splatting for Sparse-View Thermal 3D Reconstruction](https://arxiv.org/abs/2611.15435)

- **作者与机构**：Prasanna S, Gopi Raju Matta, Divya Madhuri Vemunuri, Kaushik Mitra（Indian Institute of Technology Madras）· WACV 2027
- **链接**：[arXiv](https://arxiv.org/abs/2611.15435)
- **解决了什么**：热红外的低纹理与视角相关发射率让 SfM 位姿估计崩（两视图下几乎提不出 3D 点），而现有热 3DGS 全靠稠密采集 + 逐场景优化，还要对齐 RGB 拿位姿——纯热、无位姿场景直接不可用。
- **核心机制**：以无位姿多视图几何 backbone NAS3R 为底，交替「帧内自注意力 + 全局跨视图注意力」做几何推理，三个轻量头直接回归相对位姿、稠密深度与逐像素高斯参数，一次前向出场景。针对热域加两项结构监督：soft census 损失 $\xi(I)_{p,q}=\frac{|L_q-L_p|}{\sqrt{0.81+(L_q-L_p)^2}}$ 做亮度不变的局部结构匹配，抵抗自动增益与发射率漂移；边界结构损失显式监督温度不连续处，因为热图的几何线索几乎全在边界上。在 5 个公开热数据集聚合语料上训练（10,000 步，224×224，batch 4，$\lambda_b=\lambda_c=0.075$）。
- **关键数字**：六场景均值 PSNR 25.55 / SSIM 0.828 / LPIPS 0.181；零样本 NAS3R 23.44 / 0.768 / 0.240，热微调 NAS3R+ 24.34 / 0.785 / 0.220，SPFSplat+ 19.30，MVSplat+ 16.97。两视图位姿 AUC@20° 39.7% vs NAS3R 35.8 / NAS3R+ 38.6。Table 2：仅两张无位姿图 24.96 dB / LPIPS 0.209，已与稠密 + 逐场景优化的 Thermal3DGS 25.14 / 0.252、ThermalGaussian 26.02 / 0.241、PhysIR 26.77 / 0.277 同档；同样只给两视图时这三者崩到 11.889 / 15.161 / 19.025。Table 5：单次前向 80 ms vs 逐场景 15–25 min。
- **为什么今天必读**：3DGS 进机器人现场（烟、暗、夜、搜救）绕不开非可见光模态。这篇把「通用几何先验可跨模态迁移，但必须补模态特有的结构监督」这条讲清楚了，并给出工程代价：80 ms 前向，不需要位姿、不需要 RGB 引导、不需要逐场景训练。

## 值得看

### 1. [What Can a VLA Learn from the Agent That Calls It? Task-Level Experience Distillation for Embodied Navigation](https://arxiv.org/abs/2611.16246)

- 作者：Jinze Tao, Yuxiao Han, Kangkang Dong, Yancong Wei, Xiaojun Zhu, Bokui Chen, Houde Liu
- 一句话：LLM planner 调用 VLA 导航，每个 episode 都要 planner，贵且慢。H2E 不蒸馏 planner 而是把成功会话改写成 VLA 训练数据——每条动作挂回原任务指令、偏离目标的步 mask 掉、目标 1 m 内的访问状态标成 stop，再用 LoRA 更新 8B VLA，测试时 VLA 单跑。REVERIE-CE val-unseen 全 3,189 个 episode 上 SR 从 35.0% 提到 44.9%（+9.9），SPL 26.5→38.4、NE 8.53→6.90，训练数据 2,395 条会话。
- 局限：OSR 反而从 52.0 掉到 50.1——更愿意停，但停错也变多；只在 REVERIE-CE 单一基准、单一 8B 底座上验证，且教师是 LLM planner 的成功会话，planner 换掉或成功率下降时还剩多少增益摘要未给。

### 2. [BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model](https://arxiv.org/abs/2611.14815)

- 作者：Junyoung Seo, Jaewoo Seo, Seungryong Kim, Laura Leal-Taixé, Xiuming Zhang, Seung Wook Kim（项目页在 NVIDIA SIL）
- 一句话：驾驶世界模型要么靠外部布局条件（必须给未来车辆轨迹），要么只学透视视频（运动与外观纠缠、遮挡严重）。BirdDreams 用两个视频 DiT 自回归地同时生成透视视频与一张示意 BEV 视频，两流互相交叉注意；BEV 反过来当几何接口——把最新一帧按输入 ego 轨迹平移旋转，作为「只有自车在动」的软条件。无 ego 条件时两数据集 minADE 6.15 / 3.91 对 OmniDreams 7.76 / 6.20；有条件下 ADE 3.83 / 3.42、FVD 238.9 / 294.0、FID 11.81 / 14.80，均优于 OmniDreams（Plücker）的 5.88 / 5.38、271.5 / 343.1、15.35 / 18.27。
- 局限：训练期 BEV 由场景标注渲染（真值布局监督），推理虽不需要 HD map，但自回归多帧里 BEV 流自身的误差如何累积、会不会漂移摘要未给；人类评测只有 25 人 375 次判断，且只在 PhysicalAI-AV / nuScenes 上评测。

### 3. [Duo: A Reciprocal World Model for Full-Duplex Interaction](https://arxiv.org/abs/2611.15131)

- 作者：Hengyuan Cao, Biao Gong, Guoshan Lu 等 20 人（inclusionAI）
- 一句话：把「世界模型」从预测物理未来扩到「意图 + 实现」两件事。Intent 模块自回归地做连续交互推理与是否插话的决策，Realization 模块生成音视频行为，两者按 chunk 共享时间轴、用模块化注意力掩码保证因果（不能看未来输入），再用 dual rollout distillation 抹掉训练/推理的分布差。系统可全双工听看说，支持中途打断。延迟拆解：17 帧 chunk ≈708 ms，其中推理 90–160 ms、生成 200–450 ms、解码约 30 ms。
- 局限：技术报告 v1，摘要与正文都没有与既有全双工对话/世界模型的可比指标——画质、语音质量、打断响应正确率均为 `[摘要未给]`；作者自述「first step, next version coming soon」，可复现性靠仓库而非评测。

### 4. [Does Your World Model Know Actions Have Consequences?](https://arxiv.org/abs/2611.15048)

- 作者：Ayush Gaggar, Jared Berry, Todd D. Murphey
- 一句话：CoRL 2026「Do Robots Need World Models?」workshop 立场文。现在评世界模型看重建清晰度或任务成功率，这两者都不检验「反事实动作的后果」；作者主张用动作扰动的 forced response 做灵敏度审计，把「状态误差」与「灵敏度预测准确度」的权衡显式化，当作上硬件前的前置检查。
- 局限：workshop 短文，摘要未给实验规模、灵敏度指标定义与任何基线数字（`[摘要未给]`）；作为方法论要求世界模型有可重复的干预接口，跨模型可比性尚无证据。

## 今日关联

- **CoCode-World ↔ [[08_ObjectWorld_X光|ObjectWorld]]**：两篇都把世界模型拆成「显式结构 + 生成器」，但 ObjectWorld 用物体级几何流做单视角可控生成，CoCode 用共享代理 + 拼接上下文做双视角一致；共同赌注是「几何接口比端到端 latent 更可控」。
- **STVLA ↔ [[09_OnlyAct_X光|OnlyAct]] ↔ [[12_A2WM_X光|A²WM]]**：三条都在冻结的大表示上外挂轻量模块——OnlyAct 从 V-JEPA 2 抽动作、STVLA 从 VGGT-Ω 抽空间 token 进记忆、A²WM 只学局部动作灵敏度给 QP 解。「不重训 backbone」在 VLA 侧已经是默认做法。
- **ThermalSplat ↔ [[06_RF3DGS_X光|RF3DGS]] ↔ [[14_Topo-4DGS_X光|Topo-4DGS]]**：3DGS 的三条补维路线——补模态（热红外）、补反射/透射、补拓扑生灭。三篇都在说同一件事：3DGS 的瓶颈是「假设错了」，不是「点不够密」。
- **BirdDreams / CoCode ↔ [[13_Persistence_X光|Prediction or Persistence]]**：都在质疑「生成得像」这个指标——BirdDreams 要求 ego 轨迹误差与场景响应同时成立，CoCode 要求跨视角身份一致，Persistence 要求扣掉 persistence 基线；世界模型评测正从「像不像」转向「哪一维真的被建模了」。
