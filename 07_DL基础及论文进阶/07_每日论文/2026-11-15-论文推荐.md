# 2026-11-15 论文推荐

> **今日锐评**：今天三篇拆的都是「看起来成立」的那层。清华自动化 Run Wang / Yilin Mo 与 JHU Liang Wu 的 A²WM 只离线学动作扰动的局部仿射响应、再解一个凸 QP：均值成功率 59.51% 对 GPC-QP 47.07%，每步 3.80 ms。Deccan AI 的 Maheshwari 用不调用预测器的 persistence 对照算出 V-JEPA 2 的预测器只加 +0.03~0.04、2.1 才有 +0.291——分数高不等于会预测。Bocconi / TUM 的 Topo-4DGS 放弃固定拓扑，事件后帧 PSNR 高 4.47 dB。三处共识：改接口、改评测、改结构假设，都比堆容量划算。

## 必读

### 1. [Fast Inference-Time Policy Refinement via Action-Affine World Models](https://arxiv.org/abs/2611.15011)

- **作者**：Run Wang, Yilin Mo（清华大学自动化系）, Liang Wu（Johns Hopkins University）
- **链接**：[arXiv](https://arxiv.org/abs/2611.15011)
- **解决了什么**：模仿学习策略能做出复杂操作，但执行误差会累积成失败。修误差有两条老路——追加 on-policy 强化学习（ResiP 约 $5\times10^5$ 回合、KoRR 约 $1\times10^5$ 回合交互数据），或在线规划（GPC-OPT 每步 401 ms）。这篇的前提判断是：预训练策略已经给出不错的标称行为，精修只需要预测「小动作修正会怎样改变结果」，不必重训策略、也不必在部署时反复 rollout 世界模型。
- **核心机制**：离线用「动作被扰动过的策略 rollout」学局部动作敏感度，模型把任务相关几何预测成**标称轨迹 + 对修正的线性响应** $z(\Delta a)\approx \bar z + J\Delta a$，并且一次直接预测整个规划时域（不做递归单步，避免中间误差逐层放大）。于是「预测误差的二次罚 + 修正幅度的线性约束」正好是一个凸二次规划：每步只做一次模型前向 + 一次 QP 求解，策略与模型权重全程冻结。
- **关键数字**：四个仿真操作任务均值成功率 **59.51%**，对比 GPC-QP 47.07%、GPC-OPT 44.17%、GPC-RANK 35.84%、双基线 DP 27.18% / LPB 26.71%；平均精修开销 **3.80 ms/控制步**（GPC-RANK 25.75、GPC-QP 39.47、GPC-OPT 401.05 ms），即比三者快 6.78× / 10.39× / 105.56×。分任务看提升集中在 RoundTable（42.97 vs 15.23）与 Lamp（41.02 vs 25.91），PushT 上打平 GPC-OPT（78.78）但只用 3.40 ms 而非 346.47 ms。精修所需数据仅 256–512 回合离线 rollout，且不需要 on-policy 交互。
- **为什么今天必读**：它把「世界模型」从 rollout 生成器降级成一个**局部灵敏度模型**，用可解性（凸 QP）换掉了递归预测的误差累积——是世界模型接控制这条线上少见的、把计算预算算清楚的方案；对 VLA 部署（高频闭环、策略不能重训）直接可用。
- **精读卡**：[[12_A2WM_X光|A²WM]]

### 2. [Prediction or Persistence? What Future-Prediction Scores Miss About World Models](https://arxiv.org/abs/2611.15082)

- **作者**：Animesh Maheshwari（Deccan AI）
- **链接**：[arXiv](https://arxiv.org/abs/2611.15082) · CoRL 2026 Workshop "Do Robots Need World Models?"
- **解决了什么**：选哪个视频世界模型当策略初始化 / 规划器 / 评测器，业界基本看「未来预测分数」。但这个分数同时混了三样东西：编码器好不好、近未来像不像刚过去、预测器自己有没有贡献——只有第三项才是「预测」。于是「一个什么都没预测的模型也能拿高分」，而「一个有害的预测器仍能高于随机」。
- **核心机制**：做一个配对对照（persistence control）——同一个模型复制一份、**永不调用预测器**，只按编码器特征从 11 个候选里挑真实后续（同视频片段，随机 = 0.091）。两份模型在同一批 27,000 次检索试验上做差，差值 $\delta_\theta$ 就是预测器的净贡献。因为对照与全模型共享编码器，编码器质量与「近未来像过去」这两项被消掉。
- **关键数字**：V-JEPA 2.1 ViT-g 全模型 0.736、对照 0.444，$\delta=+0.291\,[+0.281,+0.302]$；同族的 V-JEPA 2 ViT-H 0.437、ViT-L 0.424，共享对照 0.396，净贡献只有 $+0.0408$ 与 $+0.0284$——**分数 0.42+ 的同时贡献只有 0.03**。DINO-WM 得 0.136（高于随机 0.091），但它的对照是 0.315，净贡献 **−0.179**（该模型在 PushT 动作空间训练、此处属域外，作者标注仅供方向参考）。两族 0.340 的总差可拆成编码器 +0.048 与预测器 +0.291。
- **为什么今天必读**：这是今天最省算力的一篇——多一次前向就能把「世界模型评测」从比分数改成比**分数与其 persistence 基线的差**。凡是要引用「某世界模型预测更好」的地方（包括昨天那批 action-conditioned / JEPA 工作），都得先过这道对照；它也解释了为什么 V-JEPA 2 与 2.1 在下游规划上的差距会被高分掩盖。
- **精读卡**：[[13_Persistence_X光|Prediction or Persistence]]

### 3. [Topology-Aware 4D Gaussian Splatting for Egocentric Videos](https://arxiv.org/abs/2611.16012)

- **作者**：Leonardo Vanni（Bocconi University）, Stefano Gasperini（TUM）, Federico Tombari（TUM / Google）, Chiara Plizzari（Bocconi University）
- **链接**：[arXiv](https://arxiv.org/abs/2611.16012) · [项目页](https://topoego.github.io)
- **解决了什么**：第一视角视频里的日常交互大量是**拓扑变化**——切、拼、开、合，表面会分裂、合并、露出。现有 4DGS 全都靠「变形一个固定表示」，拓扑一变就出重影、丢部件（切开后只剩一片、刀凭空消失）。作者顺手指出：这个设定此前根本没有基准。
- **核心机制**：两件事拆开建模——(1) **部件级运动**：给互相作用的部件各自独立的刚性变换，允许同一物体分裂成 $K$ 片（Motion Bifurcation）；(2) **时变表面支撑**：给每个高斯一个可微的激活窗口 $W_i(t)$，不透明度写成 $\alpha_i^t=\alpha_i W_i(t)$，表面出现时激活、消失时关闭，配合事件边界构造接触面（Boundary Construction）。再加事件感知的位姿插值、联合场景精修与空间正则 $\mathcal{L}_{sp}$，全部 24 条序列共用一个架构与超参，只换输入与拓扑规格（物体数、$K$、事件树、事件时刻）。
- **关键数字**：自建 **TopoEgo**（24 条 clip，EPIC-KITCHENS + Ego4D，覆盖 fission / fusion / open / close）上，Table 1 的 8 个「数据集 × 事件族」分组**全组第一**，比各组最强基线最高 +1.26 dB（物体区域 PSNR）。Table 2：全场景 27.95 dB / SSIM 0.885 / LPIPS 0.179；拓扑物体 +0.92 dB；**事件后帧 +4.47 dB**（24.30 vs 19.83）——正是变形类方法崩得最狠的位置。无拓扑变化的刚性物体对照列也拿第一（27.92 dB），说明没有为了拓扑牺牲常规重建；四条短片对比 HyperNeRF 全场景 31.86 vs 21.11 dB。
- **为什么今天必读**：3DGS 进具身智能的瓶颈已经从「重建得像」转向「重建得住交互」；这篇给出了第一个针对拓扑事件的基准 + 一套可复用的「部件刚性 + 高斯时变激活」机制，和日报里世界模型那两篇形成互补——世界模型要预测的正是这些表面出现/消失的事件。
- **精读卡**：[[14_Topo-4DGS_X光|Topo-4DGS]]

## 值得看

### 1. [Driving World Models Move the Camera, Not the Scene](https://arxiv.org/abs/2611.15260)

- 作者：Yuqiao Feng, Xiaoyu Ao
- 一句话：规划条件化的驾驶世界模型被用来比较候选轨迹，可常用指标只检查「相机有没有跟着指令走」。作者用日志里真实发生过、但从未被驾驶过的方案造出参照：对一条日志重定时（retiming）就得到另一个速度下位姿对齐的图像与 LiDAR，立体相机则给出横向平移视图。对照之下，已发布的世界模型**动了相机却没怎么动场景**——scene response（预测复现真实变化的比例）最高只有真实视频的约三分之一，轨迹分数更是分不清「执行了速度指令」和「忽略了速度指令」；在生成器内部做干预后定位到病灶在 plan 通道：预测几何跟着上下文帧走，上下文里带上目标几何之后 plan token 就几乎不贡献了。据此提出免训练的 ReTime-Compose：把已记录速度的 rollout 帧传输到计划相机位姿，冻结模型只补没有帧覆盖的部分。冻结的生成器在 KITTI / nuScenes / Argoverse 2 上能把 0.54 m 横向位移跟得接近真实场景，三个生成器对减速计划、两个对加速计划的响应超过重采样。
- 局限：整套参照依赖「日志重定时 ≈ 同场景不同速度」的假设，只能在直线匀速段附近成立，转弯与交互密集场景的参照会失真；评测止于三项指标与三个开源生成器，没有闭环规划收益的证据，且**加速计划在一个生成器上仍不如重采样**（作者自己点出）。

### 2. [MatrixSplat: Matrix-Parallel and Feature-Scalable 3D Gaussian Splatting Rendering on GPUs](https://arxiv.org/abs/2611.15153)

- 作者：Yangming Zhang, Siyi Wu, Jian Wang, Bingzhe Li, Wei Niu, Sheng Di, Ming Li, Miao Yin（NeurIPS 2026）
- 一句话：3DGS 渲染与 GPU 架构错配——按深度排序的 alpha 合成是逐像素串行依赖，算力全落在标量 FMA 上，Tensor Core 闲着；语义特征一升维（LERF / 3D-OVS 这类）就更糟。做法是把顺序无关的加权累加形式写出来，让特征累积变成矩阵乘：tile 级 splatting 映射到 warp 级 MMA 走 Tensor Core，warp 粒度的高斯打包缓解可见性不规则、提高特征复用，再加懒加载的分通道特征取数，压低共享内存压力并把访存与矩阵执行重叠。Mip-NeRF 360 / LERF / 3D-OVS 上最高 3.8× 于 3DGS、2× 于 TC-GS 且画质与语义精度不掉，高维特征的 render kernel 最高快 36.7×，接进现有快速渲染器还能再拿 1.69–2.84×。
- 局限：这是渲染 kernel 层的重写而不是表示层改进，画质与语义精度只做到「维持」；收益绑定 Tensor Core 的 tile/MMA 形状与高维特征场景，低维纯 RGB 与移动/边缘 GPU 的加速比摘要未给，也未报显存与实现复杂度代价。

### 3. [ActWorld-JEPA: Action-Conditioned JEPA World Models Meet Latent Planning for End-to-End Autonomous Driving](https://arxiv.org/abs/2611.16579)

- 作者：Ziying Song, Shengkai Zhang, Caiyan Jia, Lei Yang, Lin Liu, Yuchen Liu, Ziyang Liu, Zirui Li, Gang Wang, Peiliang Wu, Li Wang, Yadan Luo, Chen Lv
- 一句话：JEPA 能在潜空间预测未来、不需像素重建，但「潜空间里预测一致」并不等于「候选轨迹谁更好」。Plan-Conditioned JEPA 用全局与逐步的轨迹意图引导循环潜预测，再以门控交叉注意力把预测未来与当前场景缝合；Relational Residual Reranking（$R^3$）在规划监督下建模「计划表示」与「未来表示」的一致与分歧，给出有界、门控的残差修正去调整基础规划分数——推理时只用观测上下文与候选轨迹。NAVSIM v1 navtest 94.1 PDMS，v2 navtest / navhard 91.6 / 42.7 EPDMS；nuScenes 1–6 s 平均 $L_2$ 误差 1.20 m、预测碰撞率 0.76%。
- 局限：摘要自承**最终选择器用 navtest 的聚合反馈校准**——等于在测试集上调超参，PDMS/EPDMS 的跨工作可比性要打折；且整套是驾驶专用（候选轨迹 + 规划监督），换到操作类 VLA 上没有对应接口。

### 4. [Reconstruct What You Can: Distractor-free 4D Gaussian Splatting](https://arxiv.org/abs/2611.16259)

- 作者：Joel Julin, Liuyue Xie, Ananya Bal, Mose Sakashita, Koichiro Niinuma, Laszlo A. Jeni（WACV 2027）
- 一句话：随手拍的动态视频要留住主体运动、同时压掉瞬态遮挡物、阴影、烟雾。既有方法要么假设静态场景把真运动一起干掉，要么把全部观测一起拟合，结果是重影和浮动几何。ReCan-GS 从学到的变形场里导出 **Jacobian 型形变敏感度**，当作「重建歧义」的经验代理：据此把高斯拆成动态 Core 与逐视角 Distractor，或事后剪掉敏感 Core；同一判据可去空间遮挡、光度伪影、演化中的烟雾/雾，不需要 mask、预训练分割器或针对介质的监督。
- 局限：摘要未给任何定量指标（PSNR / LPIPS / 去伪影率均为 `[摘要未给]`），判据有效性靠「敏感度 ≈ 歧义」的代理假设；真运动若本身形变剧烈（快速手物交互）就会被判成 distractor，这个失效边界摘要未讨论。

## 今日关联

- **A²WM ↔ [[10_WM-PPO_X光|WM-PPO]] ↔ [[11_K-PWM_X光|K-PWM]]**：三条「世界模型接控制」的路线今天凑齐了闭环——WM-PPO 让 critic 给想象后继估值（RL 侧）、K-PWM 用双线性结构 + EKF 做可精确传播的信念（模型侧）、A²WM 只留一个局部仿射响应给 QP 解（在线优化侧）。A²WM 是最激进的一刀：把「预测整个未来」降级成「预测修正的斜率」。
- **Prediction or Persistence ↔ [[09_OnlyAct_X光|OnlyAct]] ↔ [[12_A2WM_X光|A²WM]]**：OnlyAct 用 V-JEPA 2 空间抽动作、A²WM 用 V-JEPA 2 之外的小模型做局部修正，两篇都默认「预训练表示已经够好」；而 Maheshwari 的对照恰好提醒：这个默认值得用一次 persistence 前向去验证，别把编码器红利记在预测器账上。
- **Topo-4DGS ↔ [[06_RF3DGS_X光|RF3DGS]] ↔ [[08_ObjectWorld_X光|ObjectWorld]]**：都在给 3DGS 补「物理上该有的自由度」——RF3DGS 补反射-透射分解，ObjectWorld 补物体级几何流，Topo-4DGS 补表面的生灭。共同信号：3DGS 的下一步不是更密的点，而是更对的**结构假设**。
- **Driving WM / ReCan-GS 的共同点**：两篇都在骂「模型在拟合捷径」——驾驶世界模型只动相机不动场景、4DGS 靠把所有观测一起拟合来藏住歧义；解法也都不是加容量，而是换参照（重定时日志 / 形变敏感度）。
