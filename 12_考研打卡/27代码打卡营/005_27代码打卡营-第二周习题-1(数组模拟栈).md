# 27代码打卡营-第二周习题-1(数组模拟栈)

> **课程**：27代码打卡营 ｜ **时长**：13:29


## 📄 题目（做题本）

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是
否有效。有效字符串需满足：左括号必须用相同类型的右括号闭合。
左括号必须以正确的顺序闭合。每个右括号都有一个对应的相同类型的左括
号。请设计一个算法，解决此问题，并给出 C/C++代码。

## 💻 我的解法

```c
#include <stack>
#include <string>
using namespace std;

int match(string s, int length)
{
    int i = 0;
    stack<char> a;

    while (i < length)
    {
        // 左括号：入栈
        if (s[i] == '(' ||
            s[i] == '{' ||
            s[i] == '[')
        {
            a.push(s[i]);
        }

        // 右括号：判断是否匹配
        else if (s[i] == ')' ||
                 s[i] == '}' ||
                 s[i] == ']')
        {
            // 栈为空，说明右括号没有对应的左括号
            if (a.empty())
            {
                return 0;
            }

            if (a.top() == '(' && s[i] == ')')
            {
                a.pop();
            }
            else if (a.top() == '{' && s[i] == '}')
            {
                a.pop();
            }
            else if (a.top() == '[' && s[i] == ']')
            {
                a.pop();
            }
            else
            {
                return 0;
            }
        }

        i++;
    }

    // 最后必须全部匹配完
    return a.empty();
}
```
