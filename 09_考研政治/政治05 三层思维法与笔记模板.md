## 一、三层思维法：每个知识点都记三层

以「全过程人民民主」为例。

| 层 | 内容 |
|---|---|
| 第一层：**现实问题** | 如何让公众参与和影响治理？ |
| 第二层：**官方理论回答** | 全过程人民民主 |
| 第三层：**考试触发词** | 协商 · 基层参与 · 征求意见 · 民主监督 |

```mermaid
flowchart LR
  A["现实问题"] --> B["官方理论回答"] --> C["考试触发词 / 答案"]
```

这样以后材料一出现，你自动完成：

> [!important] 三层思维法的产物
> **现实 → 理论 → 答案**

## 二、命题人视角笔记模板

以后政治每个知识点都用这个模板。

| 项目 | 内容 |
|---|---|
| 表层知识点 | 教材怎么说 |
| 它解决什么现实问题 | 为什么会提出 |
| 命题人希望建立什么认识 | 核心立场 |
| 常见材料 | 怎么包装 |
| 正确答案关键词 | 怎么输出 |
| 最容易设置的错误 | 怎么偷换 |
| 边界 | 什么不能推出 |

> [!tip] 用好最后一行
> 「**边界：什么不能推出**」就是把 [[政治02 选择题方法论#五、逆向制度审查法：由后果检查选项|逆向制度审查法]] 提前写进笔记里。

## 三、示范：共同富裕

| 项目 | 共同富裕 |
|---|---|
| 表层知识 | 中国式现代化的重要特征 |
| 现实问题 | 收入、机会和公共服务差距 |
| 希望建立的认识 | 发展成果应更多更公平惠及全体人民 |
| 材料 | 社保、城乡、收入、公共服务 |
| 答题词 | 以人民为中心、共享发展、共同富裕 |
| 错误选项 | 平均主义、同步富裕 |
| 边界 | 允许合理差距，不否定效率 |

> [!important] 这种笔记
> 比普通的「知识点摘抄」有效很多——它同时装下了**正向输出**和**反向排除**。

### 再示范一条：全过程人民民主（照上面模板填）

| 项目 | 全过程人民民主 |
|---|---|
| 表层知识 | 社会主义民主政治的本质属性，是最广泛、最真实、最管用的民主 |
| 现实问题 | 如何让公众真正参与并影响治理，而不止于投票 |
| 希望建立的认识 | 民主贯穿选举、协商、决策、管理、监督全过程 |
| 材料 | 村民议事、社区协商、征求意见、人大立法听证 |
| 答题词 | 协商民主、基层群众自治、人民当家作主 |
| 错误选项 | 把民主窄化为选举；说它是照搬西方模式 |
| 边界 | 不是「全民直接决定一切事务」，仍以党的领导为根本保证 |

## 四、全套公式总表

### 选择题

> [!important] 选择题四步
> **命题意图 → 概念定位 → 边界检查 → 排除偷换**

### 材料分析题

> [!important] 材料题五步
> **材料现象 → 现实问题 → 命题人预设结论 → 教材标准术语 → 材料佐证**

### 最高层思维

> [!important] 一句话
> **不要只问「正确答案是什么」，**
> **而要问「为什么在这套考试体系里，它必须成为正确答案？」**

### 两层用法

| 场景 | 你做的事 |
|---|---|
| 考场外 | 分析这套政治叙事**为什么存在** |
| 考场内 | 利用对这套叙事目标的理解，**高效预测命题人需要的答案** |

## 五、落地：怎么把它变成复习动作

> [!tip] 五个可执行动作
> 1. **每学一个知识点**，就地补一张「命题人视角笔记」表（第二节模板）。
> 2. **每学一章**，往两张清单里添条目：四元组表（名词—属性—地位—功能）、反定义表（A ≠ C）。
> 3. **时政**不背新闻，按「事件 → 政策主线 → 理论落点」归档。
> 4. **做完题反向复盘**：这题在考哪个概念边界？我错在知识缺失，还是边界误判？
> 5. **考前只刷三类东西**：反定义清单、关键词配对表、大题动词表。

> [!warning] 复习顺序别倒
> **知识 → 理解命题逻辑 → 提高判断速度。**
> 先有知识点，再有命题逻辑；反过来就变成纯猜题。

> [!question]- 🎯 自测：不看上面，把三句总公式默写出来
> 1. 选择题：命题意图 → 概念定位 → 边界检查 → 排除偷换
> 2. 材料题：材料现象 → 现实问题 → 命题人预设结论 → 教材标准术语 → 材料佐证
> 3. 最高层：不要只问「正确答案是什么」，而要问「为什么在这套考试体系里，它必须成为正确答案？」
