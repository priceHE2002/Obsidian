> [!important] 三条反直觉结论
> 1. **「部署」在校招子集里是 64%**——学生岗不是只要会读论文，几乎都在问「能不能把模型跑到真机上」。这正好是你最容易补的工程短板。
> 2. **「论文」在校招子集 64%，社招只有 42%**——校招就是用论文筛研究能力，所以 CounterStruct 需要一篇像样的产出（arXiv + 开源 + 可复现实验）。
> 3. **VLA 在校招子集 67%，社招只有 20%**——说明 VLA 是「校招入口语言」，社招更看你做过什么系统。用 VLA 敲门、用 infra/数据能力立足，是最顺的路径。

## 四、可信度、局限与维护

### 4.1 链接校验

152 条 URL 逐个 curl（跟随跳转、Chrome UA、25s 超时）：**150 条 200**；1 条 302（星尘智能 Moka 校招，正常跳转）；1 条 000（腾讯 Robotics X 的第三方转载页 `jobs.niuqizp.com`，curl 层不可达，建议面试前用浏览器复核）。

### 4.2 已知局限

- **时间窗**：2026-10-31 快照。招聘页随时下线/改价，投递前必须点开原链接确认「在招」。
- **样本偏差**：以「能抓到正文」为筛选条件，所以偏好猎聘与飞书 ATS 的公司；不用猎聘的公司（如部分大厂）覆盖不足。上海占 72% 是专项任务导致，不代表市场结构。
- **薪资**：仅 90 条披露，且「面议」「未注明」居多；区间口径不统一（月薪 / 年包 / 日薪实习）。
- **方向归类**：按「标题优先 + 正文加权」的规则做**独家**分类，一条 JD 只进一个方向；实际岗位常跨方向（如 VLA+仿真）。多标签口径见 [[01_JD数据总览#三、技能覆盖率（这张表是学习优先级的原始依据）|技能覆盖率]]。
- **未收录**：ABB / 梅卡曼德 / 思灵 / 遨博 / 珞石（上海无算法岗或仅北京）、禾赛与 NVIDIA 上海岗（已暂停）、达闼（在招岗全在成都/北京/深圳）、复旦/上交电院/中科院上海微系统所（站点不可达或空壳）。

### 4.3 维护方式

1. 新增 JD：把 JSON 放进 `~/Desktop/embodied_jd/raw/`（字段见 `build.py` 的 `FIELDS`）。
2. 重跑：`python3 build.py`（用 `~/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3`，系统 python 没有 openpyxl）。
3. 更新本页数字与 [[08_JD明细_152条]]，并在 [[00_求职总览]] 的更新日志加一行。
