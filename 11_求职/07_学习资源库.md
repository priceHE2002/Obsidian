## 五、环境搭建（W0 三天清单）

```bash
# 1) Python 环境（推荐 uv 或 conda）
uv venv --python 3.10 && source .venv/bin/activate

# 2) PyTorch（按 CUDA 版本选）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 3) 仿真
pip install mujoco
pip install "lerobot[aloha,pusht]"

# 4) 验证
python -c "import torch, mujoco, lerobot; print(torch.__version__, torch.cuda.is_available())"
```

- **GPU 要求**：π0/OpenVLA 推理 ≥ 16G 显存（7B 模型需 24G+ 或量化）；Isaac Lab ≥ RTX 3090。
- **没卡怎么办**：Colab/AutoDL 租卡（按小时），或只用 LeRobot 的小模型（ACT 在 8G 卡上可跑）。
- 记录版本到仓库 `docs/env.md`，面试会问「你什么环境跑的」。
