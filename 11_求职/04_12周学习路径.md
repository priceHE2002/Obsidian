# 12 周学习路径

> [!info] 前提与假设
> - **起点**：读完 22 篇 VLA 论文（有笔记）+ DL/RL 基础 + 训练基础设施知识；**没有跑通过机器人策略，没写过 ROS/C++ 工程**。
> - **时间**：每周 20–25 h（工作日 2h + 周末 8h）。如果只有 10h/周，见 [[#七、时间减半版（10h/周）|裁剪版]]。
> - **目标**：12 周后手上要有 **1 个能演示的项目 + 1 份研究产出 + 1 份能过简历筛的简历**，而不是「学完一堆课」。
> - 每周的「产出」必须落在 GitHub 仓库 `embodied-portfolio` 里，对应 [[06_简历与面试策略]] 的项目叙事。

## 三、逐周详情

### W0 环境与基线（3 天）

- [ ] 装好环境：CUDA/PyTorch（按显卡）、`git`、`docker`、`conda/uv`；记录版本到 `docs/env.md`
- [ ] 克隆 LeRobot，跑通官方 `lerobot` 推理 demo（预训练 ACT 或 π0 权重）
- [ ] 装 MuJoCo（`pip install mujoco`）跑通一个 `mujoco_playground` 例子；Isaac Lab 视显卡决定（≥ RTX 3090 可装）
- [ ] 建 GitHub 仓库 `embodied-portfolio`，建目录：`repro/` `projects/` `research/` `docs/`
- [ ] 读 [[03_学习优先级报告#八、能力自测表（30 项，0–3 分）|自测表]] 打一遍分，标出 0 分项
- **验收**：demo 视频（30s）+ `docs/env.md` + 自测分数表

### W1 VLA 复现 I：π0 / OpenVLA

- **输入**：重读 [[02_π0]]、[[01_OpenVLA]]、[[01_PaLM-E]]、[[01_RT-2]]（你已有笔记，这次带着「代码怎么跑」读）
- **做**：
  - [ ] 跑 openpi（π0）在仿真环境的推理；记录延迟/显存/输入输出格式
  - [ ] 跑 OpenVLA 推理；对比「离散 action token」与「flow matching」在实现上的差异
  - [ ] 写 `repro/vla_compare.md`：架构 / 动作表示 / 训练目标 / 推理成本 四列表
- **验收**：能在白板上画出两条数据流；能说出各自适合什么硬件与数据规模

### W2 VLA 复现 II：ACT / Diffusion Policy + 评测

- **输入**：[[01_ACT]]、[[01_Diffusion Policy]]、[[01_Octo]]
- **做**：
  - [ ] 用 LeRobot 在公开数据集（如 `lerobot/aloha_sim_insertion_human` 或 LIBERO 数据）训练 ACT 与 Diffusion Policy
  - [ ] 用 LIBERO 或 SimplerEnv 评测，得到成功率；对照论文数字解释差距
  - [ ] `repro/results.md`：四模型成功率 + 训练成本（GPU 小时）+ 推理延迟
- **验收**：M1——四模型对比表 + 2000 字技术报告（可直接当面试材料）

### W3 RL 后训练 I：PPO / GRPO 实现

- **输入**：[[08_PPO_GRPO与交叉熵]] 重读 + CS285 对应章节
- **做**：
  - [ ] 从零实现 PPO（或读 CleanRL 后改写），在 CartPole/MuJoCo 小任务上跑出学习曲线
  - [ ] 实现 GRPO 的组内归一化，对比 PPO 的方差
  - [ ] 记录 reward 设计、KL、熵、clip 比例的监控
- **验收**：两条曲线 + 能解释「为什么 GRPO 在 LLM 上更省」

### W4 RL 后训练 II：SFT → RL 微调（VLA）

- **输入**：[[01_SimpleVLA-RL]]、[[01_FLOWER]]（联邦/持续学习视角）
- **做**：
  - [ ] 在 W2 的 SFT 模型上做 RL 微调（reward = 任务成功或距离塑形）
  - [ ] 对照 SFT 与 RL 微调的成功率/步数；记录退化案例
- **验收**：M2——一份「SFT vs RL 微调」对照报告；能讲清 reward hack

### W5 数据引擎

- **做**：
  - [ ] 用遥操作或开源数据准备 **50–100 条** demo，转成 LeRobot dataset 格式
  - [ ] 写数据清洗/切分脚本；定义评测协议（成功率/时长/泛化测试集）
  - [ ] 读 OXE / DROID / AgiBotWorld 数据说明，写 1 页对比
- **验收**：训练脚本能直接吃你的数据；数据卡片（规模/采集方式/局限）

### W6 仿真 + 部署链路

- **做**：
  - [ ] Isaac Lab（或 MuJoCo Playground）跑通一个 manipulation/locomotion 任务
  - [ ] 把训练好的策略 ONNX 导出 → TensorRT 或 `torch.compile`/量化，测延迟
  - [ ] ROS2：写一个 node 发布观测、订阅动作（或仿真接口），打通「推理→控制」
- **验收**：`docs/deploy.md` 有链路图 + 延迟数字

### W7 项目 1 收尾（核心里程碑）

- **做**：
  - [ ] 用 W5 数据训练 π0/ACT，在仿真里评测；若买了桌面臂（SO-100/ALOHA mini），做真机演示
  - [ ] 录制 2–3 分钟 demo 视频；写 README（问题/方法/结果/局限）
  - [ ] 失败分析：哪些场景失败、为什么、怎么改
- **验收**：M3——**一个能放进简历、能讲 5 分钟的项目**（[[06_简历与面试策略#三、三个 portfolio 项目|项目 1 标准]]）

### W8 论文/研究迁移 + 简历 v1

- **做**：
  - [ ] 把 CounterStruct 的「持续学习 + 固定容量」写成「具身策略持续学习」的 3 种叙事（[[06_简历与面试策略#二、CounterStruct 的三种包装|见简历笔记]]）
  - [ ] 做一个小实验：LIBERO 多任务顺序学习，对比 naive fine-tune vs 你的方法（哪怕只跑 2 个任务）
  - [ ] 写 arXiv/workshop 摘要（1 页）；简历 v1 完成
- **验收**：简历 v1 可投；研究叙事 2 分钟版能背下来

### W9 运控/MPC 速成 + C++ 工程

- **做**：
  - [ ] [[05_分方向专项路线#Track 3 · 运动控制 / 全身控制（只到能对话）|Track 3]] 速览：正逆运动学、雅可比、PD/阻抗、MPC 思想

  - [ ] 找一处开源 C++ 代码（LeRobot C++ 或 ROS2 示例）读懂 + 改一个功能
- **验收**：能和运控岗面试官聊 10 分钟不露怯

## 六、设备与预算（可选）

| 项 | 方案 A（0 元） | 方案 B（~3000 元） | 方案 C（~1.5 万） |
|---|---|---|---|
| 训练 | Colab / 实验室卡 / 租 A100（按小时） | 同左 + 消费级 RTX 4090 | 4090 主机 |
| 仿真 | MuJoCo + SimplerEnv（够用） | + Isaac Lab | + Isaac Sim 全功能 |
| 真机 | 纯仿真 | SO-100 桌面臂 + 相机（LeRobot 生态） | ALOHA mini / 二手机械臂 |
| 建议 | 先 A 起步，W5 后按需升 B | **推荐**：有真机 demo 的简历强很多 | 除非确定做真机方向 |

> 没有真机不是硬伤：**仿真 + 视频 + 诚实说明「无真机、有仿真闭环」**，比编造强。多数面试官会问「你项目里最难的 bug」，而不是「你有没有机械臂」。

4. **W9–W12（4 周）**：面试题库 + mock

砍掉：Isaac Lab、RL 微调、ROS2、C++、数据自采、运控 demo。等拿到面试再用项目倒逼补。
