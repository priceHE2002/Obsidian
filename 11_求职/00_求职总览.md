# 求职总览 · 具身智能算法岗

> [!abstract] 一句话结论
> 用 **152 条真实 JD**（92 家公司，2026-10 采集）反推：校招/实习通道最看重的是 **① VLA / 具身大模型理解 ② RL 后训练 ③ 论文/研究产出 ④ 能把模型真的部署到仿真或真机**。
> 你的最优切入不是从零补传统运控，而是 **「VLA 训练 / 后训练 + 数据与训练 Infra」**——它同时吃到你已有的研究资产（[[00_CounterStruct_v2.1_方案导读_逐章讲解|CounterStruct]]：持续学习、结构稀疏、训练实验）和 [[01_具身智能论文精讲|22 篇 VLA 论文精读]]。

## 三条主攻路线（按「匹配度 × 岗位量」排序）

| 优先级 | 路线 | JD 证据 | 你现在的距离 | 12 周可交付 |
|---|---|---|---|---|
| **A（主线）** | VLA / 具身大模型算法 | 独家方向 63/152 条（41%）；校招 33 条里 22 条是 VLA；[[08_JD明细_152条#具身大模型 / VLA\|VLA 明细]] | 论文已读 22 篇，缺**复现 + 数据 + 真机闭环** | 「π0/OpenVLA 复现 + 自采数据微调 + sim/真机评测」项目 |
| **B（差异化）** | 具身训练 / 数据 Infra | 智元「预训练 Infra」「训练效率」实习（300–500/天）、光轮智能实习（500–800/天）、字节「数据算法工程师-具身智能」 | 最近：[[01_Megatron-LM]]、[[01_FSDP]]、[[01_FlashAttention]]、[[01_LoRA]]、[[01_nano-vllm 源码剖析]] 已学 | 「多卡训练 VLA + 推理加速 + 数据管线吞吐」技术报告 |
| **C（备选）** | RL 后训练 / 仿真 sim2real | 75 条提及强化学习（49%）、校招子集 64%；[[01_SimpleVLA-RL]]、Isaac Lab 高频 | 中：PPO/GRPO 有笔记（[[08_PPO_GRPO与交叉熵]]），缺 Isaac/MuJoCo 工程 | 「Isaac Lab 里跑通 RL 微调 + sim2real 对照实验」 |

> [!tip] 为什么不是「运控 / 规划 / SLAM」
> 这三类在 JD 里各占 15–18 条，但 **校招只有 2–3 条**，且要求 3 年以上实机经验（社招 103 条中运控要求 C++ 71%、ROS 63%）。它们是「面试要能对话」的 P1 知识，不是主攻产出方向。详见 [[03_学习优先级报告#六、反面清单（明确不做的方向）|反面清单]]。

## 关键数字（先看校招子集，不要只看全量）

| 口径 | 数字 |
|---|---|
| 总样本 | **152 条 JD / 92 家公司**（上海 110 · 北京 16 · 深圳 14 · 杭州 6 · 美国 5 · 苏州 1） |
| 学生可投 | **校招 22 + 实习 11 = 33 条**（含非夕 5、摩尔线程 3、发那科 2、智元 2） |
| 方向分布（独家） | VLA 63（41%）· RL 21 · 运控 18 · 规划 15 · 自驾 8 · 感知 8 · 仿真/世界模型 7 · 灵巧/触觉 7 |
| 薪资 | 90/152 披露，**中位 30–60K**，跨度 15–110K（专家岗 200K 上限） |
| 全量技能 Top | Python 59% · C++ 56% · 部署 54% · 仿真 54% · RL 49% · 论文 48% · ROS 46% · PyTorch 42% |
| **校招子集技能 Top** | **VLA 67% · RL 64% · 部署 64% · 论文 64% · PyTorch 64% · Python 58% · VLM 55% · 仿真 55%** |
| 社招强调什么 | C++ 60% · Python 59% · 仿真 53% · 部署 48% · ROS 47% · 运控 35% · 真机 34% |

> 一句话读法：**校招看研究潜力与 VLA/RL 深度，社招看 C++/ROS/真机工程闭环。**所以学生阶段把「论文 + 复现 + 真机 demo」做出来，比刷 100 道 C++ 题更划算。
