# 投递追踪

> [!tip] 用法
> 1. 在 `11_求职/投递/` 下为**每一家公司**建一个笔记（文件名：`公司名-岗位.md`）。
> 2. 从下面「模板」复制 frontmatter，改字段即可。
> 3. 本页的 Dataview 看板会自动汇总（本 vault 已装 dataview 插件）。
> 4. 每次面试后**当天**更新 `stage` 和 `updated`，并把复盘写在笔记正文。

## 一、投递看板（自动汇总）

```dataview
TABLE WITHOUT ID
  file.link AS "公司-岗位",
  stage AS "阶段",
  city AS "城市",
  salary AS "薪资",
  next_date AS "下一步时间",
  next_action AS "下一步动作"
FROM "11_求职/投递"
WHERE stage != "已放弃"
SORT choice(stage = "面试中", 1, choice(stage = "已投递", 2, choice(stage = "笔试", 3, 4))) ASC,
     next_date ASC
```

## 二、按阶段统计

```dataview
TABLE WITHOUT ID stage AS "阶段", length(rows) AS "数量"
FROM "11_求职/投递"
GROUP BY stage
SORT length(rows) DESC
```

## 三、待跟进（7 天内）

```dataview
LIST next_action
FROM "11_求职/投递"
WHERE next_date != null AND date(next_date) <= date(today) + dur(7 days)
SORT next_date ASC
```

## 四、已获面试

```dataview
TABLE WITHOUT ID
  file.link AS "公司-岗位",
  round AS "轮次",
  updated AS "最后更新",
  next_date AS "下次面试"
FROM "11_求职/投递"
WHERE stage = "面试中"
SORT date(next_date) ASC
```
