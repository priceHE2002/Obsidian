# 一、整数的表示与类型转换

> PDF：P1-P4

## 1. n bit 整数表示范围

- **无符号整数**：

$$
0\sim 2^n-1
$$

- **带符号整数（补码）**：

$$
-2^{n-1}\sim 2^{n-1}-1
$$

> [!important] 手算判断溢出的朴素原则
> **先手算求数学真值，再检查是否超出相应类型的表示范围。**

---

## 2. 补码快速转原码 / 真值

- **符号位为 0**：补码与原码相同，直接解释真值。
- **符号位为 1**：从右向左找到第一个 `1`；该位及其右边保持不变；它左边的所有数值位取反；**符号位仍保持为 1**。
- 特别地，补码

```text
1000...00
```

表示

$$
-2^{n-1}
$$

它无法转换成同位数的常规原码，直接写真值即可。

---

## 3. 高频考点：不同类型整数变量之间转化

> [!important] 一句话总纲
> **先按“原有符号性”完成扩展 / 截断，再按“目的符号性”解释。**

### 3.1 同宽转换

- 位宽不变。
- 只改变解释方式，不改变机器数位模式。

例如：

```text
signed short <-> unsigned short
int <-> unsigned int
```

### 3.2 位宽变大

#### 原数是带符号整数

1. 先做**符号扩展**（复制符号位）。
2. 再按目的类型解释。

#### 原数是无符号整数

1. 先做**零扩展**（高位补 0）。
2. 再按目的类型解释。

### 3.3 位宽变小

1. **截断**，只保留低位。
2. 再按目的类型解释。

> [!warning] 408 题目的模型
> 以下涉及“超范围值转带符号类型”的题目，均按 408 常用代码机器的**保留低位**模型作答；严格 C 标准下，结果可能与具体实现有关。

---

## 4. 可能发生整数位宽变化的位置

| 层次 | 典型情况 | 示例 |
|---|---|---|
| C 语言层 | 赋值、强制类型转换 | `short -> int`、`int -> short` |
| 汇编语言层 | 指令指定符号扩展或零扩展 | `MOVSX`、`MOVZX` |
| 硬件层 | 短立即数、ALU 输入需要统一位宽 | 12 位立即数扩展为 32 位 |
| 硬件层 | 宽结果写回窄寄存器或只保留低位 | 只写回 `2n` 位乘积的低 `n` 位 |

---

## 5. x86 汇编：扩展与“低位部分”

> 拓展了解，原讲义标注为“不考”。

```asm
mov ax, 0FF86H
; AX = FF86H
; 0FF86H = FF86H，前导 0 仅为汇编语法需要，不影响数值

movsx ebx, ax
; 符号扩展
; EBX = FFFFFF86H，按补码解释为 -122

movzx eax, ax
; 零扩展
; EAX = 0000FF86H，按无符号数解释为 65414

; 观察“宽数据的低位部分”
mov eax, 12345678H
; EAX = 12345678H，此时低 16 位子寄存器 AX 自然为 5678H

; 后续若只读取 AX，或将 AX 写入 16 位内存单元，
; 就相当于只保留低 16 位

; 注意：不能写 mov ax, eax，因为 mov 的两个操作数必须同宽
```

> [!note]
> 扩展方式由 `MOVSX` 或 `MOVZX` 明确指定，而不是由 EAX、EBX 本身决定。机器并不知道原本存的是带符号数还是无符号数，编译器 / 汇编程序员必须按正确逻辑使用对应指令。

## 课堂练习 1｜位宽和类型变化

假定 `short`、`unsigned short` 为 16 位，`int`、`unsigned int` 为 32 位。分别求最终机器数和真值。

```c

// III. 位宽不变（16 -> 16），类型变化

// IV. 位宽变大（16 -> 32），类型也变

short r = -1;

// V. 位宽变小（32 -> 16），类型也变
int t = -1;
unsigned short u = t;      // 带符号 -> 无符号

unsigned int t2 = 65535;
short u2 = t2;             // 无符号 -> 带符号（截断保留低 16 位，再按补码解释）
```

# 二、IEEE 754 浮点数（以 float 为例）的表示

> PDF：P4-P8

> [!important] 舍入约定
> 本讲浮点转换和运算如未特别说明，均按**舍入到最近，恰好中点取偶**分析。

## 1. 浮点数结构与真值

### 1.1 单精度 float

| 字段 | 位数 |
|---|---:|
| 符号位 `S` | 1 bit |
| 阶码 `E` | 8 bit |
| 尾数 `F` | 23 bit |

- 共 32 位。
- 阶码偏置值：**127**。

### 1.2 双精度 double

| 字段 | 位数 |
|---|---:|
| 符号位 `S` | 1 bit |
| 阶码 `E` | 11 bit |
| 尾数 `F` | 52 bit |

- 共 64 位。
- 阶码偏置值：**1023**。

---

## 2. 特殊状态的浮点数

> 阶码“全 0 / 全 1”留作特殊用途，需要按专门规则解释真值。

| 类型 | 符号位 | 阶码 | 尾数 | 真值 / 含义 |
|---|---|---|---|---|
| 正零 | 0 | 全 0 | 全 0 | `+0` |
| 负零 | 1 | 全 0 | 全 0 | `-0` |
| 正非规格化数 | 0 | 全 0 | `f != 0` | $2^{-126}(0.f)_2$ |
| 负非规格化数 | 1 | 全 0 | `f != 0` | $-2^{-126}(0.f)_2$ |
| 正无穷大 | 0 | 全 1 | 全 0 | $+\infty$ |
| 负无穷大 | 1 | 全 1 | 全 0 | $-\infty$ |
| NaN | 0 或 1 | 全 1 | `f != 0` | NaN |

---

## 3. 规格化数与非规格化数真值公式

### 3.1 规格化浮点数

$$
(-1)^S\times (1.F)_2\times 2^{E-127}
$$

> [!important]
> 规格化数有**隐藏的前导 1**，因此 float 具有 **24 位有效精度**。

### 3.2 非规格化浮点数

$$
(-1)^S\times (0.F)_2\times 2^{-126}
$$

### 3.3 重要边界

- 最小正非规格化数：

$$
2^{-149}
$$

- 最小正规格化正数：

$$
2^{-126}
$$

- 最大有限正数：

$$
(2-2^{-23})2^{127}
$$

### 3.4 数轴上的关键区域

```text
负上溢 | 可表示负规格化数 | 负下溢 | 0 | 正下溢 | 可表示正规格化数 | 正上溢
                          ↑非规格化数区域↑
```

- 最小绝对值非零 float：$2^{-149}$。
- 最小正规格化正 float：$2^{-126}$。
- 最大有限正 float：$(2-2^{-23})2^{127}$。

---

## 4. 编码与解码

### 4.1 编码：十进制真值 → IEEE 754

思路：

1. 确定符号位 `S`。
2. 将绝对值转换成二进制。
3. 写成规格化形式：

$$
1.F\times 2^e
$$

4. 求阶码字段：

$$
E=e+127
$$

5. 去掉隐藏位 `1`，得到尾数字段 `F`。
6. 拼接：

```text
S | E | F
```

### 4.2 解码：IEEE 754 → 十进制真值

1. 拆分：

```text
S | E | F
```

2. 判断编码类别：规格化 / 非规格化 / 特殊值。
3. 恢复尾数：规格化恢复 `1.F`，非规格化恢复 `0.F`。
4. 计算实际指数。
5. 代入真值公式。

---

## 5. 十进制真值能否被 float 精确表示：检查精度

判断一个十进制有理数转换成二进制小数后，能否在有限位后结束。

> [!tip] 快速判断二进制小数能否有限结束
> 1. 先将真值写成最简分数。
> 2. 分母分解质因数。
> 3. 分母只含因子 `2` → 二进制小数可有限结束。
> 4. 分母含 `5`、`3`、`7` 等其他因子 → 二进制小数会无限循环。

| 数值 | 最简分数及分母 | 结论 |
|---|---|---|
| `0.125` | $1/8,\;8=2^3$ | 二进制有限 |
| `0.75` | $3/4,\;4=2^2$ | 二进制有限 |
| `0.2` | $1/5$，含因子 5 | 二进制无限循环 |
| `0.3` | $3/10,\;10=2\times5$ | 二进制无限循环 |
| `3/12` | 先约为 $1/4$ | 二进制有限 |

> [!important] 一句话总结
> 确定真值的二进制能够有限结束后，还要检查**有效数字是否能装入 float 的 24 位有效精度**。
>
> 例如：$2^{24}+1$ 不能精确表示，而 $2^{24}+2$ 可以精确表示。

---

## 6. 真值能否用 float 装下：检查范围

| 数值 | 能否成为有限 float | 能否精确表示 |
|---|---|---|
| `0.2` | 能 | 不能 |
| $2^{24}+1$ | 能 | 不能 |
| $2^{24}+2$ | 能 | 能 |
| $2^{128}$ | 不能，上溢 | — |
| $2^{-150}$ | 能，舍入后为 0 | 不能精确表示原非零值 |

---

## 7. 浮点数大小比较

- **同为正规格化数**：
  - 正数按阶码、尾数顺序比较。
  - 负数按相反方向比较。
- **同为正非规格化数**：尾数字段越大，真值越大；同为负非规格化数则相反。
- 任意正的规格化数大于任意正非规格化数；任意负规格化数小于任意负非规格化数。
- 特殊值：
  - $+\infty$ 大于所有有限数；$-\infty$ 小于所有有限数。
  - `+0 == -0`。
  - NaN 与其他数的大小比较为**无序**；NaN 与自身也不相等。

# 三、C 语言整型、浮点型跨类型转换

> PDF：P8-P9

> [!important]
> 408 常考 **32 位 `int` 与 32 位 `float`** 的转换：二者占用空间相同，但 `float` 只有 **24 位有效精度**。因此整型转 float 时通常不缺范围，却可能丢失精度。

## 1. 常见转换结论

| 转换 | 结论 |
|---|---|
| `int -> float` | 可能丢失精度 |
| `float -> int` | 范围内向 0 截断；超出目标整数范围时，标准 C 不保证结果 |
| `32 位 int -> double` | 可以精确表示 |
| `float -> double` | 已有 float 值可以精确扩大 |
| `double -> float` | 可能舍入、上溢或下溢 |

---

## 2. x86 转换指令（拓展了解，考试不考）

| C 转换 | x86 常见指令 |
|---|---|
| `int -> float` | `CVTSI2SS` |
| `float -> int`，向 0 截断 | `CVTTSS2SI` |
| `float -> double` | `CVTSS2SD` |
| `double -> float` | `CVTSD2SS` |

拓展示例：

```asm
; CVTSI2SS xmm0, eax
; 把 eax 中的带符号整数转换为 float，写入 xmm0 低 32 位
; 例：eax = 16777217
; xmm0 低 32 位为 4B800000H
; 即 16777216.0f，超出 24 位有效精度的部分被舍入

; CVTTSS2SI eax, xmm0
; 把 xmm0 低 32 位 float 向 0 截断转换为 int，写入 eax
; 例：123.75f -> 123；-123.75f -> -123
```

# 四、整数加减法、标志位与移位

> PDF：P9-P12

## 1. 四个标志位

### 1.1 整数加减运算与标志位

| 标志 | 含义 |
|---|---|
| `CF` | 无符号加法产生进位，或无符号减法发生借位 |
| `OF` | 带符号整数（补码）加减法发生溢出 |
| `ZF` | 保留结果为 0 |
| `SF` | 保留结果的最高位 |

> [!warning]
> `SF` 只是截断后结果的最高位；当 `OF = 1` 时，不能根据 `SF` 判断数学真值的正负。

> [!important] 为什么这四个标志位特别适合整数加减
> 加法 / 减法（以及比较 `CMP`，本质上做一次减法但不保存结果）会同时产生：
>
> - 结果值
> - 进位 / 借位
> - 符号信息
>
> 这些信息恰好能覆盖整数运算中最常见的判断：是否为 0、结果正负、无符号大小关系。因此后续很多 if/else、循环判断会直接依赖这些标志位。

### 1.2 整数乘除与标志位

- x86 `MUL/IMUL`：主要规定 `CF`、`OF`，溢出时置 1；`ZF`、`SF` 等通常未定义。
- x86 `DIV/IDIV`：`CF`、`OF`、`ZF`、`SF` 通常未定义。
- x86 除法溢出异常通常不能表述为“OF 置 1”。

### 1.3 浮点数与这几个标志位

普通浮点加减不按整数加减规则使用 `CF / OF / ZF / SF`；浮点运算状态通常由专用状态寄存器记录。具体浮点比较指令是否更新部分标志位，由 ISA 规定。

---

## 2. `CMP` 与 `SUB` 的区别（x86）

在 if-else 语句中，比较两个整数的大小时，机器底层对无符号整数和带符号整数都可以先用同一套减法逻辑产生标志位。

```asm
SUB A, B
; 计算 A-B，保存结果并更新标志位

CMP A, B
; 计算 A-B，不保存结果，只更新标志位
```

---

## 3. x86 条件转移

> `∧` 表示两个条件必须同时成立；`∨` 表示至少一个条件成立。

| 比较关系 | 数学写法 | 真题选项常写法 | x86 |
|---|---|---|---|
| 相等（通用） | $ZF=1$ | `ZF=1` | `JE` |
| 不等（通用） | $ZF=0$ | `ZF=0` | `JNE` |
| 无符号小于 | $CF=1$ | `CF=1` | `JB` |
| 无符号大于等于 | $CF=0$ | `CF=0` | `JAE` |
| 无符号小于等于 | $CF=1\lor ZF=1$ | `CF=1 或 ZF=1` | `JBE` |
| 无符号大于 | $CF=0\land ZF=0$ | `CF=0 且 ZF=0` | `JA` |
| 带符号小于 | $SF\oplus OF=1$ | `SF != OF` | `JL` |
| 带符号大于等于 | $SF\oplus OF=0$ | `SF = OF` | `JGE` |
| 带符号小于等于 | $ZF=1\lor(SF\oplus OF=1)$ | `ZF=1 或 SF!=OF` | `JLE` |
| 带符号大于 | $ZF=0\land(SF\oplus OF=0)$ | `ZF=0 且 SF=OF` | `JG` |

### 同一条 CMP，不同 signed/unsigned 分支

```c
int x = -1, y = 1;
if (x > y) {
    // signed 大于：-1 > 1 ?
}

unsigned int ux = 0xFFFFFFFFu, uy = 1u;
if (ux > uy) {
    // unsigned 大于：4294967295 > 1
}
```

对应汇编思路：

```asm
; x 与 y 放在 eax, ebx
cmp eax, ebx
jg  L_signed_gt       ; signed: (ZF=0) 且 (SF=OF)

; ux 与 uy 放在 eax, ebx（位串相同，但解释为无符号）
cmp eax, ebx
ja  L_unsigned_gt     ; unsigned: (CF=0) 且 (ZF=0)
```

## 4. MIPS 简要对照

MIPS 没有 x86 的 `CF、OF、ZF、SF`，但比较大小时仍要区分带符号数和无符号数。

| 指令 | 含义 |
|---|---|
| `beq rs, rt, label` | `rs = rt` 时跳转 |
| `bne rs, rt, label` | `rs != rt` 时跳转 |
| `slt rd, rs, rt` | 按带符号数比较；`rs < rt` 时 `rd = 1` |
| `sltu rd, rs, rt` | 按无符号数比较；`rs < rt` 时 `rd = 1` |
| `blt / bge` | 按带符号数进行小于 / 大于等于判断，通常为伪指令 |
| `bltu / bgeu` | 按无符号数进行小于 / 大于等于判断，通常为伪指令 |

> [!important]
> `slt/sltu` **只比较、不跳转**，把结果 `0/1` 写入 `rd`，可再配合 `beq/bne` 决定是否跳转。

示例：实现 `if ($s1 < $s2) goto L`（带符号）：

```asm
slt  $t0, $s1, $s2
bne  $t0, $zero, L
```

伪指令写法：

```asm
blt  $s1, $s2, L
```

汇编器可展开为：

```asm
slt  $at, $s1, $s2
bne  $at, $zero, L
```

### 六种比较关系的推导

| 关系 | 推导思路 | 真实指令组合 |
|---|---|---|
| `a=b`、`a!=b` | 直接判断 | `beq / bne a,b,L` |
| `a<b` | 直接判断 | `slt rd,a,b`，`rd=1` 成立 |
| `a>b` | 交换：等价于 `b<a` | `slt rd,b,a`，`rd=1` 成立 |
| `a>=b` | 取反：非 `(a<b)` | `slt rd,a,b`，`rd=0` 成立 |
| `a<=b` | 交换 + 取反：非 `(b<a)` | `slt rd,b,a`，`rd=0` 成立 |

> [!note] RISC 与 CISC 风格对照
> MIPS（RISC）硬件主要依赖 `beq/bne + slt`，其余关系由软件推导；`bgt/ble` 等常为伪指令。x86（CISC）则提供 `JL/JGE/JLE/JG` 等整套条件转移指令，靠标志位组合区分。

## 5. 移位运算

| 操作 | 补入内容 | 与乘除法的关系 |
|---|---|---|
| 左移 `k` 位 | 低位补 0 | 未丢失有效位时等价于乘 $2^k$ |
| 逻辑右移 `k` 位 | 高位补 0 | 无符号整数等价于除 $2^k$ 后向下取整 |
| 算术右移 `k` 位 | 高位补符号位 | 负数通常向负无穷取整，不一定等于 C 语言“向 0 截断”的除法 |

例如：

```text
-5 算术右移 1 位 -> -3
C 语言 -5/2 -> -2
```

### 指令对照

| 操作 | x86 | MIPS |
|---|---|---|
| 左移 | `SHL / SAL` | `SLL` |
| 逻辑右移 | `SHR` | `SRL` |
| 算术右移 | `SAR` | `SRA` |

### x86 `SHL/SAL` 的标志位

- `CF` 保存**最后一个被移出最高位的比特**。
- 仅当移位次数为 1 时：

$$
OF=CF\oplus \text{结果最高位}
$$

- 移位次数大于 1 时，`OF` 通常未定义。

> [!warning]
> 整数移位指令不能直接实现浮点数乘除 2。若把 float 位串强行当作整数移位，得到的通常是另一个无关浮点数。

# 五、整数乘法

> PDF：P12-P14

## 1. 三种实现方式

| 实现 | 核心思想 | 特点 |
|---|---|---|
| 纯软件 | 循环、移位、加法 | 无专用乘法硬件，速度较慢 |
| 加法器 + 移位 | 逐轮产生部分积 | 多周期、硬件适中 |
| 阵列乘法器 | 并行产生并累加部分积 | 速度快、硬件开销大 |

---

## 2. 乘法器的迭代结构（对应 PDF P13 图）

### 2.1 32 位无符号数乘法

核心部件：

- 被乘数寄存器 `X`：32 位。
- 乘数寄存器 `Y`：32 位。
- 乘积寄存器 `P`：32 位。
- 进位寄存器 `C`：1 位。
- 32 位 ALU。
- 控制逻辑 / 计数器：根据 `Y` 的最低位决定是否加法，并控制移位与循环次数。

每轮思路：

1. 查看 `Y` 的最低位。
2. 必要时由 ALU 将 `X` 加到部分积。
3. 保存本轮加法产生的进位。
4. 对相关寄存器整体右移。
5. 重复固定轮数。

最终结果保存在由两个 `n` 位寄存器构成的 `2n` 位乘积中。

### 2.2 32 位带符号数乘法

PDF 图中用**乘数最低位 + 辅助位**共同决定本轮操作：

| `Y` 低位 | 辅助位 | 本轮操作 |
|---:|---:|---|
| 0 | 0 | `+0` |
| 0 | 1 | `+[X]补` |
| 1 | 0 | `-[X]补` |
| 1 | 1 | `+0` |

随后对相关寄存器做算术右移，并由计数器控制重复次数。

---

## 3. 完整乘积与溢出

两个 `n` 位操作数的完整乘积最多需要 `2n` 位。

若最终**只保留低 `n` 位**：

- **无符号乘法**：高 `n` 位全 0，才不溢出。
- **带符号乘法**：高 `n` 位必须是低 `n` 位符号位的完整扩展，才不溢出。

> [!important] 复习建议（原讲义）
> 强化阶段优先掌握：完整乘积、`2n` 位机器数、高低半部分、signed/unsigned 溢出判断和三种实现方式。除非题目明确询问“第 k 轮寄存器内容”，否则无需逐轮模拟。

# 六、整数除法

> PDF：P14-P15

## 1. 除法器结构（对应 PDF P14 图）

主要部件：

- 除数寄存器 `Y`。
- 余数寄存器 `R`。
- 余数 / 商寄存器 `Q`。
- ALU 执行加 / 减。
- 控制逻辑与计数器根据余数、除数等信息控制移位、写入与循环次数。

开始运算前需要在 `[R,Q]` 中准备被除数；若被除数不足 `2n` 位，需要先进行位扩展。

---

## 2. 手算推演除法结果的逻辑

$$
x=qy+r,\qquad |r|<|y|
$$

> [!important] 一句话总结
> - **无符号除法**：小学学的除法，商向下取整，余数非负。
> - **带符号除法**：额外约定“**商向 0 截断，余数与被除数同号**”。

---

## 3. 几种除法异常

### 3.1 除数为 0

- 无符号、带符号都需要检查除数为 0。

### 3.2 带符号极值除以 `-1`

可能使商超过正数补码表示范围。

### 3.3 单字长被除数 vs 双字长被除数

#### `n` 位无符号被除数 ÷ `n` 位非零无符号除数 → `n` 位商

- 商不可能溢出。
- 除数为 0 仍会触发异常。

#### `2n` 位无符号被除数 `[R:Q]` ÷ `n` 位除数 `Y` → `n` 位商

- `R < Y`：商可装入 `n` 位。
- `R >= Y`：商溢出。

---

## 4. 被除数扩展为双倍字长 `[R:Q]`

### 4.1 无符号被除数：零扩展

- `Q = 被除数`
- `R = 全 0`

例：8 位 `239`：

```text
R:Q = 00EFH
```

### 4.2 带符号被除数（补码）：符号扩展

- `R` 与被除数符号位一致。
- 非负：`R` 全 0。
- 负数：`R` 全 1。

例：8 位 `-17`：

```text
R:Q = FFEFH
```

> [!note]
> 这里与第一章“按原有符号性扩展”的规则一致，也是 2025 年第 44 题“寄存器初值”的直接考点。

# 七、浮点数加减

> PDF：P15-P16

## 1. 基本过程

```text
检查特殊值
    ↓
对阶
    ↓
尾数加减
    ↓
规格化
    ↓
舍入
    ↓
再次规格化
    ↓
检查阶码
```

### 1.1 对阶原则

- 遵循：**小阶向大阶对齐**。
- 可能出现“**大数吞小数**”。
- 对阶右移时保留 `G、R、S` 位。

### 1.2 舍入

按“舍入到最近、恰好中点取偶”。原讲义给出的进位条件：

$$
G\land(R\lor S\lor L)
$$

其中 `L` 为保留部分最低位。

---

## 2. 浮点加减各阶段风险表

| 阶段 | 风险或现象 | float 型加减示例 | 结论 |
|---|---|---|---|
| 对阶 | 低位丢失、大数吞小数 | $2^{100}+1=2^{100}$ | 小操作数被移出有效精度 |
| 尾数相加 | 尾数产生进位 | `1.5f + 1.5f = 3.0f` | 需要右规，但不一定最终上溢 |
| 尾数相减 | 有效数字大量抵消 | $(1+2^{-23})-1=2^{-23}$ | 结果需要多次左规 |
| 右规 | 阶码加 1，可能上溢 | `FLT_MAX + FLT_MAX` | 阶码越界时得到 $+\infty$ |
| 左规 | 阶码减 1，可能进入非规格化区 | `00800000H - 007FFFFFH = 00000001H` | 结果为最小正非规格化数 |
| 舍入 | 舍入进位可能再次右规 | `3FFFFFFFH + 33800000H -> 40000000H` | 中点取偶后得到 `2.0` |
| 最终封装 | 产生无穷、非规格化数或 0 | `FLT_MAX+FLT_MAX`；边界相减；`1.0f+(-1.0f)` | 分别得到 $+\infty$、非规格化数和 0 |

---

## 3. 典型示例：两个最大有限 float 相加

设

$$
x=y=(2-2^{-23})2^{127}
$$

过程：

1. 阶码相同。
2. 尾数相加产生进位。
3. 右规。
4. 阶码加 1。
5. 阶码超出有限数范围。
6. 结果为：

$$
+\infty
$$

# 最后速记

> [!summary] 整数转换
> **同宽只改解释；变宽先按原符号性扩展 / 截断，再按目的符号性解释。**

> [!summary] float 三个最关键数
> - 有效精度：24 位（23 位尾数字段 + 隐藏前导 1）
> - 最小正非规格化数：$2^{-149}$
> - 最大有限正数：$(2-2^{-23})2^{127}$

> [!summary] signed / unsigned 比较
> 同一条 `CMP` 可以生成同一组标志位；**无符号比较主要看 CF/ZF，带符号比较主要看 SF 与 OF 的关系以及 ZF。**

> [!summary] 完整乘积与除法
> - 两个 `n` 位数的完整乘积最多需要 `2n` 位。
> - 无符号只保留低 `n` 位时：高 `n` 位全 0 才不溢出。
> - 带符号只保留低 `n` 位时：高 `n` 位必须是低半部分符号位的完整扩展。
> - 带符号除法：商向 0 截断，余数与被除数同号。

> [!summary] 浮点加减流程
> **特殊值 → 对阶 → 尾数加减 → 规格化 → 舍入 → 再规格化 → 检查阶码。**
