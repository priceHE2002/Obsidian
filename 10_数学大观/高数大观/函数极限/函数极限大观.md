# 函数极限大观

> 求极限的核心思路：**先判型，后出手**。能在极限点直接代入就代入；不能代入就先识别未定式类型，再选最省力的方法。

## 总览

本章复盘一元函数极限的常用方法，共 11 个要点。整体是一条"分流"逻辑线：

- **能不能直接代入**（要点 1）：函数在极限点连续、四则运算合法（分母不为 0）→ 代 $x_0$。
- **要不要分左右**（要点 2）：含 $e$ 指数、反三角、偶次根号、取整、分段，左右极限可能不同。
- **能不能脱帽**（要点 3）：把 $\lim f=A$ 写成 $f=A+\alpha$，把极限条件转成"极限值+无穷小"。
- **要不要换元**（要点 4）：$t=x-x_0$ 或 $x=\frac1t$，把非零/无穷远过程归到 $0$。
- **判型**（要点 5）：$\frac00$、$\frac\infty\infty$、$0\cdot\infty$、$\infty-\infty$、$1^\infty$、$0^0$、$\infty^0$ 七种未定式。
- **选方法**：
  - 乘除型 → **等价无穷小**（要点 6，本质是 Taylor 前几项）。
  - 分子分母相减、阶数不齐 → **Taylor 复杂处理**（要点 7）。
  - 基本型未定式 → **洛必达**（要点 8，注意失效坑）。
  - 幂指型（$1^\infty$ 等）→ **幂指函数专功**（要点 9）。
  - 出现 $f(b)-f(a)$ → **中值定理**（要点 10）。
- **逆问题**（要点 11）：已知极限值/极限存在，反求未知常数。

| # | 要点 | 一句话 |
|---|------|--------|
| 1 | 连续 + 四则运算 | 连续且在极限点合法 → 直接代入 |
| 2 | 左右极限 | $e$ 指数 / 反三角 / 偶次根号 / 取整 / 分段 需分左右 |
| 3 | 脱帽 | $\lim f=A \Rightarrow f=A+\alpha$ |
| 4 | 变量代换 | 把非零 / 无穷远过程归到 $0$ |
| 5 | 未定式设计 | 先识别 7 种未定式再选方法 |
| 6 | 常用等价无穷小 | Taylor 前几项；加减不代换 |
| 7 | Taylor 复杂处理 | 上下同阶 / 抵消不掉 / 吸阶大法 |
| 8 | 洛必达 | 仅基本型；注意失效 + 循环 |
| 9 | 幂指函数专功 | $1^\infty=e^A$；$f^g=e^{g\ln f}$ |
| 10 | 中值定理 | 出现 $f(b)-f(a)$ 用中值 |
| 11 | 逆问题 | 由极限值定未知常数 |

## 一、连续 + 四则运算——直接代入

若 $f(x)$ 在 $x=x_0$ 处连续，则 $\lim_{x\to x_0}f(x)=f(x_0)$。对连续函数做加、减、乘、除（分母极限不为 0），结果仍连续，可直接代入。

> 例：$\lim_{x\to 0}(e^x-2)(e^x-3)\cdots(e^x-n)$。因为 $e^x$ 连续，代 $e^0=1$，得 $(1-2)(1-3)\cdots(1-n)$。

只要"连续 + 四则运算合法"就能直代；一旦出现 $\frac00$、$\frac\infty\infty$、$1^\infty$ 等未定式，就得改用下面的方法。

---

## 二、涉及左右极限的函数

以下函数在极限点处左右极限不相等，必须先分左、右极限再判断极限是否存在：

| 类型 | 说明 |
|------|------|
| $e$ 指数型 | $e^{1/x}$ 在 $x\to0$：右极限 $+\infty$，左极限 $0$；含 $e^x$ 在 $x\to\pm\infty$ 亦不同 |
| 反三角函数 | $\arctan x,\ \text{arccot}\,x$ 在 $x\to\infty$：$x\to\pm\infty$ 分别趋于 $\pm\frac{\pi}{2}$ |
| 含偶次平方根 | $x\to\infty$ 时 $\sqrt{x^2+2}=|x|\sqrt{1+\frac{2}{x^2}}$，因绝对值左右不同 |
| 取整函数 | $[x]$ 在 $x\to$ 整数处左右极限不相等 |
| 分段函数 | 分段临界点处分别算左右，相等才存在 |

判断技巧：先提取无穷大项或符号项。比如 $\sqrt{x^2+2}=|x|\sqrt{1+\frac{2}{x^2}}$，把 $|x|$ 先按符号拆开，剩下部分 $x\to\infty$ 趋于常数。

## 三、脱帽

$$\lim_{x\to x_0}f(x)=A \quad\Longrightarrow\quad f(x)=A+\alpha,\quad \alpha\to 0\ (x\to x_0)$$

即"函数值 = 极限值 + 无穷小量"。用途：把极限条件翻译成无穷小语言，进行放缩、比较或再代入运算；把局部极限为 $A$ 的因子拆成 $A+\alpha$，简化计算。这一思想在中值定理的证明与使用中反复出现。

---

## 四、变量代换

| 原极限过程 | 代换 | 结果 |
|------------|------|------|
| $x\to x_0$ | $t=x-x_0$ | $t\to 0$ |
| $x\to\infty$ | $x=\frac{1}{t}$ | $t\to 0$ |

把"不规则的极限过程"化为标准过程（归到 $0$）。例如导数定义式 $\lim_{x\to x_0}\dfrac{f(x)-f(x_0)}{x-x_0}$，令 $t=x-x_0$，化为 $\lim_{t\to 0}\dfrac{f(x_0+t)-f(x_0)}{t}$。

## 五、极限的未定式设计

先识别未定式类型，才能选对应方法。设 $\lim f(x)=A$，$\lim g(x)=B$：

**（1）$\lim \dfrac{f(x)}{g(x)}$**

| 情形 | 结果 |
|------|------|
| $A$ 为常数，$B$ 为常数 $\ne 0$ | $\dfrac{A}{B}$ |
| $A$ 为常数，$B=\infty$ | $0$ |
| $A=\infty$，$B$ 为常数 | $\infty$ |
| $A=0$，$B=0$ | $\dfrac{0}{0}$ 未定式 |
| $A=\infty$，$B=\infty$ | $\dfrac{\infty}{\infty}$ 未定式 |

**（2）$\lim f(x)g(x)$**

| 情形 | 结果 |
|------|------|
| $A$、$B$ 为常数 | $AB$ |
| $A$ 为常数 $\ne 0$，$B=\infty$（或相反） | $\infty$ |
| $A=0$，$B=\infty$（或相反） | $0\cdot\infty$ 未定式 |

**（3）$\lim\bigl[f(x)-g(x)\bigr]$**

| 情形 | 结果 |
|------|------|
| $A$、$B$ 为常数 | $A-B$ |
| $A$、$B$ 中一个常数、一个无穷大 | $\infty$ |
| $A$、$B$ 为异号无穷大 | $\infty$ |
| $A$、$B$ 为同号无穷大 | $\infty-\infty$ 未定式 |

**（4）$\lim f(x)^{g(x)}$**

| 情形 | 结果 |
|------|------|
| $A$ 为常数 $>0$，$B$ 为常数 | $A^B$ |
| $A=1$，$B=\infty$ | $1^\infty$ 未定式 |
| $A=0$，$B=0$ | $0^0$ 未定式 |
| $A=\infty$，$B=0$ | $\infty^0$ 未定式 |
| $A=0$，$B=+\infty$ | $0$ |
| $A=0$，$B=-\infty$ | $+\infty$ |

七种未定式中，$\dfrac00$ 与 $\dfrac\infty\infty$ 是**基本型**，其余（$0\cdot\infty$、$\infty-\infty$、$1^\infty$、$0^0$、$\infty^0$）都先想办法化成这两种基本型再处理（见第八节）。

## 六、常用等价无穷小（Taylor 的前几项）

等价无穷小本质上是泰勒展开的前几项，是最常用、最快捷的求极限手段。

### 1. 常见的等价无穷小（$x\to 0$）

$$\sin x\sim x,\quad \tan x\sim x,\quad \arcsin x\sim x,\quad \arctan x\sim x$$
$$\ln(1+x)\sim x,\quad e^x-1\sim x,\quad a^x-1\sim x\ln a$$
$$(1+x)^{\alpha}-1\sim \alpha x,\quad 1-\cos x\sim \frac{1}{2}x^2$$

把 $x$ 换成 $\varphi(x)$（$\varphi(x)\to0$）仍成立。例如 $1-\cos(\sin x)\sim\dfrac12\sin^2 x$。

### 2. 常见几个等价公式的变形

**（1）$e^{f(x)}-e^{g(x)}$ 型**

$e^{f}-e^{g}$ 这类式子，提取公因式 $e^{g(x)}$ 使 $f(x)-g(x)\to0$，再对 $e^{f(x)-g(x)}-1$ 用等价无穷小：

$$e^{f(x)}-e^{g(x)}=e^{g(x)}\bigl(e^{f(x)-g(x)}-1\bigr)\sim e^{g(x)}\bigl(f(x)-g(x)\bigr)$$

**（2）$(1+x)^{\alpha}-1\sim\alpha x$**

特别当 $\alpha=\dfrac1n$（$n$ 为自然数）时：

$$\sqrt[n]{1+x}-1\sim\frac{1}{n}x$$

题中出现 $\sqrt[n]{f(x)}-1$（$f(x)\to0$）的因式时，直接使用上述代换。

**（3）$\ln f(x)$ 型**

$\ln(1+x)\sim x$。题中出现 $\ln f(x)$，先检验 $f(x)$ 的极限：若 $f(x)\to1$，则

$$\ln f(x)=\ln\bigl(1+(f(x)-1)\bigr)\sim f(x)-1$$

> 例：$\lim_{x\to0}\dfrac{\ln\cos x}{x^2}$。因 $\cos x\to1$，$\ln\cos x\sim\cos x-1$，故 $\lim\dfrac{\cos x-1}{x^2}=-\dfrac12$。（适合用等价）

### 3. 等价无穷小代换定理

设 $\lim\alpha=0$，$\lim\beta=0$，$\lim\gamma=0$。若 $\alpha\sim\gamma$，则

$$\lim\alpha\beta=\lim\gamma\beta,\qquad \lim\frac{\beta}{\alpha}=\lim\frac{\beta}{\gamma},\qquad \lim\frac{\alpha}{\beta}=\lim\frac{\gamma}{\beta}$$

即**等价无穷小代换可以用在乘除法中**。但**加减法中不能整体代换**（可能出错），应回到泰勒展开原则。口诀："乘除可局部，加减需谨慎。"

### 4. 幂指函数的等价

设 $\lim_{x\to x_0}f_1(x)=\lim_{x\to x_0}g_1(x)=0$，$f_1(x)>0$，$0<|x-x_0|<\delta$，$i=1,2$，且 $f_1\sim f_2$，$g_1\sim g_2$，则

$$\lim_{x\to x_0}f_1(x)^{g_1(x)}=\lim_{x\to x_0}f_2(x)^{g_2(x)}$$

简证：$\lim g_1\ln f_1=\lim g_2\ln\left(\frac{f_1}{f_2}\cdot f_2\right)$，利用 $\frac{f_1}{f_2}\to1$ 与 $\ln(1+u)\sim u$ 化到指数即得。

对"幂指函数相减"$f_1^{g_1}-f_2^{g_2}$，可提取公因式化为 $f_1^{g_1}\left[\left(\frac{f_1}{f_2}\right)^{g_1}-1\right]+\cdots$，再用等价或回到 Taylor。对 $\sqrt[n]{\cos x\cos 2x\cdots\cos nx}$ 这类连乘根式，可取对数化为 $\frac1n\sum\ln\cos(kx)$，再用 $\ln\cos(kx)\sim-\frac12(kx)^2$ 求和。

## 七、利用 Taylor 的复杂处理

当等价无穷小不够用（分子分母相减、阶数不齐）时，泰勒展开是最稳妥的万能手段。

### 展开原则

- **上下同阶**：当所求函数是极限式中的分母（或分子）时，若已知分子（或分母）是 $x$ 的 $k$ 阶无穷小，就把分母（或分子）展成 $k$ 阶麦克劳林公式。
- **抵消不掉**：若所求函数为两个以上函数的代数和，应分别展开到它们的**系数抵消不掉的 $x$ 次幂**为止。
- **吸阶大法**：展开后计算时，正确运用高阶无穷小运算法则——高阶加低阶等于低阶：$o(x^m)+o(x^n)=o(x^m)\ (m<n)$。

判断展开几阶的技巧：先**定阶**（一般展开到能留下"非零主项"的那一阶）；**找齐的部分看整体展开**；**复合函数内层、外层均可展开**。当已知分子分母一高一低、且"低阶会自己抵消、否则极限不存在、高阶没必要算"时，**找全"抵消临界阶"即可**。

### 综合例题

> 例：$I=\lim_{x\to0}\dfrac{2\ln(2-\cos x)-3\bigl[(1+\sin^2 x)^{1/3}-1\bigr]}{x^2\bigl[\ln(1+x)+\ln(1-x)\bigr]}$

**定阶**：分母 $x^2[\ln(1+x)+\ln(1-x)]=x^2\ln(1-x^2)\sim x^2(-x^2)=-x^4$，故需找全 $4$ 阶。

**（1）展开 $\ln(2-\cos x)$**（内层 $\cos x$ 到 4 阶，再展开外层）。记 $u=1-\cos x=\frac12x^2-\frac{1}{24}x^4+o(x^4)$：

$$\begin{aligned}
\ln(2-\cos x)&=\ln(1+u)=u-\frac12u^2+o(x^4)\\
&=\left(\frac12x^2-\frac{1}{24}x^4\right)-\frac12\left(\frac12x^2\right)^2+o(x^4)\\
&=\frac12x^2-\frac{1}{24}x^4-\frac18x^4+o(x^4)=\frac12x^2-\frac16x^4+o(x^4)
\end{aligned}$$

**（2）展开 $(1+\sin^2 x)^{1/3}-1$**（二项展开到 2 次）。记 $u=\sin^2 x=x^2-\frac13x^4+o(x^4)$：

$$\begin{aligned}
(1+\sin^2x)^{1/3}-1&=\frac13\sin^2x-\frac19\sin^4x+o(x^4)\\
&=\frac13\left(x^2-\frac13x^4\right)-\frac19x^4+o(x^4)\\
&=\frac13x^2-\frac19x^4-\frac19x^4+o(x^4)=\frac13x^2-\frac29x^4+o(x^4)
\end{aligned}$$

**（3）代回分子、分母**：

$$\begin{aligned}
\text{分子}&=2\left(\frac12x^2-\frac16x^4\right)-3\left(\frac13x^2-\frac29x^4\right)+o(x^4)\\
&=\left(x^2-\frac13x^4\right)-\left(x^2-\frac23x^4\right)+o(x^4)=\frac13x^4+o(x^4)\\
\text{分母}&=x^2\bigl[\ln(1+x)+\ln(1-x)\bigr]=x^2\ln(1-x^2)=-x^4+o(x^4)
\end{aligned}$$

**（4）求极限**：$I=\lim_{x\to0}\dfrac{\frac13x^4}{-x^4}=-\dfrac13$。

对照复盘笔记：定阶（本题 4 阶）→ 找齐的部分看整体展开 → 复合函数内外层均可展开 → 定阶、比较。$x^2$ 项系数 $\frac12$ 与 $\frac13$ 恰好抵消，只剩 $x^4$ 项之比，得 $-\frac13$。

## 八、洛必达使用要点

洛必达（L'Hôpital）法则对 $\dfrac00$、$\dfrac\infty\infty$ 型未定式极为有效，但使用要点必须记牢。

### 使用前提与转化流程

- 只能对 $\dfrac00$ 或 $\dfrac\infty\infty$ 型**才可直接使用**，使用前**先验证**是不是这两种型及其各条件。
- 其他未定式先化为基本型再应用法则：
  - **$0\cdot\infty$**：写成 $\dfrac{0}{1/\infty}$（即 $\dfrac00$）或 $\dfrac{\infty}{1/0}$（即 $\dfrac\infty\infty$）。原则上把反三角函数、对数函数放分子，其余函数取倒数放分母。
  - **$\infty-\infty$**：通分 / 有理化 / 倒代换 / 提取 $\infty$ 使 $\infty-\infty$ 变为 $\infty\cdot0$。
  - **幂指函数**：$f(x)^{g(x)}=e^{g(x)\ln f(x)}$，即指数化（先化简）。
- 洛必达应**与等价无穷小、恒等变形、四则运算、有理化等配合使用**并及时化简。用后表达式往往复杂，把**非零极限的因子**及时分离出来，会大幅简化计算。

### 不能用洛必达的情况（则需失效）

- 题中**仅仅告知** $f(x)$ 在 $x=x_0$ **一点可导**（导数未必在邻域存在/连续）。
- $x\to0$ 时含 $\sin\frac1x$、$\cos\frac1x$；或 $x\to\infty$ 时含 $\sin x$、$\cos x$。

> 例：$\lim_{x\to0}\dfrac{3\sin x+x^2\cos\frac1x}{(1+\cos x)\ln(1+x)}$。分母 $\sim2x$，拆成 $\lim\dfrac{3\sin x}{2x}+\lim\dfrac12 x\cos\frac1x=\dfrac32+0=\dfrac32$。此处含 $\cos\frac1x$，不能直接对原式洛必达（会振荡），应拆项 + 等价无穷小 + 有界量处理。

### 两个经典坑

**① 求导后极限不存在 ≠ 原极限不存在。** 若对分子分母分别求导后的极限不存在或不为 $\infty$，只说明**此题不适合用洛必达**，但**不意味原极限不存在**。

> 例：$\lim_{x\to\infty}\dfrac{2x-\sin x}{3x+\cos x}$。洛必达得 $\lim\dfrac{2-\cos x}{3-\sin x}$（不存在），故不能用。改用别法：$\lim\dfrac{2-\frac1x\sin x}{3+\frac1x\cos x}=\dfrac{2-0}{3+0}=\dfrac23$。

**② 循环现象。** 有些极限用洛必达会循环、永远求不出。

> 例：$\lim_{x\to+\infty}\dfrac{e^x+\cos x}{e^x+\sin x}$，洛必达 $\lim\dfrac{e^x-\sin x}{e^x+\cos x}=\lim\dfrac{e^x-\cos x}{e^x-\sin x}=\cdots$ 循环。实际上 $\lim\dfrac{1+\frac1{e^x}\cos x}{1+\frac1{e^x}\sin x}=\dfrac{1+0}{1+0}=1$。

## 九、幂指函数专功

$1^\infty$ 型是考研几乎**必考**的重点，单独成"专功"。

### 1. 换底法（幂指函数指数化）

若 $f(x)^{g(x)}$ 为 $1^\infty$、$\infty^0$、$0^0$ 型，都可利用 $f(x)^{g(x)}=e^{g(x)\ln f(x)}$，把极限转化为求 $g(x)\ln f(x)$ 的极限。

### 2. "$1^\infty$" 未定式求法

重要极限：$\lim_{x\to0}(1+x)^{1/x}=e$，$\lim_{x\to\infty}\left(1+\frac1x\right)^x=e$，一般形式 $\lim\bigl(1+f(x)\bigr)^{1/f(x)}=e$。

- **结论 ①**：若 $\lim f(x)=0$，$\lim g(x)=\infty$，$\lim f(x)g(x)=A$，则 $\lim\bigl(1+f(x)\bigr)^{g(x)}=e^{\lim f(x)g(x)}=e^{A}$。
- **结论 ②**：若 $\lim f(x)=1$，$\lim g(x)=\infty$，$\lim\bigl(f(x)-1\bigr)g(x)=A$，则 $\lim f(x)^{g(x)}=e^{\lim (f(x)-1)g(x)}=e^{A}$。

### 3. 利用 "$1^\infty=e^A$" 公式的推论

$$①\ \lim_{x\to\infty}\left(\frac{ax+b}{ax+c}\right)^{hx+k}=e^{\frac{h(c-b)}{a}}$$

$$②\ \lim_{\phi(x)\to\infty}\left(\frac{\phi(x)+a}{\phi(x)+b}\right)^{\phi(x)}=e^{a-b}$$

$$③\ \lim_{\phi(x)\to\infty}\left(\frac{\phi(x)+f_1(x)}{\phi(x)+f_2(x)}\right)^{\phi(x)}=e^{\,\lim\left[f_1(x)-f_2(x)\right]}$$

（推论 ③ 的证明见后续习题。）

## 十、中值定理（用来处理某些式子）

当极限题的函数表达式中出现**差的商**结构时，用中值定理把"函数差"转化为"导数 × 自变量差"：

- 出现 **$f(b)-f(a)$** → **拉格朗日中值定理**：$f(b)-f(a)=f'(\xi)(b-a)$。
- 出现 **$\dfrac{f(b)-f(a)}{F(b)-F(a)}$** → **柯西中值定理**：$\dfrac{f(b)-f(a)}{F(b)-F(a)}=\dfrac{f'(\xi)}{F'(\xi)}$。

用中值定理的目的是把函数值之差转化为导数值，通常能约掉 $b-a$ 或化简极限结构。

## 十一、极限的逆问题

**已知**极限值或极限存在，确定极限式中的**未知常数**或**隐含的极限**，是常见题型。设 $\lim_{x\to\square}$ 表示某极限过程：

- **（1）** 已知 $\lim\dfrac{f(x)}{g(x)}=A$（$A$ 为不等于零的常数）：若 $\lim g(x)=0$，则 $\lim f(x)=0$；若 $\lim f(x)=0$，则 $\lim g(x)=0$；当 $A=0$ 时，若 $\lim g(x)=0$，则 $\lim f(x)=0$。
- **（2）** 已知 $\lim\dfrac{f(x)}{g(x)}=A\ne0$，则 $\lim g(x)=\infty\Leftrightarrow\lim f(x)=\infty$，且**同阶无穷大**；特别 $x\to\infty$ 时，若 $g(x)$ 是 $n$ 次多项式，则 $f(x)$ 也必是 $n$ 次多项式，且最高次幂相同。
- **（3）** 设 $\lim f(x)g(x)=A\ne0$，则 $\lim f(x)=\infty\Leftrightarrow\lim g(x)=0$。
- **（4）** 设 $\lim\bigl[f(x)-g(x)\bigr]=A$（常数），则 $\lim f(x)=\infty\Leftrightarrow\lim g(x)=\infty$，且**同阶无穷大**。
- **（5）** 若 $\lim\dfrac{f(x)}{g(x)}$（$\dfrac00$ 型）$=A$，分子分母不是多项式时，常用泰勒展开化为多项式之比。

> 例：已知 $\lim_{x\to+\infty}\left(5x-\sqrt{ax^2-bx+c}\right)=2$，求 $a,b$。属"$\infty-\infty$"型，极限存在 ⟹ 前后两个无穷大**同阶无穷大**。$5x$ 中 $x$ 为 1 次幂，故后面无穷大的最高次幂也应为 1 次、系数相等，即 $\sqrt{ax^2}=5x$，得 $a=25$。
>
> 注意要看清 $x\to+\infty$ 还是 $x\to-\infty$：若是 $x\to-\infty$，则 $\sqrt{ax^2}=|\sqrt a\,x|=-\sqrt a\,x$，符号不同。
