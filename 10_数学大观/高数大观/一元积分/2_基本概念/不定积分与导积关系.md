# 基本概念：不定积分与导积关系

> [!info] 来源
> 整理自《【A4】一元积分计算知识点》PDF 第 2 页。

## 一、不定积分

> [!important] 核心理解
> **不定积分 = 找原函数 = "找谁干的"**
>
> 即已知 $F'(x) = f(x)$，则 $\int f(x)\,dx = F(x) + C$。积分是微分的逆运算——给定"导数"（干了什么），找"原函数"（是谁干的）。

$$\int f(x)\,dx = F(x) + C \iff F'(x) = f(x)$$

### 基本运算性质

> [!important] 常数随意进出，微分内任意加减常数
> 1. **常数随意进出**：$\int k\,f(x)\,dx = k\int f(x)\,dx$（$k$ 为非 0 常数）
> 2. **加减可拆**：$\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
> 3. **微分内任意加减常数**：$df(x) = d[f(x) + C]$，即 $d$ 里可以随意加减常数而不改变微分值
>    - 应用：凑微分时 $\int f(ax+b)\,dx = \frac{1}{a}\int f(ax+b)\,d(ax+b)$，其中 $d$ 内加 $b$ 是合法的

## 二、导积关系（⭐⭐⭐⭐⭐）

> [!important] 导积关系表（基本积分表）
> 微分（求导）与积分（求原函数）互为逆运算，逐项对应。表中"被积函数 → 原函数"即 $\int f(x)\,dx = F(x) + C$。

### 幂函数、指数、对数

| 被积函数 $f(x)$ | 原函数 $F(x)+C$ |
|------|------|
| $x^{\alpha}$ | $\dfrac{x^{\alpha+1}}{\alpha+1}$（$\alpha \ne -1$） |
| $\dfrac{1}{x}$ | $\ln\|x\|$ |
| $e^x$ | $e^x$ |
| $a^x$ | $\dfrac{a^x}{\ln a}$ |
| $\dfrac{1}{1+x^2}$ | $\arctan x$ |
| $\dfrac{1}{\sqrt{1-x^2}}$ | $\arcsin x$ |

### 三角函数

| 被积函数 $f(x)$ | 原函数 $F(x)+C$ |
|------|------|
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\tan x$ | $-\ln\|\cos x\|$ |
| $\cot x$ | $\ln\|\sin x\|$ |
| $\sec x$ | $\ln\|\sec x + \tan x\|$ |
| $\csc x$ | $\ln\|\csc x - \cot x\|$ |
| $\sec^2 x$ | $\tan x$ |
| $\csc^2 x$ | $-\cot x$ |
| $\sec x \tan x$ | $\sec x$ |
| $\csc x \cot x$ | $-\csc x$ |

### 推广形式（含参数）

| 被积函数 $f(x)$ | 原函数 $F(x)+C$ |
|------|------|
| $\dfrac{1}{x^2 + a^2}$ | $\dfrac{1}{a}\arctan\dfrac{x}{a}$ |
| $\dfrac{1}{\sqrt{a^2 - x^2}}$ | $\arcsin\dfrac{x}{a}$ |
| $\dfrac{1}{x^2 - a^2}$ | $\dfrac{1}{2a}\ln\left\|\dfrac{x-a}{x+a}\right\|$ |
| $\dfrac{1}{\sqrt{x^2 \pm a^2}}$ | $\ln\left\|x + \sqrt{x^2 \pm a^2}\right\|$ |
| $\sinh x$ | $\cosh x$ |
| $\cosh x$ | $\sinh x$ |

> [!tip] 记忆方法
> 把"求导表"倒过来就是"积分表"。看到被积函数 $f(x)$，问自己：**哪个函数求导后是它？** 这就是"找谁干的"。
>
> 注意 $\tan x$、$\cot x$、$\sec x$、$\csc x$ 的积分结果带 $\ln$——它们的分子恰是分母的导数（凑微分的直接应用）：
> - $\int \tan x\,dx = \int \frac{\sin x}{\cos x}dx = -\int \frac{d(\cos x)}{\cos x} = -\ln\|\cos x\|$
> - $\int \sec x\,dx = \ln\|\sec x + \tan x\|$（经典结论，分母有理化技巧）
