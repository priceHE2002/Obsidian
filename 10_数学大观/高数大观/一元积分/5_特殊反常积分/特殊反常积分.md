## 一、指数零到无穷积分

> [!important] 指数零到无穷积分
> $$\int_0^\infty x^n e^{-x}\,dx = n! \qquad (n = 0,1,2,\dots)$$
>
> 验证：由 $\int_0^\infty e^{-x}dx = 1$ 出发，分部积分递推即得。
> 更一般地，$\int_0^\infty x^n e^{-ax}\,dx = \dfrac{n!}{a^{n+1}}$（$a>0$）。

### 配套积分（由分部积分直接得到）

| 积分 | 结果 |
|------|------|
| $\int_0^\infty e^{-ax}\,dx$ | $\dfrac{1}{a}$（$a>0$） |
| $\int_0^\infty x e^{-ax}\,dx$ | $\dfrac{1}{a^2}$ |
| $\int_0^\infty x^2 e^{-ax}\,dx$ | $\dfrac{2}{a^3}$ |
| $\int_0^\infty x e^{-x^2}\,dx$ | $\dfrac{1}{2}$（令 $u = x^2$ 凑微分） |
| $\int_0^\infty x^3 e^{-x^2}\,dx$ | $\dfrac{1}{2}$ |

## 二、泊松积分（Poisson）

> [!important] 泊松积分
> $$\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$$
>
> 等价形式（概率论中高斯积分）：
> $$\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}, \qquad \int_{-\infty}^{+\infty} e^{-\frac{x^2}{2}}\,dx = \sqrt{2\pi}$$
>
> **证明要点**：利用二重积分与极坐标（重积分方法）——把 $\left(\int_0^\infty e^{-x^2}dx\right)^2$ 化为 $\int_0^{\pi/2}\int_0^\infty e^{-r^2}r\,dr\,d\theta = \frac{\pi}{4}$，开方得 $\frac{\sqrt{\pi}}{2}$。

> [!tip] 使用场景
> - 概率论中正态分布密度函数的归一化条件。
> - 含 $e^{-x^2}$ 的定积分（其**原函数不是初等函数**，必须用此特殊结论）。
> - 广义：$\int_0^\infty e^{-ax^2}dx = \frac{1}{2}\sqrt{\frac{\pi}{a}}$（$a>0$）。
> - 概率论通用形式：$\int_{-\infty}^{+\infty} e^{-\frac{x^2}{2}}dx = \sqrt{2\pi}$（标准正态归一化）。

## 三、两类欧拉积分

欧拉积分包括**伽马函数**与**贝塔函数**，是反常积分的两大经典结论。

### 伽马函数 $\Gamma$（Gamma）

> [!important] 伽马函数
> $$\Gamma(s) = \int_0^\infty x^{s-1} e^{-x}\,dx \qquad (s > 0)$$

**核心性质：**

1. **递推公式**：$\Gamma(s+1) = s\,\Gamma(s)$
2. **与阶乘的关系**：$\Gamma(n+1) = n!$（$n$ 为非负整数）
3. **特殊值**：$\Gamma(1) = 1$，$\Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$（由泊松积分）
4. 由 $\Gamma(s+1)=s\Gamma(s)$ 可把 $\Gamma$ 解析延拓到非正整数以外的所有实数。

> [!tip] 使用场景
> $\int_0^\infty x^{s-1}e^{-x}dx$ 型反常积分可直接套用 $\Gamma(s)$；$\int_0^\infty x^n e^{-ax}dx = \frac{\Gamma(n+1)}{a^{n+1}} = \frac{n!}{a^{n+1}}$。

### 贝塔函数 $B$（Beta）

> [!important] 贝塔函数
> $$B(p, q) = \int_0^1 x^{p-1}(1-x)^{q-1}\,dx \qquad (p>0,\ q>0)$$

**核心性质：**

1. **对称性**：$B(p, q) = B(q, p)$
2. **与伽马函数的关系**：$B(p, q) = \dfrac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$
3. **特殊值**：$B(1,1)=1$，$B\left(\frac12,\frac12\right) = \pi$（利用 $\Gamma(\frac12)=\sqrt\pi$）
4. 通过换元 $x = \frac{t}{1+t}$ 可化为 $\int_0^\infty \frac{t^{p-1}}{(1+t)^{p+q}}dt$ 形式。

> [!tip] 使用场景
> $\int_0^1 x^{p-1}(1-x)^{q-1}dx$ 型、以及 $\int_0^{\pi/2}\sin^{p-1}\theta\cos^{q-1}\theta\,d\theta$（令 $x=\sin^2\theta$）型积分可用贝塔函数。

## 四、速查表

| 积分 | 结果 |
|------|------|
| $\int_0^\infty e^{-x}\,dx$ | $1$ |
| $\int_0^\infty x^n e^{-x}\,dx$ | $n!$ |
| $\int_0^\infty e^{-x^2}\,dx$ | $\dfrac{\sqrt{\pi}}{2}$ |
| $\int_{-\infty}^{+\infty} e^{-x^2}\,dx$ | $\sqrt{\pi}$ |
| $\Gamma(s) = \int_0^\infty x^{s-1}e^{-x}dx$ | $\Gamma(s+1)=s\Gamma(s)$，$\Gamma(\frac12)=\sqrt\pi$ |
| $B(p,q) = \int_0^1 x^{p-1}(1-x)^{q-1}dx$ | $B(p,q)=\dfrac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$ |
