# 换元法

> [!info] 来源
> 整理自《【A4】一元积分计算知识点》PDF 第 3-4 页（三大积分法之一）。

## 一、换元法的分类

换元法（变量替换）的核心：**引入新变量简化被积函数**。根据被积函数特征选择不同的代换。

| 代换类型 | 适用情况 | 代换方式 |
|----------|----------|----------|
| **三角代换** | （根号下）平方和差 | $x = a\sin t$、$x = a\tan t$、$x = a\sec t$ |
| **根式代换** | 根号下一次方 | 令 $t = \sqrt{ax+b}$ 等 |
| **倒代换** | 分母次数较高（2、3…） | 令 $t = \dfrac{1}{x}$ |
| **万能代换** | 三角有理式 | 令 $t = \tan\dfrac{x}{2}$（PDF 标注 ❌ 不推荐） |
| **整体代换** | 含有复杂函数 | 令复杂部分为 $t$ |

## 二、三角代换

> [!important] 适用：（根号下）平方和差
> 换回来的时候**画三角形**辅助还原。

| 根号形式 | 代换 | 参考三角形 | 化简结果 |
|----------|------|-----------|----------|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$，$t\in[-\frac{\pi}{2},\frac{\pi}{2}]$ | 斜边 $a$，对边 $x$ | $a\cos t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | 邻边 $a$，对边 $x$ | $a\sec t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | 对边 $a$，邻边 $x$（改） | $a\tan t$ |

> [!tip] 画三角形
> 例如 $\sqrt{a^2-x^2}$：构造直角三角形，斜边 $a$、一直角边 $x$，则另一直角边为 $\sqrt{a^2-x^2}$。还原 $t$ 的正弦/余弦/正切时直接从三角形里读。**一定要画三角形，避免算错。**

## 三、根式代换

> [!important] 适用：根号下一次方
> 令根号整体为新变量，消去根号。

### 具体情形

| 被积函数特征 | 代换 |
|----------|------|
| 含 $\sqrt{ax+b}$ | 令 $t = \sqrt{ax+b}$ |
| 含 $\sqrt{\dfrac{ax+b}{cx+d}}$ | 令 $t = \sqrt{\dfrac{ax+b}{cx+d}}$ |
| 同时含 $\sqrt{ax+b}$ 与 $\sqrt[n]{ax+b}$ | 令 $t = \sqrt[\text{lcm}]{ax+b}$（取各根指数的最小公倍数） |
| 含 $\sqrt[3]{x}$ 等 | 令 $t = \sqrt[n]{x}$ |

> [!example] 例：$\int \frac{dx}{1+\sqrt{x}}$
> 令 $t=\sqrt{x}$，则 $x=t^2$，$dx=2t\,dt$：
> $$\int \frac{2t}{1+t}dt = 2\int\left(1 - \frac{1}{1+t}\right)dt = 2t - 2\ln|1+t| + C = 2\sqrt{x} - 2\ln(1+\sqrt{x}) + C$$

> [!example] 例：$\int \frac{dx}{\sqrt{x} + \sqrt[3]{x}}$
> 根指数 $2$ 与 $3$ 的最小公倍数为 $6$，令 $t = \sqrt[6]{x}$，则 $x = t^6$，$dx = 6t^5 dt$，可化为有理函数积分。

## 四、倒代换

> [!important] 适用：分母次数较高（2、3…）
> 令 $t = \dfrac{1}{x}$（即 $x = \dfrac{1}{t}$），可降低分母次数，常用于分母比分子高 2 次或以上、且无更好方法的积分。
>
> 例：$\int \frac{dx}{x^2\sqrt{x^2+1}}$，令 $x=\frac{1}{t}$ 可简化。

## 五、万能代换（PDF 标注 ❌）

> [!warning] 不推荐
> 令 $t = \tan\dfrac{x}{2}$，则 $\sin x = \frac{2t}{1+t^2}$，$\cos x = \frac{1-t^2}{1+t^2}$，$dx = \frac{2dt}{1+t^2}$。理论上可解所有三角有理式，但**计算量大、容易出错**，仅在无其他方法时使用。
>
> 适用情况：三角有理式。优先考虑凑微分、三角化简等更简洁的手段。

## 六、整体代换

> [!important] 适用：含有复杂函数
> 把复杂的"块"（如 $e^{g(x)}$、$\sqrt{f(x)}$、复杂的反三角等）整体设为 $t$，令其导数为 $dt$。

> [!example] 例：$\int \frac{e^{\sqrt{x}}}{\sqrt{x}}dx$
> 令 $t = \sqrt{x}$，则 $dt = \frac{dx}{2\sqrt{x}}$，原积分 $= 2\int e^t dt = 2e^{\sqrt{x}} + C$。也可看作"整体代换 + 凑微分"。

## 七、换元法与凑微分的配合

- 换元"去根号/去复杂结构"后，往往还需配合**凑微分**或**分部积分**。
- 三角代换后通常得到 $\sin^k t \cos^l t$ 型积分，见 [[一元积分大观#三角函数组合积分]]。
