# 基本概念：不定积分与导积关系

> [!info] 来源
> 整理自《【A4】一元积分计算知识点》PDF 第 2 页。

## 一、不定积分

> [!important] 核心理解
> **不定积分 = 找原函数 = "找谁干的"**
>
> 即已知 $F'(x) = f(x)$，则 $\int f(x)\,dx = F(x) + C$。积分是微分的逆运算——给定"导数"（干了什么），找"原函数"（是谁干的）。

$$\int f(x)\,dx = F(x) + C \iff F'(x) = f(x)$$

### 基本运算性质

> [!important] 常数随意进出，微分内任意加减常数
> 1. **常数随意进出**：$\int k\,f(x)\,dx = k\int f(x)\,dx$（$k$ 为非 0 常数）
> 2. **加减可拆**：$\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$
> 3. **微分内任意加减常数**：$df(x) = d[f(x) + C]$，即 $d$ 里可以随意加减常数而不改变微分值
>    - 应用：凑微分时 $\int f(ax+b)\,dx = \frac{1}{a}\int f(ax+b)\,d(ax+b)$，其中 $d$ 内加 $b$ 是合法的

## 二、导积关系（⭐⭐⭐⭐⭐）

> [!important] 导积关系表
> 微分（求导）与积分（求原函数）互为逆运算，以下对应关系需熟记：

| 求导 $F'(x) = f(x)$                       | 积分 $\int f(x)\,dx = F(x)+C$                       |     |      |
| --------------------------------------- | ------------------------------------------------- | --- | ---- |
| $(x^n)' = nx^{n-1}$                     | $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$         |     |      |
| $(\ln x)' = \frac{1}{x}$ | $\int \frac{1}{x}\,dx = \ln\|x\| + C$ |
| $(e^x)' = e^x$                          | $\int e^x\,dx = e^x + C$                          |     |      |
| $(\sin x)' = \cos x$                    | $\int \cos x\,dx = \sin x + C$                    |     |      |
| $(\cos x)' = -\sin x$                   | $\int \sin x\,dx = -\cos x + C$                   |     |      |
| $(\tan x)' = \sec^2 x$                  | $\int \sec^2 x\,dx = \tan x + C$                  |     |      |
| $(\arctan x)' = \frac{1}{1+x^2}$        | $\int \frac{1}{1+x^2}\,dx = \arctan x + C$        |     |      |
| $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$ | $\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$ |     |      |
| $(\sec x)' = \sec x\tan x$              | $\int \sec x\tan x\,dx = \sec x + C$              |     |      |
| $(\csc x)' = -\csc x\cot x$             | $\int \csc x\cot x\,dx = -\csc x + C$             |     |      |

> [!tip] 记忆方法
> 把"求导表"倒过来就是"积分表"。看到被积函数 $f(x)$，问自己：**哪个函数求导后是它？** 这就是"找谁干的"。
