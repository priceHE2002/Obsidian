# 三角函数组合积分

> [!info] 来源
> 整理自《【A4】一元积分计算知识点》PDF 第 11-12 页。

## 一、🔺 通用技巧：分子拆成 A 倍的分母 + B 倍的分母导

> [!important] 核心手法
> 对 $\int \frac{P(x)}{Q(x)}dx$（$P$ 与 $Q$ 相关时），把分子拆成：
> $$P(x) = A\,Q(x) + B\,Q'(x)$$
> 则积分化为 $A\int dx + B\int \frac{Q'(x)}{Q(x)}dx = Ax + B\ln|Q(x)| + C$。
>
> 这是"分子拆成 A 倍分母 + B 倍分母导"的通用模板，适用于三角组合、有理函数等。

## 二、三角相关技巧

### (1) 1 的妙用

> [!tip] $\sin^2 x + \cos^2 x = 1$ 的拆分
> 把常数 1 写成 $\sin^2 x + \cos^2 x$，或把分子中的 1 拆开，制造可约分的结构。

### (2) cos 消 1 作用（cos 二倍角公式）

> [!important] 用 $\cos 2x$ 公式消去常数项
> $$\cos 2x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$
> 利用二倍角公式把"1"换成 $\cos 2x$ 相关项，再拆项积分。

**具体变形（原 PDF 强调）：**

$$\cos 2x + 1 = 2\cos^2 x \quad\Rightarrow\quad 1 + \cos x = 2\cos^2\frac{x}{2}$$
$$1 - \cos x = 2\sin^2\frac{x}{2}$$

> [!tip] 应用
> - $1 + \cos x$、$1 - \cos x$ 作分母时，用上式把"1 + cos"化为平方，便于处理
> - $\sin x = \cos(\frac{\pi}{2} - x)$：**若被积函数中无 cos，利用诱导公式创造 cos**

### (3) sin·cos 与 sin 转化（sin 二倍角公式）

> [!important] $\sin 2x = 2\sin x\cos x$
> $$\sin x\cos x = \frac12\sin 2x$$
> 把 $\sin x\cos x$ 转化为 $\sin 2x$，配合凑微分（$d(\cos 2x) = -2\sin 2x\,dx$）处理。

### (4) sin + cos 转化为 sin（辅助角公式）

> [!important] 辅助角公式
> $$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi), \qquad \tan\varphi = \frac{b}{a}$$
> 把 $\sin + \cos$ 的线性组合合并为单一正弦，再凑微分。

### (5) 分母齐次结构，同除 cos 的几次方，往 tan 上靠

> [!important] 分母齐次 → 同除 $\cos^k x$
> 当分子分母为 $\sin$、$\cos$ 的**齐次式**时，分子分母同除 $\cos^k x$，全部化为 $\tan x$：
> $$\frac{a\sin x + b\cos x}{c\sin x + d\cos x} = \frac{a\tan x + b}{c\tan x + d} \qquad \text{（同除 } \cos x \text{）}$$
> 令 $t = \tan x$，配合 $\frac{dx}{\cos^2 x} = d(\tan x)$ 凑微分。

## 三、三角高次幂

### 1. sin、cos 高次幂

> [!important] 奇数次凑微分，偶数次降幂
> - **奇数次**：拆出一个 $\sin x$（或 $\cos x$）凑微分，剩余偶次用 $\sin^2 x = 1-\cos^2 x$（或 $\cos^2x=1-\sin^2x$）转化
> - **偶数次**：用降幂公式 $\sin^2x = \frac{1-\cos2x}{2}$、$\cos^2x = \frac{1+\cos2x}{2}$ 降低次数

### 2. csc、sec 高次幂

> [!important] 偶数次凑微分，奇数次凑微分分部
> - **sec 偶次**：$\sec^2 x = 1+\tan^2 x$，令 $t=\tan x$ 凑微分
> - **sec 奇次**：凑微分分部（$\int \sec^3 x\,dx$ 用分部积分递推；$\sec x$ 积分 $\ln|\sec x + \tan x|$）
> - **csc**：同理，利用 $\csc^2 x = 1+\cot^2 x$，令 $t=\cot x$

## 四、根号下加比减 / 减比加

> [!important] 根号下解放因式
> **$\sqrt{\frac{a+b}{a-b}}$ 型**（根号下加比减/减比加）：
> 1. **根号下分式 ➡ 解放分子**：分子分母同乘共轭，利用平方差把分式拆成两项
> 2. **根号下乘积 ➡ 两个因式解放一个**：提出一个因式出根号，剩下一个凑微分
>
> **利用平方差同乘，然后拆成两项做**。

> [!example] 例：$\int \sqrt{\frac{1+\sin x}{1-\sin x}}\,dx$
> 分子分母同乘 $(1+\sin x)$：
> $$\sqrt{\frac{1+\sin x}{1-\sin x}} = \sqrt{\frac{(1+\sin x)^2}{\cos^2 x}} = \frac{1+\sin x}{|\cos x|}$$
> 再拆成 $\sec x + \tan x$ 积分。
