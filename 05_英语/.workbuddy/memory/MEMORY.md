# 05_英语 · 项目长期约定

## 生词本排版（v5，2026-09-12 定稿）

- **折叠词条卡**是唯一数据源，标题统一为「编号 · 单词」：
  `> [!vocab]- 001 · notion`，卡内依次 `**义**`（词性写在开头）→ `**搭**`（有才写）→ `**例**`
  （`**译**` / `**辨**` / `**疑**` 选填）。成品：
  `英语生词默写本_411词.md`（411 词 / 11 Unit，不含音标，单文件）。
- **不要卷首 callout**（2026-09-12 用户自己把「怎么用」「待核对词」删了，别再生成）；
  存疑写进卡内 `**疑**`，标注要能独立读懂、不要指回卷首。
- **有考研常考搭配的词要加 `搭` 行**：写法「短语（简短释义）」，`　·　` 分隔、≤3 条；
  没搭配的词不加这一行（411 词里 194 个有）。
- **词性一律写进 `义` 开头，不放到卡片标题**（2026-09-12 要求）—— 放到标题会让部分卡
  带 `· *n.*`、部分不带，形态不齐。词性本身要逐条核：及物/不及物都常用的写 `v.`。
- **释义按考研取向整理**（2026-09-12 要求）：常考义优先、每个词性 ≤3 义、生僻旧式义不列；
  多词性用 `　·　` 分隔，单一词性把词性提到标题；补熟词僻义，改明显错的义，拿不准加 `**疑**`。
  反例记录：`round` 原 10 义、`worship` 原写成"崇拜者"、`overrule` 原写"统治"、`hinder` 原标 adj.。
- **不要默写区**。不设「我的默写」空列、不设打分行 —— 卡片收起即题面，动笔写纸上。
- **不留 `源` 字段**（原/手/补）—— 用户 2026-09-12 要求删除，不要再加回来。
- **每张卡必须有 `例`**：优先用真题原句，句尾 `（2016 · Text 1）` 标年份篇目；
  真题里没有的词用自撰句、不标出处。
- 标题层级：文档 `#` / 单元 `##` / 小节 `###`。
- 进度用原生 `- [ ]`，**必须写成真正的任务项**（行首，且不要用反引号包成行内代码，
  否则只渲染成纯文本，点不动）；三细项并列就写三行。
- **不要用表格装进度/索引**：表格里写 `[[链接|别名]]` 必须先转义竖线 `\|`，
  否则会被先按 `|` 切单元格、链接散架。进度类内容一律用任务列表。
- 错词记在单元末尾 `### 错词` 的 `> [!failure]-` 里，用列表而不是表格。
- 存疑词标题加 `*`（转义写 `satire\*`），卡内加 `**疑**`；缺释义的词标注待补，**不替用户脑补中文义**。
- **单文件交付**：排版规范、录入骨架、可选 CSS 都写在文末 `## 附录 · 排版规范与录入`，
  不再单独维护模板文件。
- 相关技能：`~/.workbuddy/skills/obsidian-vocab-card-book/`（**v7 成品**：SKILL.md +
  `scripts/` 四个脚本 = convert / verify / mine_exam_sentences / check_book，
  `references/` 三份规范 = layout-spec / content-rules / workflow + css-snippet）。
  流程：挖例句 → 转换生成 → 回读校验（`mismatches` 必须 0）→ 静态体检（`check_book` 错误必须 0）。
- **目录结构（2026-09-12 用户自己整理过）**：成品在 `05_英语/单词/英语生词默写本_411词.md`；
  旧文件与三份 JSON 在 `05_英语/.archive/2026-09-12/`。
- **可复现输入**放在 `.archive/2026-09-12/`：`defs.json`（411 条考研向释义，**带词性前缀**）、
  `examples.json`（411 条例句，带 cite 的是真题）、`collocations.json`（194 条固定搭配）、
  以及三个旧文件。用 `--themes + --defs + --examples --collocations --no-source --appendix`
  可零差异重建成品。
