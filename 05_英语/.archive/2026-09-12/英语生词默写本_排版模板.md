# 英语生词默写本 · 排版模板 v3

> [!info] 只做一件事：让「看英文想中文」不被答案打扰
> - **没有默写区**。不设「我的默写」空列、不设复习打分行 —— 折叠卡本身就是题面：收起时只剩「编号 · 单词 · 词性」，答案全藏在里面。
> - **不用插件**。折叠靠 callout 原生语法 `> [!vocab]-`，点标题即可收起／展开。
> - **单一数据源**。一个词只有一张卡，不用维护第二张表；加词 = 追加一张卡。
>
> **三条硬约定**
> - 标题层级：文档标题 `#`，单元 `##`，单元内小节 `###` —— 大纲面板整齐，`[[#Unit 01 · …]]` 跳转有效。
> - 进度一律用**原生复选框** `- [ ]`（Tasks 插件的 `task-todo` 能统计），不用 `☐` 图形字符。
> - callout 里**每行都以 `> ` 开头**，不要靠行尾双空格换行。

---

## 使用方法

> [!abstract] 一天三步
> **① 自测** 从上往下滚，只读折叠卡的标题，在心里（或纸上）说中文。
> **② 订正** 想不起来的点开卡片看 `义`；错的记到本单元末尾的 `错词` 块。
> **③ 复习** 下一天先看 `错词`，再整单元重扫一遍，然后在 Unit Card 里打勾。

> [!tip]- 折叠语法速查（点开）
> | 写法 | 效果 |
> |---|---|
> | `> [!vocab]- 标题` | 默认**收起** —— 释义隐藏，用于自测 |
> | `> [!vocab]+ 标题` | 默认**展开** —— 批量录入时更顺手 |
> | `> [!vocab] 标题` | 不可折叠（本模板不用） |
>
> **全体收起／展开**：命令面板搜 `Fold all` / `Unfold all` / `Toggle all foldings`，建议绑快捷键。
> **标题行是唯一始终可见的部分**，所以只放「编号 · 单词 · 词性」，其余一律进正文。

> [!tip]- 进阶：想让中文直接消失？（点开）
> 折叠卡之外还有一条路 —— Obsidian 的注释语法：
>
> **阅读模式**下 `%%…%%` 里的内容完全不渲染，等于自动遮挡；按 `Ctrl/Cmd + E` 切回编辑模式，答案立刻显形。
>
> 适合「一张表连着过 40 个词」的临时抽测。长期复习仍建议用折叠卡，因为卡里能放搭配和例句。

## Unit 结构（照抄这段）

```markdown
## Unit 01 · 抽象概念 · 司法与反腐

> [!abstract] Unit Card
> **范围** 001–040　·　**收录** 40 词
> **进度** 默写 `- [ ]`　订正 `- [ ]`　复习 `- [ ]`

### 词条卡

> [!vocab]- 001 · notion · *n.*
> **义** 概念；观念；想法；打算
> **源** `原`

> [!vocab]- 002 · elevate · *vt.*
> **义** 举起；提升（地位／品质）
> **搭** elevate A to B
> **例** He refused to let any failure **elevate** himself above the rules.
> **译** 他拒绝让任何失败把他自己抬到规则之上。
> **源** `原`

### 错词

> [!failure]- 反复错的词（点开再背一轮）
> - **notion** — 错记成 idea　→　正确义：概念；观念
```

单元之间用 `---` 分隔，单元末尾加一行 `[[#总进度|↑ 总进度]]`。

## 字段规范

| 字段 | 必填 | 位置 | 说明 |
|---|:---:|---|---|
| 编号 | ✓ | 卡片标题 | 三位数 `001`，全书唯一，便于 `Ctrl+Shift+F` 定位 |
| 单词 | ✓ | 卡片标题 | 拼写存疑加星：`satire*`；但标题里的星号要转义写成 `satire\*`，否则会被当成强调符 |
| 词性 | | 卡片标题 | 只在**释义里恰好一个词性标记、且在开头**时提上来，如 `*n.*`；多词性（`vt.… v.…`）整条留在 `义` 里不要切开 |
| **义** | ✓ | 卡内第 1 行 | 只写考场核心义，≤3 个，用分号分隔 |
| **搭** | | 卡内第 2 行 | 词组／固定搭配，多个用 `　·　` 分隔 |
| **例** | | 卡内第 3 行 | 真题句优先，词头加粗 `**notion**` |
| **译** | | 卡内第 4 行 | 例句中译，**另起一行**，不要拼在 `例` 后面 |
| **源** | | 卡内末行 | `原` 词册已有 · `手` 手写批复 · `补` 补录常见义 |
| **辨** | | 卡内末行 | 易混辨析，格式 `prosecute ≠ persecute` |
| **疑** | | 卡内末行 | 存疑说明，与标题的 `*` 互相呼应，便于日后批量查证 |

> [!danger] 存疑与缺义的处理
> - 拼写或释义存疑：标题末尾加 `*`，卡内加 `**疑** ……`，并在卷首 `[!warning] 待核对词` 里登记。
> - 原资料就没写释义的：写 `**义** （原资料未写释义）` + `**疑** 待补`，**不要替用户脑补中文义**。

## 附录 · 可选 CSS

> [!code]- 追加到 CSS snippet（点开复制）
> 不加也能用（未知 callout 类型会退回 Obsidian 默认灰底 + 默认图标），加了只是更醒目、更好扫。
> ```css
> .callout[data-callout="vocab"] {
>   --callout-color: 168, 118, 20;
>   --callout-icon: lucide-book-open;
> }
> .callout[data-callout="vocab"] .callout-content > div:first-child strong,
> .callout[data-callout="vocab"] .callout-content > p:first-child strong {
>   color: rgb(var(--callout-color));
> }
> .callout[data-callout="vocab"] .callout-content em { opacity: .72; }
> .callout[data-callout="failure"] { --callout-color: 200, 60, 60; }
> ```
>
> 改完在 `设置 → 外观 → CSS 代码片段` 里刷新并开启（不要在 Obsidian 运行时手改 `appearance.json`，会被内存缓存覆盖）。

> [!code]- 需要音标时再加这段
> 正文外文字体不一定覆盖 `ʃ ʒ ə ɑ ɔ ɜ ˈ ˌ`，单独指定带完整 IPA 覆盖的字体，避免豆腐块或东倒西歪。
> ```css
> code.ipa, span.ipa {
>   font-family: "Lucida Sans Unicode", "Arial Unicode MS", "Segoe UI Symbol", var(--font-monospace);
> }
> ```
> 用法：标题或正文里写 `` `/ˈnəʊʃn/` `` 或 `<span class="ipa">/ˈnəʊʃn/</span>`。
