## 附录 · 排版规范与录入

### 字段规范

| 字段 | 必填 | 位置 | 说明 |
|---|:---:|---|---|
| 编号 | 是 | 卡片标题 | 三位数 `001`，全书唯一，便于 `Ctrl+Shift+F` 定位 |
| 单词 | 是 | 卡片标题 | 拼写存疑加星：`satire*`；**标题里必须转义成 `satire\*`**，否则被当成强调符 |
| 词性 | 是 | 义 的开头 | 一律写在释义开头（`n.` / `vt.` / `adj.`），**卡片标题不放词性**，保持标题统一 |
| **义** | 是 | 卡内首行 | `词性 + 中文义`；考研取向：常考义优先，每个词性留 1—3 个核心义，用 `；` 分隔 |
| **搭** | | 义之后 | **只在有考研常考搭配时才出现**（411 词里 194 个有）；写法「短语（简短释义）」，多个用 `　·　` 分隔，最多 3 条 |
| **例** | 是 | 搭之后 | 真题句优先，命中词加粗；末尾 `（2016 · Text 1）` 标出处，自撰句不标 |
| **译** | | 例之后 | 例句中译，另起一行，不要拼在 `例` 后面 |
| **辨** | | 卡内末行 | 易混辨析，格式 `prosecute ≠ persecute` |
| **疑** | | 卡内末行 | 存疑说明，与标题的 `*` 呼应，便于日后批量查证 |

> [!note] 释义整理规范
> - **考场常考的义排前面**；词典尾巴上的生僻义、旧式义不列（如 `hinder` 的 adj.「后面的」、`bud` 的「含苞欲放」、`round` 的「轮唱」）。
> - 一个词性最多 3 个义项；多词性用 `　·　` 分隔：`n. 账户；说明　·　vi. 解释（account for）`。
> - **词性一律写在释义开头**，卡片标题只放「编号 · 单词」，所有卡片标题保持同一种形态。
> - **熟词僻义要补**：`address` 补「vt. 处理」、`sole` 补「adj. 唯一的」、`faint` 补「adj. 微弱的」。
> - **明显错的义要改**：`worship` 原写「崇拜者」（那是 worshipper）、`overrule` 原写「统治, 支配」（实为「否决；推翻」）、`concentrate` 原只留名词义。
> - 拿不准的照旧加 `**疑**` 标注，**不脑补中文义**。

> [!note] 固定搭配规范
> - **只给考研常考的搭配**，凑数的短语不如不写：411 词中有 194 个配了 `搭`，其余留空。
> - 写法「短语（简短释义）」，多个用 `　·　` 分隔，**最多 3 条**；释义要短，能一眼看懂。
> - 优先收**义项独立**的搭配（`account for` 解释；占／`ward off` 挡开／`tide over` 度过难关），
>   其次收介词搭配（`adhere to`／`insist on`／`be susceptible to`）与固定说法（`on the brink of`／`at the expense of`）。
> - 词只能出现在搭配里、单独没意义的（如 `quo` → `status quo`），也放在这里。

> [!danger] 存疑与缺义的处理
> - 拼写或释义存疑：标题末尾加 `*`，并在卡内用 `**疑**` 把存疑点写清楚（**不设卷首清单**，标注要能独立说明）。
> - 原资料就没写释义的：写 `**义** （原资料未写释义）` + `**疑** 待补`，**不要脑补中文义**。
