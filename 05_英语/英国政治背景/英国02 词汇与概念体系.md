# 02 词汇与概念体系

> [!abstract] 本笔记导航
> [[英国01 历史与制度骨架]] · **02 词汇与概念体系**（当前） · [[英国03 冲突模型与真题对照]]
>
> 制度骨架见 [[英国01 历史与制度骨架]]。这一篇处理**语言层**：同一个词在英国政治语境里到底指什么，以及哪些词是中国学生最容易按汉语字面意思读错的。

> [!danger] 先记住这 9 个"不是它的字面意思"的词
> `public school` 不是公立学校 · `establishment` 不是"建立" · `convention` 不只是"惯例" · `legacy` 不一定是"遗产" · `class` 常常不是"阶级斗争" · `the Crown` 不是"王冠" · `cabinet` 不是"橱柜" · `school` 在英国常指"学院/学派" · `college` 也不等于大学（详见下文）
>
> 另有六个借代机构名：`Westminster` · `Whitehall` · `Downing Street` · `the City` · `Fleet Street` · `Brussels`

## A. 政治制度词群

> [!question] 看到这些词直接切换"英国制度"语境
> `monarchy` · `Parliament` · `MP` · `House of Commons` · `House of Lords` · `Prime Minister` · `cabinet` · `constituency` · `sovereignty`

| 英文 | 阅读义 | 备注 |
|---|---|---|
| `monarchy` | 君主制 | 制度本身 |
| `monarch` | 君主 | 具体的人（the monarch = 在位国王/女王） |
| `constitutional monarchy` | 君主立宪制 | 国王存在但受宪政约束 |
| `the Crown` | **王室 / 王权** | 不是"王冠"。法律语境可指"国家"一方 |
| `Parliament` | 议会 | 英式译"议会"，美式对应机构叫 Congress（国会），别混 |
| `parliamentary` | 议会的 / 议会制的 | `parliamentary system` 议会制 |
| `MP` | 议员 | Member of Parliament |
| `House of Commons` | 下议院 | **真正掌权的一院** |
| `House of Lords` | 上议院 | 任命产生，审议与监督 |
| `Prime Minister` | 首相 | head of government |
| `cabinet` | **内阁** | 不是"橱柜"；首相任命的核心部长班子，集体决策 |
| `constituency` | 选区 | 议员代表的地域单位 |
| `seat` | **席位** | `win a seat` 赢得席位，不是"赢得座位" |
| `general election` | 大选 | 全国性议会选举 |
| `by-election` | 补选 | 单个选区因议员空缺而补选 |

> [!quote] 真题原句（MP 的用法）
> A group of Labour MPs, among them Yvette Cooper, are bringing in the new year with a call to institute a UK "town of culture" award.（2020 · Text 1）

> [!warning] Parliament 的"议会"不等于 US 的 Congress
> 英国议会是 ==**议行合一色彩更浓**==（政府由议会多数党组成）；美国国会与总统各自独立授权。两个词背后是两套完全不同的权力逻辑，见 [[英国01 历史与制度骨架]] 第八节。

## B. 宪法与法律概念词群

| 英文 | 阅读义 | 一句话提醒 |
|---|---|---|
| `constitution` | 宪法 | 英国有宪法规则，但没有统一文本 |
| `uncodified constitution` | 不成文宪法 | **不是"没有宪法"**，是"没有一部统一编码的文本" |
| `constitutional` | 宪法的 / 合宪的 | 与政治制度合法性相关 |
| `parliamentary sovereignty` | 议会主权 | 最高权力在议会 |
| `convention` | **宪政惯例** | 见下方专题 |
| `rule of law` | 法治 | 见下方专题 |
| `legislation` | 立法 / 法律法规 | `-ion` 是产物 |
| `legislature` | 立法机关 | `-ure` 是机关 |
| `statute` | 成文法 / 法令 | 由议会通过 |
| `sovereignty` | 主权 | Brexit 文章的核心词 |
| `referendum` | 公投 | `hold a referendum` |
| `devolution` | **权力下放** | 不是独立，见 [[英国01 历史与制度骨架]] 第二十二节 |

### convention：一个词两条命

> [!important] convention 的两种面孔
> **普通英语**：`convention` = 惯例 / 大会（a conference）
>
> **政治法律语境**：`constitutional convention` = ==**宪政惯例**==——不成文但被普遍遵守的政治规则
>
> 英国很多规则**不是严格写在一部宪法中的，而是靠长期形成的政治惯例运行**。这又一次体现"英国制度依赖历史传统"。

### rule of law：最容易理解偏的一个词

> [!danger] rule of law ≠ "用法律管理国家"
> 真正的含义是 ==**任何人，包括政府，都受法律约束**==。
>
> 因此它通常和 `arbitrary power`（专断权力）、`liberty`（自由）、`constitutionalism`（宪政）、`judicial independence`（司法独立）联系在一起。

> [!warning] 顺带区分
> `rule of law`（法治，约束政府）≠ `rule by law`（以法为工具治理）——后者可能恰恰是前者的反面。

## C. 社会与阶级词群

> [!important] 这一组是英国文化文章的第一高频背景
> 英国社会的 `class consciousness`（阶级意识）非常强，所以 `class` 在文章里出现的密度远高于美国题材。

| 英文 | 阅读义 |
|---|---|
| `class` | **社会阶层**（多数情况）；也可指"类别、等级" |
| `class-conscious` | 有阶级意识的 |
| `upper class` | 上层阶级 |
| `middle class` | 中产阶级 |
| `working class` | 工人阶级 / 劳动阶层 |
| `privilege` | 特权 / 优势 |
| `aristocracy` | 贵族阶层 |
| `elite` | 精英 / 精英阶层 |
| `establishment` | **权势集团 / 体制内精英** |
| `elitism` | 精英主义 |
| `social mobility` | 社会流动 |
| `inequality` | 不平等 |
| `hierarchy` | 等级制度 / 等级结构 |

> [!danger] class 的第一反应不该是"阶级斗争"
> 英国文章里的 `class` 更多是 ==**生活方式、口音、教育与身份的区隔**==。
>
> 同时注意它作"类别"的常用法：真题里出现过 "an entire class of patents"（==**一整类专利**==），与"阶级"完全无关。

### establishment：英美政治文章的超级重点词

> [!important] the establishment
> 通常**不是**"建立"，而是 ==**掌握社会权力的传统精英集团**==。
>
> 可能包括：`politicians` · `senior civil servants` · `judges` · `business leaders` · `elite institutions`（如名校、大报、老牌机构）。

所以：

> [!danger] anti-establishment
> = ==**反建制**==——反对既有精英集团及其规则，**不是**"反对建立某个东西"。

> [!note] 英美通用
> 这个词在美国政治文章里同样高频（`the political establishment`）。看到就译"建制派 / 权势集团"，一般不会错。

## D. 教育词群：public school 的坑

> [!danger] 全篇最容易踩的一个
> 英国的 **`public school`** 很多时候**并不是"公立学校"**，反而是 ==**历史悠久的精英私立学校**==（如 **Eton** 伊顿公学）。

| 说法 | 英国 | 美国 |
|---|---|---|
| `public school` | **顶级私立寄宿学校** | 公立学校 |
| `state school` | 公立学校 | （对应说法是 public school） |
| `private school` / `independent school` | 私立学校 | 私立学校 |
| `grammar school` | 历史上指**择优录取的公立文法学校**（英国特有） | 无对应 |

> [!warning] 判断技巧
> 英国语境看到 `public school` + `fee`（学费）+ `boarding`（寄宿）+ `Eton`/`Harrow`，一定是在讲==**精英私校**==。

| 英文 | 阅读义 |
|---|---|
| `Oxbridge` | 牛津 + 剑桥（合成词） |
| `elitism` | 精英主义 |
| `academic freedom` | 学术自由 |
| `university autonomy` | 大学自治 |
| `public funding` | 公共财政资助 |
| `tuition fee` | 学费 |
| `marketisation` | 市场化 |
| `meritocracy` | 精英治国 / 能力主义（`merit` 能力 + `-cracy` 治理） |

> [!important] 教育类文章的固定公式
> **academic values ↔ marketisation**（学术价值 ↔ 教育商业化）
>
> 常见追问：==**高等教育是公共事业，还是市场服务？**==

## E. 帝国与殖民词群

| 英文 | 阅读义 |
|---|---|
| `empire` | 帝国 |
| `imperial` | 帝国的 / 帝国的（形容词） |
| `imperialism` | 帝国主义 |
| `colony` | 殖民地 |
| `colonial` | 殖民的 |
| `colonialism` | 殖民主义 |
| `decolonisation` | 去殖民化 |
| `legacy` | **历史遗产 / 后续影响**（也可能是"遗留业务"，见下） |
| `Commonwealth` | 英联邦 |
| `heritage` | 文化遗产 / 传统 |
| `repatriation` | 归还（文物、遗骸等） |

> [!important] legacy 要按语境二选一
> - 谈帝国、殖民、种族、制度传统时：==**历史遗产 / 持续影响**==
> - 谈商业、媒体、产品时：==**遗留的老业务 / 旧模式**==（2016 · Text 4 讲传统报纸的 "a legacy business"）

## F. 福利与 NHS 词群

| 英文 | 阅读义 |
|---|---|
| `welfare` | 福利（不是"幸福"） |
| `welfare state` | 福利国家 |
| `public service` | 公共服务 |
| `benefit(s)` | **（政府发放的）救济金 / 补助** |
| `claimant` | 领取补助的人 / 申领者 |
| `entitlement` | （依法）应得的权益 / 补助资格 |
| `allowance` | 补助金 / 津贴 |
| `means-tested` | 需经收入审查的 |
| `austerity` | 财政紧缩 |
| `public spending` | 公共支出 |
| `NHS` | National Health Service 国家医疗服务体系 |
| `taxpayer` | 纳税人 |

> [!danger] benefits 不是"好处"
> 福利语境里的 `benefits` 是 ==**政府发放的救济金、补助**==。真题里 "help people stay off benefits"（帮助人们不再靠领补助生活）、"the real gains come in benefits"（2012 · Text 4，指工会谈判争到的**福利待遇**）都是这个路子。

> [!quote] 真题原句（NHS 与公共服务的分量）
> While polls show Britons rate "the countryside" alongside the royal family, Shakespeare and the National Health Service (NHS) as what makes them proudest of their country, this has limited political support.（2016 · Text 2）
>
> Any fair-minded assessment of the dangers of the deal between Britain's National Health Service (NHS) and DeepMind must start by acknowledging that both sides mean well.（2018 · Text 3）

第二句是典型的"好机构 + 新问题"结构：NHS 的初衷没问题，但把患者数据交给科技公司就产生了 `privacy` 风险——`public service ↔ commercial interest`。

## G. 市场与 Thatcher 词群

| 英文 | 阅读义 |
|---|---|
| `privatization` / `privatisation` | 私有化 |
| `nationalization` | 国有化 |
| `regulation` | 政府监管 |
| `deregulation` | 放松监管 |
| `free market` | 自由市场 |
| `competition` | 竞争 |
| `market forces` | 市场力量 |
| `individual responsibility` | 个人责任 |
| `trade union` / `union` | 工会 |
| `unionised` | 加入工会的 |
| `strike` | 罢工 |
| `public sector` / `private sector` | 公共部门 / 私营部门 |
| `Thatcherism` | 撒切尔主义（市场化、私有化、削弱工会） |

> [!quote] 真题原句（工会与两党结构）
> In Britain, more than half of public-sector workers but only about 15% of private-sector ones are unionized.（2012 · Text 4）
>

> 英国题材文章里常见 `-ise` 系拼写：`privatise` · `nationalise` · `organise` · `recognise`；`labour`（而非 labor）。**同源词的两种拼写都要认。**

## H. 联合王国与身份词群

| 英文 | 阅读义 |
|---|---|
| `the UK` | 联合王国（= GB + Northern Ireland） |
| `Britain` / `British` | 英国 / 英国的（通常指整体） |
| `England` / `English` | 英格兰 / 英格兰的（**不等于 UK**） |
| `Scotland` / `Scottish` | 苏格兰 / 苏格兰的 |
| `Wales` / `Welsh` | 威尔士 / 威尔士的 |
| `Northern Ireland` | 北爱尔兰 |
| `devolution` | 权力下放 |
| `autonomy` | 自治权 |
| `independence` | 独立 |
| `nationalism` / `nationalist` | 民族主义 / 民族主义者 |
| `separatist` | 分离主义者 |
| `identity` | **身份认同**（文化/民族/社会归属） |
| `Brexit` | 英国脱欧 |
| `immigration` | 移民（入境） |
| `referendum` | 公投 |

> [!warning] 三个"英国"别混
> `the UK` ⊃ `Great Britain` ⊃ `England`。文章写 `England` 时不要译成"英国"；写 `the UK` 时也不宜简化成"英格兰"。

> [!important] devolution ≠ independence（再强调一次）
> ==**devolution 是"仍属英国、更多自治"；independence 是"脱离英国"。**==
> 这对词是立场题的关键，读错会直接把作者态度判反。

## I. 媒体与公共机构词群

| 英文 | 阅读义 |
|---|---|
| `the press` | **新闻界 / 报业**（不是"按压"） |
| `broadsheet` | 大报 / 严肃报纸（传统上版面大） |
| `tabloid` | **小报**（版面小、强调娱乐与轰动） |
| `tabloid journalism` | 煽情小报新闻（**常带贬义**） |
| `sensational` | 耸人听闻的 |
| `scandal` | 丑闻 |
| `celebrity` | 名人 |
| `BBC` | British Broadcasting Corporation 英国广播公司 |
| `public service broadcasting` | 公共服务广播 |
| `licence fee` | （英国的）电视牌照费 |
| `watchdog` | 监督者 / 监察机构 |
| `broadcaster` | 广播机构 |

> [!important] tabloid 与 broadsheet 的对立本身就是考点
> 它隐喻 **serious ↔ sensational**、**quality ↔ popular** 的对立。看到 `tabloid` 就要预期作者可能在批评==**新闻娱乐化**==。

> [!important] BBC 为什么常出现在文章里
> 因为它有 **public service broadcasting** 传统：媒体不只是商业机构，还承担 `education`、`information`、`cultural service` 等公共责任。
>
> 因此围绕 BBC 的争论常常是：
>
> ==**public interest ↔ commercial competition**==（公共利益 ↔ 商业竞争）
>
> 这与考研英语喜欢考的思想冲突高度吻合。

> [!quote] 真题原句（报纸与严肃评论的黄金年代）
> We are even farther removed from the unfocused newspaper reviews published in England between the turn of the 20th century and the eve of World War II, at a time when newsprint was dirt-cheap and stylish arts criticism was considered an ornament to the publications in which it appeared.（2010 · Text 1）

## J. 自由与传统词群

| 英文 | 阅读义 |
|---|---|
| `liberty` | 自由（**强调免于国家权力过度干涉**） |
| `individual liberty` | 个人自由 |
| `free speech` | 言论自由 |
| `privacy` | 隐私 |
| `censorship` | 审查制度 |
| `tradition` | 传统 |
| `reform` | 改革（常指**调整**既有制度，而非推翻） |
| `continuity` | 连续性 |
| `compromise` | 妥协 |
| `adaptation` | 适应 / 调适 |
| `evolution` | 演进 |

> [!important] 英国的 liberty 传统
> 英国政治思想长期强调防止国家权力过度干涉个人。著名思想家 **John Stuart Mill** 讨论过 `individual liberty`。
>
> 所以英语文章讨论 `free speech`、`privacy`、`personal freedom`、`government regulation` 时，往往是在这个传统里展开——==**"政府能不能管到这个程度"**==。

> [!important] 英国式制度发展模式（最值得背的一句）
> **preserve the form + change the function**
>
> ==**形式保留，功能改变。**==
>
> 例如：国王仍存在，但实际政治功能已经与几百年前完全不同。这句话几乎能解释英国所有的"看起来矛盾"。
