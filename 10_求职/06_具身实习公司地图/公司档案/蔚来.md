## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：J085/J086 的技能栈与你的 P0→P1 路线几乎逐字对应（MuJoCo/Isaac 场景、RL、PyTorch、调参分析）；J141 轨迹优化正好是「传统运控」底座，符合你的保底方向；6 条本科可投，学历不是第一道墙。
- **短板与缺口**：① **出勤是最大硬伤**——6 条硬性 5天/周，你 2026-11 至 2027 上半年每周 ≤3h，现在投等于自曝；② C++ 出现在 5 条要求里，你未系统使用；③ 无真机、无 ROS2 经验，J087/J084 直接卡；④ 世界模型三条要 Diffusion/Transformer 实操，你只有课程级理解；⑤ 无实习无论文，J066 还卡届别。
- **1–3 周内可补的最小动作**：在 MuJoCo 里复现 7-DoF reach→grasp，PPO 训到成功率 ≥70%，产出 1 页「reward 设计 + 域随机化参数范围 + 训练曲线 + 失败模式」笔记；另把 IsaacLab 官方一个环境跑通并记踩坑。这恰好就是 P1 的交付物，可直接进简历。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：MuJoCo、IsaacLab、PPO、reward shaping、domain randomization、Sim2Real、Python/PyTorch、轨迹优化（可选加分）。
2. **可能被问的 3 个问题及答题要点**：
   - Q：讲一个你搭过的 RL 训练场景，reward 和 termination 怎么设计？→ 答：状态/动作空间定义 → reward 分项（接近、抓取成功、碰撞惩罚）→ 课程学习 → 并行环境数 → 训练不稳时看 episode return 方差、KL、entropy 三项定位。
   - Q：Sim2Real gap 从哪来，你怎么处理？→ 答：接触参数、摩擦、延迟、视觉域差；域随机化的参数范围要有依据（不是越大越好），配合系统辨识与动作平滑。
   - Q：PPO 和 SAC 在连续控制上怎么选？→ 答：on-policy 稳但样本效率低；SAC off-policy 样本效率高但调参敏感；仿真可并行时 PPO 更省心，真机微调用 SAC/RLPD。
3. **可产出的作品/证据**：一个 GitHub 仓库（环境 + 训练脚本 + 曲线图）、1 页复现笔记（Obsidian 导出 PDF）、一段 30 秒训练视频。
4. **软性动作**：出勤条件满足前不投；在此之前以「毕设/课程项目」名义联系仿真团队成员，问一个具体技术问题（如 J085 的多机协同用占据栅格还是 ESDF），保持弱连接。
