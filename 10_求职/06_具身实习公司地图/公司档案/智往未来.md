- **与同类公司的差异**：切片里**唯一明写薪资（300–400 元/天）+ 明确截止日（2027-10-14）+ 承诺期最短（3 个月）**的一条，透明度最高；代价是学历口径矛盾，需要自己确认。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 方向是用户第一优先级（VLA/操作）；② 技能栈 Python/PyTorch/Transformer/IL/MuJoCo/Isaac Sim **与用户 P2/P3 计划完全同构**；③ 3 个月起、4 天/周是切片里最可能谈成的时长；④ 明写薪资，说明是正规实习而非「项目制白工」。
- **短板与缺口（直说）**：
  1. **VLA 微调零经验**。「训练/微调/评估」三件事用户一件没做过，P3（开源 VLA 微调复现）还在计划里。
  2. **学历口径矛盾，存在被 HR 一刀切的风险**。正文「硕士及以上」若被严格执行，研0 直接出局。
  3. **数据 pipeline 工程能力弱**。用户能跑小实验，但没写过多进程 dataloader、没处理过大规模视频/轨迹数据格式。
  4. **真机调试零经验**。JD 明写「真实机器人调试」。
- **1–3 周内可补的最小动作**：选一个**小号 VLA**（如 LeRobot 的 SmolVLA，或 OpenVLA-OFT 的小配置）在仿真里跑一次 LoRA 微调，产出「loss 曲线 + 任务成功率 before/after + 推理频率」一页纸。做不完完整微调就退一步：把某个开源 VLA 的**推理**跑通，并写清它的数据格式（这已经能对上「数据 pipeline」）。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`VLA`、`LoRA/微调`、`Transformer`、`LeRobot`、`Isaac Sim / MuJoCo`、`数据 pipeline`、`成功率评估`。写法：「在 X 环境微调 Y 模型，成功率 a%→b%，推理 z Hz」。
2. **面试可能被问的 3 个问题，及答题要点**：
   - **Q1：VLA 微调时，你冻结哪些层？为什么？** 要点：视觉 backbone 通常冻结或低 lr，动作头/投影层全量训；数据少时用 LoRA 压参数量防过拟合；要说清显存与吞吐的权衡。
   - **Q2：怎么评估一个 VLA 策略的好坏？** 要点：离线看 action L1/DTW 不够，必须闭环成功率；要固定初始状态集、跑 N 次取均值与方差；还要看泛化（换物体/换光照）与推理延迟。
   - **Q3：VLA 的数据 pipeline 你会怎么设计？** 要点：统一 episode 格式（obs/action/timestamp）、动作空间对齐（关节 vs EE）、图像 resize/归一化、语言指令模板化、以及训练时的采样权重（按任务/成功率平衡）。
3. **可产出的作品/证据**：① 一次 VLA 微调记录（config + 曲线 + 成功率）；② 一份「VLA 数据格式对比」笔记（OpenVLA / π0 / LeRobot 三种）；③ repo 链接。
4. **软性动作**：投递前用实习僧站内信问「JD 写硕士及以上但列表标不限，研0（已录取未入学）可否投」；拿到明确答复再投，避免被系统筛掉。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**P3 起步后（约 4–6 周）投**，这是切片里最值得等的一条——3 个月承诺期 + 明确薪资 + 截止 2027-10，时间窗口足够。现在投也可以，但大概率因「无 VLA 经验」被拒，浪费一次机会。
