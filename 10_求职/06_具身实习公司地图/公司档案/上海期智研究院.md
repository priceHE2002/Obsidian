# 公司档案：上海期智研究院

## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

从岗位设计看，这是一个**以硕士毕业设计为载体的机器人研究机构**：6 条 JD 里有 4 条直接叫「硕士毕业论文实习生 1/2/3/4」，方向分别是力感知多指灵巧抓取、动力学最优控制、分层动力学 RL、VLM+RL 人形 VLA；另外 2 条是 6 个月起的「具身智能实习生」，做 VLA 训练框架和世界动作模型。技术栈高度统一：ROS2 + Isaac Sim/Lab + MuJoCo + 真机验证，且反复出现「论文实验」「论文优先」。更像高校课题组的驻场形态，而非产品公司（推断）。

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：**6/6 全覆盖**的四项是 Python、C++、RL、Isaac Lab；ROS2 5/6、Control 5/6、动力学/MPC/WBC 各 2–3 条、Isaac Sim 2/6、MuJoCo 1/6、VLM 2/6。原文措辞：「以ROS2/MuJoCo仿真多指手抓取并整合强化学习全身抓取策略，完成真机论文实验」（J182）、「构建loco-manipulation任务并在ROS2与Isaac仿真/真机验证」（J183）、「熟练Python/C++、Linux、ROS、IsaacLab/Isaac Sim/RLinf，论文优先」（J186）。
- **学历与学籍倾向**：这是切片里**对研0 最不友好的一家**。4 条写死「硕士毕业设计阶段（校外毕设资格优先）」，本质是要求「你已经在读硕士、且导师同意你出来做毕设」——研0 在结构上不可能满足。另 2 条虽未写学历，但写「≥1 年 VLM/VLA/RL 实习或研究」「≥1 年强化学习研究」。没有一条提到本科。
- **出勤 / 时长硬门槛**：4 条 ≥12 个月（毕业论文岗，等于一整年驻场），2 条 ≥6 个月；**全部要求线下真机**（职责里反复出现「真机验证」「真机实验」）。这不是「每周几天」的问题，而是「以年为单位的连续投入」。
- **职责重心**：**纯研究 + 真机实验**，且与学位绑定。动词是「建立力控模型」「设计分层奖励函数」「研究 VLM 奖励函数」「训练验证」「完成真机论文实验」。没有数据标注、没有部署工程这类杂活，说明他们招人是要出论文的，不是要人手。
- **隐性偏好与关键词**：「毕业论文」「校外毕设资格」「≥1 年相关研究」「论文优先」「足式/人形」「真机」「RLinf」「Casadi/QP」「全身控制」。这套词意味着候选人画像非常具体：**已经在某个足式/人形课题组做过一年、手上有一个能写进毕设的题目**。
- **与同类公司的差异**：其他公司招「实习生」，这家招「合作培养的硕士生」——筛选维度不是技能匹配度，而是**学籍状态 + 导师放人 + 毕设选题契合**。对研0 而言，这不是「难」，是「时间上还没到」。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：方向 100% 命中用户第一、第二优先级（灵巧操作、真机 RL、VLA 人形），J182 的「力感知多指灵巧抓取」和用户 DexWeaver 构想（灵巧手）主题同源；J187 的世界动作模型也压在第三优先级上。如果只看「想做什么」，这是切片里最对味的一家。
- **短板与缺口（直说）**：
  1. **学籍硬伤，且不可补**。研0 没有硕士学籍、没有导师、没有毕设资格，4 条核心岗连投递资格都不具备；这不是靠项目能补的。
  2. **经验年限差一个量级**。J186/J187 要「≥1 年 VLM/VLA/RL 实习或研究」，用户是 0 段实习 + 0 篇论文。
  3. **C++/ROS2/Isaac 全空白**。6/6 要求 C++，5/6 要求 ROS2，用户「尚未系统使用」。
  4. **时长**。≥12 个月意味着 2027 年入学后基本被锁死在一个课题上，与用户「先广后深、P0–P5 路线」的规划冲突，需要提前想清楚。
- **1–3 周内可补的最小动作**：**本周不做任何投递动作**。可做的是把 J182 的原文当学习大纲：在 MuJoCo 里跑通一个多指手抓取（如 `mujoco_menagerie` 的 ShadowHand + 简单 cube lift），记录「质心动力学/力控」相关参数怎么设。这件事 3 周内做不完，但可以先建一个「期智课题预研」笔记，2027 年 9 月后直接复用。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**（面向 2027 年入学后的版本）：`Isaac Lab`、`ROS2`、`MuJoCo`、`C++`、`PPO`、`WBC / MPC`、`Sim2Real`、`真机部署`。现阶段这些一个都没有，所以**这份简历现在不存在**，别硬凑。
2. **面试可能被问的 3 个问题，及答题要点**（假设 2027 年投 J186）：
   - **Q1：你的 VLA 训练框架里，VLM 奖励怎么和 RL 结合？** 要点：VLM 只做 reward model / 成功判别，不直接出动作；讲清 reward 的稀疏性与 reward hacking 风险；说清 RLinf 或类似框架里 rollout 与训练的配比。
   - **Q2：足式/人形的全身控制，为什么用分层而不是端到端？** 要点：分层解决「高频平衡 + 低频决策」的时序尺度差异；上层出轨迹/目标，下层 WBC/QP 跟踪；端到端样本效率低且难保证安全约束。
   - **Q3：真机实验里，sim2real 最主要的失配来源是什么？** 要点：接触模型与摩擦、执行器延迟与带宽、状态估计误差；对应手段是系统辨识 + 域随机化 + 在线自适应。
3. **可产出的作品/证据**：2027 年前能拿出的最好证据是**一篇可复现的技术报告**（MuJoCo 多指手抓取 + 力控参数消融），而不是刷题式项目；其次是一段真机/仿真视频。
4. **软性动作**：现在唯一有意义的动作是**建立联系而非投递**——找该院在读学生问「研0 能否提前进组做 RA / 预研」，或直接问 2027 年入学后是否还有毕设名额。不要在 2026 年投这 6 条中的任何一条。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**2027 年 9 月之后**（取得硕士学籍、确定导师后）。现在投=浪费；若一定要接触，走「咨询 RA / 预研」而非「申请实习」的话术。
- **简历突出**：C++/ROS2 工程能力 + Isaac Lab 真机迁移 + 一个与毕设选题强相关的预研项目。
