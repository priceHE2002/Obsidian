## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

从岗位名「**无人机 SLAM 开发实习生**」与职责「**无人机视觉导航、视觉 SLAM**，完成算法调试并按项目需求设计导航解决方案」看，这是一家**做无人机（或无人机机载系统）的公司**，业务里含"按项目需求"交付导航方案——**推断**有 To B 项目制业务，而非纯研发。

公司规模、产品线、客户、是否有整机：**全部未核实**。这是本切片里**唯一一条无人机方向**（其余全是地面机器人/机械臂/人形），无人机与具身智能在"本体—操作"层面几乎没有交集，只在"视觉感知 + 状态估计"这层工具上有重叠。

- **出勤 / 时长硬门槛**：**「4 个月，每周 5 天」**——这是全切片里**最硬的一条出勤要求之一**（另一个是矩阵超智 J181 的 ≥4 天/周）。与用户 2026-11 → 2027-01 **每周 ≤3 小时**的现实直接、彻底冲突。

  - "算法调试""按项目需求设计导航解决方案"——**这是交付导向**，不是研究导向。

- **隐性偏好与关键词**：「**视觉 SLAM**」（不是激光 SLAM）、「**视觉导航**」、「**算法调试**」（工程侧）、「**按项目需求**」（乙方/交付语境）。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：
  - 技能栈里的 Python / C++ / ROS / 感知 / 规划，与"机器人通用底座"重合——如果目标是"先进入机器人行业"，这些词在简历上是通用的。
  - **薪酬与截止都写明**：信息透明度高于切片里大多数岗位，能直接算投入产出。
- **短板与缺口**（直说）：
  1. **「硕士以上」是硬措辞**：研0 既无硕士学历也无学籍，**在文字上直接被排除**。
  2. **5 天/周 × 4 个月**：与用户每周 ≤3h 的现状差 13 倍以上，**没有任何谈判空间**（全职实习）。
  3. **方向完全偏离主线**：无人机视觉 SLAM 与 VLA / 机器人操作 / 灵巧手没有技术复用点；做 4 个月对投具身岗的简历**增益接近于零**。
  4. **SLAM 零基础**：视觉 SLAM（特征点、BA、回环）是独立的知识体系，学习成本高于"跑通一个 VLA demo"。
  5. **JD 时效极可疑**：2023-05 发布，**很可能早已招满或团队已变**；投递大概率无响应，浪费的是时间和期待。
  6. **薪资偏低**（150–200 元/天）且在无人机行业，**性价比最低**。
- **1–3 周内可补的最小动作**：
  - **不建议为这家公司做任何专门准备**。若一定要留一条退路：跑通 **ORB-SLAM3** 或 **VINS-Fusion** 的公开数据集 demo（1–2 天），能说清"前端跟踪 + 后端优化 + 回环"三件事即可——但优先级应排在 P1/P2 之后。
  - 更划算的动作：把这份 JD 当作"反面对照"——**明确自己不做什么**（无人机 SLAM），把时间留给 VLA。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目 / 关键词**（若将来真要投导航类岗位）：
   - 「ORB-SLAM3 / VINS-Fusion 在 ×× 数据集上跑通，ATE x cm」
   - 关键词排序：`视觉 SLAM` > `ROS2` > `C++` > `状态估计`。
   - **但现在不该写**：简历上放无人机 SLAM 会让 VLA 岗面试官觉得方向不清。
2. **面试可能被问的 3 个问题及答题要点**：
   - **Q1「视觉 SLAM 的前端和后端分别干什么？」**
     要点：前端做**帧间位姿估计**（特征提取匹配 / 光流 / 直接法），后端做**优化**（BA、位姿图），回环检测负责消除累积漂移。
   - **Q2「无人机 SLAM 和地面机器人 SLAM 有什么不同？」**
     要点：**6 自由度、无平面约束**、运动剧烈（快转速导致特征跟踪难）、**算力与功耗受限**（机载）、常需与 IMU 紧耦合（VIO）来补视觉失效。
   - **Q3「视觉失效（强光/弱纹理/快速运动）怎么办？」**
     要点：VIO 紧耦合、多传感器冗余（双目/深度/IMU）、失效检测 + 切换到其他定位源、提高关键帧频率。
3. **可产出的作品 / 证据**：跑通一个开源 VIO/SLAM 的轨迹图 + ATE 表。**但对本切片的其他公司，这份作品没有加分作用**。
4. **软性动作**：投递前**先在实习僧上确认岗位是否仍在招**（2023 年发布）；若已失效，不必花时间。
