## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

从 4 条 JD 看，RIMBOT 做**双臂 + 多指灵巧手**的具身智能：VLA / WAM / WLA / VFA 这类「视觉—语言—触觉—动作」联合建模、IL/RL 后训练、真机部署（插拔、双臂装配）。岗位拆成四条线——运控（动作重定位、IK/FK、参数辨识、全身运控）、后训练（SFT、离线/在线 RL、人类在环）、全栈（模型落地到真机）、数据（多相机/深度/3D 姿态真值），说明团队按「模型—控制—数据」分工，且有内部模型缩写体系。融资、人数、产品**未核实**。

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：Python 4/4；PyTorch 2/4（J118/J119）；VLA 3/4（J118/J119/J120）；IL 2/4（J118/J119）；RL 2/4（J118/J119）；Dexterous Hand 2/4（J117/J119）；ROS2 1/4（J119）；Pinocchio 1/4（J117）；3D Vision/SLAM 1/4（J120）。原文措辞：J118「VLA/WAM后训练：示范SFT、离线/在线RL、人类在环纠正、奖励设计、价值估计与真实机械臂操作闭环评测」；J117「动作重定位、IK/FK数值优化、运动学参数辨识、全身运控、仿真与实机调优」；J120「构建多相机/深度数据的空间真值、相机与手部3D姿态估计、异常运动学数据剔除」。
- **学历与学籍倾向**：全切片对研0 最友好的写法之一——J117「研究生优先，优秀本科可考虑」，J118「本科可尝试（硕博优先）」，J119/J120 限定「2027 届及之后在校生」。若按 2027 届本科毕业计算（**需本人确认学籍口径**），J119/J120 的届别条件是可满足的。
- **出勤/时长硬门槛**：4 天/周是底线，且 J117 明确「每周至少4天，长期实习」「建议≥6个月」；J119 ≥3 个月、J120 ≥4 个月。**四天到岗对研0 前期（每周 ≤3h）不可能**，只能等 2027 年春季后时间释放。
- **职责重心**：分层明显——J118 偏**研究/后训练**（奖励设计、价值估计、human-in-the-loop）；J119 偏**全栈落地**且要求「已完成真实机器人数据→策略→部署完整闭环并附真机 Demo」；J120 偏**数据与质量**；J117 偏**控制与真机调优**。没有纯写论文的岗。
- **隐性偏好与关键词**：WAM / WLA / VFA（内部模型命名，说明有自研路线）、人类在环纠正、奖励设计、价值估计、bad-case 反馈、真机 Demo、完整闭环、灵巧手、插拔与双臂装配。J119 那句「已完成…完整闭环并附真机Demo」是全切片最硬的一条筛选条件。
- **与同类公司的差异**：唯一把「必须交付过真机闭环 Demo」写进 JD 的公司，同时又是对本科/届别最开放的；即「入门门票宽、中期筛选狠」。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 方向命中第一优先（VLA）与第二优先（真机 RL/灵巧操作）双线；② J117/J118 明确接受优秀本科，J119/J120 的 2027 届条件用户大概率满足；③ 灵巧手方向与用户的 DexWeaver 构想同源，面试时能讲出「为什么想清楚要做灵巧手」；④ 4 条 JD 都在上海（J118/J119/J120 为上海/北京双城，需确认）。
- **短板与缺口（直说）**：
  1. **没有真机闭环 Demo**——J119 的硬门槛，用户 P0/P1 阶段完全不具备，这一条基本决定 J119 投了也白投。
  2. **ACT / Diffusion Policy / OpenVLA 只是「听说过」**——J118 要求「至少了解一种」，需要能讲清 loss、动作表示、推理频率，而不只是名字。
  3. **无 C++ / Pinocchio / 数值优化**——J117 的运控线门槛很高。
  4. **4 天/周 + 3–6 个月**与 2026-11 至 2027-08 的考试节奏冲突。
- **1–3 周内可补的最小动作**：用 LeRobot 复现 ACT（或 Diffusion Policy）在仿真抓取上的一个任务，产出「数据量 / 训练时长 / 成功率 / 失败案例」四件事 + 30 秒视频；这是唯一能对上 J119「闭环 Demo」语汇的证据形式，也是 J118 面试的谈资。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：ACT、Diffusion Policy、模仿学习、VLA 微调、PyTorch、真机/仿真闭环、成功率评测。写法示例：「复现 ACT 于 XX 抓取任务，200 条示教，成功率 72%（基线 55%）」。
2. **3 个可能面试题及答题要点**：
   - 「ACT 和 Diffusion Policy 的区别？各自适合什么场景？」→ ACT 用 CVAE + transformer 一次出动作块（action chunking），推理快、对多模态示教有容忍；DP 用扩散去噪生成动作序列，表达力强但推理慢、需降采样。给「高频控制选 ACT、复杂多峰选 DP」的判断。
   - 「离线 RL 里 reward 怎么设计？人类在环纠正怎么用？」→ 稀疏任务奖励 +  shaping；HIL 用于纠正失败片段并回灌数据集；讲清「奖励设计容易 reward hacking，需要用成功率而非回报做验收」。
   - 「VLA 后训练（SFT）和从头训策略的差别？」→ 预训练视觉语言先验 + 动作头微调，数据效率高但受底座能力上限约束；要提冻结/全参、LoRA、动作空间对齐。
3. **可产出的作品/证据**：一个 ACT/DP 复现 repo（含数据、曲线、视频、失败分析）；一页「灵巧手数据采集方案」构想（对应 DexWeaver）；可选：给 LeRobot 提一个小 PR 或 issue。
4. **软性动作**：官网投递之外，找 RIMBOT 的工程师在 GitHub/知乎/即刻上互动；J117/J118 是 A 档，优先投这两条；J119 等有真机 Demo 再投。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**先投 J118（后训练方向）与 J117（运控方向）**，两者对本科友好且不强制真机 Demo；J119 等 P2/P3 有闭环作品后再投；J120 作为数据线备选。出勤上先按「≥4 天」谈，谈不下来再问能否前 3 个月每周 2–3 天过渡。
- **简历突出**：VLA / ACT 复现、灵巧手、PyTorch。
- **开场话术**：「您好，我在做 VLA/模仿学习的复现（ACT 跑通了 XX 任务，成功率 XX%），看到贵司后训练与运控实习岗接受优秀本科，我是同济 2027 级拟录取（研0），想确认能否按 2027 届本科身份投递、以及每周到岗能否前期 3 天后转 4 天。」
- **跟进与备用路径**：官网投递后 5–7 天在 LinkedIn/邮件跟进一次；若 J118 无回应，转 J117 强调「愿意从运控/数据做起」；同时把该公司作为「真机闭环」的目标供给方，2027 年春季再冲 J119。

## 七、风险与核实项

- **研0 学籍**：J119/J120 的「2027 届及之后在校生」是否包含 2027 年入学的研0（本科 2027 届），需 HR 确认；J117/J118 的「优秀本科」如何界定也需问。
- **出勤/时长**：4 天/周 + 3–6 个月是硬约束；J118 出勤未写，需确认。
- **信息时效**：4 条均「岗位页可见·需复核」，官网为第三方招聘系统（chuyihr），岗位可能随时关闭。
- **其他**：J118/J119/J120 地点写「上海/北京」，城市分配需确认；J119 页面显示 35k–50k 与实习岗不符，**不要当作实习薪资预期**；J117 明确 1 个 HC。

## 八、结论（档位建议：冲刺 / 匹配 / 保底-观察 + 一句话理由）

**冲刺**——A 档最多、方向最对口、对本科与届别最开放，但「真机闭环 Demo + 4 天/周」两条硬条件当前都不满足，属于「跳一跳够得着」的目标。
