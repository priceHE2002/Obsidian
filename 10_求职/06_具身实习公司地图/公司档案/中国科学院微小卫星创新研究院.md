## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

中科院系统的卫星/航天器研制单位（机构性质属公开常识，**JD 未写**，仅作背景）。从岗位看，工作对象是**空间机械臂 + 卫星姿轨控系统**：建模、控制律设计、仿真测试，外加「空间具身智能自主对接与目标抓取」并「完成软件部署」。**推断**：这是一个典型的航天机电/控制类研究岗，与地面人形机器人的 VLA 路线只在「具身智能」这个词上相交。团队规模、是否有实验平台、是否解决编制/户口：未核实。

## 三、JD 要求偏好（重点，要细）

### 高频技能 / 工具
- 技能字段：`C++`、`Python`、`Control`、`Planning`、`Simulation`、`Robotics`。
- 原文职责：「协助空间机械臂与卫星姿轨控系统建模、控制律和仿真测试；研究空间具身智能自主对接与目标抓取并完成软件部署」。
- 原文要求：「机械/机器人/控制专业，**SolidWorks 和 ANSYS/ADAMS 等建模基础**」「机器人竞赛优先」。
- 这是全切片**唯一要求 CAD/CAE 软件**（SolidWorks、ANSYS、ADAMS）的岗位——纯软件背景的人在这里是劣势，不是优势。

### 学历与学籍倾向
- 「本科大三及以上」：字面上你（本科已毕业、硕士未入学）够得着学历线，但「大三及以上」的语境是**在校在读**，研0 的空档身份需要单独解释。
- 另有「**竞赛定向招募**」五个字写在岗位名里——这不是加分项，是筛选入口：没有机器人竞赛履历的人大概率不在目标池内。
- 未提论文、未提硕士/博士，学历压力小于广闻，但专业与竞赛压力更大。

### 出勤 / 时长硬门槛
- **≥6 个月、每周 ≥3 天**，写明。3 天/周比博世的 5 天/周温和，但 6 个月是硬约束。
- 若 2027 年 1 月入职，6 个月到 7 月，正好压到入学前，理论上可行——前提是你能稳定每周 3 天到岗。
- 地点上海，未提远程；航天院所通常有保密与门禁要求（**推断**，JD 未写）。

### 职责重心
- **偏工程仿真 + 控制律设计**：「建模」「控制律」「仿真测试」「软件部署」。
- 「研究空间具身智能自主对接与目标抓取」这一句是唯一的算法成分，但排在建模/控制之后，且服务对象是航天器对接，不是通用操作。
- 无数据、无训练、无 VLA。

### 隐性偏好与关键词
- 「**竞赛**」：RoboMaster、挑战杯、机械创新大赛这类履历。
- 「**建模**」出现两次（系统建模、三维建模），指的不是「训练模型」而是「物理建模」——这是最容易误解的歧义词。
- 「**部署**」在航天语境下通常指星载/地面软件部署，不是模型推理加速。
- 「姿轨控」= 姿态与轨道控制，属传统航天控制，与 RL 无关。

### 与同类公司的差异
切片里唯一的航天/科研院所岗，也是唯一把「机械设计 + 控制 + 竞赛」捆在一起招人的地方；技术栈最「硬」，与具身智能算法距离最远。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**
  - Python + 愿意学仿真，能覆盖「仿真测试」的一部分。
  - 「空间具身智能自主对接与目标抓取」这个题目本身有意思，如果你未来想做「具身 Agent + 长程任务」，这段经历能讲出故事。
- **短板与缺口（直说）**
  - **无竞赛履历**：岗位名直接写「竞赛定向招募」，你没有任何机器人竞赛记录（USER_CONTEXT 未提），这是第一道门。
  - **无机械背景证据**：SolidWorks / ANSYS / ADAMS 一样不会，USER_CONTEXT 里也没有机械设计经历；JD 明写要「建模基础」。
  - **C++ 空白**、控制理论（状态估计、反馈控制）未系统学 → 职责里的「控制律」你接不住。
  - **≥6 个月 × 3 天/周**：与你前期 ≤3h/周 冲突；且 6 个月投入换来的技能，对你 VLA 主线几乎不可迁移。
  - 岗位已下线。
- **1–3 周内可补的最小动作**
  - 若真要走这条路：装一个 SolidWorks（学生版）或 FreeCAD，画一个二连杆机械臂并做一次静力学仿真；同时在 MuJoCo 里复现一个「末端到点」的阻抗控制。两周能出东西，但**不建议现在做**——机会成本太高。

## 五、如何提升进入概率（具体准备清单）

> 前提：岗位已下线。若 2027 年该院所重开同类岗，按下列准备。

1. **简历上要出现的项目/关键词**：`机械臂运动学`、`阻抗/力控`、`MuJoCo 仿真`、`轨迹规划`、`C++`。**不要**把 VLA、Diffusion Policy 放前面，会和岗位画像冲突。
2. **可能被问的 3 个问题及答题要点**
   - Q1「空间机械臂和地面机械臂最大的控制差别？」要点：微重力下无重力补偿、动力学耦合强、时延大、可靠性要求极高（不可维修），因此更依赖模型预测与鲁棒控制而非学习型方法。
   - Q2「你怎么做抓取的目标位姿估计？」要点：讲清 6DoF 位姿估计 + 手眼关系 + 抓取点采样，承认自己只在仿真做过。
   - Q3「为什么来航天院所而不是机器人公司？」要点：给一个具体的技术动机（例如「想在强约束、可验证的环境里做控制」），别说「稳定」。
3. **可产出的作品/证据**：一份「空间机械臂抓取对接」的仿真视频 + 控制律对比（PID vs 计算力矩），这是这类单位最认的证据形态。
4. **软性动作**：这类岗位更看导师/学长推荐，公开投递效率低；若同济有相关课题组，走老师介绍比网申有效（**推断**）。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **出勤/时长**：≥6 个月 + ≥3 天/周；是否接受分段（先 3 天/周、后期全职）未知。
- **信息时效**：**已下线**，领英显示关闭申请；链接可能失效。
- **其他**：①涉密单位通常对实习生有政审/保密要求（**推断**）；②「建模」一词在 JD 中指物理建模而非机器学习，投递前务必确认岗位实际内容；③该岗位与你的 VLA 主线几乎不可迁移，需评估机会成本。
