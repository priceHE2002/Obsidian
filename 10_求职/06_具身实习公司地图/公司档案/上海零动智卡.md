## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`3DGS 场景重建（公开数据集跑通）`、`生成式数据增强`、`仿真环境搭建`、`Python/PyTorch`。
2. **面试可能被问的 3 个问题及答题要点**：
   - 「3DGS 的流程是什么？相比 NeRF 快在哪？」要点：SfM 点云初始化 → 每个高斯的位置/协方差/颜色/透明度 → 可微光栅化渲染 → 与真值图算损失反传；快在显式表示 + 光栅化而非体渲染采样。
   - 「闭环仿真怎么评估好坏？」要点：场景覆盖率、感知/规划在仿真与真实的分布差、端到端指标（碰撞率/接管率/舒适度）、可复现性（固定场景与随机种子）。
   - 「AIGC 生成的数据直接拿来训，有什么风险？」要点：域偏差与伪影、物理不合理（光照/几何）、标签不一致；需做真实性过滤 + 小比例混入 + 下游指标验证。
3. **可产出的作品/证据**：一段 3DGS 重建视频 + 1 页「重建质量 vs 训练时间」对比；一份仿真场景清单。
4. **软性动作**：24365 平台直接投（流程简单）；同时在 GitHub 给 3DGS 相关 repo 提 1 个 doc/issue，作为「我真的动手了」的旁证。若目标是具身，建议只把它当「3D 能力补课」，不写进主线叙事。
