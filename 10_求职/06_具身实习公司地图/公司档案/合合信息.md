## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 本科及以上，研0 只需确认学籍口径；② Python + 对 RL/VLA 的基本理解正好对上「了解」这一层级的要求；③ 上海、岗位较新（2026-10-10），投递窗口大概率还开着；④ 要求里写「了解 MuJoCo/Isaac/Gazebo」——用户 P0 正在学的 MuJoCo 直接可用。
- **短板与缺口（直说）**：
  1. **C++ 与 ROS2 双缺**——标签里两项都在，JD 又写「C/C++ 和 Python」，很可能面试会考 C++ 基础。
  2. **无系统联调经验**——「软硬件实验、系统联调」是职责第一句，用户连真机都没碰过。
  3. **运控算法未系统学**——PID/阻抗/MPC 只在概念层。
  4. **一条 JD 要求面极宽**，简历上任何一项写得太满都会被追问到底，很容易露怯。
  5. 单 HC，竞争可能集中。
- **1–3 周内可补的最小动作**：① MuJoCo 做一个 7-DoF 机械臂 reach + PD/阻抗控制，记录超调与稳态误差，写 1 页；② 装 ROS2 跑通 pub/sub 与一个自定义节点（2 天）；③ 简历上只写「MuJoCo 仿真 + Python 控制」，不写 C++（不会就别写）。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：MuJoCo、PD/阻抗控制、轨迹跟踪误差、Python、ROS2 基础节点、VLA 概念（了解级）。**不要**写 Isaac Sim / C++，除非真跑过。
2. **3 个可能面试题及答题要点**：
   - 「阻抗控制和 PD 位置控制的区别？」→ 位置控制只管跟踪位置；阻抗控制把末端表现为弹簧-阻尼，外力下让步，适合接触任务；讲刚度/阻尼参数如何影响稳定性。
   - 「ROS2 里一个控制回路你怎么搭？」→ 节点订阅状态话题 → 控制器计算 → 发布指令；注意时钟同步、控制频率、消息队列深度与实时性。
   - 「VLA 和传统运控是什么关系？」→ VLA 给高层语义/动作意图，运控负责底层执行与稳定；当前 VLA 输出频率低，需要动作分块或下层控制器补足——这条能显示你理解整机栈，而不只是名词。
3. **可产出的作品/证据**：一页「MuJoCo 机械臂控制实验」（图 + 误差指标）；一个 ROS2 最小节点 repo；一段 20 秒仿真视频。三样加起来足以覆盖 JD 前两句。
4. **软性动作**：岗位页直接投；同时查公司技术博客/公众号有没有具身相关内容，面试时提一句「看到你们在做 XX」，比空谈匹配有效。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **简历突出**：MuJoCo 仿真、Python、控制实验。
- **开场话术**：「您好，看到贵司具身智能算法实习（J14581）接受本科。我是同济 2027 级拟录取研究生（研0），做过 MuJoCo 下的机械臂 PD/阻抗控制实验（附记录），想确认研0 能否按本科身份投递、以及每周到岗要求。」
