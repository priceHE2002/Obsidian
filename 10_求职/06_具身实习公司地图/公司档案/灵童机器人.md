## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**
  - 你的第二优先级正是「真机 RL / 灵巧操作」，这条岗位正好落在这一档。
  - PyTorch 起步 + 愿意学 RL，方向上不冲突；人形运控是「RL 最成熟的落地场景」，学习资料多。
  - 出勤未写死，给了研0 谈条件的空间。
- **短板与缺口（直说）**
  - **人形双足运控零基础**：PPO 在 Humanoid 上的训练、奖励设计、地形课程学习，你一样没做过；这是比机械臂抓取难得多的任务。
  - **无 Isaac Gym/Lab 经验**：人形 RL 几乎都在 Isaac 里训，你没跑过。
  - **无 sim2real**：JD 明写要，你零经验。
  - **无真机部署**：不会碰过电机、IMU、实机调试。
  - **硕士标注**：研0 要谈；且公司信息不透明（无官网岗位页），存在「小团队、无带教」的风险。
  - **详情受限**：连岗位是否还在招都无法确认。
- **1–3 周内可补的最小动作**
  1. 跑通 Isaac Lab 或 MuJoCo 的 Humanoid 行走示例（用现成配置即可），产出训练曲线 + 视频。
  2. 读懂 PPO 在人形上的奖励项（速度跟踪、姿态、能耗、脚滑），能说出每一项的作用。
  3. 找一篇 sim2real 的经典做法（域随机化/系统辨识），写 1 页笔记。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`PPO`、`Isaac Lab`、`Humanoid`、`奖励设计`、`sim2real`、`域随机化`。人形岗最看重「你训过人形没有」，其次才是学校。
2. **可能被问的 3 个问题及答题要点**
   - Q1「人形走路老往前摔，奖励怎么改？」要点：先看是不是速度跟踪项权重过大导致前倾，再看姿态/高度惩罚、脚部接触奖励；给「先降目标速度、加躯干姿态惩罚、再做课程学习」的具体顺序。
   - Q2「仿真能走，真机就软腿，为什么？」要点：执行器模型（PD 增益、力矩限幅、延迟）、质量/惯量误差、地面摩擦；对策是系统辨识 + 域随机化 + 在真机上重调 PD。
   - Q3「PPO 和 SAC 在人形上你怎么选？」要点：PPO 稳定、易并行、适合大规模仿真；SAC 样本效率高但调参难。人形主流是 PPO + 大规模并行环境。
3. **可产出的作品/证据**：一段人形行走的仿真视频 + 训练曲线 + 奖励消融（去掉某一项会怎样）。视频比文字有用十倍。
4. **软性动作**：BOSS 直聘上直接开聊，第一句给「我训过 Humanoid 的 PPO，视频在 X」；小公司老板/技术负责人常亲自聊，回复率高于大厂（**推断**）。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**P1 完成后即可试**（不必等 P2）。人形运控岗对 VLA 经验无要求，对「训过 RL、能上真机」有要求；你在 P1 做完 MuJoCo 抓取 RL 后就有最低筹码。
- **简历突出**：`PPO`、`Isaac Lab`、`sim2real`。
- **开场话术**：「您好，我是同济 2027 级研0（已录取），用 Isaac Lab/MuJoCo 训过 PPO 的移动/抓取策略（视频：X），看到岗位招人形 RL 运控。想确认两点：研0 能否按本科身份实习？每周到岗天数是否可以谈？」
