- **与同类公司的差异**：别家写「研究」「复现」「论文」，这家写「调参」「日志」「数据格式」——**门槛低但活细**，是研0 最现实的入口型岗位。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 学历线正好卡在「本科及以上」，我可以按本科身份谈，不用假装硕士在读；② 职责是「微调 + 日志 + 数据 + 评测」，与我 P3 计划（开源 VLA 微调复现）方向一致，做过的活能直接对接；③ 上海本地，200 元/天虽不高但明确；④ 截止 2027-03-01，是本切片里**在招窗口最长**的 A 级岗之一。
- **短板与缺口**（直说）：
  1. **没跑过完整微调**：我只「跑通小实验」，没做过「准备数据 → 配环境 → 微调 → 看 loss/指标 → 定位不收敛原因」的闭环；JD 要的恰恰是这个闭环。
  2. **不看训练日志**：loss 曲线异常（NaN、梯度爆炸、过拟合、数据不均衡）我只有课本知识，没有排查经验。
  3. **出勤**：4 天/周，前期做不到；这是我最大的实际障碍。
  4. **无论文无实习**：简历上「相关经历」一栏仍然空。
- **证据缺口**：没有一次「我把某个开源模型微调成功并给出前后对比」的记录；也没有数据清洗的样例（比如把一批轨迹转成统一格式的脚本）。
- **1–3 周内可补的最小动作**：① 用 LeRobot 或 OpenPI 的最小配置，在公开小数据集上跑一次 SFT 微调（哪怕只训 1k step），记录 loss 曲线 + 一次失败排查过程；② 写一个「轨迹数据格式转换」小脚本（HDF5/RLDS 互转），放 GitHub；③ 把这两件事写成 1 页《我能做的调参与数据活》，投递时直接附。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`VLA/大模型 SFT 微调（1k step，loss 曲线）`、`训练日志排查（NaN/梯度爆炸/OOM）`、`轨迹数据格式规范化（HDF5/RLDS）`、`部署前评测（成功率/延迟）`、`Python/PyTorch`。
2. **面试可能被问的 3 个问题及答题要点**：
   - 「微调时 loss 不降，你怎么排查？」要点：先看数据（标注/对齐/归一化）→ 再看学习率与 warmup → 看 batch/显存是否被迫缩水 → 看 loss 实现（mask、ignore_index）→ 最后才怀疑模型；用「单 batch 过拟合」验证链路是否通。
   - 「给你一批格式混乱的机器人轨迹数据，怎么规范化？」要点：先定 schema（观测/动作/时间戳/元数据）→ 写校验（长度、频率、缺失、越界）→ 转换脚本 + 单测 → 产出数据卡（来源/规模/分布/已知缺陷）。
   - 「部署前你会评什么？」要点：任务成功率、推理延迟与频率、异常输入鲁棒性、失败模式分类；指标要固定 seed 与场景集，能对比 baseline。
3. **可产出的作品/证据**：一个 `tiny-sft` repo（数据→训练→评测→报告四段）；一份「训练日志异常案例集」（5 种典型曲线 + 处理方式）。
4. **软性动作**：得早网原页投递 + 给 HR 留言问「是否接受每周 3 天 + 周末补」；在开源社群（LeRobot/OpenPI）提 1 个数据格式相关的小 PR，作为「我真的碰过这条链路」的旁证。
