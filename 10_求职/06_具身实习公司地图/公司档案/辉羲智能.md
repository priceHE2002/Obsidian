## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：Python 2/2、C++ 1/2（J063）、VLA 1/2、Transformer / Diffusion 各 1/2（J062）、SLAM / Isaac Gym / Simulation / Planning 各 1/2（J063）。原文措辞：「机器人多模态动作模型训练、Transformer和Diffusion策略；实验部署与性能优化」（J062）、「硕士在读，PyTorch/Transformer/生成模型，≥6个月」（J062）、「机器人SLAM、仿真/规划/控制相关算法集成，使用Gazebo或Isaac Gym」（J063）、「本科可；Python/C++、机器人学/仿真基础」（J063）。
- **学历与学籍倾向**：两条口径**完全相反**。J062 写死「硕士在读」；J063 写「本科及以上在读」，是切片里对研0 最明确的放行之一。这意味着同一家公司里，**J063 是研0 唯一现实的入口，J062 需要先问「研0 能否按硕士在读投」**（切片也是这么标的）。
- **出勤 / 时长硬门槛**：J062「≥6个月」；J063「未明确」。J063 未写时长，实操中可能按 3 个月起谈（推断，未核实），是这条线相对友好的地方。
- **职责重心**：J062 偏**模型训练 + 部署优化**（研究成分高，但落点在「实验部署与性能优化」）；J063 偏**系统集成**（SLAM、仿真、规划控制拼起来跑）。两条都不是纯研究岗，都有明确工程落点。
- **隐性偏好与关键词**：「多模态动作模型」「Transformer/Diffusion」「生成模型」「SLAM」「Gazebo/Isaac Gym」「算法集成」。注意 J063 特意写「集成」而不是「研发」——要的是能把现成模块接起来的人。
- **与同类公司的差异**：切片里**唯一在同一家公司内同时给出「硕士在读」和「本科可」两种口径**的，等于自带一条「低门槛侧门」；而 J062 的技术栈（Transformer+Diffusion 策略）比多数「VLA 岗」写得更具体，说明他们确实在做策略模型而不是只做集成。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：J063 明写「本科可」，且优先级标 A、出勤未写死——**这是切片里投递成本最低的 A 级岗之一**。J062 的 Transformer/Diffusion 策略方向正好压在用户 P2/P3 上，如果 P3 做完，这条线会变得可谈。
- **短板与缺口（直说）**：
  1. **C++ 与机器人学基础空白**。J063 要「Python/C++、机器人学/仿真基础」，还点名 SLAM、Gazebo/Isaac Gym；用户 C++ 未系统使用，SLAM 零基础，Gazebo/Isaac Gym 只停留在「知道名字」。
  2. **无 SLAM / 规划 / 控制任何一项实操**。J063 的四个关键词（SLAM、仿真、规划、控制）用户一个都没有项目证据。
  3. **J062 学历卡硕士**。研0 即使技术够，也要先解决「按什么身份投」的问题。
  4. **无论文、无实习**，在牛客这类平台上会和大量硕士简历直接竞争，初筛看学校 + 学历标签的概率高。
- **1–3 周内可补的最小动作**：二选一，不要都做——① 面向 J063：在 Gazebo 里跑通一个差速车 + 简单 A* 全局路径 + 沿路径跟踪，录视频（约 5–7 天）；② 面向 J062：把 LeRobot 的 ACT 在 PushT 上跑通并写一页复现笔记（约 7–10 天）。以用户当前路线，选 ② 更划算，因为它同时服务穹彻、智往未来和 AI Lab。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：投 J063 用 `ROS2/Gazebo`、`A*/DWA`、`SLAM`、`C++`；投 J062 用 `Transformer`、`Diffusion Policy`、`VLA 微调`、`PyTorch`。**一份简历不要同时塞两套**，按岗位改。
2. **面试可能被问的 3 个问题，及答题要点**：
   - **Q1：VLA 里为什么用 Diffusion 而不是直接回归动作？** 要点：动作分布是多峰的（同一场景多种合理抓法），MSE 回归会平均成不可行动作；Diffusion 建模多峰但推理慢，需要少步采样/蒸馏；能说出你实测的推理频率。
   - **Q2：SLAM 前端后端怎么分工？** 要点：前端做帧间配准/特征跟踪出位姿初值，后端做位姿图/BA 全局优化；说清回环检测的作用，以及为什么纯视觉在弱纹理/快速运动下会丢。
   - **Q3：Gazebo 和 Isaac Gym 你更适合哪个？为什么？** 要点：Gazebo 偏系统集成与 ROS 生态、物理精度一般；Isaac Gym 偏 GPU 并行 RL、吞吐高但不便做完整系统仿真。答案要落在「我的任务是 X，所以我选 Y」。
3. **可产出的作品/证据**：一个 3–5 分钟的仿真录屏 + 对应 repo；对 J062 再加一页「ACT vs DP vs OpenVLA」的对比笔记。
4. **软性动作**：牛客上直接私信 HR 问「研0 能否按本科投 J062」；同时在 GitHub 找该公司开源仓库提 issue/PR（若有，未核实）。
