## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

JD 是「机器人运动控制（机械臂/灵巧手）」，技术栈是 PID/阻抗控制、MPC/轨迹优化、WBC 与 QP 实时控制，工具为 Pinocchio / CasADi / MuJoCo。从「灵巧手 + 实时控制」看，公司在做机械臂与灵巧手的底层控制（**推断**），偏传统机器人学而非具身大模型。团队规模、本体形态、是否自研量产**未核实**。信息源是高校实习聚合站（deizao.net），而非公司官网。

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**（单条 JD 全部标签）：Python、C++、Control、MPC、Pinocchio、MuJoCo、ROS2。原文措辞：「PID/阻抗控制、MPC/轨迹优化、WBC与QP等实时控制，使用 Pinocchio/CasADi 及 MuJoCo」；要求「2027 年及以后毕业的本科/硕士/博士；机器人动力学和 Python/C++；5 天/周」。
- **学历与学籍倾向**：**对研0 最明确友好的一条**——「2027 年及以后毕业的本科/硕士/博士」直接写死了届别，2027 届本科在读完全在范围内（**需本人确认学籍口径**）。同时没有「硕士优先」「研究生优先」的限定词。
- **出勤/时长硬门槛**：**5 天/周**，且截止日 2027-09-11（长窗口）。这是全切片唯一把「5 天/周」写进要求的岗位——对研0 前期（每周 ≤3h）是硬冲突，只能等到 2027 年时间释放后再谈。
- **职责重心**：**偏底层实时控制与优化**，不是学习类算法。「实时控制」「QP」「WBC」三个词说明日常工作是把优化问题写成可实时求解的控制器，并调到不抖、不超限；研究成分低，工程与数学成分高。
- **隐性偏好与关键词**：实时（real-time）、QP（二次规划）、CasADi（符号优化建模）、Pinocchio（刚体动力学库）、WBC、阻抗控制、灵巧手。这一组词几乎就是「现代机器人控制栈」的清单，和 VLA/IL 那一套几乎不重叠。
- **与同类公司的差异**：唯一明确写「2027 届及以后 + 5 天/周 + CasADi」的岗位；也是唯一把「灵巧手」写进标题的运控岗（RIMBOT 的灵巧手在标签里，不在标题）。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 届别条件（2027 及以后）与研0 完全吻合，是全切片里最不需要「求 HR 通融」的一条；② 截止 2027-09-11，时间窗口长，可以「先准备再投」；③ 灵巧手与 DexWeaver 构想同向，动机故事好讲；④ MuJoCo 已在学习路径上（P0）。
- **短板与缺口（直说）**：
  1. **5 天/周**——2026-11 至 2027-08 前期每周 ≤3h，完全无法满足；即便后期 25–30h/周 也刚够 5 天 × 5–6h，压力大。
  2. **MPC / WBC / QP 数学门槛高**——需要凸优化、动力学、约束处理，用户「数学与深度学习基础在补」，短期补不上。
  3. **C++ / Pinocchio / CasADi 全零**，而这正是岗位的日常工具。
  4. 无真机调试经验（抖动、限幅、实时性）。
  5. 信息源是聚合站，JD 可能已过期或非最新版本（**需复核**）。
- **1–3 周内可补的最小动作**：① 用 Pinocchio + MuJoCo 做一个「机械臂重力补偿 + PD + 力矩限幅」的 demo，记录跟踪误差；② 跑通 CasADi 官方 MPC 例子，改成 2 连杆版本并画相图；③ 写半页「为什么 WBC 要用 QP」的理解笔记。三件事做完，勉强能在面试里不空白。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：Pinocchio、MuJoCo、PD/阻抗控制、MPC（入门）、CasADi、QP、力矩限幅、跟踪误差。
2. **3 个可能面试题及答题要点**：
   - 「WBC 为什么用 QP？约束怎么写？」→ 多任务优先级 + 物理约束（力矩上限、摩擦锥、关节限位）天然是带约束的二次规划；讲清 task space 加速度作为决策变量、松弛变量处理冲突任务。
   - 「阻抗控制和导纳控制区别？」→ 阻抗：控制力以表现为质量-弹簧-阻尼（适合刚性环境）；导纳：测力后改位置（适合柔性/人机协作）；给一个装配场景的判断。
   - 「MPC 里预测时域和控制时域怎么选？」→ 时域长看得远但算得慢；控制时域短可降维；实时性靠 warm start、稀疏求解、降采样。
3. **可产出的作品/证据**：一个 Pinocchio/CasADi 的 2 连杆 MPC demo（含代码、相图、力矩曲线）；一份「灵巧手控制待解决问题」清单（对应 DexWeaver），显示你懂难点在哪。
4. **软性动作**：截止远，**先加收藏、设 2027-03 提醒**；期间在 GitHub 关注 Pinocchio/CasADi 生态，提 documentation 级 PR；若能在学校实验室碰真机，优先攒「真机调参」经历——这是这家最看重的。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**不在 2026 年内投**。等 2027 年 3–5 月（届时时间可到 25–30h/周），且已有 Pinocchio/MPC demo 再投；投前先确认岗位是否仍在（聚合站时效存疑）。
- **简历突出**：Pinocchio / MuJoCo、MPC 入门、灵巧手。
- **开场话术**：「您好，看到贵司招收 2027 届及以后的运动控制实习（机械臂/灵巧手）。我是同济 2027 级拟录取研究生（研0），做过 Pinocchio + MuJoCo 的机械臂 PD/重力补偿与 2 连杆 MPC 小实验，想确认 5 天/周到岗能否从 2027 年春季开始。」
- **跟进与备用路径**：投后一周跟进；若 5 天/周 卡死，问能否先兼职 3 天过渡；同时把运控能力当作「底座」——即使这家不成，对 RIMBOT 运控线、成电福智都有用。

## 七、风险与核实项

- **研0 学籍**：「2027 年及以后毕业的本科/硕士/博士」是否包含 2027 年入学的研究生（本科 2027 届毕业），需 HR 书面确认；这是本条最大的不确定点。
- **出勤/时长**：5 天/周是硬门槛，且未写最短月数，需问。
- **信息时效**：截止 2027-09-11 看似宽松，但信息来源为高校实习聚合站，**岗位可能早已招满**；投前必须去公司官方渠道复核。
- **其他**：JD 未写薪资；未写是否提供住宿/通勤补贴（上海 5 天/周到岗成本不低）；公司规模与产品**未核实**。
