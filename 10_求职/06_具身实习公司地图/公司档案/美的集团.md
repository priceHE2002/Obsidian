## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

美的以家电为主业（公开常识，JD 未提）；本切片显示其在上海持续招「具身智能」「机器人操作」「人形全身运控」「3D 场景理解」「VLA/WAM 数据配方」实习生，说明存在一个跨操作/运控/感知的具身智能研究或预研团队（**推断**，团队规模、汇报线、是否独立研究院均**未核实**）。JD 同时出现「真机部署」「人形机器人全身动态运控」「VLA/WAM 微调评测」，不像纯算法预研，更像有真机与数据链路的工程型研究团队（推断）。

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**（13 条内计数）：Python 13/13；PyTorch 12/13；VLA 9/13；RL 8/13；VLM 5/13；IL 4/13；Isaac Sim 4/13；C++ 3/13；Isaac Lab 3/13；PPO/SAC 3/13；ROS2 2/13；其余 MuJoCo、World Model、Evaluation、Dexterous Hand、Reward Model、Transformer 各 1–2 次。原文措辞：J068「Python/C++；了解IL/RL/自监督」；J071「Python/C++、PyTorch、PPO/SAC或OpenVLA/π」；J072「IsaacSim/IsaacLab/MuJoCo」。
- **学历与学籍倾向**：明显偏硕博——硕士在读 4 条、硕/博在读 2 条，只有 J068 写「本科或研究生在读」。J069 正文写「硕士或博士在读」，但列表页写「本科」，属**自相矛盾**，需按正文理解（推断）。研0 全部没有正面措辞，7 条是「需确认研0 可否按硕士在读投递」，5 条「学历门槛待咨询」——即**没有任何一条 JD 确认接受研0**。
- **出勤/时长硬门槛**：偏硬。J068「5天/周、6个月」；J071「≥6个月」；J073/J094/J095「4天/周」；J069/J074「4 个月 + 4/5 天」。即或 4 天/周×4 个月起步，或 6 个月长实习，**没有 2–3 天/周的柔性选项**。
- **职责重心**：偏研究 + 真机落地混合。研究侧措辞：「研究机器人预训练的数据配方/筛选策略」「复现主流多模态策略」「复现RL论文、分析Sim2Real gap」；工程侧措辞：「协助真机部署」「参与技术文档、算法评估与实验复盘」。不是纯调参岗，JD 里「复现」「实验复盘」「评测」出现频率高，说明团队按论文/实验节奏推进（推断）。
- **隐性偏好与关键词**：「复现」（J071、J072）、「真机」（J070、J072、J073）、「评测/实验」（J068、J070、J074）、「VLA/WAM」（J070）、「从数据到部署」的链路感（J069、J100）。对「能独立把一篇论文跑成可对比实验」的人更友好（推断）。
- **与同类公司的差异**：这是本切片里岗位面最宽的一家（操作/运控/感知/数据/Agent 全覆盖），但学历与出勤两条同时偏硬，且 13 条里 7 条已过截止或下线——**岗位多≠机会多**。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：方向对得上第一优先（VLA/操作 9 条、IL 4 条），我原本就想做「灵巧手 + 操作策略」；上海本地，能线下面试、短期到岗；数学与 DL 基础在补，读论文/写实验笔记的习惯已经在跑。
- **短板与缺口**（直说）：
  1. **身份**：研0 不是「硕士在读」，没有学生证/学籍在读证明，13 条里 0 条明确接受研0，7 条要「确认」，实际大概率被 HR 系统按学历筛掉。
  2. **技能深度**：PyTorch 只是「能读代码、跑通小实验」，离 JD 要的「模型训练与评测能力」（J070）、「复现主流多模态策略」（J071）差一个数量级；C++、Isaac Sim/Lab、MuJoCo、ROS2 全部为零或接近零。
  3. **出勤**：J068 要 5 天/周×6 个月，我 2026-11 至 2027-08 前期每周 ≤3h，**硬冲突**；4 天/周的岗位（J073/J094/J095）也同样做不到。
  4. **背书**：无实习、无论文、无 GitHub 可展示仓库，简历在「项目经历」一栏是空的。
- **证据缺口**：没有任何一个「我训过、我评过、我有曲线」的东西；也没有一页能解释「研0 是什么、什么时候能全职」的说明材料。
- **1–3 周内可补的最小动作**：① 把 P1 推到「能演示」——MuJoCo 里跑通一个抓取/推物任务，固定 3 个 seed，出成功率表 + 1 张学习曲线；② 写 1 页《研0 学籍与可投入时间说明》（含 2027 入学、可全职时间段），投递时随简历附上；③ 精读 J071 提到的 OpenVLA/π 之一，写 1 页结构笔记（不改代码也算证据）。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`MuJoCo 抓取 PPO 复现（成功率 x/10，3 seed）`、`ACT/Diffusion Policy 复现（P2）`、`OpenVLA 推理跑通`、`Python/PyTorch`、`IL/RL`、`实验复盘`。不要写没做过的 C++/ROS2。
2. **面试可能被问的 3 个问题及答题要点**：
   - 「IL 和 RL 在操作任务上怎么选？」要点：IL 数据效率高但有分布偏移/复合误差，需 DAgger 类纠正；RL 能超人类但奖励设计与仿真成本高；真机上常见「IL 打底 + 少量 RL 微调」，并说明我会先做哪个 baseline。
   - 「怎么评估一个 VLA/操作策略？」要点：固定场景集与 seed、成功率 + 泛化（换物体/光照/位姿）+ 长程完成率；必须有 baseline 与消融，不能只报单次 demo。
   - 「Sim2Real gap 从哪来？」要点：视觉（纹理/光照/相机内参）、动力学（摩擦/质量/延迟）、接触与传感噪声；对应手段是域随机化、系统辨识、真实数据微调。
3. **可产出的作品/证据**：一个公开 repo（哪怕 200 行）+ README 写清「任务/指标/结果/失败分析」；一篇 1 页复现笔记发在 vault 并同步到 GitHub Pages 或知乎（可选）。
4. **软性动作**：先在实习僧/得早网收藏 J068、J071、J073 并设提醒（复核是否还开着）；给团队发一封 150 字邮件，主题写「研0｜MuJoCo 抓取复现 + 可全职时间」，附 repo 链接；在具身智能社群（如 LeRobot/OpenPI 中文群）里找人内推，比海投有效。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：不要现在投。等 ① P1 有可演示结果（预计 3–4 周）且 ② 能承诺 ≥4 天/周 的时间窗明确后，再单点投 J068；J071/J073 作为第二梯队同批投。
- **简历突出**：`MuJoCo/Isaac 仿真复现`、`VLA/IL 实验评测`、`可全职时间窗明确`。
- **开场话术**：「您好，我是同济 2027 级研0 小何，方向 VLA/机器人操作。已在 MuJoCo 复现 PPO 抓取（3 seed，成功率 x/10），附 repo 与 1 页实验笔记。想确认贵司具身智能实习生是否接受研0 按本科身份投递，以及 2027 年上半年能否以 4 天/周到岗。」
- **跟进与备用路径**：5 个工作日无回复则换渠道（得早网原页/猎聘同名岗）；若学历硬卡，转投同切片中「本科可 + 低出勤」的公司（FMC³、智柔操作），把美的留到入学后再投（届时身份变成硕士在读，胜率显著上升）。

## 七、风险与核实项

- **研0 学籍**：13 条无一明确接受研0；J068 写「本科或研究生在读」，需电话确认「研0 是否可按本科在读处理」；J069 学历正文与列表矛盾，必须问清。
- **出勤/时长**：J068 的 5 天/周×6 个月与我前期 ≤3h/周 直接冲突；J071「≥6 个月」也长。需确认是否接受「先 3 天/周、暑假转全职」。
- **信息时效**：6 条标注「期限未过·需复核」，3 条已过截止、4 条明确下线；本档写的截止日（如 J068 2027-01-14）可能已被平台刷新，投前必须点开原链接确认。
- **其他**：J069 与得早网 281303 为同一广告（已去重），J073 与该公司其他操作岗职责可能重叠——同一团队多岗位重复发布，投递时避免同一简历投 3 个高度相似岗。

## 八、结论（档位建议：冲刺 / 匹配 / 保底-观察 + 一句话理由）

**冲刺**——方向最全、平台最正规，但「硕士在读 + 4–5 天/周 + 6 个月」三重门槛叠加，研0 现在只能靠 J068 单点突破，等 P1 有结果 + 出勤窗口明确后再打。
