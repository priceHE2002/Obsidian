## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

从岗位名（「**人形机器人**算法实习生」「**足式**强化学习控制算法」「机器人运动规划」）与职责看，这是一家**做足式/人形机器人本体与运控算法**的公司：JD 里反复出现步态规划、实时姿态控制、复杂地形导航、多自由度机械臂轨迹优化、以及「在机器人上部署调优」的感知岗（J181），说明**自家有机器人整机并在做真机部署**。技术栈集中在 MuJoCo / Isaac Gym / Isaac Lab / ROS，属于典型 sim2real 路线。

公司人数、融资、产品型号、客户：**未核实**（JD 未提及）。是否已有量产整机：**推断**为在研阶段，无直接证据。

  1. **J180 目前 5 项里 0 项达标**：RL 没真训过收敛、足式原理没学过、无科研/竞赛、仿真没系统用过、ROS 没碰过。计分制下这是"0/5"，不是"差一点"。

  - 补 ROS2 基础：跑通 talker/listener + 一个 launch 文件（2 小时量级），简历可写"ROS2 基础"。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目 / 关键词**：
   - 「Isaac Lab 复现 ×× locomotion 任务，训练 x 步收敛，记录 sim2real 参数敏感性」——关键词：`Isaac Lab`、`sim2real`、`locomotion`。
   - 「MuJoCo 手写 PD 站立控制器，关节跟踪误差 x rad」——证明懂控制而不只是调库。
   - 关键词排序：`Isaac Lab / MuJoCo` > `PPO` > `sim2real` > `ROS2` > `C++`。
2. **面试可能被问的 3 个问题及答题要点**：
   - **Q1「足式机器人为什么普遍用 PPO 而不是 SAC/DDPG？」**
     要点：on-policy 在大规模并行仿真里样本效率劣势被抹平、训练稳定、对 reward 尺度不敏感；配合 Isaac Gym 的万级并行环境，PPO 是最省工程成本的解。
   - **Q2「sim2real gap 主要来自哪，你怎么处理？」**
     要点：① 动力学参数（摩擦、质量、电机延迟/带宽）② 观测噪声与延迟 ③ 地形与接触建模。手段：domain randomization、actuator network、观测历史堆叠、真机 residual 微调。**要点是说出"先测哪些量、再决定随机化什么"**。
   - **Q3「给你一个没写过的机器人（比如 12 自由度四足），你怎么从 0 搭训练环境？」**
     要点：URDF 导入 → 检查惯量与碰撞体 → 定义观测（基座姿态/关节角/速度/命令）→ 动作（PD 目标角）→ reward 分项 → 先训站立再训行走 → curriculum。答"分阶段"比答"调参"得分高。
3. **可产出的作品 / 证据**：一个 Isaac Lab 训练视频 + 一张 reward 曲线 + 一页参数表；若有条件，做一个"同一策略在 MuJoCo 与 Isaac 上成功率对比"的小实验——**跨仿真器一致性**是这家会眼前一亮的东西（推断）。
4. **软性动作**：官网直接投（无内推线索，**未核实**）；在 GitHub 上找矩阵超智公开仓库（若有）提 issue/PR；关注其技术博客/公众号是否有工程分享（**未核实是否存在**）。
