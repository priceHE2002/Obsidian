- **学历与学籍倾向**：**硕士及以上**（硬线），本切片三条硬硕士之一（另两条 Sharpa J114、合碳 J200）。研0 处在「已录取未入学」的灰色地带，是最大不确定项。
- **出勤/时长硬门槛**：未明确——但校招镜像站的岗位通常按「实习 + 转正」设计，需问清最短周期。
- **职责重心**：研究 + 真机（灵巧操作是全切片研究味最重的方向）。原文的动词是「研究」「训练」「闭环」，不是「部署」「调试」。
- **隐性偏好与关键词**：多指、手内操作（in-hand manipulation）、柔性物体、工具使用、触觉、多任务数据闭环、「至少一项」仿真器。「**至少一项**」是唯一的进入口子——不必全会。
- **与同类公司的差异**：技术栈最全、门槛最高（硕士 + 六类算法 + 两个仿真器）；也是唯一明确写「触觉优先」的岗位。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：方向是你第一优先级里的第一（灵巧操作），与 DexWeaver 构想同源；「Isaac/MuJoCo 至少一项」给了用 P0/P1 成果切进去的可能；ACT/Diffusion Policy 正是你 P2 要做的对照实验。
- **短板与缺口**：① **硕士及以上硬线**，研0 被卡的概率最高；② 要求覆盖 PPO/SAC/BC/ACT/DP/VLA 六类，你目前只有「能读代码、跑通小实验」；③ 手内操作与触觉强依赖真机与硬件，你无真机；④ 无实习无论文；⑤ 岗位挂在蚂蚁校招镜像站，需确认是否对应当前可投批次。
- **1–3 周内可补的最小动作**：不追全栈，只做「一个能讲深的点」——在 MuJoCo 里用 SAC 或 PPO 训一个简化灵巧手任务（如 ShadowHand 的 cube rotate / reach），只报一个指标（成功率），并写清为什么选这个算法、失败模式是什么。这正是「至少一项」的最小证据。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：Isaac Sim / MuJoCo、PPO/SAC、模仿学习、Diffusion Policy、灵巧手、Sim2Real。**至少让其中 3 个出现在项目描述里，而不只是技能栏。**
2. **可能被问的 3 个问题及答题要点**：
   - Q：手内操作（in-hand manipulation）为什么难？→ 答：接触丰富且欠驱动、触觉信息缺失、奖励稀疏、接触参数对 sim2real 极敏感、状态估计困难。
   - Q：BC 与 RL 在灵巧手上怎么取舍？→ 答：示教数据成本高但稳定；RL 需要高保真仿真与大量样本；折中是先用 BC/ACT 初始化再用 RL 微调（或 DP 做多模态动作）。
   - Q：你怎么把 MuJoCo 的策略搬到真机？→ 答：域随机化 → 系统辨识（摩擦/延迟/质量）→ 动作平滑与安全限幅 → 分阶段放开（先空载、再轻物体）。
3. **可产出的作品/证据**：ShadowHand cube rotate 的 MuJoCo 训练视频 + 成功率曲线 + 1 页失败分析。
4. **软性动作**：先确认校招批次；若校招通道不适用，找研究实习/RA 通道；关注灵波与蚂蚁具身的公开论文，就其中一篇提一个具体问题。
