## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：VLA 3/4、PyTorch 2/4（J060/J123）、IL 2/4（J060/J121）、3D Vision / Perception 各 2/4。技术栈的**信息密度极不均衡**：J121 一条就把 ACT、Diffusion Policy、OpenVLA、π0、Isaac Sim、Isaac Lab、MuJoCo、Sim2Real 全列了，而 J122 只有「VLA」一个词。原文措辞：「做机器人上肢接触操作RL、ACT/DP/OpenVLA/π0策略的后训练和泛化」（J121）、「参与6D感知/抓取、多模态模型在真机上的验证」（J060）、「针对机器人视觉和具身场景完成深度学习算法开发、优化、部署与工程调试」（J123）。
- **学历与学籍倾向**：4 条全部「未明确」，一条都没写本科/硕士。这有两种可能：① 真不卡学历，看项目；② 卡但不愿写出来（推断）。**必须靠沟通确认**，不能假设宽松。切片对 J122 的备注很克制：「具体学历、算法栈与每周时长待HR确认」——说明信息确实缺失，不是没摘到。
- **出勤 / 时长硬门槛**：4 条全「未明确」。这在家实习招聘里通常意味着**面谈时按候选人情况定**，对用户反而是利好（可以谈 3 天/周或先远程）。
- **职责重心**：**偏工程落地 + 真机**。J121 的「后训练和泛化」、J060 的「真机上的验证」「模型部署」、J123 的「部署与工程调试」，都是产品化语言；没有出现「论文」「发表」「科研输出」。这意味着面试会问「你跑通过什么、调过什么、跑多快」，而不是「你读过哪篇」。
- **隐性偏好与关键词**：「真机」「部署」「泛化」「后训练」「6D 抓取」「上肢接触操作」「工程调试」。另外 J121 点名 π0 / OpenVLA，说明他们**真的在用开源 VLA 基座做后训练**，这是用户 P3 计划的直接对口点。
- **与同类公司的差异**：切片里**唯一把「ACT/DP/OpenVLA/π0 后训练」写进 JD 的公司**，技术路线最接近用户 P2→P3 的学习路径；但也是信息最不透明的一家（学历、出勤、HC 全不明），投递前必须问人。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：J121 的技能清单（ACT / DP / OpenVLA / π0 / Isaac Sim / MuJoCo / Sim2Real）**几乎是用户 P2+P3 的原文**，方向不需要任何解释就能对上；「真机验证」的偏好也匹配用户「先仿真后真机」的路线；出勤未写死，给了研0 谈条件的空间。
- **短板与缺口（直说）**：
  1. **没有任何一条策略跑通过**。J121 要的是「后训练和泛化」，用户目前连 ACT 的 train loop 都还没独立跑完（P0/P1 阶段）。
  2. **无真机经验**。JD 反复说「真机上的验证」，用户没碰过真实机械臂。
  3. **无 PyTorch 工程深度**。「能读代码、跑通小实验」距离「改 loss、调 dataloader、压推理延迟」还有明显差距。
  4. **信息不透明带来的隐性风险**：4 条都不写学历，如果实际卡硕士，研0 会在 HR 环节被刷；不先问就投，等于赌。
- **1–3 周内可补的最小动作**：在 MuJoCo 或 ManiSkill 里跑通 **ACT 或 Diffusion Policy 的开源实现**（推荐 LeRobot 的 ACT + PushT），产出「训练曲线 + 成功率 + 3 个失败 case 分析」一页纸。这一步同时命中 J121 的 ACT/DP 和 J060 的操作策略，是性价比最高的补丁。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`ACT`、`Diffusion Policy`、`OpenVLA / π0 微调`、`Isaac Lab`、`MuJoCo`、`Sim2Real`、`真机部署`。项目写法用「策略 → 数据 → 指标」：例如「在 PushT 上复现 ACT，成功率 x%→y%，推理 12Hz」。
2. **面试可能被问的 3 个问题，及答题要点**：
   - **Q1：ACT 的后训练（post-training）你会怎么做？** 要点：先分清「从零训」和「在预训练基座上微调」；后训练的关键是数据配比（自有真机数据 vs 开源数据）、action space 对齐、冻结/解冻策略、以及灾难性遗忘的监控；能说出你实际用过的 lr、batch、chunk size。
   - **Q2：π0 和 OpenVLA 的差异？为什么一个用 flow matching 一个用离散 token？** 要点：π0 走 flow matching 连续动作、推理需多步积分但动作平滑；OpenVLA 把动作离散成 token、可直接复用 LLM 解码但精度受 quantize 限制。要能说清推理频率与精度的 trade-off。
   - **Q3：真机上策略抖/失败，你怎么排查？** 要点：先分清是感知（标定、遮挡、光照）还是策略（分布外、chunk 边界）还是执行（延迟、PID、关节限位）；用固定初始位姿 + 重复 N 次统计成功率，而不是看单次视频。
3. **可产出的作品/证据**：① ACT/DP 复现 repo（含 config、曲线、失败分析）；② 一段 30–60 秒真机或仿真视频；③ 一页「π0 / OpenVLA 技术对比」笔记（证明读得懂论文）。
4. **软性动作**：先在官网/公众号找 HR 或工程师问清「研0 是否可投、每周最少几天、能否远程」；同时给 OpenVLA 或 LeRobot 提 1 个小 PR（doc/配置修复），让对方在简历之外看到你的名字。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**先问后投**。信息问清（学历口径、每周天数、是否接受研0）再投 J060/J121；J122 信息太少，先不投。理想投递点是 P1 完成、有 ACT 复现证据之后（约 3–4 周）。
- **简历突出**：① ACT/DP 复现闭环；② π0/OpenVLA 微调（P3 后替换）；③ 真机/仿真 Sim2Real 调参。
- **开场话术**：「您好，我是同济 2027 级研0（现本科身份），在复现 ACT/Diffusion Policy 并做 MuJoCo Sim2Real 小实验，看到贵司 J121「强化学习/操作策略后训练」岗，想确认是否接受研0 以及每周最少到岗天数？附复现笔记链接。」
- **跟进与备用路径**：3 天无回复换渠道（脉脉/领英找工程师）；若学历卡死，退而问「是否有 RA / 开源共建」的参与方式，先建立关系等 2027 年入学。

## 七、风险与核实项

- **研0 学籍**：4 条全部未写学历，**必须书面确认**；不要用「应该不卡」做决策。
- **出勤/时长**：全部未明确；需问清每周最少天数、是否接受「先远程后线下」、最短实习期。
- **信息时效**：3 条标注「官网列表待确认」，J122 的要求「过于概括」；HC 是否真实开放需问。
- **其他**：薪酬全未公开；4 条共用同一页面，无法判断是否为同一 HC 的多个标题；J123 的「PyTorch/三维方向」是切片推断的技术关联，非 JD 原文要求。

## 八、结论（档位建议：冲刺 / 匹配 / 保底-观察 + 一句话理由）

**冲刺**——J121 的「ACT/DP/OpenVLA/π0 后训练 + Isaac/MuJoCo + Sim2Real」几乎是用户 P2/P3 路线的原文，方向匹配度全切片最高，但学历与出勤全部未写、且用户尚无一条策略跑通的证据，属于「方向对、证据缺」的高价值试探。
