## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：Python ~13/14（几乎每条）、PyTorch 8/14、RL 7/14、World Model 6/14、VLA 5/14、C++ 4/14、PPO/GRPO 3/14、Isaac Sim/Lab 3/14、IL 3/14、Agent 3/14、Dexterous Hand 2/14。原文措辞：「研究Real2Sim2Real与具身场景生成；探索液体/柔体/触觉仿真」（J001）、「复现并改进操作基座模型、训练策略；开展真机/仿真评测」（J002）、「Isaac Sim/Lab等仿真、PPO/GRPO」（J001）。
- **学历与学籍倾向**：只有 3 条写了明确学历——J001「本科以上、研究生优先」、J002「在读本科或研究生」、J003「硕士及以上在读」；其余 11 条写「未明确」。这是个**看起来宽松、实际按硕士在读筛**的分布：写得越模糊，越可能在初筛时用学校/在读层次过滤。研0 措辞上，J002 的可靠性备注明确写「研0优先考虑」，是全部 14 条里对研0 最友好的一条。
- **出勤 / 时长硬门槛**：J001「≥6个月且每周线下≥4天」、J002「线下≥6个月」——两条 A 级岗都把**线下 + 半年**写死，且不给远程口径。其余 12 条未写，不等于宽松，只是没写。
- **职责重心**：明显**偏研究 + 偏平台建设**，不是纯业务落地。A/B 级岗的动词是「研究」「复现」「探索」「评测」「建设基准」；C 级岗里 J007/J008/J009/J013 是实打实的平台/工具链工程。整体看：**研究岗要论文级品味，平台岗要工程底子**，用户目前两头都还没立住。
- **隐性偏好与关键词**：「复现」（J002 直接写 LeRobot/OpenPI/StarVLA）、「真机/仿真评测」、「数据建设」、「Real2Sim2Real」、「物理一致性」。这些词指向一种能力画像：**能独立把一个开源策略在仿真里跑通、并说清失败原因**，而不是只会调库。
- **与同类公司的差异**：切片里唯一同时在「基座模型 + 世界模型 + 仿真平台 + 大模型后训练」四条线上招人的机构，岗位梯度最全；但也因此**最不缺候选人**，14 条里有 11 条不写学历，说明筛选权在 HR/课题组手里，投递前的沟通成本高。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **短板与缺口（直说）**：
  1. **出勤直接冲突**。J001 要「≥6 个月 + 每周线下 ≥4 天」，用户 2026-11–2027-08 前期每周 ≤3h（有考试/学业节点），这条在 2027 年春季前基本无法满足；J002 只写「线下 ≥6 个月」，同样要连续在岗。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`Python / PyTorch`、`LeRobot`、`ACT / Diffusion Policy`、`Isaac Lab`、`PPO`、`Sim2Real`、`VLA 微调`，外加一个 GitHub 链接。项目描述写成「复现 X → 指标 Y → 失败归因 Z」的三段式，不要写「了解/熟悉」。
2. **面试可能被问的 3 个问题，及答题要点**：
   - **Q1：ACT 和 Diffusion Policy 的区别？你为什么选 ACT？** 要点：ACT 用 CVAE + Transformer 一次回归一个 action chunk，推理快、适合高频控制，但对多峰分布表达弱；DP 用扩散去噪建模多模态，表达强但推理慢、要降采样/蒸馏。要能说出 chunk size、控制频率、以及你在 PushT 上实测的成功率差。
   - **Q2：Sim2Real gap 你怎么定位和缩小？** 要点：分三层 ablate——观测（相机噪声/光照/标定）、动力学（摩擦/质量/延迟/关节阻尼）、控制（频率、滤波、通信延迟）；先 domain randomization，再 system identification；举一个你实际调过的参数和它带来的成功率变化。
   - **Q3：PPO 用在机器人操作上最大的问题是什么？** 要点：稀疏奖励 + 样本效率低 + 探索困难；解法是 reward shaping、demo 初始化（RLPD/offline-to-online）、大规模并行 env、以及课程学习。要能说清 on-policy 为什么在真机上昂贵。
3. **可产出的作品/证据**：① 1 页 ACT 复现笔记（PDF 或 Obsidian 发布页）；② 一个公开 repo，README 带复现步骤 + 结果表 + 失败案例；③ 3 分钟录屏（仿真里机械臂完成任务）。三样齐了再投 J002。
4. **软性动作**：投递前先在官网/公众号找课题组联系人，问一句「研0（已录取未入学）能否按本科在读身份走实习流程」；同时在 LeRobot 或 OpenPI 提 1 个 doc typo / 小 bug 的 PR，作为「能读源码」的第三方证据。
