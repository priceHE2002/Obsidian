- **研究 + 复现为主**：大量「复现」「研究」「分析泛化鲁棒性」「设计奖励、复现实验」，不是纯调参。

### 隐性偏好与关键词
- 「复现」出现频率极高（OpenVLA、π0、Diffusion Policy、SERL、ACT、RT-1/2）→ 团队默认新人先能复现别人的东西。
- 「真机」「接触丰富（contact-rich）」「sim2real 系统调试」→ 看重手上有没有真东西，而不只是课程项目。
- 「泛化鲁棒性」「bad cases」「实验闭环」「归因」→ 要的是能做实验设计和误差分析的人。
- 「从 0 到 1」「跨团队」在切片中未出现，不要往简历里硬套这套词。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`MuJoCo`、`PPO/SAC`、`ACT`、`Diffusion Policy`、`OpenVLA`、`SFT/LoRA`、`sim2real`、`成功率/泛化评测`。每个词后面必须挂一个你能讲 5 分钟的项目，宁少勿虚。
2. **可能被问的 3 个问题及答题要点**
   - Q1「你复现过 π0 吗？说一下它的 action expert 怎么接 VLM 的。」
     要点：先承认只复现到 DP/ACT 层级，再讲清 VLA 的三段式（视觉语言主干 → 动作头/action expert → 流匹配或 diffusion 解码），最后落到「我下一步打算在 LeRobot 上跑 π0 的推理」。**不会就说不会，但要展示你知道路线图**。
   - Q2「真机上一旦策略失败，你怎么定位是感知、数据还是策略的问题？」
     要点：分三层——先看输入观测是否漂移（相机/标定）、再看数据分布是否覆盖该工况、最后看策略在仿真同分布的失败率。举你 P1 里的具体例子。
   - Q3「给你一个操作任务，怎么设计评测？」
     要点：成功率 × 泛化维度（位姿/光照/物体实例）× 鲁棒性（扰动、遮挡），加上失败模式分类（抓空/滑落/碰撞）。这条直对 J024 的「成功率/鲁棒性评测与试验数据归因」，即使投 A 级岗也用得上。
3. **可产出的作品/证据**：一个 GitHub repo（README 写清复现来源、改动点、指标对比）+ 一页 PDF 笔记 + 30 秒真机/仿真视频。三件套齐全，研0 身份就不是问题。
4. **软性动作**：官网投递后，在飞书招聘页找到该岗位 HR/团队，用一封 150 字邮件附 repo 链接；同时在 GitHub 上给 LeRobot/OpenVLA 提 1 个 documentation 或 reproducibility 的小 PR——这是最容易做出、又最容易被看见的证据。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：现在不要投 A 级两岗，先花 3–4 周做完 P1+P2；等出勤条件允许（2027 年初起可 4–5 天/周）再投 J015。**唯一现在就该动的是 J024（评测）和 J028/J031（数据/工具链）**——这三类不要求你先有模型，且能让你进到内部再转岗。
- **简历突出**：`复现`、`MuJoCo 真机对齐`、`评测口径`。
- **开场话术**：「你好，我是同济 2027 级研0（已录取，可按本科在读身份实习），目前在按 P1→P2 路线做 MuJoCo 抓取复现与 ACT/DP 对照，repo 在 X。看到贵司 J015 要求复现 OpenVLA/π0，我已完成前置的 DP 部分，想问是否接受研0 按本科身份进入流程？」

## 七、风险与核实项

- **研0 学籍**：J015 写「优秀本科生可」但未定义「优秀」；J021 明写硕博。需确认：研0 能否以「本科已毕业、硕士已录取」身份走实习流程、能否签实习协议、是否需要学信网在读证明（研0 期间可能开不出）。
- **出勤/时长**：J018/J034 的「≥6个月」与 J032 的「5天/周」需要明确起算时间；若团队只接受「连续 6 个月全职」，你 2027-08 入学前只有约 9 个月窗口，且前期无法满足。
- **信息时效**：25 条全部标注「岗位页可见·需复核」，且均无截止日期 → 极可能存在挂了很久的僵尸岗，投前必须逐个点开确认。
- **其他**：J030 切片备注「可能与牛客另一个强化学习运控广告重复」；J033 与官网同方向岗位可能重复 HC。投递前按「官网 > 牛客」优先级择一，避免同一团队收到两份简历。
