## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

从 12 条 JD 看，NVIDIA 上海团队围绕 **Isaac 生态**（Isaac Lab / Isaac Gym 仿真与策略训练平台）、**人形机器人学习**（loco-manipulation、GR00T、Cosmos 世界模型）和 **VLA / RL 后训练**招实习生：既有研究岗（Applied Research、Humanoid Robot Learning），也有平台基建岗（Robot Learning Platform、Cosmos Lab、Multi-Agent Systems）。岗位用 Workday 官方 JR 号，2026 与 2027 批次并存，说明是滚动项目制实习。团队人数、汇报线与转正机制**未核实**。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：方向完全命中用户目标前三（VLA、真机 RL、世界模型都在招）；「实验复现能力」（J174）正是 P1–P2 在做的事；已有 DexWeaver / FrontierGuard-RL 两个研究构想，可作为「研究方向想清楚了」的谈资。
- **短板与缺口（直说）**：
  1. **学籍**——10/12 要求硕士/博士在读，研0 未入学，按字面不符合；若被卡，等于 90% 岗位直接关门。
  2. **Isaac 零实操**——6/12 点名 Isaac Lab，用户连 MuJoCo 都还在 P0。
  3. **GPU/CUDA 工程**——J166/J171 需要并行与性能优化，用户无相关经验。
  4. **无产出**——无论文、无开源 PR，J167 的加分项全空。
  5. **无 sim2real 闭环**——J170/J173 要「仿真训练→真机验证」，作品集停在 P0/P1 无法举证。
- **1–3 周内可补的最小动作**：① 用 MuJoCo 跑通一个 reach/lift 任务并记录曲线（不硬上 Isaac，先证明能跑通）；② 若机器支持，装 Isaac Lab 跑官方 lift-cube 示例，写 1 页「环境搭建 + 踩坑 + 指标」笔记；③ 把上述过程整理成公开 repo，README 写清复现步骤。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：Isaac Lab（入门级即可）、MuJoCo、PyTorch、PPO/SAC、sim2real、VLA 复现（OpenVLA / ACT / Diffusion Policy 任一）。写成「复现了 X，成功率 Y%，训练 Z 小时」比「熟悉」有用。
2. **3 个可能面试题及答题要点**：
   - 「讲一个你做的 RL 训练实验，reward 怎么设计？」→ 说清环境、观测/动作空间、reward 每一项的动机、训练曲线、失败模式（不收敛、reward hacking），并坦白规模小。
   - 「Isaac Lab 和 MuJoCo 什么区别，什么时候用哪个？」→ GPU 并行 / 大规模 PPO vs 精确接触 / 轻量快速迭代；Isaac 依赖 Omniverse 与显卡，MuJoCo 适合验证算法。
   - 「sim2real gap 你怎么处理？」→ 域随机化（质量、摩擦、执行器延迟、观测噪声）、系统辨识、执行器建模、真机少量微调；承认没上过真机，但讲清读过的方案。
3. **可产出的作品/证据**：一个公开 repo（仿真 + 曲线图 + README）；一页「Isaac Lab 搭建踩坑记录」；一份 1 页研究构想（DexWeaver）说明数据与评测设计。
4. **软性动作**：先发邮件/LinkedIn 问「2027 级拟录取（研0）能否按本科身份投 Intern」，拿到口径再投；关注 Isaac 相关公开课/hackathon；给 Isaac Lab 提 documentation 级别的小 PR（真做，不求大）。

## 八、结论（档位建议：冲刺 / 匹配 / 保底-观察 + 一句话理由）

**冲刺**——方向最对口、平台最值钱，但「硕士/博士在读 + Isaac/GPU 工程 + 有产出」三重门槛对研0 现阶段过高，适合当高价值练兵目标而非主投。
