## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① PPO + Isaac Gym 是 P1 阶段就能覆盖的内容，学习路径清晰、资料多（legged_gym、rsl_rl 都有开源）；② 方向属用户第二优先（真机 RL）的底座分支，不算偏离；③ 只要 Python/PyTorch，不要求 C++（这条 JD 里没有）。
- **短板与缺口（直说）**：
  1. **岗位已下线**，没有投递入口。
  2. 无 Isaac Gym 使用经验（用户连 MuJoCo 都在 P0）；Isaac Gym 对显卡有要求，本地环境可能跑不动。
  3. 无 legged locomotion 背景知识（观测设计、reward 项、地形课程学习），临时补要 2–3 周。
  4. 无真机，而 CAERI 这类机构大概率有实物平台，面试会问「上过真机吗」（**推断**）。
  5. 汽研院具身团队的规模与投入程度未知，可能只是探索性项目。
- **1–3 周内可补的最小动作**：跑通 legged_gym（或 MuJoCo 版）里 Ant/Humanoid 的 PPO 训练，记录 episode return 曲线与训练步数；若显存不够，降到小网络与并行环境数。这件事**同时服务于 NVIDIA J170/J173 的准备**，一举两得。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：PPO、Isaac Gym / legged_gym、locomotion、reward 设计、课程学习、episode return 曲线。
2. **3 个可能面试题及答题要点**：
   - 「PPO 的 clip 与 GAE 分别解决什么问题？」→ clip 限制更新步长防策略崩溃；GAE 用 λ 折中偏差与方差，估计 advantage。
   - 「locomotion 的 reward 一般怎么设计？」→ 速度跟踪 + 存活 + 姿态/高度惩罚 + 动作平滑/能耗惩罚；讲清「奖励权重一变行为就变」，需要 curriculum。
   - 「并行环境怎么加速训练？」→ Isaac Gym 在 GPU 上并行数千环境，向量化观测/动作；瓶颈常在 CPU-GPU 拷贝与 Python 开销。
3. **可产出的作品/证据**：一张训练曲线图 + 一段策略行走/站立视频 + 一页「reward 项与权重实验记录」；这套材料对任何 RL 运控岗都通用。
4. **软性动作**：岗位已关，**不必内推**；把它当作「Legged Gym 学习目标」写进 P1 清单，等 CAERI 或同类机构重开时（2027 春招）再投。
