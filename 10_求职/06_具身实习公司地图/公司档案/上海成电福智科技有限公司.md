## 一、公司是谁 / 做什么（仅据 JD 可见线索，其余「未核实」）

## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：Python 7/7；C++ 4/7（J158/J159/J160/J161）；ROS 或 ROS2 4/7（J158「ROS/ROS2」、J159「ROS」、J160「ROS/ROS2」、J163「对接ROS2」）；PyTorch/TensorFlow 3/7（J160/J161/J162）；MuJoCo/PyBullet 2/7（J158「用MuJoCo/PyBullet验证并真机调试」、J159「MuJoCo/Isaac Sim仿真」）；MPC/WBC/轨迹优化 3/7（J158 要求「至少一类MPC/阻抗控制/轨迹优化算法」，J159「WBC」，J164「路径规划」）。原文措辞：J158「设计人形/仿生机器人运动学、动力学建模、参数辨识和轨迹规划；研究柔顺/阻抗控制」；J159「参与实体平台移植与抖动、避障问题调试」；J162「在仿真中评估任务成功率、鲁棒性与实时性」。
- **学历与学籍倾向**：无任何「本科可投」表述；岗位直接以「（博士）」「（硕士）」分档，且薪资也随之分档（博士 5000–6000 元/月起，硕士 2500 元/月起）。研0 属「未入学」，两条线都要先问；博士档明确不可及，硕士档理论上可谈。
- **出勤/时长硬门槛**：**7/7 均要求 ≥6 个月**，是全切片里最长的一档；未写每周天数，但从「真机调试、平台移植」的职责看隐含高频到岗（**推断**，未核实）。
- **职责重心**：**偏工程落地与真机调试**，不是纯研究。证据：J159「参与实体平台移植与抖动、避障问题调试」、J161「对接视觉/激光传感器，完成仿真和真机集成测试」、J163「实现多模态任务测试、数据采集、结果分析和可视化」。研究表述多为「研究/研发」，但落点都在平台与真机。
- **隐性偏好与关键词**：临港（地点）、参数辨识、柔顺/阻抗控制、WBC、抖动/避障问题、工业装配、仓储、服务场景、评测指标、SQL（J163 附带要求）。「真机项目优先」出现在 J159，说明有真机经历比有论文更吃香。
- **与同类公司的差异**：本切片唯一按学历分档定价、且把「≥6 个月」写成统一硬门槛的传统机器人公司；研究色彩明显弱于 NVIDIA，工程/调试色彩和学历分层最强。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：① 方向覆盖用户第二、第三优先（运动控制、具身数据与评测），不是纯 VLA 独木桥；② 有明确投递邮箱，绕开投递系统，研0 可以直接写信问；③ J163「大模型评测（硕士）」所需的是实验设计 + Python + 批量测试脚本，门槛相对最低；④ 用户有 RL 与评测的兴趣，和 J162/J163 的「任务成功率、鲁棒性、实时性」指标能对上。
- **短板与缺口（直说）**：
  1. **≥6 个月全职**——2026-11 至 2027-08 用户前期每周 ≤3h，这一条基本一票否决，除非能谈到远程/项目制。
  2. **无 C++ / ROS2 / 真机**——7 条里 4 条要 C++、4 条要 ROS，用户两项都是零。
  3. **运动学动力学 + MPC/WBC 未学**——J158/J159 的数学门槛不低，研0 补不动。
  4. **薪资极低**（硕士档 2500 元/月起），性价比需要重新评估。
  5. **信息时效差**——公告 2026-03-23 刊载，距今约 7.5 个月，是否还在招完全未知。
- **1–3 周内可补的最小动作**：① 在 MuJoCo 里做一个 2 连杆或 6-DoF 机械臂的 IK + PD 位置控制 demo，记录跟踪误差与超调；② 跑通 Pinocchio 的 FK/IK 官方例子，写半页笔记；③ 把两者合成一页「运控入门证据」放进作品集。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：MuJoCo、Pinocchio、IK/FK、PD/阻抗控制、轨迹跟踪误差、Python、ROS2 基础（哪怕只是跑过 pub/sub）。
2. **3 个可能面试题及答题要点**：
   - 「PID 三个参数怎么调，超调和稳态误差怎么权衡？」→ 从 P 引起超调、D 抑制振荡、I 消除稳态误差讲；给一个自己调过的具体曲线；承认只在仿真里调过。
   - 「IK 有解析解和数值解，什么时候用哪个？」→ 解析解快但要特定构型；数值解（雅可比伪逆、阻尼最小二乘）通用但可能落局部极小、需处理奇异位形。
   - 「仿真和真机差在哪？」→ 摩擦/间隙/执行器延迟/传感噪声/柔性；对应做法是参数辨识 + 域随机化 + 真机微调；坦白没上过真机，但读过参数辨识流程。
3. **可产出的作品/证据**：一页「机械臂 IK + PD 跟踪」实验记录（含误差曲线）；一段 20 秒仿真视频；一份把 J158/J159 要求逐条对照的自评表（证明读懂了 JD）。
4. **软性动作**：直接给公告邮箱 `lijiayao@cdfztech.com` 写信，问三件事——是否仍在招、研0 可否按硕士档投、能否接受每周 2–3 天 + 线上；临港通勤成本也要一并问清。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**先发问询信，不投简历**。拿到「还在招 + 研0 可谈 + 出勤可松动」三个答复后再投入准备，否则不值得为 2500 元/月牺牲 6 个月。
- **简历突出**：MuJoCo 仿真、Python、评测/实验设计（对应 J163 更现实）。
- **开场话术**：「您好，看到贵司 3 月发布的人形机器人/评测实习岗，想确认目前是否仍在招。我是同济 2027 级拟录取研究生（研0），本科阶段做过 MuJoCo 下的机械臂控制仿真，想了解硕士档岗位能否接受拟录取学生、以及每周到岗天数的下限。」
- **跟进与备用路径**：一周未回再发一次，仍无回音即放弃；把该公司当作「真机/运控经验供应商」而非目标雇主，若 2027 年入学后有空档再回头。

- **信息时效**：公告 2026-03-23 刊载，属「历史公告·在招待核」，页面仍在不等于岗位仍在。
