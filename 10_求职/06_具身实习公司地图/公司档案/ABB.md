## 三、JD 要求偏好（重点，要细）

### 高频技能 / 工具
- 技能字段只有四个：`Python`、`C++`、`Control`、`Perception`。
- 原文职责：「机器人编程、实验室自动化与视觉系统调试，支持机器人现场集成」；要求原文：「机器人控制/编程或视觉基础；每周4天、3个月」。
- 注意「**或**」字：控制/编程**或**视觉，二者会一个即可，这是低门槛信号。
- 没有任何深度学习、PyTorch、VLA、RL 字样——**这条 JD 与具身智能算法基本无关**。

### 学历与学籍倾向
- 「未明确」：既没写本科，也没写硕博，也没写「在读」。字面上是本切片里学历最松的一条。
- 未出现「研0」「应届」「在读」等限定词 → 说明筛简历时学历权重低，更看能不能上手干活。
- 风险在于「未明确」也可能是「HR 没填」，实际仍按本科/硕士筛，需电话确认。

### 出勤 / 时长硬门槛
- **3 个月、每周 4 天**，写得很具体，说明是实打实要人驻场。
- 时间窗口：截止 2026-12-09，若 12 月入职，3 个月到 2027 年 3 月——**恰好卡在你「前期 ≤3h/周」的阶段**。
- 地点上海，未提远程。

### 职责重心
- **偏工程落地 / 现场集成**：编程、调试、现场支持，三个词都是动手活。
- 没有「研究」「复现」「论文」类表述，创新空间小。
- 对研0 的正向意义：能第一次见到真实机械臂、真实相机标定、真实通信链路——这是仿真里学不到的。

### 隐性偏好与关键词
- 「**现场**」「**调试**」「**集成**」——要能出差/进实验室、能忍受反复试错的人。
- 「实验室自动化」暗示客户/场景是生物医药或检测类实验室（**推断**，JD 未写）。
- 没提「论文」「开源」「从 0 到 1」，说明不看重学术产出。

### 与同类公司的差异
切片里唯一明写「180–200 元/天」且不要求算法背景的岗位；也是唯一一家纯工业机器人背景、与 VLA 主线几乎不交叉的公司。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**
  - Python 基础 + 「能读代码、跑通小实验」足以覆盖「机器人编程」的入门部分。
  - 学历未明确，研0 有沟通空间；且薪资、时长、截止日都写得清楚，是切片里信息最完整的一条。
  - 你缺的正是「真实设备经验」，这里能给。
- **短板与缺口（直说）**
  - **C++ 空白**：JD 把 C++ 列进技能，而你的 C++ 尚未系统使用；不过原文是「控制/编程或视觉基础」，若走视觉侧可绕开。
  - **无视觉调试经验**：相机标定、手眼标定、光源调试，你一样没做过。
  - **4 天/周**：与你 2026-11 至 2027 年初 ≤3h/周 的现状冲突，只能等 2027 年春季后。
  - **方向偏离**：这条 JD 学不到 VLA/RL，对你想做的第一优先级几乎零加成；做 3 个月的机会成本是 P2/P3 停摆。
  - **无实习经历**：连「进过实验室/进过产线」都没有，面试问「你调过什么设备」会答不上。
- **1–3 周内可补的最小动作**
  1. 用 Python + OpenCV 做一次相机标定（棋盘格），产出标定脚本 + 重投影误差截图——这是本条 JD 最直接的能力证明。
  2. 在 MuJoCo 里写一个最简单的「移动到目标点」的位置控制脚本，理解关节空间/笛卡尔空间的区别。
  3. 读一遍 ROS2 的 topic/service 概念（不必跑通），至少能在面试里说清「上位机怎么和机械臂通信」。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`Python`、`OpenCV 相机标定`、`机械臂运动学`、`视觉调试`、`ROS2 通信`。不要写 VLA/RL——和这条 JD 无关，反而显得不匹配。
2. **可能被问的 3 个问题及答题要点**
   - Q1「相机和机械臂怎么标定？」要点：讲清手眼标定两种装法（eye-in-hand / eye-to-hand）、需要采集哪些位姿、用什么工具（OpenCV calibrateHandEye / easy_handeye），最后承认「我只在仿真和单相机内参上做过，没做过真实手眼」。
   - Q2「机械臂抓偏了 2cm，你怎么查？」要点：分三层——标定误差（重投影/手眼）、通信延迟（指令下发与到位的时间戳）、夹爪/工件公差。给一个排查顺序，别说「调参」。
   - Q3「你写过最有工程感的代码是什么？」要点：拿你 P1 的训练/评测脚本讲模块划分与可复现性，别讲课程作业。
3. **可产出的作品/证据**：一个「相机标定 + 目标检测 + 机械臂抓取点位计算」的最小 demo（仿真里跑即可），配 1 页说明；这比任何算法论文都贴这条 JD。
4. **软性动作**：实习僧投递后，直接在平台上问 HR「是否接受研0 按本科身份、2027 年 3 月起 4 天/周」；这类岗位 HR 回复率通常高于算法岗（**推断**）。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**不着急投**。截止 2026-12-09，但你 12 月入职就要连做 3 个月 4 天/周，与学业冲突。建议 2027 年 2–3 月再谈，或现在先投、明确要求 3 月起始。
- **简历突出**：`Python 工程能力`、`视觉标定`、`动手调试`。
- **开场话术**：「您好，我是同济 2027 级研0（已录取），Python 熟练、做过相机标定与仿真抓取的小项目。看到岗位要求 3 个月每周 4 天，我 2027 年 3 月起可以满足，想确认这个时间点是否还接受投递？」
- **跟进与备用路径**：若被拒，问一句「是否有算法/仿真方向的实习 HC」——工业机器人公司通常也有仿真与算法团队，这是把保底岗转成目标岗的最低成本问法。

## 七、风险与核实项

- **研0 学籍**：学历未明确，但「未明确」不等于「不限」；需确认能否签实习协议、是否需要在校证明。
- **出勤/时长**：3 个月 × 4 天/周 是否可拆成「先远程后驻场」，需谈；截止 12-09 意味着 HC 可能要求 12 月内到岗。
- **信息时效**：截止 2026-12-09，距今约 1 个月，属「未过期但临近」，投前点开链接确认。
- **其他**：薪资 180–200 元/天 在上海属偏低（**判断，非 JD 事实**）；岗位内容与具身智能算法主线偏离，需自问是否愿意用 3 个月换一次工业现场经验。

## 八、结论

**档位：保底-观察。**
理由：门槛是全切片最低的一档（学历未明确、技术栈只有 Python/C++/视觉基础），能给你第一次真实设备经验，但工作内容是集成调试而非算法研究，对 VLA 主线的加成很小——只在一份算法岗都拿不到时启用。
