- **短板与缺口（直说）**

  2. 在 Isaac Sim 里用同样的 URDF/USD 建一次场景，比较两者在相同控制输入下的轨迹差异——这就是「校准」的最小雏形。
  3. 写 1 页《URDF→USD 转换踩坑记录》，这类笔记在仿真岗面试里杀伤力极大。

## 五、如何提升进入概率（具体准备清单）

> 前提：岗位已过期。若该公司重开同类岗（大概率会），按下列准备。

1. **简历上要出现的项目/关键词**：`MuJoCo`、`Isaac Sim`、`URDF/USD`、`sim2real 对齐`、`传感器噪声建模`、`Linux`。项目描述里要出现具体数字（如「关节跟踪误差 < 0.5°」）。
2. **可能被问的 3 个问题及答题要点**
   - Q1「仿真里抓取成功率 90%，真机只有 40%，你怎么查？」要点：按「模型—感知—执行」三层拆：URDF 惯性/摩擦参数是否失真、相机内外参与真实是否一致、控制器延迟与夹爪力控是否有差距。给排查顺序，不要笼统说「domain randomization」。
   - Q2「URDF 转 USD 常出什么问题？」要点：关节轴定义、单位（m vs cm）、mesh 缩放、碰撞体简化、articulation root 设置。
   - Q3「3DGS 重建的场景能直接拿来训练吗？」要点：能用于视觉层的数据增广与 novel view，但物理不可交互；需要与物理仿真结合（把重建当背景、物体仍用刚体）。
3. **可产出的作品/证据**：一个「同一 URDF 在 MuJoCo 与 Isaac 中行为对比」的 repo + 对比视频 + 误差表。这是仿真岗的硬通货。
4. **软性动作**：在 GitHub 上关注 IsaacSim / MuJoCo 的 issue 区，回答 1–2 个 URDF 相关小问题；这类公司的技术负责人常在社区里出现（**推断**）。
