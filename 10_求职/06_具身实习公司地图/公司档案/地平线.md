## 三、JD 要求偏好（重点，要细）

- **高频技能 / 工具**：Python、PyTorch、World Model、VLA、4D Vision、Transformer（6 项，单条 JD 里全列）。原文措辞：「研究具身WAM、Action-Conditioned World Model、UMM与4D基础模型；训练评测及科研输出」「硕士在读；PyTorch、世界模型/多模态与英文论文复现能力」。
- **学历与学籍倾向**：**明确「硕士在读」**，没有本科选项，也没有「优秀本科生可放宽」的措辞。研0 按本科身份投，字面不符。
- **出勤 / 时长硬门槛**：**5 天/周**——全切片里出勤要求最硬的一条（对比：智往未来 4 天、AI Lab 4 天、期智按期）。这基本等于全职实习，与「在校上课/考试」直接冲突。
- **职责重心**：**纯研究**。「研究」「训练评测」「科研输出」三个词决定了日常是读论文、改模型、跑实验、写报告，不涉及部署、数据标注、系统集成。
- **隐性偏好与关键词**：「英文论文复现能力」是这条 JD 最锋利的一句——它要求的不是「读过」，而是**能把一篇英文论文的代码跑出来并对上数字**；「WAM」「UMM」「4D 基础模型」则是圈内黑话，不熟的人连 JD 都读不顺。
- **与同类公司的差异**：切片里**研究纯度最高、门槛最硬**的一条：硕士在读 + 5 天/周 + 英文论文复现，三个条件叠在一起，筛掉的是绝大多数候选人；好处是方向极清晰（世界模型），坏处是没有回旋空间。

## 四、与我的匹配度（强项 / 短板 / 证据缺口）

- **强匹配**：世界模型是用户第三优先级方向，且用户有「FrontierGuard-RL」这类研究方案构想，说明对「世界模型 + RL」的题目有感觉；PyTorch 起步虽浅，但方向不跑偏。
- **短板与缺口（直说）**：
  1. **5 天/周出勤不可行**。用户 2026-11–2027-08 前期每周 ≤3h，5 天/周意味着彻底放弃学业节点，这条是**结构性冲突**，不是努力能补的。
  2. **硕士在读**。研0 字面不符。
  3. **英文论文复现能力为零证据**。用户没有复现过任何一篇世界模型/生成模型论文，连 4D/视频生成的基础都没打。
  4. **无科研输出**。JD 要「科研输出」，用户无论文、无技术报告、无实验记录。
- **1–3 周内可补的最小动作**：不要碰 WAM/UMM 这种大模型级复现（3 周做不完）。最小动作是**复现一篇小规模世界模型论文的核心实验**，例如在 2D 推箱子环境里训一个 action-conditioned latent dynamics model，验证「给定动作预测下一帧」的 loss 能降下来。约 2–3 周，能产出一张曲线 + 一段预测视频。

## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`World Model`、`Action-Conditioned`、`Transformer`、`Diffusion / Flow`、`视频预测`、`PyTorch`。项目描述必须带「复现了 X 论文的 Y 实验，指标差 Z%」。
2. **面试可能被问的 3 个问题，及答题要点**：
   - **Q1：Action-Conditioned World Model 和普通视频生成模型的区别？** 要点：动作是条件输入，模型要学到「动作→状态转移」的因果，而不只是像素分布；评测要看长程 rollout 的一致性，不是单帧 FID。
   - **Q2：世界模型怎么用来做规划/RL？** 要点：在 latent 空间 rollout 候选动作、用学到的 reward/value 打分（model-based planning）；难点是 compounding error 与 model exploitation，需要短 rollout + ensemble 惩罚。
   - **Q3：你怎么判断一篇论文的复现「对上了」？** 要点：先对齐数据与预处理，再对齐指标定义，最后才是超参；给出你容忍的误差范围；如果对不上，要能定位到是数据、实现还是评测口径。
3. **可产出的作品/证据**：一篇 2–3 页的复现报告（方法、实验设置、指标对比表、失败分析）+ 一段预测视频；这比任何课程项目都更接近该岗的语言。
4. **软性动作**：通过官方渠道（官网/公众号）核实该岗是否仍在招，并问「研0 能否按硕士在读投」；同时关注该公司是否有非世界模型的机器人岗（切片未覆盖，需自行查）。

## 六、投递策略（时机 / 简历突出点 / 开场话术 / 跟进）

- **时机**：**不建议现在投**——5 天/周与学业冲突、硕士在读不符、且截止 2027-01-05 意味着这是「当下就要全职到岗」的岗位。若 2027 年春季后能全职，且已有世界模型复现作品，再投。
- **简历突出**：① 英文论文复现（带指标对齐）；② Transformer/Diffusion 实现经验；③ 长程预测/rollout 的实验设计。
- **开场话术**（信息核实版）：「您好，我是同济 2027 级研0（现本科身份），在复现 action-conditioned world model 的小规模实验，想确认 J083 是否接受研0、以及 5 天/周能否协商为 3 天？」

## 八、结论（档位建议：冲刺 / 匹配 / 保底-观察 + 一句话理由）
