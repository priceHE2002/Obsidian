## 五、如何提升进入概率（具体准备清单）

1. **简历上要出现的项目/关键词**：`手部姿态估计（MANO/21 关键点）`、`RGB-D 融合`、`PyTorch`、`推理加速（TensorRT 概念/ONNX 导出）`；C++ 只写「在学」。
2. **面试可能被问的 3 个问题及答题要点**：
   - 「MANO 是什么？怎么从图像得到 MANO 参数？」要点：MANO 是参数化手模型（pose + shape 参数 → 778 顶点网格）；流程是 backbone 提特征 → 回归 MANO 参数 → 前向得网格 → 用 2D/3D 关键点或渲染损失监督。
   - 「RGB/Depth/IMU 怎么融合？」要点：先做时间同步与标定，再早期融合（拼接输入）/中期（特征级）/晚期（决策级）；深度补几何、IMU 补高频运动，遮挡时尤其有用。
   - 「端侧部署怎么把延迟压下来？」要点：模型剪枝/蒸馏、ONNX 导出 + TensorRT FP16/INT8 量化、算子融合、降低输入分辨率、异步流水线；要报「精度-延迟」曲线而不是只说变快。
3. **可产出的作品/证据**：一段手部关键点可视化视频 + 1 页「MANO 参数含义」笔记；若能做到，再加一张「FP32 vs FP16 延迟对比」小表。
4. **软性动作**：得早网投递时附一句「可先做 3 天/周 + 远程」；在 GitHub 给 hand pose 相关 repo 提 1 个 issue/PR；找 VR/XR 社群的人问「这家实习强度」。
