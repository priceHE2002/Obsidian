## 审敛总流程（先算通项极限）

> [!important] 三步走
> **① 先算 $\lim\limits_{n\to\infty}u_n$**：$\ne0$ → 发散；$=0$ → 继续（这一步只能判发散）。
> **② 看通项符号**：均非负 → **正项**；正负相间 → **交错**；正负不定 → **任意项**。
> **③ 正项内部按长相选工具**：$n!\to$ 比值；$n$ 次方 $\to$ 根值；幂 $\to$ 比较；单减 $f(n)\to$ 积分。
>
> 比值/根值算出 $\rho=1$ 就是"没算出来"，必须退回比较判别法或必要条件。

## 判别法速查

| 判别法 | 适用长相 | 判据 | 结论 |
|---|---|---|---|
| 必要条件 | 一切级数（第一步） | $\lim u_n$ | $\ne0$ ⇒ 发散；$=0$ ⇒ 无法判定 |
| 充要条件 | 正项级数 | $\{S_n\}$ 有界 | 有界 ⇔ 收敛 |
| 比较（一般形式） | 正项，可放缩 | $u_n\le v_n$ | **大收则小收，小散则大散** |
| 比较（极限形式） | 正项，可等价替换 | $\lim\frac{u_n}{v_n}=l$ | $0<l<+\infty$ 同敛散；$l=0$ 大收则小收；$l=+\infty$ 小散则大散 |
| 比值 | 含 $n!$、连乘 | $\rho=\lim\frac{u_{n+1}}{u_n}$ | $\rho<1$ 收；$\rho>1$ 发；$\rho=1$ 不定 |
| 根值 | 含 $n$ 次方 | $\rho=\lim\sqrt[n]{u_n}$ | $\rho<1$ 收；$\rho>1$ 发；$\rho=1$ 不定 |
| 积分 | $f(n)$，$f$ 非负、连续、单减 | $\int_1^{+\infty}f(x)\mathrm dx$ | 与级数同敛散 |
| Leibniz | 交错 | $u_n$ 单减 ＋ $u_n\to0$ | 收敛；$\lvert R_n\rvert\le u_{n+1}$ |
| Dirichlet／Abel | 振荡因子 × 单调小量 | 部分和有界 ＋ 单减趋 $0$ | 收敛（见 [[无穷级数大观#3.4.3 Dirichlet／Abel 判别法\|3.4.3]]） |

## 三个对象速查（放缩的落脚点）

| 对象 | 级数 | 收敛 | 发散 |
|---|---|---|---|
| 等比级数 | $\sum q^{n}$ | $\lvert q\rvert<1$ | $\lvert q\rvert\ge1$ |
| $p$ 级数 | $\sum\frac{1}{n^{p}}$ | $p>1$ | $p\le1$（$p=1$ 为调和级数） |
| 广义 $p$ 级数 | $\sum\frac{1}{n^{p}\ln^{q}n}$ | $p>1$；或 $p=1,q>1$ | $p=1,q\le1$；或 $p<1$ |

> [!tip] 顺手要背的四个具体结论
> $\sum\frac{1}{n}$ 发散、$\sum\frac{1}{n^{2}}$ 收敛、$\sum\frac{1}{n\ln n}$ 发散、$\sum\frac{1}{n\ln^{2}n}$ 收敛。

## 抽象级数条件反射速查

| 已知 | 条件反射出什么 | 用途 |
|---|---|---|
| $\sum u_n$ 收敛 | $u_n\to0$ | 只能反过来判发散 |
| $\sum u_n$ 收敛 | $\{u_n\}$ **有界**（最终可放缩为 $1$） | 配合"$u_n\ge0$"或"$\sum\lvert u_n\rvert$ 收敛"才能推 $\sum u_n^{2}$ 收敛；配合"$\sum\lvert u_n\rvert$ 收敛 ＋ $v_n$ 有界"可推 $\sum\lvert u_nv_n\rvert$ 收敛 |
| $\sum u_n$ 发散 | $\sum\lvert u_n\rvert$ **发散** | 2.4 性质 1 的逆否 |
| $a_n$ 单减，$\sum(-1)^{n-1}a_n$ 发散 | $\lim a_n\ne0$ | 由发散倒推通项不趋 $0$ |
| 正项级数收敛 | 奇数项、偶数项子级数均收敛 | 从整体推局部 |
| 要比较大小 | 有正项 → 比较一般形式；无正项 → **加减法构造正项级数** | 4.3.3 |
| 要估计和 | 绝对值相加（三角不等式）＝ 最大上界 | 4.3.4 |

## 反例速查（推翻命题用）

| 想推翻 | 反例 |
|---|---|
| 通项趋 $0$ ⇒ 收敛 | $\sum\frac1n$ |
| 收敛 ⇒ 绝对收敛 | $\sum\frac{(-1)^{n-1}}{n}$ |
| 收敛 ⇒ 平方收敛 | $\sum\frac{(-1)^{n}}{\sqrt n}$（平方后 $\sum\frac1n$） |
| 收敛 ⇒ 逐项相乘仍收敛 | $u_n=v_n=\frac{(-1)^{n}}{\sqrt n}$（乘积为 $\sum\frac1n$） |
| 发散＋发散 ⇒ 发散 | $\sum(-1)^{n}$ 与 $\sum(-1)^{n-1}$ |
| 加括号收敛 ⇒ 原级数收敛 | $1-1+1-1+\cdots$ |
| $\sum(a_{2n-1}+a_{2n})$ 收敛 ⇒ $\sum a_n$ 收敛 | $a_{2n-1}=-1,\ a_{2n}=1$ |
| Leibniz 可省"$u_n$ 单减" | $u_n=\frac1n$（$n$ 奇）、$\frac{1}{n^{2}}$（$n$ 偶） |
| $\sum\lvert u_n\rvert$ 发散 ⇒ $\sum u_n$ 发散 | $\sum\frac{(-1)^{n-1}}{n}$ |

完整版（含每条的验证）见 [[无穷级数大观#4.1 第一板斧：级数反例大观]]。

## 六组必记公式（默写用）

| 名称 | 公式 |
|---|---|
| 三个重要极限 | $\lim\left(1+\frac1n\right)^{n}=e$；$\lim\frac{\sqrt[n]{n!}}{n}=\frac1e$；$\lim\sqrt[n]{a}=1$ |
| 无穷大比阶 | $\ln^{\alpha}n\ll n^{\beta}\ll a^{n}\ll n!\ll n^{n}$ |
| 收敛必要条件 | $\sum u_n$ 收敛 ⇒ $\lim u_n=0$ |
| 绝对收敛 ⇒ 收敛 | $\sum\lvert u_n\rvert$ 收敛 ⇒ $\sum u_n$ 收敛 |
| 交错 $p$ 级数 | $\sum\frac{(-1)^{n-1}}{n^{p}}$：$p>1$ 绝对、$0<p\le1$ 条件、$p\le0$ 发散 |
| Leibniz 余项 | $\lvert R_n\rvert\le u_{n+1}$ |
