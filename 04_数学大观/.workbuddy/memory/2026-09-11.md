# 2026-09-11

## 一元积分大观.md 排版修复
- 文件：`高数大观/一元积分/一元积分大观.md`。发现 **11 处 LaTeX 被 C 风格转义吞掉反斜杠**的损坏：
  `\b`→BS、`\f`→FF、`\v`→VT、`\a`→BEL（表现为 `egin{aligned}` / `rac{}` / `arphi` / `rctan`），
  `\r`→CR（写入时又被转成真换行，于是 `\right)` 断成两行、把 callout 打断），`\\`→`\`（行尾断行符丢一半）。
- 用脚本反向修复：控制字符还原 → 合并被 CR 拆开的 `\right)` → 行尾单 `\` 还原为 `\\` → 把 `\\`+`> &=` 接成 `\\ &=`。
  结果：0 控制字符、19 个 `aligned` 块全部配对、`$$` 53 组闭合。
- 顺带按 math-derivation-style 风格：二倍角链、交换积分次序、根号下加比减例题改为 `aligned` 链条；
  根式代换例题补回原始积分作 LHS；区间再现链补 `\implies`；Wallis 偶数项分子 `…2·1` 修正为 `…3·1`；
  全文 `\frac12` 统一为 `\frac{1}{2}`。
- 全库扫描：其他 md 文件无同类损坏。
- 已存为技能 `latex-backslash-repair`（含诊断+修复脚本），下次遇到同类"公式变乱码"直接调用。
