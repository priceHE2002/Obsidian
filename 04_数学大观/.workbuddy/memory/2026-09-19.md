## 4.3.1 / 4.3.2 改写：把"公式先行"翻成"人话先行"

用户贴出 4.3.1 截图："这里写得太复杂了，请你把我当成一个弱智一样讲解"。

**病根**：这两节是**公式先行**——标题后第一句就是 `$y_p=x^ke^{\lambda x}Q_m(x)$`，
紧接着"$Q_m$ 是与 $P_m$ 同次数的待定多项式""$k$ 等于 $\lambda$ 作为特征根的重数"，
读者得先把符号全翻译一遍才读得下去。**口诀反而是整节里唯一的人话。**

**改写模板（四步，已固化进技能 ⑤′ 第 6 条）**：
1. `[!tip] 先说人话：这一步到底在干什么` —— 通解＝齐次通解＋特解，齐次会算了，剩下的活只有"猜一个特解"；
   并给出**比喻**：待定系数法＝照着右边抄一份 → 系数留空 → 代回去解系数。
2. **第一步 认形状**：`$f(x)=e^{\lambda x}P_m(x)$` 配一张**两列"符号｜人话"表**
   （$P_m$ 是多项式 / $\lambda$ 是指数上那个数、**没有 $e$ 就当 $\lambda=0$** / $m$ 是次数），每项带具体数字例。
3. **第二步 照抄**：`$y_p=x^k e^{\lambda x}Q_m(x)$` 逐项解释，并把"指数照抄""多项式次数相同"
   这两句口诀**逐项挂到公式上**。
4. **第三步 $k$ 取几**：给三行表（不是根 / 单根 / 二重根 → $k=0/1/2$ → 试设形式 → **为什么**）。
5. **第四步**：代回定系数；再给一张「**同一个方程 $y''-3y'+2y=f(x)$，只换右边**」的五行对照表
   （$e^{3x}/e^{2x}/5e^x/xe^{2x}/x^2+1$ → $\lambda$ → 撞不撞根 → $k$ → 试设），一眼看出规则怎么用。
6. 4.3.2 同结构，但先解释**为什么 cos、sin 都要写**（求导让它们互相变身），
   $k$ 的判据从 $\lambda$ 换成 $\alpha+i\beta$ 并说明原因（cos/sin 本就是共轭复根对应的解）；
   对照表用 $y''+4y=f(x)$（根 $r=\pm2i$），第一行**算到底**给出 $y_p=\frac{x}{4}\sin2x$。

**新增"为什么"的解释**（原文只有规则没有理由）：
- 撞车为什么非乘 $x$："不乘的话 $y_p$ 本身就是齐次解，代进左边得 $0$、右边是 $f(x)\neq0$，自相矛盾"；
- 口诀"撞一次车就乘一个 $x$" ——**撞上的重数就是 $x$ 的幂次**。

**验算**：`y''+4y=cos2x` 用 sympy 验，得 $A=0,\ B=\frac14$，$y_p=\frac{x}{4}\sin2x$ ✓ 与笔记一致。
