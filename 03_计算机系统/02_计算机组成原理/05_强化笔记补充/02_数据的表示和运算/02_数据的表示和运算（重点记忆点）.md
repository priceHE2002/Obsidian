# 第二章 数据的表示和运算 · 重点记忆点（详解）

## 0. 全章骨架

```
2.1 数制与编码   进制转换 → BCD/ASCII/汉字 → 原/反/补/移 → C 语言类型转换
```

一句话主线：**整数看「位宽 + 符号性」，浮点看「阶码 + 尾数精度」**。

# 2.1 数制与编码

## 2.1.1 进位计数制与转换　★★

| 转换 | 方法 | 技巧 |
|---|---|---|
| 十 → 二（整数） | 除 2 取余，**倒着读** | 先拆成 2 的幂次之和更快 |
| 十 → 二（小数） | 乘 2 取整，**正着读** | 0.1、0.2、0.3 都是无限循环 |
| 二 ↔ 十六 | **4 位一组**，从右往左补 0 | 1010 1101₂ = ADH |
| 二 ↔ 八 | 3 位一组 | 常用在权限位 |
| 任意 → 十 | 按权展开 | $1011_2 = 8+2+1 = 11$ |

🟡 记几个量级：$2^{10}=1024 \approx 10^3$，$2^{20}\approx 10^6$，$2^{30}\approx 10^9$。

## 2.1.2 字符与十进制编码　★

| 编码 | 规则 |
|---|---|
| **BCD（8421 码）** | 4 位二进制表示 1 位十进制数；`1001` 是 9，`1010`～`1111` 非法 |
| **余 3 码** | 8421 码 + 3（0011），相邻码字只差 1 位 |
| **ASCII** | **7 位**（128 个字符），存 1 字节时最高位补 0 |
| **汉字** | 区位码 + `2020H` = 国标码；国标码 + `8080H` = 机内码 |

🔴 ASCII 三组必记：`'0'=30H`、`'A'=41H`、`'a'=61H`（大小写差 `20H`，数字与字母不连续）。

## 2.1.3 定点数的编码：原码 / 反码 / 补码 / 移码　★★★

设字长 $n$ 位（含 1 位符号位）：

| 码制 | 负数怎么来 | 0 的个数 | 表示范围 |
|---|---|---|---|
| 原码 | 符号位 1 + 绝对值 | **2 个**（+0、−0） | $\pm(2^{n-1}-1)$ |
| 反码 | 原码数值位取反 | **2 个** | $\pm(2^{n-1}-1)$ |
| **补码** | 反码 + 1（或 $2^n - |x|$） | **1 个** | $-2^{n-1} \sim 2^{n-1}-1$ |
| 移码 | **补码符号位取反** | 1 个 | $-2^{n-1} \sim 2^{n-1}-1$ |

🔴 **补码快速转原码**（强化 P1 给的）：符号位为 1 时，**从右往左找第一个 1，它和右边不变，左边全部取反**，符号位保持 1。
特例：`1000…00` 就是 $-2^{n-1}$，**没有同位宽原码**，直接写真值。

🟡 8 位：原码 $-127\sim127$，补码 $-128\sim127$；16 位补码 $-32768\sim32767$。
🟡 移码的意义：把阶码变成无符号数，**直接按无符号比较大小**就是真值大小。

## 2.1.4 C 语言整数类型与类型转换（强化 P1 重点）　★★★

🔴 **一句话规则**：**先按「原有符号性」完成扩展/截断，再按「目标符号性」解释。**

| 情况 | 操作 | 例子（short 16 位，int 32 位） |
|---|---|---|
| 位宽不变，只换符号 | **位串不变**，换解释 | `short -1` → `unsigned short`：`FFFFH` = 65535 |
| 变宽，原数带符号 | **符号扩展**（复制符号位） | `short -122`(`FF86H`) → int `FFFFFF86H` = −122 |
| 变宽，原数无符号 | **零扩展**（高位补 0） | `unsigned short FF86H` → int `0000FF86H` = 65414 |
| 变窄 | **截断**，只留低位 | `unsigned int 65535` → `short`：`FFFFH` = −1 |

> [!warning] 三个高频坑
> ① `unsigned short p = 0xFF86; int q = p;` → 先**零扩展**再按 int 解释 = **65414**，不是 −122。
> ② `short r = -1; unsigned int s = r;` → 先**符号扩展**成 `FFFFFFFFH`，再按无符号解释 = **4294967295**。
> ③ 位宽没变只换符号时，机器数一个 bit 都不动，变的只是解释方式。

🟡 **int ↔ float**（32 位对 32 位，但 float 只有 24 位有效精度）：
- `int → float`：范围够，**可能丢精度**（如 $2^{24}+1$ 变成 $2^{24}$）
- `float → int`：**向 0 截断**（123.75→123，−123.75→−123）；超出范围结果未定义
- `int → double`：精确；`double → float`：可能舍入/上溢/下溢

# 2.2 运算方法与运算电路

## 2.2.1 加法器与 ALU　★★

| 部件 | 逻辑 | 说明 |
|---|---|---|
| 半加器 | $S=A\oplus B$，$C=AB$ | 不考虑低位进位 |
| 全加器 | $S=A\oplus B\oplus C_{in}$，$C_{out}=AB+AC_{in}+BC_{in}$ | 一位完整加法 |
| 串行（行波）加法器 | 进位逐位传 | 延迟 $\approx n \times$ 门延迟，慢 |
| **并行进位（CLA）** | $G_i=A_iB_i$、$P_i=A_i\oplus B_i$，$C_{i+1}=G_i+P_iC_i$ | 进位同时算出，延迟 $O(\log n)$ |
| ALU | 74181 一类 | 用功能选择端 $M$ 切换算术/逻辑运算 |

🟡 判溢出用的两个进位：$C_n$（最高位向外的进位）与 $C_{n-1}$（符号位的进位）。

## 2.2.2 移位运算　★★

| 操作 | 补入 | 等价于 |
|---|---|---|
| 逻辑左移 | 低位补 0 | 无符号乘 2 |
| 逻辑右移 | 高位补 0 | 无符号除 2 向下取整 |
| **算术右移** | **高位补符号位** | 负数向负无穷取整 |

🔴 经典对照：8 位补码 $-5$（`FBH`）算术右移 1 位 = $-3$；而 C 语言 `-5/2` = **−2**（向 0 截断）。**两者不相等**，这是选择题常客。
🟡 x86 的 `SHL/SAL` 把最后移出的位放进 **CF**；移位次数为 1 时 OF 才有定义。

## 2.2.3 加减运算、溢出与标志位　★★★

补码加减：$[A+B]_{补}=[A]_{补}+[B]_{补}$；$[A-B]_{补}=[A]_{补}+[-B]_{补}$（**连同符号位一起加，进位丢掉**）。

🔴 **溢出判断三法**（结果超出补码范围才是溢出）：

| 方法 | 判据 |
|---|---|
| 双符号位（变形补码） | `00`/`11` 正常；`01` 正溢；`10` 负溢 |
| 单符号位进位 | $C_n \oplus C_{n-1}=1$ 即溢出 |
| 符号判断 | 同号相加，结果符号变号 → 溢出 |

🔴 **四个标志位**（强化 P1）：

| 标志 | 含义 | 谁用 |
|---|---|---|
| **CF** | 无符号加法的进位 / 减法的借位 | 无符号比较 |
| **OF** | 带符号（补码）溢出 | 带符号比较 |
| **ZF** | 结果为 0 | 相等判断 |
| **SF** | 结果最高位（符号） | 带符号比较 |

> [!warning] 一句话
> `SF` 只是**截断后结果的最高位**；`OF=1` 时不能拿 `SF` 判断数学真值的正负。

🟡 `CMP A,B` 与 `SUB A,B` 做的是同一件事，区别是 **CMP 不保存结果、只更新标志位**。

**条件转移（x86，记结论不记指令）**：

| 关系 | 判据 |
|---|---|
| 无符号 < | `CF=1` |
| 无符号 ≥ | `CF=0` |
| 无符号 ≤ | `CF=1 或 ZF=1` |
| 无符号 > | `CF=0 且 ZF=0` |
| 带符号 < | `SF≠OF` |
| 带符号 ≥ | `SF=OF` |
| 带符号 ≤ | `ZF=1 或 SF≠OF` |
| 带符号 > | `ZF=0 且 SF=OF` |

> [!tip] 例
> `int x=-1, y=1;` 机器数 `FFFFFFFFH` 与 `00000001H`。
> 做 `x-y`：结果为 `FFFFFFFEH`，CF=1（借位）、OF=0、ZF=0、SF=1。
> 按**带符号**看 $-1<1$（`SF≠OF` 成立）；按**无符号**看 $4294967295>1$（`CF=1` 只说明「小于」不成立）。同一条机器指令，两套解释。

## 2.2.4 整数乘法　★★

**三种实现**（强化 P1）：纯软件（循环移位加）、加法器 + 移位（多周期）、阵列乘法器（并行，快但贵）。

**无符号乘法**：32 位 ALU + 64 位乘积寄存器 P + 乘数寄存器 Y；每轮看 **Y 最低位**，为 1 就加被乘数，然后 **P、Y 一起逻辑右移**。

**带符号乘法（Booth 一位乘）**：增设附加位 $y_{n+1}=0$，看 $y_n y_{n+1}$：

| $y_n y_{n+1}$ | 操作 |
|---|---|
| 00 或 11 | 加 0 |
| **01** | 加 $[x]_{补}$ |
| **10** | 加 $[-x]_{补}$ |

每轮之后**算术右移**。

🔴 **乘积与溢出**：两个 $n$ 位数的完整乘积要 $2n$ 位。
- 无符号：只留低 $n$ 位时，**高 $n$ 位全 0** 才不溢出
- 带符号：**高 $n$ 位是低 $n$ 位符号位的完整扩展**才不溢出

## 2.2.5 整数除法　★

- **无符号**：就是小学除法，商向下取整、余数非负。
- **带符号**：约定 **商向 0 截断、余数与被除数同号**。
- 电路：$2n$ 位「余数 R : 商 Q」+ $n$ 位除数 Y，每轮左移、试减。

🔴 **两个异常**：除数为 0；**绝对值最大的负数 ÷ (−1)** 商超出正数补码范围。

🟡 **被除数扩展成双字长 $R{:}Q$**（2025 真题考点）：
- 无符号：**零扩展**，Q = 被除数，R 全 0
- 带符号：**符号扩展**，R 与被除数符号位一致（非负全 0、负数全 1）

## 2.2.6 数据的存储与排列　★★

| 概念 | 规则 | 例子 |
|---|---|---|
| **大端** | 高字节放低地址（网络字节序） | `0x12345678` → `12 34 56 78` |
| **小端** | 低字节放低地址（x86） | `0x12345678` → `78 56 34 12` |
| **边界对齐** | 按 2/4/8 字节对齐存放 | 结构体里可能插入填充字节 |

🟡 对齐的代价是空间，收益是「一次访存就能取到一个数据」，不用跨存储字。

# 2.3 浮点数的表示与运算

## 2.3.1 IEEE 754 表示　★★★

| 格式 | 符号 S | 阶码 E | 尾数 F | 偏置值 | 有效精度 |
|---|---|---|---|---|---|
| float（32 位） | 1 | 8 | 23 | **127** | 24 位（隐含 1） |
| double（64 位） | 1 | 11 | 52 | **1023** | 53 位 |

🔴 **规格化真值**：
$$(-1)^S \times 1.F \times 2^{E-127}$$
**非规格化**（E 全 0）：
$$(-1)^S \times 0.F \times 2^{-126}$$

**编码（真值 → 机器数）**：定符号 → 绝对值转二进制 → 写成 $1.F\times2^e$ → $E=e+127$ → 去掉隐藏的 1 得 F → 拼接。

**解码（机器数 → 真值）**：拆 S/E/F → 先判类别（规格化 / 非规格化 / 特殊值）→ 恢复 `1.F` 或 `0.F` → 真实指数 → 算真值。

> [!tip] 例：−13.25
> $13.25 = 1101.01_2$，规格化 $1.10101\times2^3$ → $E=3+127=130=10000010_2$，F 去掉隐含 1 得 `101010…0`。
> 结果 `1 10000010 10101000000000000000000` = `C1540000H`。

## 2.3.2 特殊值与范围　★★★

| 类型 | E | F | 值 |
|---|---|---|---|
| ±0 | 全 0 | 全 0 | +0 / −0 |
| 非规格化数 | 全 0 | ≠0 | $\pm 0.F\times2^{-126}$ |
| ±∞ | 全 1 | 全 0 | $+\infty$ / $-\infty$ |
| NaN | 全 1 | ≠0 | 无定义（非数） |

🔴 **三个边界值（float）**：

| 边界 | 值 | 机器数 |
|---|---|---|
| 最小正非规格化数 | $2^{-149}$ | `00000001H` |
| 最小正规格化数 | $2^{-126}$ | `00800000H` |
| 最大有限正数 | $(2-2^{-23})\times2^{127}\approx3.4\times10^{38}$ | `7F7FFFFFH` |

🟡 绝对值最小的负数：`80000001H` = $-2^{-149}$。
🟡 阶码全 0 / 全 1 是**特殊用途**，不能按规格化公式硬算。

## 2.3.3 能不能精确表示（强化 P1 高频）　★★★

🔴 **判断法**：把十进制真值写成**最简分数**，看分母。
- 分母只含因子 2（$2^k$）→ 二进制小数**有限**，可能精确表示
- 分母含 3、5、7 等因子 → 二进制**无限循环**，一定不能精确表示

| 数值 | 最简分数 | 结论 |
|---|---|---|
| 0.125 | $1/8=2^{-3}$ | 有限，可精确 |
| 0.75 | $3/4$ | 有限，可精确 |
| **0.2** | $1/5$ | 无限循环，**不能精确** |
| 0.3 | $3/10$ | 无限循环 |

🔴 **还有第二关：精度够不够**。float 只有 24 位有效数字：
- $2^{24}+1$ → **不能**精确（需要 25 位）
- $2^{24}+2$ → **能**精确
- $2^{128}$ → 范围上溢，不是有限 float
- $2^{-150}$ → 舍入成 0

> [!tip] 两个「能」要分清
> 「能装下（在范围内）」≠「能精确表示」。0.2 能装下，但存的是近似值；$2^{24}+2$ 既装得下也精确。

## 2.3.4 浮点数加减　★★★

🔴 **五步（强化 P1 的完整版是七步）**：

```
检查特殊值 → 对阶 → 尾数加减 → 规格化 → 舍入 → 再次规格化 → 检查阶码
```

| 步骤 | 做什么 | 风险 |
|---|---|---|
| **对阶** | **小阶向大阶看齐**，小阶尾数右移 | 低位丢失，**大数吞小数**（$2^{100}+1=2^{100}$） |
| 尾数加减 | 按定点加减做 | 相加可能进位；相减可能大量抵消 |
| **右规** | 尾数溢出时右移 1 位、阶码 +1 | 阶码可能**上溢**（`FLT_MAX+FLT_MAX` → $+\infty$） |
| **左规** | 尾数最高位不是 1 时左移、阶码 −1 | 可能进入**非规格化**区 |
| **舍入** | 0 舍 1 入 / 恒置 1 / 就近舍入（中点取偶） | 舍入进位可能**再次右规** |
| 查阶码 | 判上溢/下溢 | 上溢给 ∞，下溢给 0 或非规格化数 |

🟡 **就近舍入的实现**：对阶右移时保留 **G（保护位）、R（舍入位）、S（粘位）**，进位条件为 $G\land(R\lor S\lor L)$（L 为保留部分最低位）。

> [!warning] 五个判断（强化课原题）
> ① 对阶**本身不会**直接导致阶码上溢（阶码没变）。
> ② 右规**可能**导致阶码上溢。
> ③ 左规**可能**导致阶码下溢。
> ④ 尾数相加进位**不等于**浮点结果上溢，还要看右规后阶码是否越界。
> ⑤ 舍入进位**可能**间接造成阶码再 +1。

## 2.3.5 浮点乘除　★

- **乘法**：阶码相加再减偏置（$E_1+E_2-127$），尾数相乘，规格化 + 舍入
- **除法**：阶码相减再加偏置（$E_1-E_2+127$），尾数相除，规格化 + 舍入
- 阶码溢出判断同加减；尾数用原码乘除更直观

# 附 B · 30 条速记

1. $n$ 位补码范围 $-2^{n-1}\sim2^{n-1}-1$，原码 $\pm(2^{n-1}-1)$。
2. 补码转原码：右起第一个 1，它和右边不变，左边全反。
3. `1000…0` 是最小负数，没有同位宽原码。
4. 移码 = 补码符号位取反，用来直接比较阶码大小。
5. 类型转换：先按原符号性扩展/截断，再按目标符号性解释。
6. 变宽：带符号符号扩展，无符号零扩展；变窄：截断。
7. `int→float` 可能丢精度，`float→int` 向 0 截断。
8. CF 管无符号进位/借位，OF 管带符号溢出。
9. `CMP` 与 `SUB` 只差「存不保存结果」。
10. 无符号比较看 CF/ZF，带符号比较看 SF/OF/ZF。
11. 溢出：双符号 01 正溢、10 负溢；或 $C_n\oplus C_{n-1}=1$。
12. 算术右移补符号位，-5>>1 = -3 ≠ -5/2 = -2。
13. x86 移位把最后移出位放 CF。
14. 全加器 $S=A\oplus B\oplus C_{in}$，$C_{out}=AB+AC_{in}+BC_{in}$。
15. 并行进位 $C_{i+1}=G_i+P_iC_i$，$G_i=A_iB_i$，$P_i=A_i\oplus B_i$。
16. 乘积 2n 位；无符号高 n 位全 0 才不溢出。
17. 带符号乘法高 n 位必须是低 n 位的符号扩展。
18. Booth：01 加 x，10 减 x，00/11 加 0，之后算术右移。
19. 无符号除法商向下取整、余数非负。
20. 带符号除法商向 0 截断、余数与被除数同号。
21. 除法异常：除 0；最小负数 ÷ −1。
22. 双字长被除数初值：无符号零扩展，带符号符号扩展。
23. 大端高字节在低地址，小端低字节在低地址。
24. float：1+8+23，偏置 127；double：1+11+52，偏置 1023。
25. 规格化真值 $(-1)^S\times1.F\times2^{E-127}$。
26. 非规格化真值 $(-1)^S\times0.F\times2^{-126}$。
27. 边界：$2^{-149}$、$2^{-126}$、$(2-2^{-23})2^{127}$。
28. 能否精确表示：分母只含因子 2，且有效位 ≤ 24。
29. 浮点加减：小阶向大阶对齐，对阶会大数吞小数。
30. 阶码上溢给 ∞，下溢给 0 或非规格化数。

# 附 D · 五个计算模板

**① 补码 ↔ 真值**
负数的补码：右起第一个 1，左边全反得原码，再读绝对值；或直接算 $2^n-|x|$。

**② 类型转换**
先定「原符号性」→ 扩展（符号/零）或截断 → 再按目标类型解释。永远按这个顺序，不要跳步。

**③ IEEE 754 编码**
符号 → 绝对值二进制 → $1.F\times2^e$ → $E=e+127$ → 填 F（去掉隐含 1）。
解码反过来，先判 E 是否全 0/全 1。

**④ 浮点加减**
查特殊值 → 对阶（小向大）→ 尾数加减 → 规格化（左规/右规）→ 舍入 → 再规格化 → 查阶码溢出。

**⑤ 乘法溢出**
算出 $2n$ 位完整乘积：无符号看高 $n$ 位是否全 0；带符号看高 $n$ 位是否等于低 $n$ 位的符号扩展。
